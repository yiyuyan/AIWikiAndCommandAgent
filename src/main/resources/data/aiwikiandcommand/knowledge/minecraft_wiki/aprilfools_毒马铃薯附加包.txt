'''毒马铃薯附加包（Poisonous Potato Add-On）'''是由[https://www.jigarbov.net/ Jigarbov Productions]开发的官方[[附加包]]，发布于2024年4月1日，作为2024年[[愚人节玩笑]]的一部分。<ref> [https://www.minecraft.net/en-us/marketplace/pdp?id=790be090-9bce-4870-85e7-cd868402c3e5 Poisonous Potato Add-On in Minecraft Marketplace <nowiki>&#124;</nowiki> Minecraft]</ref>此附加包是免费的。

== 内容 ==
=== 物品 ===
; [[File:Poisonous Potato Bundle.png|32px|class=pixel-image]] 毒马铃薯收纳袋（Poisonous Potato Bundle）

; [[File:Baked Poisonous Potato.png|32px]] 烤毒马铃薯（Baked Poisonous Potato）
* 通过在[[熔炉]]烹饪[[毒马铃薯]]获得。
* 无法通过[[烟熏炉]]和[[营火]]烹饪。
* 可以回复{{fp|5|6}}并给予玩家3-4种5级的正面状态效果，这些状态效果会持续30秒。

; [[File:Explosive Poisonous Potato.png|32px]] 爆炸毒马铃薯（Explosive Poisonous Potato）
* {{ctrl|使用}}时会被抛出并产生巨大的爆炸。
* 由1个[[毒马铃薯]]、4个[[火药]]和4个[[红石粉]]合成。

; [[File:Poisonous Potato Nubs.png|32px]] 毒马铃薯块（Poisonous Potato Nubs）
* 由[[毒马铃薯]]合成。
* 与[[药水]]类似，投掷后会造成[[中毒]]状态效果。

; [[File:Explosive Poisonous Potato Nubs.png|32px]] 爆炸马铃薯块（Explosive Poisonous Potato Nubs）
* 由7个毒马铃薯小块、1个[[火药]]和1个[[红石粉]]合成。
* 投掷后会造成小型爆炸。

; [[File:Sprouted Poisonous Potato Nubs.png|32px|class=pixel-image]] 发芽毒马铃薯块（Sprouted Poisonous Potato Nubs）

; [[File:Sprouted Explosive Poisonous Potato Nubs.png|32px|class=pixel-image]] 发芽爆炸毒马铃薯块（Sprouted Explosive Poisonous Potato Nubs）

; 毒马铃薯盔甲
* [[File:Poisonous Potato Helmet.png|32px]] 毒马铃薯头盔（Poisonous Potato Helmet）
* [[File:Poisonous Potato Chestplate (add-on).png|32px]] 毒马铃薯胸甲（Poisonous Potato Chestplate）
* [[File:Poisonous Potato Leggings.png|32px]] 毒马铃薯护腿（Poisonous Potato Leggings）
* [[File:Poisonous Potato Boots.png|32px]] 毒马铃薯靴子（Poisonous Potato Boots）
* 头盔、鞋子提供{{armor|6}}护甲值；护腿提供{{Armor|12}}护甲值；胸甲提供{{Armor|16}}护甲值
* 穿在身上时，材质为一个毒马铃薯，并在玩家周围产生一个毒圈，在毒圈附近的生物会产生[[中毒]]效果。
* 与原版合成摆放方式相同，材料为[[毒马铃薯]]。

; [[File:Poisonous Potato Guide.png|32px]] 毒马铃薯指南（Poisonous Potato Guide）
* 指导玩家如何制作烤毒马铃薯和制作毒马铃薯方块、毒马铃薯剑、毒马铃薯盔甲和毒马铃薯矿车。
* 包含附加包的制作人员名单。

; {{Animate|Poisonous Potato Powered Wooden Sword.png; Poisonous Potato Powered Stone Sword.png; Poisonous Potato Powered Iron Sword.png; Poisonous Potato Powered Golden Sword.png; Poisonous Potato Powered Diamond Sword.png; Poisonous Potato Powered Netherite Sword.png|32px}} 毒马铃薯剑
* 毒马铃薯剑攻击力为对应的普通的剑的攻击力×2+2。
* 被毒马铃薯剑攻击的生物会产生[[中毒]]效果。
* 由1把[[剑]]和1个[[毒马铃薯]]合成。

; [[File:Poisonous Potato Stew.png|32px]] 毒马铃薯炖菜（Poisonous Potato Stew）

; [[File:Wrench.png|32px]] 扳手（Wrench）
* Jigarbov Productions制作的所有附加包中都包含的物品。

; 刷怪蛋
* [[File:Mutato Item.png|32px]] Mutato刷怪蛋
* [[File:Mashacre Item.png|32px|class=pixel-image]] Mashacre刷怪蛋
*  [[File:Tubber Trekkers Item.png|32px|class=pixel-image]] 块茎行者刷怪蛋

=== 实体 ===
; [[File:Poisonous Potato Couch.png|32px]][[File:Poisonous Potato Couch (entity).png|32px]] 毒马铃薯沙发（Poisonous Potato Coach）

; [[File:Poisonous Potato Balloon.png|32px]][[File:Poisonous Potato Balloon (entity).gif|32px]] 毒马铃薯气球（Poisonous Potato Balloon）
* 可以骑乘。

; [[File:Poisonous Potato Chair.png|32px]][[File:Poisonous Potato Chair (entity).png|32px]] 毒马铃薯椅子（Poisonous Potato Chair）

* 不需要铁轨也可以移动。

==== 生物 ====
; [[File:Mutato.png|32px]] Mutato 
* 一种被动生物, 在破坏马铃薯植株时有2%的概率生成。
* 拥有{{hp|60}}生命值和{{hp|7}}的攻击力。
* 在攻击时会给予目标15秒的[[中毒]]效果。
* 可通过马铃薯或毒马铃薯驯服。

; [[File:Tubber Trekkers.png|32px]] 块茎行者（Tuber Trekkers）
* 可以被骑乘。
* 死亡时掉落其刷怪蛋。

; [[File:Mashacre.png|32px]] Mashacre
* Mutato的敌对变种。
* 拥有{{hp|100}}生命值和{{hp|20}}的攻击力。
