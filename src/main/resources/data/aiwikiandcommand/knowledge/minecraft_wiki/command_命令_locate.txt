在聊天框中为命令执行者显示给定的[[结构]]、[[生物群系]]或{{only|JE|for=[[兴趣点]]}}的最近坐标和[[距离]]。{{fn|由于{{bug|MC-138887}}，有时该命令显示的结果并非是距离最近的。}}{{in|je}}点击返回的坐标后，会自动在聊天框输入{{cmd|tp @s ''坐标''}}。若指令是在[[Java版函數|函數]]中執行，則不會顯示訊息。<ref>{{bug|MC-298295|||WAI}}</ref>

== 语法 ==
* '''Java版'''
:<code>locate biome <biome></code>
:<code>locate poi <poi></code>
:<code>locate structure <structure></code>

* '''基岩版'''
:<code>locate biome <biome: Biome></code>
:<code>locate structure <structure: Structure> [useNewChunksOnly: Boolean]</code>

== 参数 ==
{{el|je|short=1}}：{{argument|biome|resource_or_tag}}<br>
{{el|be|short=1}}：{{argument|be=1|biome: Biome|enum}}
: 指定要定位的生物群系的命名空间ID或{{only|for=生物群系标签|JE}}。参见[[生物群系/ID]]及{{slink|Java版标签/生物群系}}以查看所有可用的生物群系ID和生物群系标签。

{{el|je|short=1}}：{{argument|poi|resource_or_tag}}
: 指定要定位的兴趣点的命名空间ID或兴趣点标签。参见{{slink|兴趣点|兴趣点类型}}及{{slink|Java版标签/兴趣点类型}}以查看所有可用的兴趣点ID和兴趣点标签。

{{el|je|short=1}}：{{argument|structure|resource_or_tag_key}}（区分大小写）<br>
{{el|be|short=1}}：{{argument|be=1|structure: Structure|enum}}
: 指定要定位的结构的命名空间ID或{{only|for=结构标签|JE}}。参见{{slink|生成结构|可被定位的结构}}及{{slink|Java版标签/结构}}以查看所有可用的结构ID和结构标签。

{{el|be|short=1}}：{{argument|be=1|useNewChunksOnly: Boolean|enum}}
: 仅定位在尚未生成的区块中的结构，默认为<code>false</code>。
: {{arg desc|be=bool}}

== 示例 ==
* 获得最近的[[林地府邸]]的坐标：{{cmd|link=none|locate structure mansion}}
* 获得最近的[[沙漠]]生物群系的坐标：{{cmd|link=none|locate biome desert}}
* 获得最近的[[讲台]]的坐标：{{cmd|link=none|locate poi librarian}}{{only|java}}
