修改相机预设的控制方案。

此命令需与{{cmd|camera}}命令一同使用。

== 语法 ==
: <code>controlscheme <players: target> clear</code>
:: 清除控制方案。
: <code>controlscheme <players: target> set <control scheme: controlscheme></code>
:: 设定控制方案。

== 参数 ==
{{argument|be=1|players: target|CommandSelector<Player>}}
: 指定要被修改控制方案的[[玩家]]。
: {{arg desc|be=CommandSelector<Player>}}

{{argument|be=1|control scheme: controlscheme|Enum}}
: 指定控制方案。
: {{arg desc|be=enum}}必须为以下其中之一：
:* {{cd|camera_relative}} — 相对相机进行移动，视角保持水平并跟随移动方向
:* {{cd|camera_relative_strafe}} — 相对相机进行移动，视角保持水平并跟随朝向
:* {{cd|locked_player_relative_strafe}} — 相对玩家进行移动，视角跟随朝向
:* {{cd|player_relative}} — 相对玩家进行移动，视角保持水平并跟随移动方向
:* {{cd|player_relative_strafe}} — 相对玩家进行移动，视角保持水平并跟随朝向
