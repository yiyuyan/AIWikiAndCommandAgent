本页面列出了{{el|ee}}与未开启“Education Edition”选项的{{el|be}}世界相比的独有特性。部分特性在{{el|be}}中开启该选项的世界中也可用。

== 常规 ==
* 教程世界
** 引导玩家进行游戏中的导航、制作、放置或打破方块。
** 包含化学世界。与[[原主机版]]中的教学世界不同。
* 课程
** 可在[https://education.minecraft.net 官网]下载。
* 3D输出
** 允许玩家在现实世界中使用他们的作品并通过Remix 3D分享它们。
* [[课堂模式]]
** Minecraft的一个子应用，显示了世界的高层地图视图、所有玩家列表、教师传送学生的能力和交流窗口。
** 它提供给可能想观察学生活动而不参与游戏的教育工作者，并且学生不需要游玩。
* [[代码连接]]
** 这是一个允许教育工作者和学生探索，创造和体验身临其境的Minecraft世界的扩展——一切通过编写代码。
* 简单课堂协作
** 一个多达40名学生的教室，可以在一个世界上玩，并且不需要单独的服务器设置。
** 学生只需加入同学的世界，就可以成对或团队一起工作。
* 简单且安全的登录
** 学生个人和教师登录Office 365教育账号来在玩教育版时确保数据的隐私和安全。

== 方块 ==
* [[边界]]<ref group="注" name=be>{{in|be}}开启了“Education Edition”的世界中也存在此方块或物品。</ref>
** 阻止所有实体经过其在所在Y轴，但玩家可以使用[[末影珍珠]]来通过它们。
* [[允许方块]]<ref group="注" name=be/>
** 玩家可以挖掘或破坏其上方的方块，即使在其他地方不可以。
* [[拒绝方块]]<ref group="注" name=be/>
** 玩家不可以挖掘或破坏其上方的方块，即使在其他地方可以。
* [[黑板]]
** 一种功能类似[[告示牌]]，但能展示更多文本的方块。
** 有不同的尺寸——小黑板（1×1）、告示板（2×1）和大黑板（2×3）。可以被编辑。
** 和[[告示牌]]不同，黑板只有一个面可供书写。
* [[元素构造器]]<ref group="注" name=be/>
** 在其中通过调整质子、电子和中子的数量来构造[[元素]]。
* [[化合物创建器]]<ref group="注" name=be/>
** 在其中通过元素组合来创建[[化合物]]。
* [[实验台]]<ref group="注" name=be/>
** 在其中的网格内组合[[元素]]和[[化合物]]创造物品。
* [[材料分解器]]<ref group="注" name=be/>
** 将[[方块]]分解成它们的构成[[元素]]。
* [[加热块]]<ref group="注" name=be/>
** 融化附近的[[雪]]、[[冰]]和[[浮冰]]，但不发光。
* [[水下TNT]]<ref group="注" name=be/>
** 在水下爆炸时也可以破坏方块。
* [[水下火把]]<ref group="注" name=be/>
** 可以放置在水下的火把。
* [[彩色火把]]<ref group="注" name=be/>
** 彩色的火把，但若未开启{{pa|Vibrant Visuals|}}并启用点光源，则不会发出彩色的光。
* [[强化玻璃]]<ref group="注" name=be/>
** 拥有比普通玻璃更高的[[爆炸抗性]]和[[硬度]]。
* [[强化玻璃板]]<ref group="注" name=be/>
** 强化玻璃的玻璃板变种。
* [[元素]]<ref group="注" name=be/>
** 用于制作化合物。

== 物品 ==
* [[相片簿]]
** 让学生记录他们的项目的进展，并存储摄像机拍的照片。
* [[照片]]
** 一种记录摄像机拍摄内容的物品。
* [[NPC刷怪蛋]]<ref group="注" name=be/>
** 用于生成[[NPC]]。
* [[智能体刷怪蛋]]<ref group="注">在[[基岩版]]中可以使用[[命令]]获得此物品，但除非使用WebSocket连接到[[代码连接]]（可以使用如[https://github.com/lrocher/CodeConnectFix CodeConnectFix]的外部工具），否则没有作用。</ref>
** 用于生成[[智能体]]。
* [[漂白剂]]<ref group="注" name=be/>
** [[白色染料]]的替代品。
* [[冰弹]]<ref group="注" name=be/>
** 可以使[[水]][[结冰]]的[[弹射物]]，类似于[[冰霜行者]]魔咒。
* [[超级肥料]]<ref group="注" name=be/>
** [[骨粉]]的升级版，可以使[[农作物]]立即成熟。
* [[药物]]<ref group="注" name=be/>
** 一类可用于去除特定效果的饮品。
* [[烟花棒]]<ref group="注" name=be/>
** 在点亮时发出[[粒子效果]]的物品，可以被放置在[[副手]]。
* [[荧光棒]]<ref group="注" name=be/>
** 可以在玩家手中点亮一段时间的物品。不会照亮周围。
* [[化合物]]<ref group="注" name=be/>
** 使用元素制作出的物品。

== 非生物实体 ==
* [[气球]]<ref group="注" name=be/>
** 被气球绑着的实体会向上飘浮。可以被绑在[[栅栏]]上。

== 生物 ==
* [[摄像机]]
** 可以捕获并存储图像。
* [[NPC]]<ref group="注">{{in|be}}开启了“Education Edition”的世界中也存在此生物，或使用命令生成。</ref>
** 在游戏中引导玩家，给予指示并提供更多信息。
* [[智能体]]
** 通过让玩家进行编程来控制，帮助玩家学习编程。
