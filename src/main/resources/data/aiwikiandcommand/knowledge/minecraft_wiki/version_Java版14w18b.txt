'''14w18b'''是[[Java版1.8]]的第21个快照，发布于2014年5月2日<ref>{{cite|url=http://mojang.com/2014/04/minecraft-snapshot-14w18a/|archive-url=1|archive=1|title=Minecraft snapshot 14w18b|author=Dinnerbone|website=Mojang.com|date=Apr 30, 2014}}</ref>，用于修复一些[[14w18a]]中的漏洞与崩溃问题。

== 更改 ==
=== 生物 === 
'''[[末影人]]和[[末影螨]]'''
* 不再互相攻击。

== 修复 ==

|;old
|2346|铁砧的碰撞箱不成比例。
|4222|当有夜视效果时，被玩家攻击的生物不变红。
|6095|漏斗模型中有很小的空隙。

|48899|TNT在水中被激活会造成伤害。

|51168|面朝下的投掷器和发射器只能将物品向西发射。

|54008|当加载含有物品展示框的世界或者放置物品展示框时，游戏崩溃。
