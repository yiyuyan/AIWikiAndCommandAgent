在聊天框中为命令执行者显示指定[[生物群系]]的最近坐标和距离。

== 语法 ==
* '''Java版'''
:<code>-{}-locatebiome <''生物群系ID''></code>

== 参数 ==
<code>-{}-''生物群系ID''</code>

: 指定要定位的生物群系或生物群系标签。参见[[生物群系/ID]]以查看所有可用的生物群系ID。

{{Result table|参数未正确指定|unparseable|fail}}
{{Result table|当前[[维度]]中不生成所请求的生物群系（或属于标签定义的任意一个生物群系）|fail}}
{{Result table|无法在12801×12801方块的正方形区域中找到请求的生物群系（或属于标签定义的任意一个生物群系）||N/A}}

{{Result table}}

== 示例 ==
* 定位[[沙漠]]生物群系的坐标：{{cmd|link=none|locatebiome desert}}。
