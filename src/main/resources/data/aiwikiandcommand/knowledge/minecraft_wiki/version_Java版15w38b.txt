'''15w38b'''是[[Java版1.9]]的第25个快照，发布于2015年9月17日<ref name="blogpost_15w38b">{{cite|url=http://mojang.com/2015/09/minecraft-snapshot-15w38a/|archive-url=1|archive=1|archive-time=20151015185859|title=Minecraft 1.9 snapshot 15w38b|author=Dinnerbone|website=Mojang.com|date=Sep 16, 2015}}</ref>，加入了1条新的闪烁标语，并修复了[[15w38a]]中的漏洞与崩溃。

== 新内容 ==
=== 常规 ===
'''[[闪烁标语]]'''
* “doot doot”

== 更改 ==
=== 生物 ===
'''[[骷髅马]]和[[僵尸马]]'''
* 现在属于[[亡灵生物]]。
