将玩家转送至另一服务器。

== 语法 ==
: <code>-{}-transferserver <''服务器：字符串''> <''端口：整数''></code>

== 参数 ==
<code>-{}-''服务器：字符串''</code>
: 指定转送目标服务器的地址。IPv6形式的IP地址必须使用双引号括住，例如<code>"2001:DB8:2de::e13"</code>。
<code>-{}-''端口：整数''</code>
: 指定目标服务器的端口号。
