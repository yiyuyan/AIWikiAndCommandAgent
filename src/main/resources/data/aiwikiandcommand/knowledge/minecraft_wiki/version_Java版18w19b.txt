'''18w19b'''是[[Java版1.13]]的第34个快照，发布于2018年5月9日<ref>{{snap|18w19b|May 9, 2018}}</ref>，加入了新的声音事件，以及重新加入了对[[18w16a]]前世界的支持，并修复了一些漏洞。

== 更改 ==
=== 常规 ===
'''声音事件'''
* 加入了<code>entity.husk.converted_to_zombie</code>。
'''其他'''
* 现可重新进入18w16a前的世界，然而那些在18w16a中创建的世界仍然损坏。<ref>{{tweet|ProfMobius|994186578611273728}}</ref>
