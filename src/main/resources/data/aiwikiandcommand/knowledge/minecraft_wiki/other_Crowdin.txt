'''{{w|Crowdin}}'''是一个本地化管理平台，目标是通过翻译来让网站、{{tr|应用|應用程式}}、游戏和其他软件在全球普及。[[Mojang Studios]]从2011年12月9日开始在Crowdin上托管[[Java版]]和[[Minecraft启动器|启动器]]的多语言翻译。

[[基岩版]]、[[教育版]]、[[Minecraft Dungeons]]和[[Minecraft Legends]]等项目的翻译由[[微软]]聘请其他翻译团队完成，而非在Crowdin上完成。

== 翻译 ==
Minecraft在Crowdin上有两个子项目：
* Minecraft（Java版）：https://zh.crowdin.com/project/minecraft
* Minecraft启动器：https://zh.crowdin.com/project/minecraft-launcher

注册Crowdin账号并加入项目后，用户就可以向项目列出的任意语言提交翻译。

== 用户组 ==
=== 翻译员 ===
初次加入项目的用户会成为一名'''翻译员（Translator）'''。欲参与项目，在进入项目主页后需要：
# 选择翻译的目标语言。每种语言下的百分数反映翻译工作的完成度。
# 选择待翻译的子文件夹。首个子文件夹包括其所代表的版本及这个版本前所有版本的游戏内容，其之后的正式版内容各拥有一个单独的子文件夹。点击右侧的“Translate All”按钮即可全选。
# 进入搜索界面。可在左侧的搜索栏搜索词条，而点击漏斗按钮可以打开过滤器，设置过滤条件进一步筛选词条。点击左上角可进入快捷栏来切换项目、文件夹和语言。右侧的评论栏除一般讨论外还可以提交报告（Issue）指出翻译遇到的问题。
# 进入单个词条提交翻译。翻译员也可以通过“+”和“-”按钮来对一条翻译进行支持或反对，按钮后的数字表示该翻译的目前票数。已批准的翻译无论票数多少都会置顶。对于已批准的翻译可以建议新翻译，此时一般需点击弹出的“通知审核员（NOTIFY PROOFREADER）”按钮从而在评论中给当前语言的审核员提交报告。

=== 审核员 ===
翻译员可以被项目管理员提拔为'''审核员（Proofreader）'''。审核员可以批准（Approve）翻译、查看隐藏词条，但不能进行投票。一个语言只能有少数几个审核员来维持翻译工作的秩序。

经由审核员批准的翻译会無法由翻譯員變更，以此最终決定翻译內容，同时审核员也要严格遵守Mojang给出的指引和听取社区大多数玩家的意见，以及经常查看和处理翻译员提交的问题和滥用报告，同时在Discord服务器内保持沟通。

Mojang的官方负责人会直接和审核员进行交流，以促使审核员履行好职务和向一众翻译员传达来自官方对翻译的意见和指引。相应地，审核员可以获取Mojang提供的外部工具来方便审核员对翻译进行审核工作，例如提供一个Tampermonkey插件以允许审核员查看投票情况，并以此甄别是否有用户在进行恶意操作。

要成为审核员，必须年满18岁，是一名长期参与翻译的翻译员，且是能够对目标语言达到精通级别的翻译员。Mojang一般不会立即接受来自普通翻译员的提拔请求，而是在目标语言缺乏长期监管或经由已有审核员的推荐下才会予以考虑。

== 语言 ==
{{Main|语言}}

截至2025年5月，Minecraft在Crowdin上共提供175个语言的翻译项目。某个语言的翻译项目在完成度较高时才会被正式应用。

如果[[Java版]]和[[Minecraft启动器|启动器]]中的翻译有错误，应该直接在Crowdin的评论（Comments）讨论（Discussions）中提出，而非在[[漏洞追踪器]]报告。

== 新版本 ==
在Minecraft的新版本开发中，Mojang经常向语言文件添加新的内容。一般而言，如果新版本中有新的字符串，Mojang会在新版本发布的同时（或稍晚一些）在Crowdin上开放新内容的翻译。

对[[Java版]]而言，从[[Java版11w49a|11w49a]]到[[Java版1.5.2|1.5.2]]，语言文件由Mojang手动获取Crowdin上的翻译更新，并打包在[[客户端核心文件]]中。自[[13w16a]]开始，Mojang将语言文件作为[[资源索引文件]]的一部分更新。自[[Java版22w42a|22w42a]]开始，资源索引文件不再与版本挂钩，因而此后的所有版本都可以接收当前的语言文件更新；与之相对，[[Java版1.19.2|1.19.2]]及之前的版本不再接收更新，除非Mojang特意修改之前的资源索引文件。

目前，Mojang在每天03:00（UTC）左右自动构建Crowdin上的所有语言项目（参见[https://zh.crowdin.com/project/minecraft/activity-stream Crowdin上的活动流]）。在某条字符串没有翻译被审核员批准的情况下，系统会自动取票数最高的翻译代替。如果平票，则会按时间取最后提交的翻译。當字串被批准後，該翻譯才是最終「穩定」的版本。

如果某条字符串在Crowdin上的某个语言项目中没有翻译，在构建新版本语言文件时，这条字符串不会出现在该语言的语言文件中。自[[13w16a]]开始，源语言（美式英语）的语言文件仍然保留在[[客户端核心文件]]中，以保证没有翻译的字符串回退为显示原文。

Crowdin上语言文件的自动构建与Java版游戏内的语言文件更新没有必然联系。一般而言，Mojang只在新版本发布时更新资源索引，此时语言文件也会应用当天Crowdin上自动构建的版本。但是，Mojang偶尔也会在其他时间毫无征兆地更新资源索引。即使是为了更新其他散列资源文件（如音效等），语言文件也会随之应用最新的构建版本。

部分字符串可能在Crowdin上被隐藏。一般用户在Crowdin上无法查看这些字符串，但它们最终仍然会在语言文件中出现。

== 翻译规范 ==
[[File:Minecraft Glossary for Crowdin.jpg|缩略图|右|术语表]]
在2016年1月，Mojang通过制定'''[https://docs.google.com/spreadsheets/d/1xxDvR2MrPUaxXwNfn-oJX-fBerEsZkfo 规范术语表（Glossary）]'''来规定所有语言和所有版本内的用语一致且不应翻译的标准用语，包括{{tr|Creeper（[[苦力怕]]）|Creeper（[[苦力怕]]）|[[Creeper]]}}、Enderman（[[末影人]]）和Nether（[[下界]]）等。

对于术语表中列为“不应翻译”（NOT TO BE TRANSLATED）的词汇，文字为拉丁字母的语言应当保留英文原文，即使某些语言的字母表与英文不同也是如此。名词的大小写可以依照各语言的习惯，不需要与原文相同。

同时，术语表规定文字为非拉丁字母的语言（如日语、俄语、阿拉伯语等），可以使用各自的书写系统音译这些“不应翻译”的词汇，而不必保留拉丁字母。

由于向Mojang申请过特殊豁免，中文可以继续意译这些词汇。

== 中文翻译 ==
<!-- 为避免不必要的麻烦，请不要随意在此段添加带有明显立场的地区表述！ -->

Minecraft有大量玩家以汉语为主要使用语言。为满足各地玩家的不同需求，社区志愿者在Crowdin上为Minecraft维护着4种中文翻译文本。

在惯用字词差异之外，各项目的翻译风格与运作模式也有着或多或少的区别，具有各自的特色。

; [https://zh.crowdin.com/project/minecraft/zh-CN {{samp|zh_cn}}]
该翻译项目对应的游戏内语言名称为“<span lang=zh-cn>-{简体中文 (中国大陆)}-</span>”，在Java版[[11w49a]]发布时正式应用，是游戏内多语言支持的首批项目之一。现任审核员有[https://zh.crowdin.com/profile/ff98sha ff98sha]（{{Userlink|Ff98sha}}）、[https://zh.crowdin.com/profile/Lxazl5770 Lxazl5770]（{{Userlink|Lxazl5770}}）和[https://zh.crowdin.com/profile/powup333 powup333]（{{Userlink|Powup333}}）。

关于该项目的建议请在Crowdin、[[MCW:交流群#qqtranslation|交流群]]或[https://discord.com/invite/HPJ8z2Y6Zk Discord服务器]中提出。

该项目的早期主要参与者[https://zh.crowdin.com/profile/Craft_Lawrence Craft_Lawrence]（{{Userlink|Craft Lawrence}}）、[https://zh.crowdin.com/profile/powup333 powup333]（{{Userlink|Powup333}}）和[https://zh.crowdin.com/profile/sjjklh sjjklh]（{{Userlink|Sjjklh}}）在2015年被Mojang赠予绘有中国国旗的[[Crowdin中文翻译者披风|特殊翻译者披风]]。

; [https://zh.crowdin.com/project/minecraft/zh-TW {{samp|zh_tw}}]
该翻译项目对应的游戏内语言名称为“<span lang=zh-tw>-{繁體中文 (台灣)}-</span>”，在Java版[[12w01a]]发布正式应用，是游戏内多语言支持的首批项目之一。现任审核员有[https://zh.crowdin.com/profile/__HJ __HJ]、[https://zh.crowdin.com/profile/dragontaki Dragon Taki]、[https://zh.crowdin.com/profile/ff98sha ff98sha]（{{Userlink|Ff98sha}}）、[https://zh.crowdin.com/profile/powup333 powup333]（{{Userlink|Powup333}}）和[https://zh.crowdin.com/profile/shkl0206 shkl0206]。

有关该项目的提议请在Crowdin、[https://t.me/MC_zh_TW 交流群]或[https://discord.gg/PpPZS4S Discord服务器]中提出。

; [https://zh.crowdin.com/project/minecraft/zh-HK {{samp|zh_hk}}]
该翻译项目对应的游戏内语言名称为“<span lang=zh-hk>-{繁體中文 (香港特別行政區)}-</span>”，在Java版[[21w16a]]发布时正式应用，现任审核员有[https://zh.crowdin.com/profile/Lxazl5770 Lxazl5770]（{{Userlink|Lxazl5770}}）和[https://zh.crowdin.com/profile/lammail LammaIL]（{{Userlink|LammaIL}}）。

该项目是为了弥补早期单一“繁体中文”选项的不足而创建的，主要迎合港澳地区用户的习惯。

有关该项目的提议请在Crowdin或[https://discord.gg/PEb2yVGABq Discord服务器]中提出。

; [https://zh.crowdin.com/project/minecraft/lzh {{samp|lzh}}]
该翻译项目对应的游戏内语言名称为“<span lang=lzh>-{文言 (華夏)}-</span>”，在Java版[[Java版1.17.1-pre2|1.17.1-pre2]]发布时正式应用，现任审核员有[https://zh.crowdin.com/profile/ff98sha ff98sha]（{{Userlink|Ff98sha}}）和[https://zh.crowdin.com/profile/sorajima_asugawa sorajima_asugawa]（{{Userlink|SorajimaAsugawa}}）。

[[wzh:文言文|文言文]]是古代汉语直至20世纪初的标准书面语，通行于[[wzh:汉字文化圈|汉字文化圈]]。在现代，文言文已经淡出日常使用，其标准书面语的地位被官话白话文取代。该项目的翻译风格主要基于宋代之后的文言文。

有关该项目的提议请在Crowdin、[[MCW:交流群#qqlzh|交流群]]或[https://discord.gg/bf77Bqf8qs Discord服务器]中提出。
