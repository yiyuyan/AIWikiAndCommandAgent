'''13w47c'''是[[Java版1.7.4]]的第3个快照，发布于2013年11月21日<ref>{{cite|url=http://mojang.com/2013/11/minecraft-snapshot-13w47a-twitch-tv-broadcasting/|archive-url=1|archive=1|title=Minecraft Snapshot 13w47e – Twitch.tv broadcasting!|author=Dinnerbone|website=Mojang.com|date=Nov 21, 2013}}</ref>，以修复[[13w47a]]和[[13w47b]]中的崩溃。</onlyinclude>

== 你知道吗 ==
* 此版本曾经在[[启动器]]中移除，但在2018年9月重新加入。
