'''18w05a'''是[[Java版1.13]]的第16个快照，发布于2018年1月31日<ref>{{snap|18w05a|January 31, 2018}}</ref>，为命令{{cmd|execute}}加入了新的参数，加入了新的命令{{cmd|bossbar}}，更新了命令UI和翻译文件，并修复了一些漏洞。

== 新内容 ==
=== 命令格式 ===
'''{{cmd|bossbar}}'''
* {{cmd|bossbar create <boss栏> <显示名称>}}可创建一个Boss栏。
** <code>-{}-boss栏</code>用来指定Boss栏<code>namespace:name</code>，例：<code>foo:bar</code>。如果没有<code>namespace</code>则默认为<code>minecraft</code>。
** <code>-{}-显示名称</code>是Boss栏的显示名称，只接受JSON语法。
* {{cmd|bossbar set <目标boss栏> name <显示名称>}}可以更改Boss栏的名字。
* {{cmd|bossbar set <目标boss栏> color <!-- 此为颜色代码，请勿翻译 -->(blue{{!}}green{{!}}pink{{!}}purple{{!}}red{{!}}white{{!}}yellow)}}可用来更改Boss栏与该名称的颜色（修改文字颜色只限于当没有在文字格式中指定它的颜色时），默认为<code>white</code>。
* {{cmd|bossbar set <目标boss栏> style (notched_10{{!}}notched_12{{!}}notched_20{{!}}notched_6{{!}}progress)}}能改变boss栏的样式，默认为<code>progress</code>。
** 可以设为以下的样式：<code>notched_6</code>、<code>notched_10</code>、<code>notched_12</code>、<code>notched_20</code>或<code>progress</code>。
** <code>notched</code>会设定boss栏在视觉上的分段数。
** <code>progress</code>会设置为1段，也就是直长条。
* {{cmd|bossbar set <目标boss栏> value <当前值>}}会改变boss栏的当前值，默认为<code>0</code>。
* {{cmd|bossbar set <目标boss栏> max <最大值>}}会设置boss栏的最大值，默认为<code>100</code>。
* {{cmd|bossbar set <目标boss栏> visible <visible>}}会设定boss栏是否可见，默认为<code>true</code>。
* {{cmd|bossbar set <目标boss栏> players <目标玩家>}}会设定那些玩家可以看见boss栏，默认为无人可看见。
* {{cmd|bossbar remove <目标boss栏>}}会把整个目标boss栏给移除。
* {{cmd|bossbar list}}会显示所有存在的boss栏。
* {{cmd|bossbar get <指定boss栏> (max{{!}}players{{!}}value{{!}}visible)}}会回传值作为命令的 <code>result</code>
'''{{cmd|execute store}}'''
* 新的子命令{{cmd|execute store}}：{{cmd|execute store (result{{!}}success) bossbar <目标boss栏> (value{{!}}max) <连锁子命令>}}。
** 将会储存指定运行命令的<code>result</code>或<code>success</code>为boss栏的<code>value</code>当前值或<code>max</code>最大值设定。
'''常规'''
* 为命令UI增加了基本的目标选择器。
