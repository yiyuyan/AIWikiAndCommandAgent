'''足迹与故事活动（Trails & Tales Event）'''<ref group="注">[[主菜单]]上称作'''夏季活动（Summer Event）'''，游戏内聊天栏称作'''足迹与故事主题公园（Trails and Tales Theme Park）'''。</ref>是在2023年6月23日10:00（PST）至6月25日22:00（PST）限时开放的官方[[活动服务器]]，游戏内容和[[足迹与故事]]的新增特性有关。

== 足迹与故事主题公园 ==
玩家的活动区域是整个主题公园的内部。

主题公园主要分为广场、“樱花树林”（Cherry Grove）、“骆驼峡谷”（Camel Canyon）和“失落世界”（The Lost World）4个区域，其中包含多种娱乐设施和供多人游玩的小游戏。与工作人员NPC对话即可参加游戏。竞赛类游戏会在结束时公布参与者的排名。{{more info|每个小游戏的游玩人数上限}}

园区的路边有垃圾箱和能坐的长椅。[[骆驼]]、[[鸡]]、[[苦力怕]]、[[恶魂]]、[[山羊]]、[[铁傀儡]]、[[熊猫]]、[[绵羊]]、[[嗅探兽]]和[[监守者]]10种生物公仔隐藏在公园的各个角落。

=== 广场 ===
[[File:Sniffer_Hedge_(Trails_and_Tales_Summer_Event)_Render.png|嗅探兽草雕|thumb]]
广场靠近主题公园的大门，四周环绕着多个房屋。商品区的中心有一个[[嗅探兽]]形状的草艺雕塑。

; 疯狂矿车
[[File:Minecart_(Trails_and_Tales_Summer_Event)_Render.png|木质矿车|thumb]]
{{Quote|想来一次有趣的公园之旅？那就来玩“疯狂矿车”吧！|“疯狂矿车”NPC}}
“疯狂矿车”（Minecart Madness）的起点位于玩家出生点的左侧。玩家可乘坐木质纹理的[[矿车]]行驶在主题公园的边界，依次路过“樱花树林”“骆驼峡谷”和“失落世界”，最后在起点的对面下车。矿车经过[[气泡柱]]水洼时会被向上抬升。

玩家经过[[沙漠神殿]]时可发现隐藏的苦力怕公仔。

; 商店
{{Quote|我能帮你什么吗？|商店NPC}}

每个商店内都有一个服务员NPC。与NPC对话或与店中陈列的商品实体交互可获得对应的物品。物品无法从[[物品栏]]中丢出，但会在玩家退出服务器时消失。

饮用火把花茶可获得[[夜视]]效果，其他食物和饮品则会给予玩家[[迅捷]]效果。面具和帽子可以放入头盔槽来戴在头上。

=== 樱花树林 ===
[[File:Sign_Cherry_Grove_(Trails_and_Tales_Summer_Event)_Render.png|thumb|“樱花树林”门牌]]

大量的[[樱花树]]和樱花木建筑是“樱花树林”区域的特色。

; 竹筏漂流竞速
{{Quote|希望你不介意全身都湿透！漂流竞速比赛有时候很激烈！<br><br>准备好了吗？|“竹筏漂流竞速”NPC}}

在“竹筏漂流竞速”（River Raft Racers）中，玩家需乘坐“竹筏”（用了竹筏纹理的橡木船）在环形河流中竞渡，于1分30秒内环绕场地一圈，沿途可收集水面上浮动的“花朵”。

; 生物群系踪迹迷宫
“生物群系踪迹迷宫”（Biome Trail Maze）是一个中等难度的计时迷宫，结构类似于[[洞穴]]，环境设计成微缩的[[海底神殿]]、[[绯红森林]]、[[沙漠]]、[[深暗之域]]、[[要塞]]和[[末地]]。

玩家可在迷宫中发现隐藏的监守者和恶魂公仔。

; 樱花树跑酷
“樱花树跑酷”（Cherry Tree Parkour）是一个中等难度的计时跑酷区域，途经大型樱花树、仿日式建筑和2个记录点。

; 热气球
[[File:Hot_Air_Balloon_(Trails_and_Tales_Summer_Event)_Render.png|thumb|热气球]]
玩家可乘坐热气球（Hot Air Balloon）实体原地上升，以俯瞰整个主题公园。热气球能同时搭载4名玩家。

; 竹筏露脸展板
“竹筏露脸展板”（Raft Cutout）上画着正在划竹筏的Zuri和Efe。玩家站在展板背面的台子上时，相机视角会对准展板正面，以供玩家留影。

=== 骆驼峡谷 ===
[[File:Sign_Camel_Canyon_(Trails_and_Tales_Summer_Event)_Render.png|“骆驼峡谷”门牌|thumb]]

“骆驼峡谷”是主题公园中的沙漠风格区域，有风蚀柱景观、[[沙漠神殿]]及[[村庄|沙漠村庄]]风格的小镇。

; 沙漠快跑
{{Quote|参赛选手，准备好了吗？<br><br>跳上一只我们为你提供的温顺骆驼，参加快节奏的沙漠跑道比赛！<br><br>准备好了吗？|“沙漠快跑”NPC}}
“沙漠快跑”（Desert Dash）竞速游戏要求玩家在2分钟内骑乘[[骆驼]]环绕沙地赛道两圈。{{ctrl|敲击}}赛道上飘浮的蓝色气球会施予骆驼3秒的[[迅捷]]II效果。

=== 失落世界 ===
[[File:Sign_Lost_World_(Trails_and_Tales_Summer_Event)_Render.png|“失落世界”门牌|thumb]]

“失落世界”是一个[[嗅探兽]]主题的植被繁茂区域。

; 生物脑袋迷
{{Quote|你能通关“生物脑袋迷”吗？<br><br>记住音符盒的旋律，每一轮都会播放更长的旋律。你能记住多少呢？<br><br>准备好了吗？|“生物脑袋迷”NPC}}
“生物脑袋迷”（Mob Head Mania）共有4个游玩场地，每个场地限一名玩家游玩。在每轮游戏中，玩家会听到由[[苦力怕]]、[[猪灵]]、[[末影龙]]、[[骷髅]]和[[僵尸]]的音效拼接而成的“旋律”，接着要按顺序点击带有对应[[生物头颅]]的[[音符盒]]上的按钮，以复现这段旋律。回答正确可继续游玩下一轮{{more info|轮数上限}}，回答错误会立即终止游戏。头一轮只播放一种生物的音效，接下来的每轮会多加一种音效。

; 丛林树跑酷
“丛林树跑酷”（Jungle Tree Parkour）是一个中等难度的计时跑酷区域，途经2个记录点。

; 远古洞穴跑酷
“远古洞穴跑酷”（Ancient Cave Parkour）是一个高难度的计时跑酷区域，途经3个记录点。
