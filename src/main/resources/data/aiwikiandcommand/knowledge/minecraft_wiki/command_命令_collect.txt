使用[[智能体]]的物品栏中的1个方块收集3个维度中的物品。<!-- Collects all items within a one block from Agent in three dimensions. -->

== 语法 ==
: <code>-{}-collect <''物品：字符串''></code>

== 参数 ==
<code>-{}-<''物品：字符串''></code>
: 指定智能体的物品栏中的1个方块所需要收集的物品。字符串必须是[[基岩版数据值#物品ID|物品ID]]或者是物品形式存在的[[基岩版数据值#方块ID|方块ID]]（例如<code>golden_sword</code>）。
