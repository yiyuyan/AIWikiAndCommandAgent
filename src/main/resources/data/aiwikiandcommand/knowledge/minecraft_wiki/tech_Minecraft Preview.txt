'''Minecraft Preview'''是一个用于测试{{el|be}}的beta特性的独立应用。与原有的将beta特性直接加入游戏本体、用户选择加入测试的测试方式不同，beta特性与基岩版正式版得以共存。<ref name="minecraft-preview-initial-post">{{cite|url=https://help.minecraft.net/hc/en-us/articles/4423653831821|title=Minecraft Preview FAQ - Home|website=help.minecraft.net|date=January 31, 2022}}</ref>

截至目前，此测试计划仅对Windows用户<ref name= "PreviewWin10">{{tweet|JORAX79|1491518112016961538|Happy Wednesday! Minecraft Preview is NOW available on Windows for all players who own the Bedrock version of Minecraft there. You can install by visiting the below link (you may have to refresh the page once for the "Install" button to appear)|February 9, 2022}}</ref>、Xbox用户<ref name= "PreviewXbox"">{{cite|url=https://news.xbox.com/en-us/2022/02/07/the-minecraft-preview-is-now-available/|title=The Minecraft Preview is now available to all Xbox Insiders on Xbox!|website=news.xbox.com|date=February 7, 2022}}</ref>、PlayStation用户，以及少数iOS和iPadOS平台上的用户有效。

== 开发 ==
2022年1月31日，[[Mojang]]宣布测试版计划以Minecraft Preview的形式扩展到其他平台，最早通过TestFlight在iOS/iPadOS平台上发布与{{el|be}}正式版相独立的Minecraft Preview应用。此计划最早在TestFlight上仅有500个名额<ref>{{tweet|JORAX79|1488619719724703746|Day 1 Minecraft Preview on iOS stats (all anonymous):<br><nowiki>- Slots: 500</nowiki><br><nowiki>- Installs: 487</nowiki><br><nowiki>- Most sessions for 1 player: 46</nowiki><br><nowiki>- Most crashes for 1 player: 20 (looking into this!)</nowiki><br><nowiki>- JIRA (bugs.mojang.com) bugs created or up-voted for Preview: 6</nowiki>|February 1, 2022}}</ref>，后来又增加了500个名额。<ref>{{tweet|JORAX79|1489381137747042307|Hi all - we will be adding 500 additional slots for the iOS version of Minecraft Preview at 6:30pm PST (2:30am UTC)! That will be about 3 hours from now.<br>As a reminder the opt-in link is http://aka.ms/PreviewApple. But it isn't ready yet - remember to check in 3 hours 😄|February 3, 2022}}</ref>

2022年2月7日，Minecraft Preview通过Xbox Insider Hub发布到Xbox平台上，用于测试将存档迁移到新应用上。此测试分为2个阶段，第一阶段会向所有Xbox Insider玩家发布<ref name="PreviewXbox"/>，第二阶段则仅向购买了{{el|be}}的玩家发布。<ref>{{tweet|JORAX79|1490751506420670467|This is true and warrants an update to the FAQ. The current Xbox Insider version of Preview is available to everyone in that program. When Preview officially releases on Xbox, it will only be available to those own Minecraft.|February 7, 2022}}</ref>

2022年2月9日，Minecraft Preview在Windows平台上发布，已购买游戏的玩家才可以下载并进行游戏。<ref>{{tweet|JORAX79|1491518112016961538|Happy Wednesday! Minecraft Preview is NOW available on Windows for all players who own the Bedrock version of Minecraft there. You can install by visiting the below link (you may have to refresh the page once for the "Install" button to appear)|February 9, 2022}}</ref>

2024年2月15日，Minecraft Preview在PlayStation平台上发布。

== 参与方法 ==
=== iOS & iPadOS ===
需要预先注册[https://developer.apple.com/cn/testflight TestFlight]以[https://aka.ms/PreviewApple 获取测试资格]，目前Minecraft Preview仅对TestFlight上有限数量的用户可用。

=== Windows ===
Minecraft Preview在[https://xbox.com/games/store/-/9P5X4QVLC2XR Microsoft Store]上对所有已购买Windows版游戏的玩家，以及订阅了PC Game Pass或Xbox Game Pass Ultimate的玩家可用。<ref name="minecraft-preview-initial-post"/>

=== Xbox ===
Minecraft Preview在{{tr|[https://xbox.com/zh-HK/games/store/-/9NQ19C36R0VD <nowiki>Microsoft Store和Xbox app</nowiki>]|[https://xbox.com/games/store/-/9NQ19C36R0VD <nowiki>Microsoft Store和Xbox app</nowiki>]}}上对所有已购买Xbox版游戏的玩家，以及订阅了PC Game Pass或Xbox Game Pass Ultimate的玩家可用。<ref name="minecraft-preview-initial-post"/>

=== PlayStation ===
打开设置，选择侧边栏底部的“Preview”，点击“获取PlayStation 4 Preview”或“获取PlayStation 5 Preview”即可下载Minecraft Preview。<ref name="minecraft-preview-initial-post"/>

=== 其他平台 ===
FAQ中提到Minecraft Preview将会发布到其他平台上，并且FAQ也会在Minecraft Preview发布到这些平台上时同步更新。<ref name="minecraft-preview-initial-post"/>
