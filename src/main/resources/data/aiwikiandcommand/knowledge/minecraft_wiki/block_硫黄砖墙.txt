'''硫黄砖墙（Sulfur Brick Wall）'''是[[硫黄砖]]制作的[[墙]]。

== 生成 ==
硫黄砖墙不会生成在世界中。

== 获取 ==
=== 合成 ===

|B2=Sulfur Bricks

|B3=Sulfur Bricks
|C3=Sulfur Bricks
|Output=Sulfur Brick Wall,6
|type= Decoration block
}}

{{Stonecutting

}}

== 破坏 ==
挖掘硫黄砖墙的合适工具是镐。硫黄砖墙需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

硫黄砖墙被破坏后会掉落自身。

== 用途 ==
{{main|墙#用途}}
硫黄砖墙可用于装饰，并有与其他墙相似的特性。
