'''16w36a'''是[[Java版1.11]]的第5个快照，发布于2016年9月8日<ref name="blogpost_16w36a">{{cite|url=http://mojang.com/2016/09/minecraft-snapshot-16w36a/|archive-url=1|archive=1|title=Minecraft snapshot 16w36a|author=LadyAgnes|website=Mojang.com|date=Sep 8, 2016}}</ref>，修复了一些漏洞。

== 更改 ==
=== 方块 ===
'''[[花]]'''
* 花的碰撞箱现在将对应方块上准确的视觉位置（不再始终放置在方块的中间）。

'''[[树叶]]'''
* 从树叶散发出去的粒子效果现在将对应生物群系的颜色而改变。
