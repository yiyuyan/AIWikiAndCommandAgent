'''朱砂砖（Cinnabar Bricks）'''是[[朱砂]]制作的装饰性方块。

== 生成 ==
朱砂砖不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|A2=Polished Cinnabar |B2=Polished Cinnabar
|A3=Polished Cinnabar |B3=Polished Cinnabar
|Output=Cinnabar Bricks,4
|type=Building block
}}

=== 切石 ===
{{Stonecutting
|Cinnabar; Polished Cinnabar
|Cinnabar Bricks
}}

== 破坏 ==
挖掘朱砂砖的合适工具是镐。朱砂砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

朱砂砖被破坏后会掉落自身。
