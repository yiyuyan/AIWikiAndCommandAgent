输出游戏版本信息。

== 用法 ==
=== 返回信息示例 ===
<pre>-{}-
Server version info:
id = 25w15a
name = 25w15a
data = 4422
series = main
protocol = 1073742069 (0x400000f5)
build_time = Tue Apr 08 20:14:00 CST 2025
pack_resource = 56
pack_data = 72
stable = no
</pre>
以上各字段的具体含义参见{{slink|版本信息文件格式}}。

== 语法 ==
: <code>version</code>

== 结果 ==
永远执行成功。
