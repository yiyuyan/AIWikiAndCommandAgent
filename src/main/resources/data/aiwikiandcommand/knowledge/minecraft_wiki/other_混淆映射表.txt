'''混淆映射表（Obfuscation Map）'''又称'''反混淆表'''，是[https://www.guardsquare.com/en/products/proguard Proguard]输出的映射了被混淆的类和类成员在混淆前后的名称的文本文件。<ref>{{link|url=https://www.guardsquare.com/manual/configuration/usage#obfuscationoptions|title=ProGuard manual &#124; Usage|website=Guardsquare}}</ref>自[[Java版19w36a|19w36a]]以来所有版本的[[client.json]]中都会导出混淆映射表。在19w36a发布一小段时间后，[[Java版1.14.4|1.14.4]]的client.json也获得更新，导出了混淆映射表。<ref>{{tweet|Dinnerbone|1169257039597645824|I've been pushing for this for a while, so I'm really happy that we were finally able to release the obfuscation mappings public. @SeargeDP had a great idea to release the 1.14.4 mappings as comparison, so those are going out right now.|September 4th, 2019}}</ref>

2025年10月29日，Mojang宣布从[[群骑纷争]]的下一个小更新的首个快照（即[[Java版26.1-snapshot-1|26.1-snapshot-1]]）开始，Java版代码将不再被混淆，因此混淆映射表将会被移除。此外，在[[Java版25w45a|25w45a]]至[[Java版1.21.11|1.21.11]]的所有版本中，Mojang同时发布了已混淆和未混淆的核心文件，以帮助模组作者进行过渡。<ref>{{article|removing-obfuscation-in-java-edition|Removing obfuscation in Java Edition|Oct 29, 2025}}</ref>

== 用途 ==
混淆映射表原意是用来反混淆被混淆后的堆栈记录的（例如[[崩溃|崩溃报告]]中的堆栈记录）。<ref>{{link|url=https://www.guardsquare.com/en/products/proguard/manual/usage|title=ProGuard manual &#124; Retrace|website=Guardsquare}}</ref>对应教程[[Tutorial:获取崩溃报告#对报告进行反混淆|在此]]。

[[Dinnerbone]]和[[Adrian Östergård]]表示混淆映射表会使编写[[Mod]]更方便。<ref>{{tweet|Dinnerbone|1168818898101293056|Tomorrow's snapshot has a small surprise for modders! Should make one or two people happy :)|September 3rd, 2019}}</ref><ref>{{tweet|adrian_ivl|1169234792984002561|Happy modding!|September 4th, 2019}}</ref>[[Searge]]表示混淆映射表可以替代一些[[辅助程序与编辑器]]，例如[[Mod Coder Pack]]。<ref>{{tweet|SeargeDP|1169247787529248770|This should answer the questions of everyone who kept asking about MCP updates for newer versions of Minecraft. Spoiler: there won't be any, they are finally not necessary anymore.|September 4th, 2019}}</ref>

=== 第三方用途 ===
{{disclaimer|section=1}}
混淆映射表中包含的信息足以反混淆Minecraft使之反编译出容易理解的代码。可能有[[辅助程序与编辑器]]能够方便地反编译反混淆后的Minecraft。

根据许可证，这类反混淆反编译后的代码只能以修改后的版本发布，或作为更大的项目的一部分。

== 你知道吗 ==
* 到2020年8月16日许可证更新为止，当年发布的版本在其混淆映射表文件的许可证中仍然使用<code># (c) 2019 Microsoft Corporation.</code>。
* 在客户端混淆映射表中，第一个方法是<code>youJustLostTheGame()</code>，这是致敬[[wzh:The Game (游戏)|The Game]]的一个彩蛋。
** 这个方法用于在按住调试按键{{key|Ctrl+F3+C}}十秒后触发游戏崩溃。
** 在[[21w13a]]至[[24w33a]]之间的版本的混淆映射表中，该方法的位置被重排到了第四位。<ref>{{Bug|MC-270510|||Fixed}}</ref>
