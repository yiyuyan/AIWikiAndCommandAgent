'''1.16.3-rc1'''是[[Java版1.16.3]]的唯一一个发布候选版本，发布于2020年9月7日<ref>{{article|minecraft-1-16-3-release-candidate-1|Minecraft 1.16.3 Release Candidate 1|September 7, 2020}}</ref>，修复了一些漏洞。

== 修复 ==
{{Fixes|fixedin=1.16.3 Release Candidate 1|showdesc=1
|;1.16前正式版的漏洞
|135164|生物死亡时会继续手持其原先持有的方块或物品，导致方块和物品看起来被复制了。
|159335|从生物身上掉落的盔甲的耐久度可以是负值。
|;1.16.2的漏洞
|196449|猪灵、猪灵蛮兵、疣猪兽和僵尸疣猪兽攻击玩家时无法正确寻路。
|198678|将金锭和另一件物品扔给幼年猪灵并将其杀死，会掉落两份该物品。
}}</onlyinclude>
