'''宠物蜜蜂（Pet Bee）'''是[[蜜蜂]]在[[25w14craftmine]]愚人节版本中的[[宠物（25w14craftmine）|宠物]]变种。

== 生成 ==
解锁并激活可解锁项目“[[可解锁项目#pet bee|宠物蜜蜂（Pet Bee）]]”后进入新的[[矿境]]或在矿境中解锁并激活该项目时会生成一只宠物蜜蜂。

== 掉落物 ==
宠物蜜蜂被杀死时不会掉落物品和[[经验]]。

== 行为 ==
宠物蜜蜂与常规版本中的蜜蜂类似，但有以下不同：
* 玩家的近战攻击无法对宠物蜜蜂造成伤害。
* 玩家无法对宠物蜜蜂使用[[花（消歧义）#可以视为花的方块|花等物品]]。
* 宠物蜜蜂不会[[蜜蜂#采粉、授粉和产蜜|采粉]]。
* 宠物蜜蜂不会进出[[蜂巢（方块）|蜂巢]]。
