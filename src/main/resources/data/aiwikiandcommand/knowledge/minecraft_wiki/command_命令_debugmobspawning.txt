在指定位置上进行一次生物的[[周期生成]]。

== 语法 ==
: <code>-{}-debugmobspawning <''类别''> <at></code>

== 参数 ==
<code>-{}-<''类别''></code>
: 指定[[生成#生成类别|生成类别]]。必须为以下之一：<code>monster</code>、<code>creature</code>、<code>ambient</code>、<code>axolotls</code>、<code>underground_water_creature</code>、<code>water_creature</code>、<code>water_ambient</code>或<code>misc</code>。

{{argument|at|block_pos}}
: 指定开始生成的位置。
: {{arg desc|je=block_pos}}

== 结果 ==
永远执行成功。
