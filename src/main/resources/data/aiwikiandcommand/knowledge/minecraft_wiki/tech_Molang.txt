'''Molang'''是一种基于表达式的简单语言，用于快速、数据驱动地在运行时计算数值，与游戏中的数值和系统直接连接。Molang在[[基岩版]]的[[附加包]]中使用，其设计目标是在保持高性能的同时，为动画等低级系统提供数据驱动的可变行为支持。<ref>[https://docs.microsoft.com/en-us/minecraft/creator/reference/content/molangreference/examples/molangconcepts/molangintroduction "Molang Documentation - Introduction to Molang"]</ref>

[[Mojang]]提供官方文档[https://docs.microsoft.com/en-us/minecraft/creator/reference/content/molangreference/ Molang文档]，其中详细介绍了该语言的工作原理和使用位置。

== 用途 ==
Molang表达式用于输出可以动态变化的值（通常是数值）。这使得在[[JSON]]格式的限制内能够编写更复杂的行为逻辑。Molang可在[[资源包]]（客户端）和[[行为包]]（[[服务端]]）的JSON文件中的多个位置使用：

* [[粒子数据格式|粒子组件]]中的数值
* [[基岩版存档格式/实体格式|实体定义文件]]的<code>scripts</code>和<code>part_visibility</code>字段
* 可穿戴物品（Attachable）定义文件的<code>scripts</code>字段
* 动画文件中的数值
* 动画控制器<code>transitions</code>字段中的条件判断
* 方块行为<code>permutations</code>字段中的条件判断
* 渲染控制器中的数组和资源分配
* 特定[[基岩版存档格式/实体格式/组件|实体组件]]中的数值
* 配方对象中的数据字段

== 使用指南 ==
Molang表达式以纯文本字符串的形式存储在JSON文件中，由英文双引号<code>"</code>括起。因此，表达式内部如需定义字符串，必须使用英文单引号<code>'</code>。与指令不同，Molang表达式不区分大小写，即大小写不会影响表达式的解析结果。

对于只包含单个语句的表达式，结尾的分号<code>;</code>可以省略。包含多个语句的表达式则需要使用分号来分隔各个语句。

== 语法 ==
Molang采用类C语言的语法风格。一个表达式可以是简单的单语句计算，也可以是多语句的复杂脚本。

=== 表达式类型 ===
Molang表达式分为两种形态：

==== 简单表达式 ====
简单表达式（Simple Expression）：仅包含一个语句，结尾不需要分号<code>;</code>，该语句的计算结果直接作为表达式的返回值。例如：

<pre>math.sin(query.anim_time * 1.23)</pre>

==== 复杂表达式 ====
复杂表达式（Complex Expression）：包含多个子表达式（即多个语句），每个子表达式的结尾必须使用分号<code>;</code>作为结束标识。复杂表达式通常需要使用<code>return</code>语句来返回最终值；若省略<code>return</code>语句，则表达式返回<code>0.0</code>。例如：
<pre>
temp.moo = math.sin(query.anim_time * 1.23);
temp.baa = math.cos(query.life_time + 2.0);
return temp.moo * temp.moo + temp.baa;
</pre>
复杂表达式在JSON中可以写在同一行，也可以换行且保留缩进。

== 变量 ==
Molang提供三种类型的变量：

=== 实体变量 ===
实体变量（Entity Variable）——使用<code>variable.</code>或简写<code>v.</code>前缀，是可以在表达式中存储以备后续使用的值。大多数变量可以通过<code>=</code>运算符声明和重新赋值，例如<code>v.<名称> = <值>;</code>。以这种方式声明的变量在其所属实体或粒子的生命周期内可读写，且在世界保存并重新加载后不会被保留。

=== 临时变量 ===
临时变量（Temp Variable）——使用<code>temp.</code>或简写<code>t.</code>前缀，仅在声明该变量的表达式执行期间存在。

=== 上下文变量 ===
上下文变量（Context Variable）——使用<code>context.</code>或简写<code>c.</code>前缀，是只读变量，仅在定义该表达式的上下文中可用。例如，<code>context.owning_entity</code>只能在可穿戴物品（Attachable）文件的Molang表达式中读取，因为该变量返回装备该可穿戴物品的实体。

== 函数 ==

=== 查询函数 ===
查询函数（Query Function）使用<code>query.</code>或简写<code>q.</code>前缀，以布尔值或数值的形式返回关于世界、实体等信息。它们是只读的，不可修改。例如，<code>query.health</code>返回当前实体的生命值；若不在实体上下文中使用，则返回<code>0</code>。

部分查询函数可以接受参数，参数放在函数名后的圆括号内，多个参数之间用逗号分隔。参数可以作为数值读取，也可以作为字符串读取，字符串参数可作为标签、槽位、实体等对象的标识符。例如，<code>q.is_item_name_any('slot.weapon.mainhand', 0, 'minecraft:iron_ingot')</code>根据当前实体主手第一个槽位（主手只有一个槽位，与物品栏或快捷栏不同；槽位索引从0开始）中的物品名称（即类型ID）是否匹配后续参数中的任意一个，返回<code>1</code>（真）或<code>0</code>（假）。

部分查询函数在行为包和资源包中均可使用，另一些则仅限其中一侧使用。例如，<code>query.remaining_durability</code>仅在服务端可用于物品组件<code>minecraft:repairable</code>。

常用查询函数包括：

* <code>query.anim_time</code>：当前动画已播放的时间（秒）
* <code>query.is_alive</code>：实体是否存活，返回<code>1.0</code>或<code>0.0</code>
* <code>query.is_sneaking</code>：实体是否潜行
* <code>query.is_baby</code>：实体是否为幼年形态
* <code>query.health</code>：实体当前生命值
* <code>query.get_equipped_item_name</code>：返回指定槽位的物品名称
* <code>query.scoreboard</code>：读取计分板数据
* <code>query.last_hit_by_player</code>：实体是否最后被玩家击中
* <code>query.modified_move_speed</code>：实体的归一化移动速度（<code>0</code>至<code>1</code>之间）
* <code>query.life_time</code>：实体存在的时间（秒）
* <code>query.delta_time</code>：上一帧到当前帧的时间间隔（秒）
* <code>query.variant</code>：返回实体的变种序号

完整的查询函数列表可查阅Minecraft官方文档：[https://docs.microsoft.com/en-us/minecraft/creator/reference/content/molangreference/ Molang文档]。

=== 数学函数 ===
数学函数（Math Function）使用<code>math.</code>前缀（无单字母别名），执行特定的数学运算，参数的传入方式与部分查询函数类似。

例如，<code>math.floor(3.8)</code>将输入值向下取整，返回<code>3.0</code>。
