'''1.13.2'''是{{el|je}}的一次次要更新，发布于2018年10月22日<ref>{{article|minecraft-java-edition-1132|Minecraft Java Edition 1.13.2|October 16, 2018}}</ref>，优化了多项性能，并修复了一些漏洞。

== 更改 ==
=== 常规 ===
* 提升世界加载性能。
* 提升游戏启动性能。
* 提升海龟寻路性能。
* 提升生物生成性能。
* 提升其他各种性能。
