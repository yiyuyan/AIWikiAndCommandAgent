'''1.13.2-pre1'''是[[Java版1.13.2]]的首个预发布版，发布于2018年10月16日<ref>{{article|minecraft-java-edition-1132|Minecraft Java Edition 1.13.2|October 16, 2018}}</ref>，修复了[[Java版1.13.1]]遗留的一些漏洞，并做了一些性能改进。

== 更改 ==
=== 常规 ===
'''性能'''
* 提升了世界加载性能。
* 提升了游戏启动性能。
* 提升了海龟寻路性能。
* 提升了生物生成性能。
* 提升了其他各种性能。

== 修复 ==
{{fixes|fixedin=1.13.2-pre1|prefix=Minecraft|showdesc=1

|;1.13的漏洞
|134115|升级时，区块边界处的容器中物品丢失。
