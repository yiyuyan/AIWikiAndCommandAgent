清除玩家物品栏的物品。

== 用法 ==
可以清除物品栏中的物品，当从容器（箱子、工作台等）中用光标拿起物品时，此类物品也可以清除。

{{in|be}}还可以清除光标持有的、来自物品栏的物品，而{{in|je}}此类物品只能在非创造模式下清除。

{{in|je}}还可以清除玩家的2×2合成槽位中的物品。

== 语法 ==
* '''Java版'''
: <code>clear [<targets>] [<item>] [<maxCount>]</code>

* '''基岩版'''
: <code>clear [player: target] [itemName: Item] [data: int] [maxCount: int]</code>

== 参数 ==
{{argument|targets|entity|player: target|CommandSelector<Player>}}
: 指定要被清除物品的玩家。如果未指定，默认为命令执行者。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{argument|item|item_predicate|itemName: Item|CommandItem}}
: 指定要被清除的物品。如果未指定，默认为所有物品。
: {{arg desc|je=item_predicate|be=CommandItem}}

{{argument|be=1|data: int|int}}
: 指定要被清除物品的[[基岩版数据值|数据值]]。如果未指定或为{{cd|-1}}，则不考虑物品的数据值；如果指定数据值对该物品无效，默认为{{cd|0}}。
: {{arg desc|be=int}}应该在-1到2147483647之间（含）。

{{argument|maxCount|integer|maxCount: int|int}}
: 指定要被清除物品的最大值。如果未指定{{only|be|for=或为{{cd|-1}}}}，则默认清除所有符合要求的物品；如果为{{cd|0}}，则不会清除物品，而是返回指定物品的数量。
: {{arg desc|be=int|je=integer|min=0}}{{in|be}}应该在-1到2147483647之间（含）。

== 示例 ==
* 清除自己的所有物品：<code>clear</code>
* 清除Alice的所有物品：<code>clear Alice</code>
* 清除Alice的所有羊毛：<code>clear Alice #minecraft:wool</code>{{only|java}}或<code>clear Alice minecraft:wool</code>{{only|bedrock}}
* 清除所有玩家的橙色羊毛：<code>clear @a minecraft:orange_wool</code>或<code>clear @a wool 1</code>{{only|bedrock}}
* 清除距离最近玩家的带有“[[锋利]] I”[[附魔]]的金剑：<code>clear @p minecraft:golden_sword[minecraft:enchantments[{"minecraft:sharpness":1}]</code>{{only|JE}}
* 检测一个随机玩家的物品栏内是否拥有石头：<code>clear @r minecraft:stone -1 0</code>{{only|Bedrock}}或<code> clear @r minecraft:stone 0</code>{{only|Java}}
