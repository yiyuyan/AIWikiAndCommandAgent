'''为什么会变成这样呢？（How did we get here?）'''是用于充当物品对应方块的[[方块]]。

== 生成 ==
“为什么会变成这样呢？”不会生成在世界中。

== 获取 ==
“为什么会变成这样呢？”可以通过将物品作为方块放置获取。

== 破坏 ==
没有工具可以加速对“为什么会变成这样呢？”的挖掘。

{{Breaking table/manual|only=je|nocopper=1|
{{BlockSprite|How did we get here?}} 为什么会变成这样呢？|0.25|none
}}

“为什么会变成这样呢？”被破坏后不会掉落。

== 用途 ==
在[[22w13oneBlockAtATime]]中，所有的物品都可以作为方块放置。“为什么会变成这样呢？”被用于充当该版本中物品的对应方块。

“为什么会变成这样呢？”可以[[含水]]。
* 在[[调试模式]]中可查看其全部普通和含水变种。

“为什么会变成这样呢？”附着下侧非空气方块，类似地毯。

“为什么会变成这样呢？”从[[下落的方块]]转化时[[自更新]]，玩家放置和合成时不检查附着。

=== 显示 ===

* 拥有{{cd|item}}属性（放置时为[[方块状态]]，持有时为[[NBT标签]]），可指定需要显示的物品的内部ID（0-1104）。
** [[File:White Carpet.png|32px]] 值为0时，有着[[白色地毯]]的模型和纹理。
** 值非0时，对应物品以其二维图形式平铺在方块上，物品的顶部朝向南方。

== 你知道吗 ==
* [[发光地衣]]和[[幽匿脉络]]落地后会转化为“为什么会变成这样呢？”方块而非对应的方块形式。
* 使用{{cmd|setblock}}命令放置带有代表方块ID的<code>generic_item_block</code>，则会显示方块，但垂直坐标轴和旋转角不会对齐，导致方块顶部指向南，各面会被毗邻隐藏以匹配正常方块时本应毗邻隐藏的面。例如，<code>setblock ~ ~ ~ minecraft:generic_item_block[item=15]</code>显示“草”方块。
* “为什么会变成这样呢？”被[[活塞]]移动时有[[白色地毯]]的模型和纹理。
