'''难度（Difficulty）'''直接影响了Minecraft游戏的难易程度。其由整个世界全局性的'''世界难度（Difficulty）'''和依赖于特定位置的'''区域难度（Regional difficulty）'''两部分组成。

== 世界难度 ==
{{Filetr|DifficultyButton.gif|右}}

目前游戏中有四种难度设置：和平、简单、普通、困难。它们可以在[[选项]]中或通过命令{{cmd|difficulty}}更改，{{in|je|nc=1}}还可以在选项中锁定。[[极限模式]]下，[[玩家]]的游戏难度会被锁定为困难。

=== 和平 ===
{{relevant tutorial|在和平难度中收集资源}}
不会生成除[[潜影贝]]、{{only|be|for=[[疣猪兽]]}}、[[猪灵]]和[[末影龙]]以外的[[敌对生物]]，并且它们不会攻击玩家（末影龙除外）。使用{{cmd|summon}}命令召唤这些敌对生物会执行失败。使用刷怪蛋生成这些敌对生物时，生物不会生成，{{in|be|nc=1}}若为生存模式，则还会消耗刷怪蛋。生物不会攻击玩家，也无法对玩家造成伤害。玩家的[[生命值]]会随时间恢复，但是受伤速度过快或受到致命伤害时仍可能[[死亡]]。[[饥饿值]]永远不会消耗，即使低于最大值也会快速恢复。{{in|je}}只能食用[[金苹果]]、[[附魔金苹果]]、[[紫颂果]]、[[谜之炖菜]]和[[蜂蜜]]；{{in|be}}所有[[食物]]都可以食用。

尽管[[骆驼尸壳]]、[[骷髅马]]和[[僵尸马]]属于友好生物，但它们不会在和平难度下自然生成，因为它们的生成机制与敌对生物相关。

目前，在大多数情况下，和平难度下不可通关Minecraft，除非使用含已开启的[[末地传送门]]的[[种子（世界生成）|种子]]，否则无法进入[[末地]]。在大多数情况下，杀死[[烈焰人]]从而获得[[烈焰棒]]，合成[[烈焰粉]]并进一步合成[[末影之眼]]是激活末地传送门的必要条件。不过，自然生成的末地传送门中的每个[[末地传送门框架|框架]]都各有10%的概率是已经嵌入末影之眼的，因此有极其微小的概率（10{{^|-12}}）会直接生成已激活的末地传送门，从而允许玩家不获得烈焰棒直接进入末地。在和平难度下[[进度]]或[[成就]]不能被全部达成。

难度为和平且{{gamerule|natural_health_regeneration|naturalRegeneration}}为<code>true</code>时，玩家每{{convert|20}}增加{{hp|1}}生命值。

{{in|je}}难度为和平且{{gamerule|natural_health_regeneration}}为<code>true</code>时，玩家每{{convert|10}}增加{{hunger|1}}饥饿值，且每{{convert|20}}增加1点[[饱和度]]。

{{in|be}}难度为和平时，玩家每{{convert|10}}增加{{hunger|1}}饥饿值。

=== 简单 ===
会生成敌对生物，不过造成的伤害比普通难度低。饥饿值会消耗，并在耗尽时使玩家的生命值逐渐降至{{hp|10}}。[[洞穴蜘蛛]]和[[蜜蜂]]在简单难度中不会使目标[[中毒|中-{}-毒]]，[[凋灵]]也不会给予玩家[[凋零]]效果，但[[凋灵骷髅]]会给予玩家凋零效果。[[闪电]]只会让击中的方块起火，而不会直接导致周围的方块着火。[[僵尸]]不会将[[村民]]感染为[[僵尸村民]]。

=== 普通 ===
会生成敌对生物，能造成标准量的伤害。饥饿值会消耗，并在耗尽时使玩家的生命值逐渐降至{{hp|1}}。[[僵尸]]有50%概率将[[村民]]感染为[[僵尸村民]]。

=== 困难 ===
会生成敌对生物，能造成的伤害比普通难度更高。饥饿值会消耗并在耗尽时让玩家饿死。[[僵尸]]能够破坏[[木门]]及[[铜门]]，且{{in|je|nc=1}}可能在受到攻击时生成[[增援]]僵尸。[[僵尸]]杀死[[村民]]时总是会将其感染为[[僵尸村民]]。{{in|java}}[[蜘蛛]]生成时可能会带有[[迅捷]]、[[力量（状态效果）|力量]]、[[生命恢复]]或[[隐身]]这四种[[效果]]中的一种。

== 区域难度 ==
[[File:Local Difficulty Debug.png|缩略图|400px|[[调试屏幕]]下显示的区域难度值（对应[[调试选项]]{{cd|local_difficulty}}）]]

区域难度是一个介于0.00和6.75之间的值，基于不同的因素计算得到。这些因素包括当前区块的“占据时间”、在世界里总共游玩的时长、[[月相]]以及当前难度设置。{{in|je}}当前区域难度在[[调试屏幕]]上显示为“Local Difficulty”（本地难度）之后的第一个值。

在本段中：
* 区块的“占据时间”随着玩家在区块所经过的每一刻而增加。多个玩家的时间会累积起来——如果50个玩家在某区块中度过了1个小时，相当于1个玩家在该区块度过了50个小时。
* {{in|be}}“占据时间”不存在。
* 世界的“总时间”指{{cmd|time query daytime}}获取到的值加上调试屏幕上的天数转换为刻的值，即<math>\text{总时间} = \text{天数} \times 24000 + \text{当日时间}</math>，不等同于世界的实际游玩时间（{{cmd|time query gametime}}获取到的值）。

和平难度下，区域难度总为0。下文的“难度”不包含和平难度。

世界的总时间将在第3个游戏日后开始影响区域难度，随后影响逐渐增大，在63个游戏日时不再继续增大影响。游戏将根据该值计算“总时间因子”。总时间大于63个游戏日时，总时间因子为0.25（即与63个游戏日时的总时间因子相同）；小于3个游戏日时，总时间因子为0；不小于3个游戏日但不大于63个游戏日时，<math>\text{总时间因子} = \frac{(\text{总时间刻数} - 72000)}{5760000}</math>。

区块的占据时间对区域难度的影响最多是50个小时。游戏将根据占据时间、月相计算“区块因子”：
# 困难难度下，如果占据时间大于50个小时，则这一步的值为1，否则为<math>\frac{\text{占据时间刻数}}{3600000}</math>；其他难度下的值为困难难度下的值的{{frac|3|4}}；
# 将上一步的值加上总时间因子、月亮亮度的{{frac|1|4}}中的较小者，两者相等则加上该相等的值；
# 简单难度下，最终的值为上一步的值的一半，其他难度下最终的值即为上一步的值。

最后，计算<math>0.75 + \text{总时间因子} + \text{区块因子}</math>，在简单，普通或困难难度下分别将该值保持不变、乘2或乘3，就得到最终的区域难度。

在简单难度中区域难度的范围是0.75–1.5，在普通难度时为1.5–4.0，在困难难度时为2.25–6.75。

=== 副区域难度 ===
{{Filetr|Regional difficulty to Clamped regional difficulty.png|缩略图|325px|“区域难度”和“副区域难度”的关系}}
'''副区域难度（Clamped<ref group="注">此处“Clamped”指“值被限定在一个区域内”，即其范围在0.00至1.00之间。</ref> regional difficulty）'''是一个介于0.00和1.00之间的值，基于区域难度计算得到。{{in|je}}当前副区域难度在调试屏幕上显示为“Local Difficulty”之后的第二个值。

设区域难度为<math>R</math>，副区域难度为<math>C</math>，副区域难度与区域难度的关系式为：<math>C = \begin{cases}0.0, & R < 2.0 \\\dfrac{R - 2.0}{2.0}, & 2.0 \leq R \leq 4.0 \\ 1.0, & R > 4.0 \end{cases}</math>

该计算过程的Java代码如下所示，其中<code>RegionalDifficulty</code>代表区域难度的值，<code>value</code>代表副区域难度的值。
<syntaxhighlight lang="java">
 if ( RegionalDifficulty < 2.0 ) {
     value = 0.0;
 } else if ( RegionalDifficulty > 4.0 ) {
     value = 1.0;
 } else {
     value = ( RegionalDifficulty - 2.0 ) / 2.0;
 }
</syntaxhighlight>

因此，在简单难度下，由于区域难度最高为1.5，该值将始终为0；在困难难度下，由于区域难度最低为2.25，该值将至少为0.125；。

在简单难度中区域难度没有影响；普通难度中且满月时在一个区块中游玩21小时将达到最大影响；而困难难度中且满月时在区块中只要游玩{{frac|4|1|6}}小时就能达到最大影响，并且在游玩超过{{frac|16|2|3}}小时时将保持最大影响。

{{in|be}}区域难度不单独使用，仅作为副区域难度计算的中间量使用。

{{in|be}}由于漏洞，在困难难度中，几乎总为1{{info needed|何时不为1？}}；在普通难度中，仅随月相变化，在{{range|0.0|0.25}}之间。
