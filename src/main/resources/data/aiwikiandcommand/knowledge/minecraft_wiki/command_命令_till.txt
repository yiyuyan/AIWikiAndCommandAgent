在指定方向上犁地。

== 语法 ==
: <code>-{}-till <''方向：字符串''></code>

== 参数 ==
: ''方向：字符串''
:: 指定方向让[[智能体]]犁地。
:: 必须为以下之一：
::* <code>forward</code>——向前犁地。
::* <code>back</code>——向后犁地。
::* <code>left</code>——向左犁地。
::* <code>right</code>——向右犁地。
::* <code>up</code>——向上犁地。
::* <code>down</code>——向下犁地。
