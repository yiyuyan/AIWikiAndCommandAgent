这篇指南简要概述了{{edition|java}}[[Java版Beta 1.0|Beta 1.0]].x的更新内容。本指南假定读者对[[万圣节更新]]（Alpha 1.2.x版本）的内容有基本了解。

== 方块 ==
=== 更改 ===
{|{{Simple Guide table|Changed Blocks}}
|-
|[[箱子]]
|[[File:Chest (S) JE1.png|84px]]
|
* 当距离箱子太远或箱子被摧毁时，容器界面会关闭。
|-
|[[树叶]]
|[[File:Oak Leaves JE3 BE4.png|84px]]
|
* 再次引入了树叶枯萎机制。
|}

== 物品 ==
=== 更改 ===
{|{{Simple Guide table|Changed Items}}
|-
|[[鸡蛋]]
|[[File:Egg JE1 BE1.png|84px]]
|
* 现在可以被掷出了。掷出一个鸡蛋有可能会生成一只鸡。
|}

== 游戏内容 ==
=== 新内容 ===
{|{{Simple Guide table|New Gameplay}}
|-
|[[披风]]
|
* 为Mojang职员加入了披风。
|}

=== 更改 ===
{|{{Simple Guide table|Changed Gameplay}}
|-
|[[物品栏]]
|
* 加入了服务器端物品栏。
* 加入了物品提示。
* 物品不能再存储在合成槽中。
|}
