'''水下TNT（Underwater TNT）'''是一种[[爆炸]]时无视[[水]]的[[TNT]]变种，激活后为'''被激活的水下TNT（Primed Underwater TNT）'''。

== 生成 ==
水下TNT不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|B1= Sodium
|B2= TNT
|Output= Underwater TNT
|description={{only|bedrock|education}}
}}

== 破坏 ==
水下TNT被挖掘时会立刻被破坏。

{{Breaking table|only=be}}

水下TNT被破坏后会掉落自身。

== 用途 ==
{{main|TNT#用途}}

水下TNT的行为与TNT一致，但生成的是被激活的水下TNT而非被激活的TNT。

== 行为 ==
{{main|TNT#行为}}

被激活的水下TNT爆炸时无视范围内的[[水]]，其余性质与被激活的TNT一致。

== 你知道吗 ==
* 现实中炸药几乎不会含有钠，因为钠单质会与水剧烈反应而引燃炸药，钠离子则会吸水导致炸药受潮，其他形式的钠很少会存在。
