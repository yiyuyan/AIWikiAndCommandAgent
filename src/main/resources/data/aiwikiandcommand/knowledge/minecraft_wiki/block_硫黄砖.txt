'''硫黄砖（Sulfur Bricks）'''是[[硫黄]]制作的装饰性方块。

== 生成 ==
硫黄砖不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|A2=Polished Sulfur |B2=Polished Sulfur
|A3=Polished Sulfur |B3=Polished Sulfur
|Output=Sulfur Bricks,4
|type=Building block
}}

=== 切石 ===
{{Stonecutting
|Sulfur; Polished Sulfur
|Sulfur Bricks
}}

== 破坏 ==
挖掘硫黄砖的合适工具是镐。硫黄砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

硫黄砖被破坏后会掉落自身。
