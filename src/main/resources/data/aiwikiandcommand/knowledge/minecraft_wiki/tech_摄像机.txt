'''摄像机（Camera）'''是一个可以捕获并存储图像的物品和生物。在[[教育版]]中，它能配合[[相片簿]]使用来创建照片收藏<ref>https://education.minecraft.net/support/knowledge-base/using-cameras-portfolios/</ref> 。

摄像机同时存在为[[方块]]、[[物品]]、[[实体]]，下文分别称'''摄像机方块'''、'''摄像机物品'''、'''摄像机实体'''。

== 生成 ==
摄像机方块不会生成在世界中。

摄像机实体由摄像机物品生成。

== 获取 ==
{{see also|Tutorial:获取任意物品}}
摄像机无法在未开启[[作弊]]的[[生存模式]]的世界中获取。

{{in|be}}摄像机物品是不可通过{{cmd|give}}获取的物品，不存在于[[创造模式物品栏]]中，只能通过存档编辑或[[附加包]]获得。

{{in|ee}}摄像机物品可以通过[[创造模式物品栏]]获得。

== 破坏 ==
摄像机方块被挖掘时会立刻被破坏。

{{Breaking table|only=be}}

摄像机方块被破坏后不会掉落。

== 掉落物 ==
摄像机实体死亡时不掉落任何[[物品]]或[[经验]]。

== 用途 ==
摄像机方块仅用于为摄像机物品提供物品模型，没有其他用途或行为。

=== 拍摄 ===
{{control|使用}}摄像机物品可以拍摄一张屏幕截图。{{control|潜行}}时{{control|使用}}摄像机物品会拍摄特写照片。对方块顶部{{control|使用}}摄像机物品会将其放置为摄像机实体。

{{in|be}}开启{{pa|Vibrant Visuals|}}后，摄像机拍摄的照片无法正确渲染内容。

拍摄后的照片会被保存在{{only|ee|for=[[相片簿]]}}或{{only|be|for={{filename|screenshots}}文件夹}}中：
* Windows：{{filepath|%LOCALAPPDATA%\Packages\MinecraftUWP_8wekyb3d8bbwe\LocalState\screenshots\<''世界文件夹''>\photos}}
* Android：{{filepath|/sdcard/Android/data/com.mojang.minecraftpe/files/screenshots/<''世界文件夹''>/photos}}

=== 燃料 ===
摄像机物品可以用作[[熔炉]]、[[高炉]]或[[烟熏炉]]的[[燃料]]，每个摄像机物品可烧炼1.5个物品。

== 行为 ==
摄像机实体是一种[[生物]]。

玩家对摄像机实体长按{{control|交互}}会使其拍摄镜头对准的画面。

{{in|be}}摄像机实体不能正常拍摄截图。

类似于[[盔甲架]]，许多生物会对环境中存在的摄像机实体有反应。

摄像机不具有类似[[船]]的结构完整性，会在生命值降低至{{hp|0}}时死亡。

{{in|be}}摄像机实体无法被[[目标选择器]]选中。

=== 受伤害行为 ===
摄像机只会受到{{only|ee|for={{cmd|kill}}指令}}、[[状态效果]]以及来自玩家的伤害，并免疫其他所有伤害。

摄像机受到玩家的伤害时会立即死亡，不会播放死亡音效和动画。

== 你知道吗 ==
* 摄像机底部的纹理被错误地扭转。
* 在MINECON 2012的Minecraft携带版展板以及Jbernhardsson的直播上，摄像机被指出可能在未来计划中给其添加合理的用途，例如提供更为简便的截图并分享的方式。<ref>{{ytl|YMhyX_lKWV4}}</ref>在BlockTalk的问答中，摄像机被简略地作为MCPE未来所计划的“共享”主题的一部分提到。<ref>{{ytl|Ruf6tvqsD84}}</ref>
