'''15w39a'''是[[Java版1.9]]的第26个快照，发布于2015年9月21日<ref>{{cite|url=http://mojang.com/2015/09/minecraft-snapshot-15w39a/|archive-url=1|archive=1|title=Minecraft 1.9 snapshot 15w39c|author=Dinnerbone|website=Mojang.com|date=Sep 21, 2015}}</ref>，更改了一些生物的实体高度，并修复了一些漏洞。

== 更改 ==
=== 生物 ===
'''[[苦力怕]]'''
* 高度从1.8格更改为1.7格。

'''[[骷髅]]'''
* 高度1.95格从更改为1.99格。

'''[[凋灵骷髅]]'''
* 尺寸从2.535格高、0.72格宽更改为2.4格高、0.7格宽。

'''[[牛]]'''
* 高度从1.3格更改为1.4格。

'''[[哞菇]]'''
* 高度从1.3格更改为1.4格。

'''[[铁傀儡]]'''
* 高度从2.9格更改为2.7格。

'''[[鱿鱼]]'''
* 边长大小从0.95格更改为0.8格。

'''[[村民]]'''
* 高度1.8格从更改为1.95格。

'''[[狼]]'''
* 高度从0.8格更改为0.85格。
