'''磨制朱砂墙（Polished Cinnabar Wall）'''是[[磨制朱砂]]制作的[[墙]]。

== 生成 ==
磨制朱砂墙不会生成在世界中。

== 获取 ==

== 破坏 ==
挖掘磨制朱砂墙的合适工具是镐。磨制朱砂墙需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

磨制朱砂墙被破坏后会掉落自身。

== 用途 ==
{{main|墙#用途}}
磨制朱砂墙可用于装饰，并有与其他墙相似的特性。
