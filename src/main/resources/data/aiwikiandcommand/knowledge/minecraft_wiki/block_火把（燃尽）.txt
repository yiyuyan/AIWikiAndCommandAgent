'''火把（燃尽）（Torch (Burnt-out)）'''是熄灭的[[火把]]，不会提供亮度。

== 生成 ==
[[火把]]被放置后，会在几个[[随机刻]]后变为火把（燃尽）。

== 获取 ==
火把（燃尽）只能通过破坏对应方块获得。

== 破坏 ==
火把（燃尽）被挖掘时会立刻被破坏。

{{Breaking table/manual|only=je|nonetherite=1
|{{BlockLink|id=Torch (Burnt-out)|火把（燃尽）}}|0|none
}}

火把（燃尽）被破坏后会掉落自身。

== 用途 ==
{{see also|火把#用途}}

火把（燃尽）不会发光，也不能用于融化[[雪]]和[[冰]]。

=== 点燃 ===
对着火把（燃尽）{{ctrl|使用}}打火石可以将其变为火把。使用[[发射器]]发射打火石不能将其变为火把。
