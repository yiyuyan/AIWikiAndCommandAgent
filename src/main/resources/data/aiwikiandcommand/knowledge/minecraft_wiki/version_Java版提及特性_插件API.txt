'''插件API'''<ref>{{tweet|dinnerbone|184570898920112128}}</ref>'''（Plugin API，社区中亦称Workbench）'''是计划允许Mod作者更容易增加更多内容到游戏中。和Mod相比之下，插件不需要在[[minecraft.jar]]内改变任何东西。但是他们也会稍微限制一些权限。<ref>{{tweet|dinnerbone|184585004389646336}}</ref><ref>[http://getsatisfaction.com/mojang/topics/official_modding_support_modding_api '''模块化 API:''' 模块化 API]</ref>Bukkit团队将会帮助开发官方插件API。<ref>[http://www.mojang.com/2012/02/minecraft-team-strengthened/ '''模块化 API:''' Bukkit 研发 API]</ref>

插件API已经在一些版本更新计划提及，[[Java版Alpha v1.0.1_01|Alpha v1.0.1_01]]<ref>{{notch|772794270|Server scripting|July 5, 2010}}</ref>发布后不久，这个计划就定在1.3正式版，然后被推迟到1.4，又定在1.5，但没有完全实现。之后被无限推迟。<ref>{{tweet|jeb|246175831037202432}}</ref><ref>{{tweet|dinnerbone|272733076738682881}}</ref>

== 功能 ==
根据计划，插件应该更容易找到，下载并安装<ref>{{tweet|dinnerbone|184583108547444736}}</ref><ref>[http://www.youtube.com/watch?v=FPUn5-vRNeM '''模块化 API:''' Curse 访问 Jeb（第一部份）]</ref><ref>[http://www.youtube.com/watch?v=Mv8Sz2sqBB0 '''模块化 API:''' Curse 访问 Jeb（第二部份)]</ref>API将不会和Bukkit一样。

以下功能是部份已计划的插件API：
* 插件将会兼容多人模式。
* 它的目的是让Mod（或者说插件）更容易地安装，并且让它更不容易破坏你的游戏。
* Minecraft官网将会改进，帮助带来最有趣的社区插件和自定义地图的界面。
* 这将更容易添加和动画模型。
* 改变游戏的存储数据方式，对于它的许多材料和物品。
