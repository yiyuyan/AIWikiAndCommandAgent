广播一条关于你的信息。

== 语法 ==
* '''Java版'''
:<code>me <action></code>

* '''基岩版'''
: <code>me <message: message></code>

== 参数 ==
{{argument|action|message|message: message|CommandMessage}}
: 指定要显示的消息。
: {{arg desc|je=message|be=CommandMessage}}
: {{in|je}}使用了<code>emote_command</code>[[聊天类型]]。
