'''Block by Block'''（逐块构筑/块块相依）是一个基于[[Mojang]]与[http://unhabitat.org 联合国人类居住区规划署（联合国人居署/UN-HABITAT）]之间的合作关系的慈善项目。此机构的目标是提升年轻人规划城区公共空间的能力。Block by Block项目的目标是为改善世界各国的公共空间筹集资金，主要聚焦于发展中国家的贫困社区。<ref name = "about">https://blockbyblock.org/about</ref>

== 历史 ==
非盈利性的Block by Block最初在Byggtjanst的帮助下创立于2012年。Byggtjanst是一家瑞典公司，曾测试过Minecraft在为年轻人设计低成本住房领域的应用并取得了良好的结果。经过了在肯尼亚和尼泊尔的最初尝试后，Block by Block现在已应用于全世界。

该项目目前在非洲、拉丁美洲、亚洲和欧洲共35个国家运行。Mojang和微软公司是Block by Block计划的主要支持者。

== 途径 ==
# 基于图像、规划、Google地图以及其他可用信息，联合国人类居住区规划署在Minecraft中制作一个公共空间的基本模型。
# 联合国人类居住区规划署安排一名Minecraft专家来提供Minecraft培训与支持。
# 与青年，项目人员和合作伙伴一起举办社区参与讲习班，以此来：
* 培训参与者有关Minecraft建模的基础知识。
* 促进有关公共空间问题的对话。
* 结合参与者们提出的想法制作Minecraft模型。
* 整理模型中包含的想法。

在那之后：
# 向参加者简要介绍活动并将他们分成2-4人的小组，向每组提供一台计算机。
# 参与者有足够的时间在Minecraft中把他们的想法展现出来。根据他们的信息技术知识与Minecraft知识水平，这大概会花2至4天时间。
# 参加者向利益相关者展示他们的Minecraft模型——包括城市专业人员，政策制定者，政府官员和联合国人类居住区规划署工作人员。设计将被在审计会议上讨论，并由利益相关者们商定最终设计。
# Minecraft设计方案将被进行专业设计，最后是预算处理。
