'''<samp>grass_carried</samp>'''<ref name="MCForums">https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-discussion/1968560-my-report-on-3-strange-new-blocks</ref>是一种用于渲染[[草方块]]物品模型的方块。

== 获取 ==
grass_carried只能通过编辑物品栏获得。

== 破坏 ==
grass_carried被挖掘时会立刻被破坏。

{{Breaking table/manual|{{BlockLink|id=grass-block|grass_carried}}|0|}}

grass_carried被破坏后不会掉落。

== 外观 ==
grass_carried的外观与草方块较为相似，但有两个明显的差异：
* grass_carried的顶部纹理颜色与草方块的明显不同，并且相比当时的常规草方块，grass_carried的顶面与侧面颜色更为统一。
** 这是因为grass_carried使用预先染色的纹理，而草方块使用灰度纹理进行染色。
* 草方块底部使用[[泥土]]的纹理，但grass_carried底部使用草方块侧面的纹理：[[File:Grass_Block_(facing_NWU)_BE3.png|32px]]

== 用途 ==
尽管使用了相似的外观，grass_carried在行为上与草方块几乎没有任何相同之处。
* grass_carried可被瞬间挖掘，破坏后不产生掉落物。<ref name=BreakingFootage">https://youtu.be/djvCj4tZdNM?t=9m06s</ref>
* grass_carried不能被转变为[[耕地]]。<ref name="MCForums"/>
* 在grass_carried上方放置固体方块不会使其转变为泥土。
* 需要放置在草方块上的方块，如[[花]]和[[甘蔗]]，不能放在grass_carried上方。<ref name="MCForums"/>

grass_carried在物品栏中没有图标。<ref>https://youtu.be/djvCj4tZdNM?t=8m35s</ref>
