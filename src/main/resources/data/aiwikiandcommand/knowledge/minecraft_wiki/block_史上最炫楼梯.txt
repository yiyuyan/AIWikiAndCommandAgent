'''史上最炫楼梯（Swaggiest stairs ever{{sic}}）'''是下界合金质的[[楼梯]]。

== 生成 ==
史上最炫楼梯会于“missing”维度中，在信标基座旁自然生成7个，作为通往箱子的阶梯。

== 获取 ==
史上最炫楼梯只能通过破坏史上最炫楼梯获得。

== 破坏 ==
挖掘史上最炫楼梯的合适工具是镐。史上最炫楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table/manual|only=je|nocopper=1|
{{BlockSprite|netherite stairs}} 史上最炫楼梯|50|wooden pickaxe
}}

史上最炫楼梯被破坏后会掉落自身。

== 用途 ==
{{see also|楼梯#用途}}
与其他下界合金质物品一样，[[物品实体]]形式的史上最炫楼梯会漂浮在[[熔岩]]上，且不会被[[火]]和熔岩摧毁，但仍可被[[仙人掌]]或爆炸等方式摧毁。
