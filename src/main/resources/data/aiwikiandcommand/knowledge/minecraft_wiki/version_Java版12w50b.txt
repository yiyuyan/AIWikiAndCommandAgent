'''12w50b'''是[[Java版1.4.6]]的第3个，也是最后一个快照，发布于2012年12月14日<ref>{{cite|url=http://mojang.com/2012/12/minecraft-snapshot-12w50b/|archive-url=1|archive=1|title=Minecraft Snapshot 12w50b|author=Jens Bergensten|website=Mojang.com|date=Dec 14, 2012}}</ref>，发布以修复快照[[12w50a]]里的漏洞和崩溃。

== 更改 ==
=== 游戏内容 ===
'''[[魔咒]]'''
* 荆棘魔咒的伤害现可自定义。
* 火焰保护魔咒现在会更快地熄灭玩家身上的[[火]]。
* 爆炸保护现在减少爆炸反冲。
