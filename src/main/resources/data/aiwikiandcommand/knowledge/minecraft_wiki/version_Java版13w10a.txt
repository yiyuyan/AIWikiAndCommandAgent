'''13w10a'''是[[Java版1.5]]的第14个快照，发布于2013年3月4日<ref>{{cite|url=http://mojang.com/2013/03/minecraft-snapshot-13w10a/|archive-url=1|archive=1|title=Minecraft Snapshot 13w10a|author=Jens Bergensten|website=Mojang.com|date=Mar 4, 2013}}</ref>，加入了探测铁轨的纹理和史莱姆生成率根据月相改变的特性。

== 新内容 ==
=== 方块 ===
'''[[探测铁轨]]'''
* 加入了激活的[[探测铁轨]]的纹理。

== 更改 ==
=== 生物 ===
'''[[史莱姆]]'''
* 生成率现在会根据当前月相而改变。
