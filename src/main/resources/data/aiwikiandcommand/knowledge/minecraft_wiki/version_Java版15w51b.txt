'''15w51b'''是[[Java版1.9]]的第48个快照，发布于2015年12月17日<ref>{{cite|url=http://mojang.com/2015/12/minecraft-snapshot-15w51a/|archive-url=1|archive=1|archive-time=20151219012157|title=Minecraft 1.9 snapshot 15w51b|author=Searge|website=Mojang.com|date=Dec 17, 2015}}</ref>，修复了关于生物AI与寻路的一个漏洞与一项崩溃。

== 更改 ==
=== 生物 ===
'''[[蠹虫]]'''
* 现在若[[游戏规则]]<code>doMobGriefing</code>设定为{{cd|false}}，则不会进入方块。
