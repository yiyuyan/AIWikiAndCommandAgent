'''时间线标签（Timeline Tags）'''是[[时间线]]的组合。

{{TOC|right}}

== 使用 ==
在[[维度类型]]定义文件中，时间线标签被用于指定当前维度类型中所包含的多个时间线。示例文件参见{{slink|Tutorial:环境属性|设置环境属性}}。
