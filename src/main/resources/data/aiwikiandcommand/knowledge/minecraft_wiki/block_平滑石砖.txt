'''平滑石砖（Smooth Stone Bricks）'''是[[石砖]]的已移除变种。

== 生成 ==
平滑石砖不会生成在世界中。

== 获取 ==
平滑石砖不能在生存模式中正常获得，但可以通过[[创造模式]]中使用{{ctrl|选取方块}}或[[命令]]获得。

== 破坏 ==
挖掘平滑石砖的合适工具是镐。平滑石砖需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table/manual|only=be|{{BlockSprite|Stone Bricks}} 平滑石砖|1.5|wooden pickaxe}}

平滑石砖被破坏后会掉落自身。

== 用途 ==
平滑石砖目前仅用于装饰。
