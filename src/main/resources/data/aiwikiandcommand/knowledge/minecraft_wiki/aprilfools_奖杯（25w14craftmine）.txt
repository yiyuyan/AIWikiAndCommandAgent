'''奖杯（Trophy）'''是一种装饰性方块。

== 生成 ==
奖杯不会生成在世界中。

== 获取 ==
玩家获得进度“[[进度/25w14craftmine#advancements-anchor-feats.eat_your_veggies|权威马铃薯杀手]]”时会获得奖杯“超级马铃薯怪”（Mega Spud）。

对[[微光之门]]{{ctrl|使用}}试炼钥匙或不祥试炼钥匙会获得奖杯“差点意思”奖牌（"Close But No" Medal）。

金奖杯（Golden Cup）不能在生存模式中正常获得，其亦不在创造模式物品栏内，但可以通过命令等方式获取。

== 破坏 ==
奖杯被挖掘时会立刻被破坏。

{{Breaking table/manual|only=je|nocopper=1
|{{BlockLink|id=trophy}} 奖杯|0
}}

奖杯被破坏后会掉落自身。

== 用途 ==
玩家从矿境返回[[主世界]]时，物品栏中的奖杯不会被清除。
