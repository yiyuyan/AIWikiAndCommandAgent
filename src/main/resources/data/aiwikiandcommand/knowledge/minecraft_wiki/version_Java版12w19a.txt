'''12w19a'''是[[Java版1.3.1]]的第5个快照，发布于2012年5月10日<ref>{{cite|url=http://mojang.com/2012/05/minecraft-snapshot-12w19a/|archive-url=1|archive=1|title=Minecraft Snapshot 12w19a|author=Jens Bergensten|website=Mojang.com|date=May 10, 2012}}</ref>，修复了一些漏洞。

== 新内容 ==
=== 方块 ===
'''[[可可果]]'''
* 在丛林中加入了可可果。
** 生成于丛林木。
** 拥有3个生长阶段，掉落可可豆的数量取决于生长阶段。

'''[[砂岩]]和[[石砖]]'''
* 砂岩和石砖有了正确的名字（例子：平滑砂岩、裂纹石砖）。

=== 世界生成 ===
'''[[巨型生物群系]]'''
* 加入了巨型生物群系[[世界类型]]。

== 更改 ==
=== 物品 ===
'''[[可可豆]]'''
* 更改了纹理。
* 破坏丛林木[[树叶]]不再掉落可可豆。

'''[[曲奇]]'''
* 现在回复{{Hunger|2}}饥饿值而不是{{Hunger|1}}。

=== 常规 ===
'''[[奖励箱]]'''
* 如果附近有一样高度的方块，[[火把]]会生成于奖励箱周围。

== 修复 ==
; 修复了6个漏洞
: 附魔弓和剑现在再次能正常工作了（其他工具现在有提示框了）。
: 末地和下界现在再次能正常生成了。
: 物品修复现在再次能正常工作了。
: 从创造模式开始的游戏不会再从生存模式开始了。
: 奖励箱现在再次能正常工作了。
: 粒子不能再激活上面有箭矢的木质压力板了。</onlyinclude>

== 你知道吗 ==
* 在此版本中，加载单人游戏世界时，需先将{{filename|minecraft.zip}}中的{{filepath|server/minecraft_server.jar}}（服务端）手动放置到{{filepath|.minecraft/server}}下才能继续加载世界。
