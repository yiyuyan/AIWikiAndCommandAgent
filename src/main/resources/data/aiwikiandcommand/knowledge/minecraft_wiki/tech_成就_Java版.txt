{{Quote|我喜欢成就。我知道许多人不喜欢，但是我喜欢。我有个想法，把成就系统做得比较像游戏里的探索。<br>你会在一个树状的成就系统中看到第一个成就，当你完成顶端成就后，你可以解锁剩下的成就。第一个成就可能是砍下一棵树，或是杀一只鸡，然后成就树的分支引导你做更多事。希望它能鼓励人们尝试新的领域。<br>它也可能成为一项艰巨的任务，比如杀死一头龙什么的，这会把一些故事融入到成就树中。<br>我想让这些成就成为你乐意尝试的事情，而不是必须得去做的工作。人们可以遵循它们，但仅仅是在他们想这么做的时候。|[[Notch]]在[http://www.gamasutra.com/view/news/33220/Interview_Markus_Persson_On_Bringing_Achievements_to_Minecraft.php Gamasutra的一次采访]中}}

'''成就（Achievements）'''是[[Java版]]中已移除的挑战系统，由[[进度]]取代。

== 描述 ==
[[File:TakingInventory.png|256px|right|成就完成时弹出的信息]]

[[File:AchievementInterface.png|256px|right|成就界面，第一个成就已完成]]

[[File:AllJavaAchievementsCompleted.png|256px|right|完整的成就树，所有成就已完成]]

{{in|java}}成就系统的界面呈树状结构。要获得部分成就必须获得其前提成就。<!--起初，成就树显示在界面左侧，右侧显示一个成就树的缩略图。小图从最终版中去除了，仅仅显示成就树。【作为历史内容应当移至历史栏目 ，但变更时间没有确定，故暂时注释保留】-->成就树的背景样式类似游戏内的[[世界生成]]模式（界面自顶部开始主要分层分布[[泥土]]、[[石头]]、[[基岩]]，其中石头层有类似于游戏内的[[矿石/旧矿物图表#洞穴与山崖前|矿石分布]]）。玩家可按住、拖动鼠标与滚轮缩放查看成就树的详细分支。

在此界面中，玩家离达成一个成就的目标越近，显示的悬浮文本内容就越详细：
* 已获得的成就以“名称/描述/已得到！”的形式呈现（例如“{{tr|获得木头|獲得木頭}}/{{tr|摧毁树木直到跳出一个木头方块|持續破壞樹木直到原木掉落為止}}/{{tr|已得到！|已完成！}}”）。
* 尚未获得、玩家已获得了全部前提成就的成就以“名称/描述”的形式呈现。
* 尚未获得、玩家与其相距一个或两个前提成就的成就以“名称/需要XX”的形式呈现（例如“{{tr|结束了。|結束了。}}/{{tr|需要‘结束了？’|需要「結束了？」}}”）。
* 尚未获得、玩家与其相距三个前提成就的成就以“???/需要XX”的形式呈现（例如“???/{{tr|需要‘开始了？’|需要「一切的開端？」}}”）。
* 尚未获得、玩家与其相距四个前提成就的成就不会呈现；只会显示一个图标，没有悬浮文本。
* 尚未获得、玩家与其相距四个前提成就以上的成就不会显示（包括图标）。

成就的获取以每个玩家及每个世界为基准：每个新的世界中的每个新玩家均可以在一棵独立的成就树中获取成就。

当玩家获得一项成就时，会在同一世界所有玩家的聊天框内显示“{{tr|获得成就！|獲得成就！}}”字样和该成就的名称。

成就可以在任何[[游戏模式]]中获得，因此一些难以获得的成就可以轻松地在[[创造模式]]中获得，比如'''{{tr|在铁路上|暢行無阻}}'''，'''{{tr|当猪飞的时候|等哪天豬會飛了…噢！}}'''和'''{{tr|狙击手的对决|狙擊手對決}}'''等。
* '''{{tr|见鬼去吧|以牙還牙}}'''例外，因为该成就需要通过[[恶魂火球]]击败恶魂获得，而恶魂不会在创造模式攻击玩家。

可以通过命令{{cmd|achievement}}给予或移除成就。当使用此命令给予玩家一项成就时，其前置成就也会一并获取。

可以通过删除{{filepath|saves/<''世界名''>/stats}}文件夹来重置所有成就，但这么做也会重置[[统计]]数据。

== 历史 ==
{{HistoryTable
|{{HistoryLine||2011年2月25日|link=http://www.gamasutra.com/view/news/33220/Interview_Markus_Persson_On_Bringing_Achievements_to_Minecraft.php|
在Gamasutra的一次采访中，[[Notch]]说：
{{quote|我喜欢成就。我知道许多人不喜欢，但是我喜欢。我有个想法，把成就系统做得比较像游戏里的探索。你会在一个树状的成就系统中看到第一个成就，当你完成顶端成就后，你可以解锁剩下的。}}

他还提到：
{{quote|第一个成就可能是砍下一棵树，或是杀一只鸡，然后成就树的分支引导你做更多事。希望它能鼓励人们尝试新的领域。它也可能成为一项艰巨的任务，比如杀死一头龙什么的，这会把一些故事融入到进度树中。}}

最后，Notch被问及“成就是否会引导玩家按照预先设定好的路径进行冒险，而不是像当前这样鼓励探索和发现”。他回答道：
{{quote|绝对不会。我想让这些成就成为你乐意尝试的事情，而不是必须得去做的工作。人们可以遵循它们，但仅仅是在他们想这么做的时候。}}
}}
|{{HistoryLine||2011年3月18日|link={{notch|3940195633/the-state-of-minecraft}}|Notch在他的博客上谈到了成就和[[统计]]。他说了如下内容：
{{quote|我正着手于成就和统计系统。一个设计问题是离线模式和当你重新连接时的同步，但是现在已经解决了。在办公室我们有一帮人不喜欢游戏里的成就系统，所以目标是设计他们喜欢的东西。}}

同时，他也说成就系统不会成为琐碎的工作：
{{quote|成就系统不会成为琐碎的工作，如 ‘砍1000棵树’，而是一些挑战如‘骑着猪跳下悬崖’。然而统计系统会用来记录你砍了多少棵树。长期的计划是，可以在minecraft.net的统计页面显示你的成就和统计，如果你想要炫耀的话。}}}}

== 你知道吗 ==
* “获得成就！（Achievement Get!）”引自一个梗：早期日文版《[[wzh:超級瑪利歐陽光|{{tr|超级马力欧 太阳之光|超級瑪利歐陽光}}]]》''（Super Mario Sunshine）''截图显示当{{tr|马力欧|瑪利歐}}获得阳光值时会显示“获得阳光！（Shine Get!）”。因为这些梗与截图引起的广泛关注，“获得XX！（[noun] Get!）”后来成为图片中流行的用语，Notch也经常浏览这些图片。
