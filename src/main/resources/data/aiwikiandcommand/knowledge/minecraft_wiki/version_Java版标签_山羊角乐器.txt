'''山羊角乐器标签（Instrument Tags）'''是[[山羊角乐器]]的组合。

{{TOC|right}}

== 使用 ==
山羊角乐器标签用于控制生成的山羊角的种类。

== 標籤清單 ==
{{tag list|mode=missing|instrument}}<!--自动检查缺失的模板，请勿移除-->

=== goat_horns ===
* 在创造模式物品栏中显示的所有不同乐器的山羊角。

{{tag list|instrument|goat_horns}}

=== regular_goat_horns ===
* 普通山羊掉落的山羊角。
* 可从[[掠夺者前哨站]]战利品箱子中获取的山羊角。

{{tag list|instrument|regular_goat_horns}}

=== screaming_goat_horns ===
* 尖叫山羊掉落的山羊角。

{{tag list|instrument|screaming_goat_horns}}
