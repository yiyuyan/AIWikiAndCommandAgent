'''一只蚂蚁（An Ant）'''是用于模拟[[wzh:兰顿蚂蚁|兰顿蚂蚁]]的方块。

== 生成 ==
一只蚂蚁固定在“ant”维度中<code>0 1 0</code>处生成，朝向北方。

== 获取 ==
一只蚂蚁没有对应的物品形式。

== 破坏 ==
一只蚂蚁不能被挖掘破坏。

{{Breaking table/manual|only=je|nocopper=1|
{{BlockSprite|an ant}} 一只蚂蚁|-1|none
}}
一只蚂蚁被破坏后不会掉落。

== 用途 ==
当一只蚂蚁的下方为[[黑色混凝土]]或[[白色混凝土]]时，其每[[游戏刻]]会按照如下的兰顿蚂蚁的规则进行一次移动，并改变其下方的方块。

当一只蚂蚁的下方为黑色混凝土时，右转90度，并将其下方的方块改为白色混凝土，然后向前移动一格；当一只蚂蚁的下方为白色混凝土时，左转90度，并将其下方的方块改为黑色混凝土，然后向前移动一格。

一只蚂蚁在移动时会无视途中的任何方块而直接将其替换，这也包括其他的一只蚂蚁。如果多个一只蚂蚁相撞，它们会合并为一个方块。

如果一只蚂蚁的下方不是黑色混凝土或白色混凝土，一只蚂蚁不会移动。
