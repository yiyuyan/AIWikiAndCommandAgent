'''12w24a'''是[[Java版1.3.1]]的第11个快照，发布于2012年6月14日<ref>{{cite|url=http://mojang.com/2012/06/minecraft-snapshot-week-24/|archive-url=1|archive=1|title=Minecraft Snapshot Week 24|author=Jens Bergensten|website=Mojang.com|date=Jun 14, 2012}}</ref>，加入了局域网[[多人游戏]]（LAN）以及{{cmd|tp}}命令，并修复了一些漏洞。

== 新内容 ==
=== 游戏内容 ===
'''[[LAN]]'''
* 允许在本地服务器的用户连接到一个玩家的单人游戏中。
** 玩家可以使用{{cmd|publish}}来广播到局域网让其他玩家加入游戏。
*** 这仍在开发中，因此还缺少一些必要的设置，例如玩家会得到什么游戏模式、是否能够使用作弊。
*** 这个命令是暂时工作的，玩家甚至不能在未开启作弊的情况下使用
* LAN在未来将会做成独立GUI界面。

=== 命令格式 ===
'''{{cmd|tp}}'''
* 允许玩家互相传送。

== 更改 ==
=== 方块 ===
'''[[拉杆]]'''
* 现在能把拉杆放置在[[方块]]的底部。

'''[[末影箱]]'''
* 现在每个玩家有了各自的末影箱物品栏，而不是整个世界共用一个。
* 现在除非使用精准采集魔咒，玩家破坏末影箱会掉落8个[[黑曜石]]而不掉落自身。

=== 物品 ===
'''[[末影珍珠]]'''
* 更改了纹理。

=== 常规 ===
'''[[语言]]文件'''
* [[末地传送门框架]]现在有了提示框。

== 修复 ==
; 修复了16个漏洞
: 修复了末影珍珠在物品栏中不正确对齐的漏洞。
: 修复了所有语言中，双箱子界面中显示“大箱子”的漏洞。
: 修复了“破坏物品”提示框偶尔在其他页面上显示的漏洞。
: 部分修复了游戏不能保存玩家的数据、停止生成区块和使所有生物停止活动的漏洞。这些漏洞有时仍会出现。
: 修复了末影龙在被击中一次后不会对玩家造成伤害的漏洞。
: 修复了爆炸不会推动玩家的漏洞。
: 修复了不能在出生点保护范围内使用铁桶盛起水的漏洞。
: 修复了与村民交易时遗留在交易界面第二格中的物品丢失的漏洞。
: 修复了缺失的声音（水中移动、火焰、火焰熄灭、下界传送门、熔岩流动、熔岩滴落）。
: 修复了在右键点击时尝试使用绊线的漏洞。
: 纹理包文件夹按钮现在能在macOS上正常工作了。</onlyinclude>
