'''14w03b'''是[[Java版1.8]]的第5个快照，发布于2014年1月16日<ref>{{cite|url=http://mojang.com/2014/01/minecraft-snapshot-14w03a/|archive-url=1|archive=1|title=Minecraft Snapshot 14w03b|author=Dinnerbone|website=Mojang.com|date=Jan 16, 2014}}</ref>，发布以修复[[14w03a]]里的漏洞和崩溃。

== 修复 ==
{{fixes|fixedin=14w03b|prefix=Minecraft|showdesc=1
|;old
|17156|在{{cmd|give|link=none}}命令使用高物品ID值时，会{{tr|抛出|丟擲|投擲}}<code>ArrayIndexOutOfBoundsException</code>异常。
|40420|纹理和渲染有问题。
|45254|加粗文字不能被正确右对齐或居中对齐（无效的字符串长度）。
|;dev
|44533|活塞缩回时，活塞会被复制，且只有被复制出的活塞有动画。
|44606|放置门时，已放置的方块可以被替换。
|44673|门的复制漏洞（使用红石火把实现）。
|44702|选择器参数在预期位置不起作用。
|44870|命名ID在大多数的NBT标签中不起作用。
|44886|无法执行{{cmd|spawnpoint|link=none}}命令。
|;previous
|44990|铁栏杆、普通玻璃板和炼药锅不透明。
|44993|玩家（有自定义皮肤）的头颅有显示错误。
|45004|放置花盆会导致游戏崩溃。
|45014|Realms中被邀请的玩家的皮肤有显示错误。
|45018|如果玩家被杀死，其皮肤上的帽子部分会消失。
|45026|<code>Hopper: java.lang.NullPointerException: Rendering screen</code>。
|45032|对末影箱使用{{cmd|fill|link=none}}命令后导致游戏崩溃。
|45034|涉及天空的渲染错误。
|45065|当玩家在末地死亡后在床上复活时，游戏会崩溃。
}}</onlyinclude>
