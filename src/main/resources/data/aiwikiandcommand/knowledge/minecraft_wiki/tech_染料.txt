=== 其他 ===
; 青金石
{{main|青金石#获取}}
[[青金石]]可以通过挖掘[[青金石矿石]]掉落，每个矿石掉落4-9个。使用[[时运]]魔咒的[[镐]]可以增加掉落物。它们可用于合成蓝色染料。

; 骨粉
{{main|骨粉#获取}}
[[骨粉]]可以通过[[堆肥]]获取。它们可用于合成白色染料。

; 可可豆
{{main|可可豆#获取}}
[[可可豆]]可以通过收获可可果获得，每个成熟的可可果会掉落3份，但每个未成熟的可可果都只会掉落1份。它们可用于合成棕色染料。

; 墨囊
{{main|墨囊#获取}}
[[墨囊]]会在[[鱿鱼]]死亡时掉落，每只鱿鱼掉落1-3个。使用[[抢夺]]魔咒的武器可以增加掉落物。它们可用于合成黑色染料。

染料能在[[绵羊]]身上{{control|使用}}来改变羊毛的颜色。对染色的绵羊使用剪刀后，它们会掉落相应颜色的羊毛，也会在羊毛重新长出时保留羊毛的颜色。[[繁殖]]染色的绵羊会使小绵羊的羊毛保留其中一个双亲的颜色或变成双亲颜色的结合。颜色结合使用与染料一样的规则，例如红色和黄色的绵羊会生出橙色的小绵羊。因为染色的绵羊会剪出无限的羊毛，所以染色和剪羊毛比直接染羊毛效率高。

染料也能在驯服的[[狼]]或者[[猫]]身上使用。对着驯服的狼或者猫{{control|使用}}染料会改变狼或者猫颈圈的颜色（默认为红色）。

{{in|be}}染料还可以在创造模式中将[[潜影贝]]的壳染色。

==== 盔甲 ====
[[File:dyegraph.png|200px|缩略图|在皮革胸甲显示两个染料的所有组合]]

皮革[[盔甲材料|材质]]的[[盔甲]]和[[马铠]]以及[[狼铠]]可以通过以下方法染色：
* {{in|je}}直接在工作台上用染料给皮革盔甲染色。
* {{in|be}}将皮革盔甲或皮革马铠浸入已加入染料的[[炼药锅]]中。

皮革盔甲能通过和染料合成来给它们染色。皮革盔甲共有5,713,438种可能的颜色，因为可以把多于一个染料放在工作台里和皮革盔甲合成。盔甲能被染色几次，过去的颜色会影响最后的结果。对炼药锅{{ctrl|使用}}染色的盔甲能恢复它们原本的颜色。

游戏中计算被染料（<math>C_1, C_2</math>……）染色的盔甲最终颜色的公式为<math>\frac{\max(C.r, C.g, C.b)}{\max(\bar{C}.r, \bar{C}.g, \bar{C}.b)} \cdot \bar{C}</math>，伪代码如下：
<pre>
initialize sumR = sumG = sumB = sumMax = 0

for each color:
 sumR = sumR + color_s_Red
 sumG = sumG + color_s_Green
 sumB = sumB + color_s_Blue
 sumMax = sumMax + max(color_s_Red, color_s_Green, color_s_Blue)
 
averageRed = sumR / numberOfColors
averageGreen = sumG / numberOfColors
averageBlue = sumB / numberOfColors
averageMaximum = sumMax / numberOfColors
 
maximumOfAverage = max(averageRed, averageGreen, averageBlue)
gainFactor = averageMaximum / maximumOfAverage
 
resultRed = averageRed * gainFactor
resultGreen = averageGreen * gainFactor
resultBlue = averageBlue * gainFactor
</pre>

由于此算法的特性，最后的颜色不会比输入颜色的平均色更深（通常会更浅）；最后的颜色也不会比最浅的输入颜色更浅。此公式也不会产生高于255的RGB数值（对于8-bit RGB颜色来说无效）。

在[[铁砧]]上经过了重命名的皮革盔甲被染色或洗净后仍会保留其自定义名称。

=== 其他用途 ===
以下物品有其他的用途：
* [[墨囊]]可用于合成[[书与笔]]，出售给图书管理员[[村民]]换取[[绿宝石]]，以及去除[[告示牌]]文字的发光效果。
* [[可可豆]]可用于合成[[曲奇]]，以及种植在[[丛林木]]上来获取更多可可豆。
* [[青金石]]可用于合成[[青金石块]]，以及用作在[[附魔台]]上附魔的材料。
* [[骨粉]]可用于合成[[骨块]]，以及催熟各种植物、动物方块和下界菌。

这些物品能用于合成染料。{{in|je}}这些物品不能直接用作染料；{{in|bedrock}}这些物品仅在合成配方（给[[旗帜]]添加图案除外）中可以被视为染料，进而直接作为原材料使用。

== 颜色 ==
{{redirect|颜色|文字使用的颜色代码|格式化代码#颜色代码}}
每种染料都对应了某种颜色，染色方块或物品上会使用这些颜色进行着色。

; 纹理漫反射颜色
[[旗帜]]、皮革盔甲、皮革马铠、狼铠、[[信标]]光柱、[[猫]]和[[狼]]的项圈、[[绵羊]]羊毛和[[热带鱼]]花纹的颜色。

; 烟火之星颜色
烟花火箭爆炸时内部[[烟火之星]]包含的颜色。

; 文字颜色
使用染料对[[告示牌]]着色后，告示牌文字的渲染颜色。告示牌文字边框的颜色为此颜色各颜色分量减少60%的颜色。

; {{text anchor|混色机制}}
两种染料颜色的'''有效混色'''指的是这两种染料[[#合成|合成]]出的另一种染料的颜色，如果两种染料不能合成出新的染料则不存在有效混色。有效混色只会检测合成配方，因此会受[[数据包]]自定义的配方影响{{info needed|在基岩版中是否受附加包影响？}}。

[[繁殖]]出的幼年[[绵羊]]的羊毛颜色以及幼年[[猫]]和幼年[[狼]]的项圈颜色为其双亲羊毛或项圈颜色的有效混色，如果有效混色不存在，则随机遗传双亲中一方的羊毛或项圈颜色。

== 你知道吗 ==
* 玩家能以1个棕色染料、2个黄色染料、2个黑色染料、3个绿色染料、4个蓝色染料、4个红色染料和6个白色染料通过合成获得每种颜色的染料各1个。
* 染色绵羊繁殖的机制反映了[[wzh:拉马克主义#用进废退说|用进废退说]]：生物进化时继承上一代的外在改变，传到后代。
* 除了棕色（仅染色）、青色和黄色（仅颜色代码）之外，染料的颜色与[[格式化代码]]中的聊天字体颜色相匹配。
