'''沉船（Shipwreck）'''是主要在海洋中生成的[[结构]]。

== 生成 ==
沉船有两种生成。标准的沉船可以生成于[[海洋]]、[[冻洋]]、[[冷水海洋]]、[[温水海洋]]、[[暖水海洋]]、[[深海]]、[[冰冻深海]]、[[冷水深海]]和[[温水深海]]中。搁浅的沉船可以生成于[[沙滩]]或[[积雪沙滩]]的陆地上。

== 结构 ==
{{for|详细的结构图示和方块构成|沉船/结构}}
[[File:Variouswrecks.png|thumb|沉船的一些变种]]
沉船的形状像经典的帆船或海盗船，生成时有三种形式：直立、侧翻和翻转。多数情况下，沉船会缺失船头、船尾、桅杆或者其他结构，但是也会有完好无损的沉船。它们仅由木质材料组成，包括{{only|java|for=[[原木]]|short=1}}、{{only|bedrock|for=[[去皮原木]]|short=1}}、[[木板]]、[[木栅栏]]、[[木楼梯]]、[[木台阶]]、[[箱子]]、[[木活板门]]和[[木门]]。

可应用于沉船结构的木质材料包括橡木、云杉木、白桦木、丛林木、深色橡木和{{only|be|for=金合欢木|short=1}}，但通常同一艘沉船只使用两种木质材料。木质材料A构成船的桅杆、船舷边、船身外壳和船舱内壁，木质材料B则构成船的甲板、船舱底板、甲板围栏和船首的斜桅。总共有以下{{only|je|for=8种|short=1}}/{{only|be|for=9种|short=1}}组合：

== 战利品 ==
{{seealso|箱子战利品}}
[[File:Shipwreck_internal_structure.png|200px|thumb|一艘沉船的横截面图，展示了3个箱子的位置]]
沉船有1-3个[[箱子]]，内含战利品。其中补给箱在船头，宝箱在船尾的上部，地图箱在船尾下部。如果一艘船的某个部分缺失了，那么处于该部分的宝藏箱也将缺失。

== 你知道吗 ==
