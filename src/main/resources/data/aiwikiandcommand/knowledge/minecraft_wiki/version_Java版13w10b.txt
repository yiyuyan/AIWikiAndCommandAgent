'''13w10b'''是[[Java版1.5]]的第15个，也是最后一个快照，发布于2013年3月6日<ref>{{cite|url=http://mojang.com/2013/03/minecraft-snapshot-13w10b/|archive-url=1|archive=1|title=Minecraft Snapshot 13w10b|author=Jens Bergensten|website=Mojang.com|date=Mar 6, 2013}}</ref>，更新了发射器和投掷器的发射机制，并修复了[[13w10a]]里的漏洞和崩溃。

== 更改 ==
=== 方块 ===
'''[[发射器]]和[[投掷器]]'''
* 现在只会在收到红石信号时发射。要想再次发射，信号必须关闭并再次开启。（之前它们会在有信号和旁边有方块更新时就发射）。
