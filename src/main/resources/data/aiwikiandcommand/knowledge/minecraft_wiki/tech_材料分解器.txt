'''材料分解器（Material Reducer）'''是一个用来学习自然的方块，能将Minecraft中的方块分解成它们的构成[[元素]]。

== 生成 ==
材料分解器不会生成在世界中。

== 获取 ==
材料分解器不能在生存模式中正常获得，但可以通过[[创造模式物品栏]]、[[创造模式]]中使用{{ctrl|选取方块}}或{{cmd|give}}[[命令]]获得。

== 破坏 ==
挖掘材料分解器的合适工具是镐。

{{Breaking table|only=be}}

材料分解器被破坏后会掉落自身。

== 用途 ==
{{Filetr|MaterialReducer ClassicGUI.png|thumb|材料分解器在经典UI下的界面}}

材料分解器中有10个物品栏槽位。顶部的中心槽是输入槽，放入方块后，在下方的9个输出槽就会出现该方块的构成[[元素]]。

某些方块（如[[灵魂沙]]和[[下界岩]]）并不存在于现实世界，因此这些方块会被分解为一个带有问号的未知元素。

一旦有1个元素被从输出槽中取出，输入槽就会清空；若输出槽尚未全部清空，则输入槽会变成红色且不接受任何方块的输入，直到输出槽全部清空为止。

使用材料分解器分解大部分方块都会给予100个元素。

当材料分解器顶部着火时，其将无法使用。
