'''1.21.11-rc2'''是[[Java版1.21.11]]的第2个发布候选版本，发布于2025年12月5日<ref>{{article|minecraft-1-21-11-release-candidate-2|Minecraft 1.21.11 Release Candidate 2|Dec 5, 2025}}</ref>，修复了一个崩溃漏洞。

此版本也额外发布了未经混淆的版本，称为'''1.21.11 Release Candidate 2 Unobfuscated'''（启动器内称'''1.21.11-rc2_unobfuscated'''），旨在过渡至后续小更新时移除混淆。<ref>{{article|removing-obfuscation-in-java-edition|Removing obfuscation in Java Edition|Oct 29, 2025}}</ref>
