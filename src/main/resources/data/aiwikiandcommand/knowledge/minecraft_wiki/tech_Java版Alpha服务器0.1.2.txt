'''0.1.2'''是{{el|je}}的一次服务端更新，与[[Java版Alpha v1.0.16 01|客户端Alpha v1.0.16_01]]在2010年8月12日一同发布。<ref name="blogpost">{{notch|943095997/minecraft-alpha-v1-0-16-01-minecraft-server-0-1-2|Minecraft Alpha v1.0.16_01, Minecraft Server 0.1.2|August 12, 2010}}</ref>

== 新内容 ==
* 加入了对新的命令的支持：
** {{cmd|tp <player1> <player2>}}可移动玩家1至玩家2处。
** {{cmd|save-all}}可强制将服务器保存至硬盘。
** {{cmd|save-off}}可禁用自动保存。
** {{cmd|save-on}}可启用自动保存。

== 重新上传 ==
该版本于18:18（UTC）被重新上传，加入了对{{cmd|save-on}}命令的支持。<ref name="blogpost"/>
