'''1.14.2'''是{{el|je}}的一次次要更新，发布于2019年5月27日<ref>{{article|minecraft-java-edition-1-14-2|Minecraft Java Edition 1.14.2|2019年5月27日}}</ref>，加入了更多字体，并修复了一些漏洞。此版本不兼容1.14和1.14.1的服务端。

== 新内容 ==
=== 常规 ===
'''[[字体]]'''
* 加入了默认的越南文字体。
* 更改了默认亚美尼亚文字体中的一个字符。
* 加入了默认的希伯来语和亚美尼亚语字体中缺少的字形。
* 在默认字体中添加了符文字母。

== 更改 ==
=== 方块 ===
'''[[营火]]'''
* 含水的[[营火]]不再能被着火的[[箭]]点燃。
'''[[潜影盒]]'''
* 空的潜影盒在创造模式下被破坏时，不会再掉落其自身。

=== 生物 ===
'''[[鹦鹉]]'''
* 不再生成在[[草丛]]上，而是生成在[[草方块]]上。

=== 游戏内容 ===
'''[[袭击]]'''
* 袭击生物现在只生成在完全加载的[[区块]]中。

'''[[光照]]'''
* 现在首次打开以前版本保存的世界时会重新计算光照。

=== 常规 ===
'''[[调试屏幕]]'''
* 现在包含服务器端的区块数量。

'''错误信息'''
* 加载区域时遇到的错误现在会在日志文件中输出更多诊断信息了。

'''[[闪烁标语]]'''
* 移除了“Woo, minecraftforum!”（正如论坛所宣布的那样，它将很快被存档。）
