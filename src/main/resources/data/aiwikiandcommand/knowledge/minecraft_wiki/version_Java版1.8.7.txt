'''1.8.7'''是{{el|je}}的一次次要更新，发布于2015年6月5日<ref>{{cite|url=http://mojang.com/2015/06/minecraft-1-8-7-security-release/|archive-url=1|archive=1|title=Minecraft 1.8.7 Security Release|author=Dinnerbone|website=Mojang.com|date=Jun 5, 2015}}</ref>。修复了4个有关游戏安全性问题的漏洞。此版本兼容1.8到1.8.6的服务端。

== 更改 ==
=== 生物 ===
'''[[骷髅]]'''
* 在太阳下寻找遮蔽处时不再忽略玩家。
