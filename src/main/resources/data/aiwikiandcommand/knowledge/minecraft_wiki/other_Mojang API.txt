'''Mojang API'''是[[Mojang]]提供的应用程序编程接口，允许用户使用自编程序检索玩家数据，它适用于第三方启动器开发人员、服务器运营商和插件开发人员。

所有查询目前限制为每10分钟600次。对于没有购买游戏的注册账户，也可以进行部分信息的查询。

== 服务器的请求与响应 ==
服务器能接受很多请求，如果没有特殊说明，对于具有负载的请求服务器有下面的限制：
* 请求头中的<code>Content-Type</code>必须是<samp>application/json</samp>。如果不是，服务器将返回HTTP状态码415。
* 如果请求中要求负载，则负载必须是一个有效的JSON文本。如果不是，服务器将返回HTTP状态码400。

如果请求成功，服务器会做出如下的响应：
* 一个成功的HTTP状态码（2XX）。
* 返回一个空的负载（这时服务器返回状态码204）或是一个JSON文本。

如果请求失败，服务器会返回一个非2XX的HTTP状态码并返回形式如下方的负载：

<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|error}}：对于错误的简短介绍。
** {{Nbt|string|errorMessage}}：错误信息。
** {{Nbt|string|cause}}：错误原因。
</div>

== 获取玩家信息 ==
获取玩家信息的API都不需要身份验证得到的访问令牌，部分API可以查询没有购买游戏的注册账户。

=== 获取玩家的UUID ===
; 输入
玩家的名称（不区分大小写）。 

; GET请求
* <code>-{}-<nowiki>https://api.mojang.com/users/profiles/minecraft/</nowiki><''玩家名称''></code>
* <code>-{}-<nowiki>https://api.minecraftservices.com/minecraft/profile/lookup/name/</nowiki><''玩家名称''></code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|id}}：玩家的[[UUID]]。
** {{Nbt|string|name}}：正确大写的玩家名称。 
** {{Nbt|bool|legacy}}：如果此账户没有迁移到Mojang账户，输出中包含此项。
** {{Nbt|bool|demo}}：如果是没有购买游戏的注册账户，输出中包含此项。
</div>

; 示例
<code><nowiki>https://api.mojang.com/users/profiles/minecraft/jeb_</nowiki></code><br>提供玩家<samp>jeb_</samp>的UUID。

<syntaxhighlight lang="json">
 {
   "name": "jeb_",
   "id": "853c80ef3c3749fdaa49938b674adae6"
 }</syntaxhighlight>

; 错误信息
* 如果没有命名为这个名字的玩家，返回HTTP状态码404。

=== 批量获取玩家UUID ===
; 负载
一个存储小于10个的玩家名称字符串的JSON列表，玩家名称不区分大小写。

; POST请求
<code><nowiki>https://api.mojang.com/profiles/minecraft</nowiki></code>

; 响应
<div class="treeview">
* {{Nbt|list}} 给定玩家的所有UUID列表。对于不存在的玩家名称，将不返回任何结果。
** {{Nbt|compound}} 玩家名称。
*** {{Nbt|string|id}}：玩家的UUID。
*** {{Nbt|string|name}}：正确大小写的玩家名称。
*** {{Nbt|bool|legacy}}：如果此账户没有迁移到Mojang账户，输出中包含此项。
*** {{Nbt|bool|demo}}：如果是没有购买游戏的注册账户，输出中包含此项。
</div>

; 示例
发送<code><nowiki>["jeb_","notch"]</nowiki></code>。
<syntaxhighlight lang="json">
 [
   {
     "id": "853c80ef3c3749fdaa49938b674adae6",
     "name": "jeb_"
   },
   {
     "id": "069a79f444e94726a5befca90e38aaf5",
     "name": "Notch"
   }
 ]</syntaxhighlight>

; 错误信息
{| class="wikitable mw-collapsible mw-collapsed"
! HTTP状态码
! 错误（error）
! 错误具体信息（errorMessage）
! 错误说明
|-
| rowspan=3 | 400
| rowspan=3 | CONSTRAINT_VIOLATION
| rowspan=2 | size must be between 1 and 10
| 请求负载的JSON列表为空。
|-
| 请求负载的JSON列表中元素数量大于10个。

| 请求负载的JSON列表中含有空字符串。
|}

=== 获取玩家的皮肤和披风 ===
; 输入
玩家的UUID以及[[wikipedia:Digital signature|签名]]的请求。可以在一分钟后最早重复对给定UUID的查询。

; GET请求
<code><nowiki>https://sessionserver.mojang.com/session/minecraft/profile/</nowiki><''UUID''></code> 或<br><code><nowiki>https://sessionserver.mojang.com/session/minecraft/profile/</nowiki><''UUID''>?unsigned=false</code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|id}}：玩家的[[UUID]]。
** {{Nbt|string|name}}：正确大写的玩家名称。
** {{Nbt|boolean|legacy}}：如果这个账户是一个旧的Minecraft账户，这项才存在。
** {{Nbt|list|properties}}：玩家属性的列表。
*** {{Nbt|string|name}}：玩家属性的名称。到目前为止只有<code>textures</code>（玩家纹理）这一属性。 
*** {{Nbt|string|signature}}：只有在请求<code>unsigned=false</code>时，使用<samp>Yggdrasil</samp>私钥的签名才会作为Base64字符串传递。
*** {{Nbt|string|value}}：[[wikipedia:Base64|Base64]]字符串，其中包含玩家所有的纹理（皮肤和披风）。解码后的字符串内容如下：
**** {{Nbt|compound}} 纹理对象。
***** {{Nbt|int|timestamp}}：[[wikipedia:Unixtime|Unix时间戳]]，以毫秒为单位，时间为调用纹理数据的时间。
***** {{Nbt|string|profileId}}：玩家的UUID，不带连字符。
***** {{Nbt|string|profileName}}: 玩家名称。
***** {{Nbt|boolean|signatureRequired}}: 只有在请求<code>unsigned=false</code>时才存在。
***** {{Nbt|compound|textures}}：纹理。
****** {{Nbt|compound|SKIN}}：[[皮肤]]纹理。如果这名玩家没有自定义皮肤，这项不存在。
******* {{Nbt|string|url}}：皮肤纹理的URL链接。
******* {{Nbt|compound|metadata}}：可选。皮肤的元数据。
******** {{Nbt|string|model}}：固定值<code>slim</code>。当皮肤模型为<samp>Alex</samp>时这一项才存在，模型为<samp>Steve</samp>则无该元数据。
****** {{Nbt|compound|CAPE}}：[[披风]]纹理。如果这名玩家没有披风，这项不存在。
******* {{Nbt|string|url}}：披风纹理的URL链接。默认没有披风，仅当Mojang在玩家的账户数据中输入了披风时，才会显示披风。
</div>

; 示例
<code><nowiki>https://sessionserver.mojang.com/session/minecraft/profile/853c80ef3c3749fdaa49938b674adae6</nowiki></code><br>返回如下结果：
<syntaxhighlight lang="json">
 {
   "id": "853c80ef3c3749fdaa49938b674adae6",
   "name": "jeb_",
   "properties":
   [
     {
       "name": "textures",
       "value": "ewogICJ0aW1lc3R..."
     }
   ]
 }
</syntaxhighlight>
其中{{Nbt|string|value}}使用Base64解码之后的内容为：
<syntaxhighlight lang="json">
{
  "timestamp" : 1653838459263,
  "profileId" : "853c80ef3c3749fdaa49938b674adae6",
  "profileName" : "jeb_",
  "textures" : {
    "SKIN" : {
      "url" : "http://textures.minecraft.net/texture/7fd9ba42a7c81eeea22f1524271ae85a8e045ce0af5a6ae16c6406ae917e68b5"
    },
    "CAPE" : {
      "url" : "http://textures.minecraft.net/texture/9e507afc56359978a3eb3e32367042b853cddd0995d17d0da995662913fb00f7"
    }
  }
}
</syntaxhighlight>

; 错误信息
{| class="wikitable mw-collapsible mw-collapsed"
! HTTP状态码
! 错误（error）
! 错误具体信息（errorMessage）
! 错误说明
|-
| 204
| （返回空负载）
| （返回空负载）
| 此UUID不代表任何玩家。

== Microsoft身份验证 ==
该过程包含多个步骤并且需要不同的令牌，但最终会获取到一个标准的'''Minecraft'''令牌。目前所有的账户均已启用这一新的验证系统。

在使用Microsoft验证之前，必须要先通过创建[https://docs.microsoft.com/zh-cn/azure/active-directory/develop/quickstart-register-app Microsoft Azure应用程序]来获得[https://docs.microsoft.com/zh-cn/azure/active-directory/develop/v2-oauth2-auth-code-flow OAuth 2.0]客户端ID（无需获取密钥）；之后根据[https://help.minecraft.net/hc/en-us/articles/16254801392141p 这篇支持文档]，还需填写[https://aka.ms/mce-reviewappid 此表单]以申请API访问权限，否则使用{{cd|api.minecraftservices.com}}域名下的任意API时都只会返回{{cd|403}}。之后，就可以获取Microsoft令牌。

请注意：在获取令牌时，{{cd|tenant}}参数'''必须'''为{{cd|consumers}}，{{cd|scope}}参数中'''必须'''包含{{cd|XboxLive.signin}}，否则无法进行获取Xbox Live令牌等操作。

=== 使用Microsoft令牌获取Xbox Live令牌 ===
; 负载
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|compound|Properties}}：验证属性。
*** {{Nbt|string|AuthMethod}}：登录方法。固定值<code>RPS</code>。
*** {{Nbt|string|SiteName}}：网站名称。固定值<code>user.auth.xboxlive.com</code>。
*** {{Nbt|string|RpsTicket}}：登录使用的票据。值为<code>-{}-d=<''Microsoft访问令牌''></code>。
** {{Nbt|string|RelyingParty}}：依赖的平台。固定值<code>http://auth.xboxlive.com</code>。
** {{Nbt|string|TokenType}}：访问令牌的类型。固定值<code>JWT</code>。
</div>

; POST请求
<code><nowiki>https://user.auth.xboxlive.com/user/authenticate</nowiki></code>

要求SSL实现支持SSL重协商。

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|IssueInstant}}：获取Xbox Live令牌的时间。
** {{Nbt|string|NotAfter}}：Xbox Live令牌过期时间。
** {{Nbt|string|Token}}：Xbox Live访问令牌。
** {{Nbt|compound|DisplayClaims}}：未知。
*** {{Nbt|list|xui}}：未知。
**** {{Nbt|compound}}
***** {{Nbt|string|uhs}}：用户的哈希码。
</div>

=== 使用Xbox Live令牌获取XSTS令牌 ===
; 负载
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|compound|Properties}}：验证属性。
*** {{Nbt|string|SandboxId}}：沙盒ID。固定值<code>RETAIL</code>。
*** {{Nbt|list|UserTokens}}：用户的Xbox Live令牌。
**** {{Nbt|string}}：用户的Xbox Live令牌，在上一步获取。
** {{Nbt|string|RelyingParty}}：依赖的平台。固定值<code>rp://api.minecraftservices.com/</code>。
** {{Nbt|string|TokenType}}：访问令牌的类型。固定值<code>JWT</code>。
</div>

; POST请求
<code><nowiki>https://xsts.auth.xboxlive.com/xsts/authorize</nowiki></code>

要求SSL实现支持SSL重协商。

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|IssueInstant}}：获取XSTS令牌的时间。
** {{Nbt|string|NotAfter}}：XSTS令牌过期时间。
** {{Nbt|string|Token}}：XSTS访问令牌。
** {{Nbt|compound|DisplayClaims}}：未知。
*** {{Nbt|list|xui}}：未知。
**** {{Nbt|compound}}
***** {{Nbt|string|uhs}}：用户的哈希码。
</div>

; 错误信息
如果没有成功获取XSTS令牌，服务器返回HTTP状态码401。

=== 通过XSTS令牌获取Minecraft访问令牌 ===
; 负载
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|identityToken}}：身份令牌。值为<code>-{}-XBL3.0 x=<''用户哈希码''>;<''XSTS访问令牌''></code>。
</div>

; POST请求
<code><nowiki>https://api.minecraftservices.com/authentication/login_with_xbox</nowiki></code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|username}}：一个UUID，但不是账户的UUID。
** {{Nbt|list|roles}}：未知，为空。
** {{Nbt|string|access_token}}：Minecraft访问令牌。
** {{Nbt|string|token_type}}：令牌类型。固定值<code>Bearer</code>。
** {{Nbt|string|expires_in}}：有效时间，以秒为单位。
</div>

=== 验证账户是否拥有Minecraft ===
; 请求头
<code>Authorization</code>要求为<code>-{}-Bearer <''有效的Minecraft访问令牌''></code>。

; GET请求
<code><nowiki>https://api.minecraftservices.com/entitlements/mcstore</nowiki></code>

; 响应
如果账户拥有Minecraft，服务器将会返回下面的负载：
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|list|items}}：数据和签名列表。
*** {{Nbt|string|name}}：数据名称，<code>product_minecraft</code>或<code>game_minecraft</code>。
*** {{Nbt|string|signature}}：数据的JWT签名。
** {{Nbt|string|signature}}：JWT签名。
** {{Nbt|string|keyID}}：未知。
</div>

如果账户不拥有Minecraft或者是XGP用户，服务器将返回空负载。

== 玩家配置操作 ==
操作玩家配置的API基本都在<code><nowiki>https://api.minecraftservices.com</nowiki></code>服务器下，并且都要求请求头包含<code>Authorization</code>，且值为<samp>Bearer <''有效的Minecraft访问令牌''></samp>。如果请求头不包含访问令牌信息或者访问令牌无效，服务器将返回HTTP状态码401。

=== 获取配置信息 ===
; GET请求
<code>/minecraft/profile</code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|id}}：玩家的UUID。
** {{Nbt|string|name}}：玩家名称。
** {{Nbt|list|skins}}：玩家拥有的所有皮肤信息。
*** {{Nbt|compound}}：一个皮肤。
**** {{Nbt|string|id}}：皮肤的UUID。
**** {{Nbt|string|state}}：皮肤的使用状态。
**** {{Nbt|string|url}}：皮肤的URL。
**** {{Nbt|string|variant}}：皮肤类型。如果是Steve模型的皮肤这一项是<code>CLASSIC</code>，如果是Alex模型的皮肤这一项是<code>SLIM</code>。
** {{Nbt|list|capes}}：玩家拥有的所有披风信息。
*** {{Nbt|compound}}：一个披风。
**** {{Nbt|string|id}}：披风的UUID。
**** {{Nbt|string|state}}：披风的使用状态。
**** {{Nbt|string|url}}：披风的URL。
**** {{Nbt|string|alias}}：披风的别名。
</div>

=== 获取玩家属性 ===
; GET请求
<code>/player/attributes</code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|compound|privileges}}：玩家的能力。
*** {{Nbt|compound|onlineChat}}：玩家接受聊天信息的能力。
**** {{Nbt|boolean|enable}}：为真时玩家可以接受聊天信息，为假时不能。
*** {{Nbt|compound|multiplayerServer}}：玩家加入多人服务器的能力。
**** {{Nbt|boolean|enable}}：为真时玩家可以加入多人服务器，为假时不能。
*** {{Nbt|compound|multiplayerRealms}}：玩家加入Realms的能力。
**** {{Nbt|boolean|enable}}：为真时玩家可以加入Realms，为假时不能。
*** {{Nbt|compound|telemetry}}：玩家发送遥测数据的能力。
**** {{Nbt|boolean|enable}}：为真时玩家可以发送遥测数据。
*** {{Nbt|compound|optionalTelemetry}}：玩家发送可选遥测数据的能力。
**** {{Nbt|boolean|enable}}：为真时玩家可以发送可选遥测数据。
** {{Nbt|compound|profanityFilterPreferences}}：玩家Realms聊天过滤选项。
*** {{Nbt|boolean|profanityFilterOn}}：是否开启Realms聊天过滤。
** {{Nbt|compound|banStatus}}：玩家封禁状态。
*** {{Nbt|compound|bannedScopes}}：玩家封禁的范围。
**** {{Nbt|compound}}：玩家的封禁范围对象。如果玩家未被封禁，则不存在这些对象。目前只有<code>MULTIPLAYER</code>项。
***** {{Nbt|string|banId}}：封禁的UUID。
***** {{Nbt|string|expires}}：封禁到期时间。如果玩家被永久封禁，这一项不存在。
***** {{Nbt|string|reason}}：封禁原因。
***** {{Nbt|string|reasonMessage}}：封禁消息。
</div>

=== 启用/禁用Realms聊天过滤 ===
; 负载
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|compound|profanityFilterPreferences}}：玩家Realms聊天过滤选项。
*** {{Nbt|boolean|profanityFilterOn}}：是否开启Realms聊天过滤。
</div>

; POST请求
<code>/player/attributes</code>

; 响应
与获取玩家属性的响应相同。

=== 获取屏蔽玩家列表 ===
; GET请求
<code>/privacy/blocklist</code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|list|blockedProfiles}}：被屏蔽的玩家列表。这些玩家的聊天信息和Realms邀请将不可见。
*** {{Nbt|string}}：被屏蔽玩家的UUID。
</div>

=== 获得签名密钥对 ===
; POST请求
<code>/player/certificates</code>

; 响应
<div class="treeview">
* {{Nbt|compound}} 根标签

== 好友操作 ==

{{Needs update|trans|extra=该部分内容存在错误和信息缺失，在该完成修订前，建议首先参考英文 Minecraft Wiki 中的对应内容|section=1}}

好友操作的API都在<code><nowiki>https://api.minecraftservices.com</nowiki></code>服务器下，且与玩家配置操作一样都要求请求头包含<code>Authorization</code>。

好友操作有请求频率限制。在上一条请求发出后，10秒内不能再次请求好友操作API，否则服务器将以HTTP状态码429拒绝请求。同步在线状态API则没有请求频率限制。

== 服务器操作 ==
=== 获取屏蔽服务器信息 ===
; GET请求
<code><nowiki>https://sessionserver.mojang.com/blockedservers</nowiki></code>

; 响应
服务器将返回一个文本，每一行都是被屏蔽的服务器的哈希码。

=== 客户端登录验证 ===
; 负载
<div class="treeview">
* {{Nbt|compound}} 根标签
** {{Nbt|string|accessToken}}：有效的Minecraft访问令牌。
** {{Nbt|string|selectedProfile}}：不带有连字符的玩家UUID。
** {{Nbt|string|serverId}}：服务器的ID。
</div>

其中服务器的ID由下方算法计算而成：

<syntaxhighlight lang="java">
public static String generateServerId(String baseServerId,   // 服务器的基础ID，通常为空字符串""
                                      PublicKey publicKey,   // 服务器的RSA公钥
                                      SecretKey secretKey    // 服务器与客户端之间使用的对称加密AES密钥
                                     ) throws Exception { 
    MessageDigest messageDigest = MessageDigest.getInstance("SHA-1");
    messageDigest.update(baseServerId.getBytes("ISO_8859_1"));
    messageDigest.update(secretKey.getEncoded());
    messageDigest.update(publicKey.getEncoded());
    byte[] digestData = messageDigest.digest();
    return new BigInteger(digestData).toString(16);
}
</syntaxhighlight>

; POST请求
<code><nowiki>https://sessionserver.mojang.com/session/minecraft/join</nowiki></code>

; 响应
如果验证成功，服务器返回HTTP状态码204。

=== 服务器登录验证 ===
; 输入
不区分大小写的玩家名称、由上方算法得出的服务器ID和客户端IP（可选）。

; GET请求
<code>-{}-<nowiki>https://sessionserver.mojang.com/session/minecraft/hasJoined?</nowiki>username=<''玩家名称''>&serverId=<''服务器ID''>&ip=<''客户端IP''></code>

; 响应
如果验证成功，服务器将返回和上方获取玩家的皮肤和披风一样的负载。
