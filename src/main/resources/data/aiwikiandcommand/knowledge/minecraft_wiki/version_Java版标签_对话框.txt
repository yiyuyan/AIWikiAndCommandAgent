'''对话框标签（Dialog Tags）'''是[[对话框]]的组合。

{{TOC|right}}

== 使用 ==
游戏内部使用对话框标签定义了无需通过命令即可调用的对话框。除此以外，对话框标签目前仅能被<code>dialog_list</code>类型的对话框调用。

== 標籤清單 ==
{{tag list|dialog|mode=missing}}<!--自动检查缺失的模板，请勿移除-->
=== pause_screen_additions ===
* 持有该标签的对话框可通过暂停菜单直接进入。
* 标签中对话框数量>1时，进入{{cd|custom_options}}对话框列表。

{{tag list|dialog|pause_screen_additions}}

=== quick_actions ===
* 持有该标签的对话框可通过快捷操作选项绑定键（默认为{{key|G}}）直接进入。
* 标签中对话框数量>1时，进入{{cd|quick_actions}}对话框列表。

{{tag list|dialog|quick_actions}}
