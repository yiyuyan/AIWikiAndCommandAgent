'''绊线钩（Tripwire Hook）'''是一种可用于在[[绊线]]线路中检测[[实体]]的[[方块]]。

== 生成 ==
=== 自然生成 ===
[[丛林神庙]]中会生成4个绊线钩。

[[试炼密室]]的柱廊结构及<code>encounter_4</code>结构中会生成绊线钩。

== 破坏 ==
绊线钩被挖掘时会立刻被破坏，用于挖掘的工具的耐久度不会下降。

{{Breaking table}}

绊线钩被破坏后会掉落自身。

{{in|je}}绊线钩被破坏时（放置后立即被来自对侧绊线钩的[[方块更新]]破坏的除外）计算绊线线路当前的正确状态，并依次放置相应状态的对侧绊线钩和绊线，放置绊线时不检查绊线线路是否再次改变状态。

== 用途 ==
绊线钩可以用作合成材料或红石元件。

绊线钩必须{{ctrl|放置}}于{{verify|for=[[方块支撑形状]]表面中心完整的方块的侧面表面}}。

当绊线钩附着的方块变动（移动、破坏、替代等），不再允许附着时或有[[活塞]]试图推动它或将方块推入其位置时，绊线钩会掉落为方块物品。

[[沙子]]或[[沙砾]]这类受重力影响的方块正下方为绊线钩时不会开始下落。下落到绊线钩的位置时，它会掉落为方块物品。

{{in|je}}若[[水]]流过绊线钩，绊线钩会被破坏并掉落为方块物品；若[[熔岩]]流过绊线钩，绊线钩会被破坏但不会掉落为方块物品。

=== 红石元件 ===

绊线钩可用于在大面积区域中检测生物、物品和其他[[实体]]。

==== 绊线线路 ====
绊线钩需要“绊线线路”才能正常工作。
* 在两个互相面向的绊线钩中间使用[[绊线]]连接，最大距离40个方块（不包含绊线钩本身）。

在无效绊线线路中的绊线钩会显现出“折叠”的样子，而在有效绊线线路中的绊线钩则会显现出“伸直”的样子。不同绊线线路的绊线可以并排放置，也可以上下堆叠，甚至可以交叉放置。

{{in|je}}绊线钩被放置、被触发和结束触发时计算绊线线路当前的正确状态，并依次放置相应状态的对侧绊线钩、本侧绊线钩和绊线。放置本侧绊线钩和绊线时，不检查绊线线路是否再次改变状态（例如PP更新引起的绊线的连接方向改变）。

==== 开启 ====
在有效绊线线路中，特定[[实体]]（[[生物]]、[[物品（实体）|物品实体]]等）的[[边界箱]]与绊线的[[碰撞箱]]相交时，对应的绊线线路被触发，其中的绊线钩会被开启。

不会触发绊线线路的实体包含[[箭]]、[[喷溅药水]]、[[掷出的末影珍珠]]和[[末影之眼]]等。

绊线钩在绊线线路中的任何一个绊线被摧毁时会开启{{convert|10}}。但用[[剪刀]]摧毁绊线和破坏对侧的绊线钩都不会开启绊线钩。
* 它们都会让绊线钩的方块状态（<code>attached</code>{{only|je}}或<code>attached_bit</code>{{only|be}}状态）从<code>true</code>变为 <code>false</code>，该变化可被[[侦测器]]检测。

==== 行为 ====
[[File:Tripwire hook as power source.png|缩略图|绊线钩开启时，输出信号并强充能其附着方块，绊线不会输出信号]]
绊线钩开启时，模型会向下折叠，并会：
* 为毗邻的[[红石线]]提供15点信号强度。
* 为毗邻且朝向正确（主输入端面向绊线钩）的[[红石比较器]]和[[红石中继器]]提供15点信号强度。
* 激活毗邻且朝向正确（若需要，如[[活塞]]）的任何[[红石元件#机械元件|机械元件]]。
* '''[[强充能]]'''自身附着的[[红石导体]]至充能等级15。

== 你知道吗 ==
* {{in|je}}绊线线路状态变化时，绊线钩先记录线路的状态，再依次设置对侧绊线钩和自身的状态以及绊线的{{cd|attached}}状态（若绊线钩的{{cd|attached}}状态有变化）；若绊线钩附着[[门]]或[[活板门]]，线路中绊线钩信号的变化可以激活或取消激活门或活板门，从而破坏附着在门上的绊线钩，并引起绊线钩和绊线状态的变化，但这些变化可以被先更新线路状态的绊线钩后续设置的状态覆盖。
* {{in|je}}若绊线线路中的一个绊线被破坏后迅速插入一个绊线钩，线路东、北侧绊线钩和所有绊线的状态不会更新。
