{{Relevant guide|Java版指南/骇人更新}}

'''骇人更新（Pretty Scary Update）'''，是[[Java版]]的一次主要更新，发布于2012年10月25日<ref name="12w40a blog post">{{cite|url=http://www.mojang.com/2012/10/minecraft-snapshot-12w40a/|archive-url=1|archive=1|title=Minecraft Snapshot 12w40a|author=Jens Bergensten|website=Mojang.com|date=Oct 4, 2012}}</ref>。此次更新的官方名称在[[12w36a]]中被公布。<ref>{{cite|url=http://www.mojang.com/2012/09/minecraft-snapshot-12w36a/|archive-url=1|archive=1|title=Minecraft Snapshot 12w36a|author=Jens Bergensten|website=Mojang.com|date=Sep 6, 2012}}</ref>该更新加入了许多不同的怪物和变种，可穿戴和放置的[[头颅]]，一个新的Boss[[凋灵]]，方块[[命令方块]]与[[信标]]等。

此次更新的开发始于[[12w32a]]，其发布于2012年8月9日。

== 重要特性 ==
{{main|Java版1.4.2}}

此次更新最大的更新是新加入的Boss：[[凋灵]]。其他的重大特性有[[铁砧]]、[[信标]]与[[命令方块]]等。

'''新内容''':
* 信标
* 胡萝卜钓竿
* 物品展示框、花盆
* 马铃薯、胡萝卜、南瓜派
* 铁砧
* 僵尸会感染村民
* 凋灵、凋灵骷髅
* 蝙蝠、女巫
* 怪物可以捡起物品、武器与盔甲
* 命令方块

== 跟进版本 ==
* 1.4.4加入了{{cmd|enchant}}命令，并修复了1.4.2的许多错误。
* 1.4.5继续修补了1.4.4的错误。
* 1.4.6在2012年12月发布，主要加入了烟花火箭，附魔书以及荆棘魔咒。
* 1.4.7修复了1.4.6引入的崩溃和错误。

== 你知道吗 ==
* 在宣传海报中，马铃薯被写成“potatos”（正确的写法是“potatoes”）
* 骇人更新本来计划包含官方[[Mod]] API，但与新的[[光照]]系统、[[红石电路|红石]]特性、渲染系统随后一同宣布推迟。<ref>https://web.archive.org/web/20151105192606/https://twitter.com/jeb_/status/246177156193980416</ref><ref>{{tweet|Dinnerbone|251719813704069120}}</ref><ref>{{tweet|Dinnerbone|253772962530996224}}</ref><ref>{{tweet|jeb_|253778582369861632}}</ref>
* [[Dinnerbone]]在12w40a中宣布了1.4正式版的发布日期为2012年10月24日。<ref name="12w40a blog post" />但随后由于1.4.1以及1.4.2的更新，发布日期被推迟到10月25日。
