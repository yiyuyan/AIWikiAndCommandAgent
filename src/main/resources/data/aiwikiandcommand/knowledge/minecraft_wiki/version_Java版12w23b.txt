'''12w23b'''是[[Java版1.3.1]]的第10个快照，发布于2012年6月7日<ref>{{cite|url=http://mojang.com/2012/06/minecraft-snapshot-week-23/|archive-url=1|archive=1|title=Minecraft Snapshot Week 23|author=Jens Bergensten|website=Mojang.com|date=Jun 7, 2012}}</ref>，修复了一个漏洞。

== 修复 ==
; 修复了1个漏洞
: 修复了在生存模式中使用工具瞬间破坏方块时会频繁出现<code>NullPointerException</code>的漏洞。</onlyinclude>
