获取、合并、修改或移除[[方块]]、[[实体]]或[[命令存储]]的[[NBT格式|NBT数据]]。

== 用法 ==
当前只能对[[方块实体]]、[[实体]]、[[命令存储]]执行{{cmd|data}}命令，并且无法修改（包括设置和删除）[[玩家]]的NBT数据。若需修改玩家[[物品栏]]数据，可使用{{cmd|item}}命令。

'''获取NBT数据'''

若在聊天栏执行{{cmd|data get}}，则会将获取到的NBT进行字符串化，变为[[SNBT]]显示在聊天栏：
* 标签名被渲染为{{color|#55FFFF|亮蓝色}}
* 数值被渲染为{{color|#FFAA00|金色}}。一些数值还可能尾随类型后缀，此时以{{color|#FF5555|红色}}渲染。
* 字符串内容被渲染为{{color|#55FF55|亮绿色}}。
* 其余一些表示语法结构的符号被渲染为{{color|#FFFFFF|白色}}。

获取到的数据可以通过{{cmd|execute store ...}}存储，进而可将列表、数组和字符串的长度存入记分板。更多信息参见{{slink||输出}}。

'''设置NBT数据'''

{{cmd|data modify ... set ...}}用于设置NBT数据。
* 对于不存在的标签值，将自动添加为新的NBT数据。例如对{{snbt|<nowiki>{foo: 1}</nowiki>|bg=1}}，执行{{cmd|data modify ... newbar set value 1b}}将得到{{snbt|<nowiki>{foo: 1, newbar:1b}</nowiki>|bg=1}}

'''修改NBT数据'''

{{cmd|data merge}}和{{cmd|data modify ... merge ...}}只能对{{nbt|compound|复合标签}}操作。
* 同名标签值将被覆盖。例如对{{snbt|<nowiki>{foo: 1, pol: 1.2f}</nowiki>|bg=1}}合并{{snbt|<nowiki>{foo: [1, 2, 3], bar: true}</nowiki>|bg=1}}，将得到{{snbt|<nowiki>{foo: [1, 2, 3], bar: true, pol:1.2f}</nowiki>|bg=1}}。

{{cmd|data modify ... prepend ...}}、{{cmd|data modify ... insert ...}}和{{cmd|data modify ... append ...}}只能对{{nbt|list|列表}}和{{nbt|int-array}}{{nbt|byte-array}}{{nbt|long-array|数组}}操作。
* {{cd|prepend}}表示插入到头部，这导致所有元素后移并使得总元素数加1。
* {{cd|insert}}表示插入到一个元素的位置前。位置通过索引确定。
* {{cd|append}}表示插入到尾部，这导致总元素数加1。

在内部，索引值将转换为正索引值参与运算。正负索引值关系满足<code>正索引值=负索引值+元素总数+1</code>。

{{cmd|data modify ... set string ...}}、{{cmd|data modify ... prepend string ...}}、{{cmd|data modify ... insert string ...}}和{{cmd|data modify ... append string ...}}将从数据源获取字符串并对其进行切片，然后使用切片结果修改该目标。若数据源为数值则会先转换为字符串。
* 对命令存储{{cd|minecraft:test}}{{snbt|<nowiki>{S: "abc", L:[]}</nowiki>|bg=1}}执行{{cmd|data modify storage test L append string storage test S 0 1}}将得到{{snbt|<nowiki>{S: "abc", L:["a"]}</nowiki>|bg=1}}（取出字符串的第一个字符）。

'''移除NBT数据'''

{{cmd|data remove}}用于移除指定NBT路径下的数据。

== 语法 ==
<!-- 由于细微语法差异导致页面整体差异大，同时也没那么必要改，在此留作备忘，记得在26.3发布后移除注释并将<targetPos>全部改为<target>，<sourcePos>全部改为<source>，并调整语法使其最简。 -->
<code>/data</code>有四个子命令（<code>[[#get|get]]</code>、<code>[[#merge|merge]]</code>、<code>[[#modify|modify]]</code>、<code>[[#remove|remove]]</code>）。

; <code>/'''data''' ...</code>
: <code>... '''{{Text anchor|get}}''' (block <targetPos>|entity <target>|storage <target>) [<path>]</code>
: <code>... '''get''' (block <targetPos>|entity <target>|storage <target>) <path> [<scale>]</code>
:: 获取（方块实体、实体或[[命令存储]]的）NBT数据。若未指定<code><path></code>（NBT路径），则返回目标的整个NBT。若指定<code><scale></code>，则将目标NBT的数值结果乘以<code><scale></code>后再返回。

: <code>... '''{{Text anchor|merge}}''' (block <targetPos>|entity <target>|storage <target>) <nbt></code>
:: 将指定的<code><nbt></code>数据合并到指定（方块实体、实体或[[命令存储]]的）NBT数据。

: <code>... '''{{Text anchor|modify}}''' (block <targetPos>|entity <target>|storage <target>) <targetPath> ...</code>
:: 修改指定（方块实体、实体或[[命令存储]]的）NBT。
:: <code>... '''append''' ...</code>
::: 在指定列表或数组的'''末尾'''增加元素。
:: <code>... '''insert <index>''' ...</code>
::: 在指定列表或数组的指定元素位置前插入元素。
:: <code>... '''merge''' ...</code>
::: 将一个复合标签与指定的复合标签合并。若存在同名标签，则后者覆盖前者。
:: <code>... '''prepend''' ...</code>
::: 在指定列表或数组'''开头'''插入元素。
:: <code>... '''set''' ...</code>
::: 将指定NBT标签覆盖为新的值。若指定NBT标签不存在，将同时创建该NBT标签。
::: <code>... from (block <sourcePos>|entity <<nowiki/>source>|storage <<nowiki/>source>) [<sourcePath>]</code>
:::: 使用特定[[方块实体]]、实体或[[命令存储]]的NBT标签作为数据来源。
::: <code>... string (block <sourcePos>|entity <<nowiki/>source>|storage <<nowiki/>source>) [<sourcePath>]</code>
::: <code>... string (block <sourcePos>|entity <<nowiki/>source>|storage <<nowiki/>source>) <sourcePath> [<start>]</code>
::: <code>... string (block <sourcePos>|entity <<nowiki/>source>|storage <<nowiki/>source>) <sourcePath> <start> [<end>]</code>
:::: 使用特定方块实体、实体或命令存储中的字符串或数字类型（将会先转换为字符串）标签的子字符串作为数据来源（即进行切片）。对于正值，若省略<code><start></code>则从字符串第0个字符开始，若省略<code><end></code>则到最后一个字符为止，负值亦然。
::: <code>... value <value></code>
:::: 使用<code><value></code>作为数据来源。

: <code>... '''{{Text anchor|remove}}''' (block <targetPos>|entity <target>|storage <target>) <path></code>
:: 删除指定NBT。

== 参数 ==
{{argument|targetPos|block_pos}}
: 指定一个[[方块实体]]的坐标，以将此方块实体作为NBT操作的目标。
: {{arg desc|je=block_pos}}

{{argument|target|entity}}（仅{{cd|entity <target>}}模式）
: 指定一个实体作为NBT操作的目标。
: {{arg desc|je=entity|amount=single|type=entities}}

{{argument|target|resource_location}}（仅{{cd|storage <target>}}模式）
: 指定一个[[命令存储]]作为NBT操作的目标。
: {{arg desc|je=resource_location}}

{{argument|path|nbt_path}}
: 指定要获取或移除的NBT标签的路径。
: {{arg desc|je=nbt_path}}

{{argument|scale|double}}
: 指定缩放倍率，用以将获取到的数值乘上该倍率后再输出。
: {{arg desc|je=double}}

{{argument|nbt|nbt_compound_tag}}
: 指定要合并到操作目标中的NBT复合标签。
: {{arg desc|je=nbt_compound_tag}}

{{argument|targetPath|nbt_path}}
: 指定操作目标中具体要操作的NBT标签的路径。对于<code>/data (modify|remove) ...</code>，允许路径选取多个NBT标签；对于<code>/data get ...</code>，路径应选取单个NBT标签。
: {{arg desc|je=nbt_path}}

{{argument|index|integer}}
: 指定一个列表或数组索引，以表示列表或数组中的某个具体位置。非负时，从左端开始，向右递增，依次为0、1、2……；为负数时，从最右端开始，向左端递减，依次为-1、-2、-3……。
: {{arg desc|je=integer}}

{{argument|sourcePos|block_pos}}
: 指定一个[[方块实体]]的坐标，以将此方块实体作为NBT数据来源。
: {{arg desc|je=block_pos}}

{{argument|source|entity}}（仅{{cd|entity <<nowiki/>source>}}模式）
: 指定一个实体作为NBT数据来源。
: {{arg desc|je=entity|amount=single|type=entities}}

{{argument|source|resource_location}}（仅{{cd|storage <<nowiki/>source>}}模式）
: 指定一个[[命令存储]]作为NBT数据来源。
: {{arg desc|je=resource_location}}

{{argument|sourcePath|nbt_path}}
: 指定数据来源中具体要获取的NBT标签的路径。
: {{arg desc|je=nbt_path}}

{{argument|start|integer}}
: 要从源字符串中提取的首个字符的索引值（从0开始），负数表示从末尾开始计数。
: {{arg desc|je=integer}}

{{argument|end}}
: 要从源字符串中排除的首个字符的索引值（从0开始），负数表示从末尾开始计数。
: {{arg desc|je=integer}}

{{argument|value|nbt_tag}}
: 指定一个NBT标签作为来源数据。
: {{arg desc|je=nbt_tag}}

== 示例 ==
* 获取执行者的饱和度：
*: <syntaxhighlight lang="mcfunction">data get entity @s foodSaturationLevel</syntaxhighlight>
* 使10格内最近的物品实体无法被玩家捡起：
*: <syntaxhighlight lang="mcfunction">data modify entity @n[type=item,distance=..10] PickupDelay set value -1</syntaxhighlight>
* 获取随机物品实体的Y轴位置：
*: <syntaxhighlight lang="mcfunction">data get entity @e[type=item,limit=1,sort=random] Pos[1]</syntaxhighlight>
* 获取最近玩家快捷栏第一格物品的[[命名空间ID]]：
*: <syntaxhighlight lang="mcfunction">data get entity @p Inventory[{Slot:0b}].id</syntaxhighlight>
* 将距离坐标(0, 64, 0)最近的[[海豚]]的护甲[[属性]]设置为20：
*: <syntaxhighlight lang="mcfunction">data modify entity @n[x=0,y=64,z=0,type=dolphin] attributes[{id:"minecraft:armor"}].base set value 20</syntaxhighlight>
* 将位于(1, 64, 1)处容器内的第一个物品设置为钻石块（保留原有的其他NBT）：
*: <syntaxhighlight lang="mcfunction">data modify block 1 64 1 Items[0].id set value "minecraft:diamond_block"</syntaxhighlight>
* 将最近的僵尸副手物品的掉落概率调整为80%，主手物品的掉落概率调整为0%：
*: <syntaxhighlight lang="mcfunction">data merge entity @n[type=zombie] {drop_chances:{offhand:0.8f,mainhand:0.0f}}</syntaxhighlight>
[[File:Minecart with Stonecutter.gif|右|100px]]
* 将距离最近的[[矿车]]中的方块模型改为[[切石机]]（效果如右图所示，以此法更改实体数据的矿车没有切石机的功能，但仍然可以正常搭载生物）：
*: <syntaxhighlight lang="mcfunction">data merge entity @n[type=minecart] {CustomDisplayTile:1b,DisplayState:{Name:"stonecutter",Properties:{facing:"west"}},DisplayOffset:-4}</syntaxhighlight>
* 向命名空间ID为<code>test:test</code>的[[命令存储]]合并一段NBT数据：
*: <syntaxhighlight lang="mcfunction">data merge storage test:test {input:{arg1: 233}, output: {fun_res1: 0}}</syntaxhighlight>
* 将位于(0, 64, 0)的箱子的NBT中的{{nbt|list|Items}}列表中的第一个元素添加至位于(2, 64, 0)的箱子的NBT中的{{nbt|list|Items}}列表的尾部，作为该列表的理论上的最后一个元素（事实上，该列表会因为箱子内槽位物品的改变而重新排列，排列顺序以每个元素中的{{nbt|byte|Slot}}标签的值为准）：
*: <syntaxhighlight lang="mcfunction">data modify block 2 64 0 Items append from block 0 64 0 Items[0]</syntaxhighlight>
* 为位于(0, 64, 0)的箱子中的第一个物品添加/修改{{nbt|int|damage}}标签，值为<code>700</code>。存在两种示例达到相同效果：
*: <syntaxhighlight lang="mcfunction">data modify block 0 64 0 Items[0].components merge value {damage:700}</syntaxhighlight>
*: <syntaxhighlight lang="mcfunction">data modify block 0 64 0 Items[0].components.damage set value 700</syntaxhighlight>
* 将位于(2, 64, 0)的箱子中的第一个物品（设其位于第一个槽位）的复合标签添加至第一个槽位已有物品的位于(0, 64, 0)的箱子中的{{nbt|list|Items}}列表的理论尾部（实际上，前者会覆盖后者，即：将后者箱子的第一个槽位的物品替换为前者箱子的第一个槽位的物品）：
*: <syntaxhighlight lang="mcfunction">data modify block 0 64 0 Items append from block 2 64 0 Items[0]</syntaxhighlight>
* 使用<code>set</code>+<code>string</code>修饰方法将位于(0, 64, 0)箱子中的第一个物品的{{nbt|string|id}}替换为(2, 64, 0)中的第一个物品的该标签：
*: <syntaxhighlight lang="mcfunction">data modify block 0 64 0 Items[0].id set string block 2 64 0 Items[0].id 0</syntaxhighlight>
* 从{{nbt|string|buffer}}取第一个字符到{{nbt|string|cur_char}}，然后清除{{nbt|string|buffer}}中的第一个字符。
*: <syntaxhighlight lang="mcfunction">
data modify storage wiki:string cur_char set string storage wiki:string buffer 0 1
data modify storage wiki:string buffer set string storage wiki:string buffer 1
</syntaxhighlight>
* 从{{nbt|list|args.input}}取所有元素，添加到{{nbt|list|args.output}}头部。
*: <syntaxhighlight lang="mcfunction">
data modify storage wiki:test args.output prepend from storage wiki:test args.input[]
</syntaxhighlight>
