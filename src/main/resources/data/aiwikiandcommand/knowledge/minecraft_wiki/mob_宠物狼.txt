'''宠物狼（Pet Wolf）'''是[[狼]]在[[25w14craftmine]]愚人节版本中的[[宠物（25w14craftmine）|宠物]]变种。

== 生成 ==
解锁可解锁项目“[[可解锁项目#pet wolf|宠物狼（Pet Wolf）]]”后进入新的[[矿境]]或在矿境中解锁该项目时会生成一只宠物狼。

== 掉落物 ==
宠物狼被杀死时不会掉落物品和[[经验]]。

== 行为 ==
宠物狼与常规版本中的狼类似，但有以下不同：
* 玩家的近战攻击无法对宠物狼造成伤害。
* [[骷髅]]、[[凋灵骷髅]]、[[流浪者]]和[[沼骸]]不会主动避开宠物狼，但宠物狼仍会主动攻击它们，使它们也开始攻击宠物狼。
* 玩家无法对宠物狼{{ctrl|使用}}[[骨头]]，尽管玩家在距宠物狼8格内的位置手持肉类或[[骨头]]时，宠物狼会侧着头，像在乞求食物。
* 宠物狼可以被升级为大型狼、携带[[下界合金剑]]或穿着[[狼铠]]。

== 音效 ==
宠物狼的部分音效随其音效变种而改变，但部分音效总是一致。
