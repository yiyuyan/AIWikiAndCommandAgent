'''1.19.2'''是{{el|je}}的一次次要更新，发布于2022年8月5日<ref name="article_1.19.2">{{article|minecraft-java-edition-1-19-2|Minecraft Java Edition 1.19.2|August 5, 2022}}</ref>，修复了2个严重漏洞。此版本不兼容1.19的服务端，兼容1.19.1的服务端。
