将指定位置的方块更改为另一个方块。

== 语法 ==
* '''Java版'''
: <code>setblock <pos> <block> [destroy|keep|replace|strict]</code>

* '''基岩版'''
: <code>setblock <position: x y z> <tileName: Block> [blockStates: block states] [destroy|keep|replace]</code>

== 参数 ==
{{argument|pos|block_pos|position: x y z|CommandPosition}}
: 指定要被更改方块的位置。
: {{arg desc|je=block_pos|be=CommandPosition}}

{{argument|block|block_state|tileName: Block|Block}}
: 指定更改后的新方块。
: {{arg desc|je=block_state|be=Block}}

{{el|be|short=1}}：{{argument|be=1|blockStates: block states|BlockStateCommandParam}}
: 指定新方块的[[方块状态]]。
: {{arg desc|be=BlockStateCommandParam}}

{{cd|d=pretty|destroy{{!}}keep{{!}}replace|destroy{{!}}keep{{!}}replace{{!}}strict}}
: 指定方块更改的处理方式，必须为以下其中之一：
:* <code>destroy</code> — 原方块以[[掉落物]]的形式掉落（液体方块及如藤蔓等仅可由剪刀采集的方块除外），并播放方块被破坏的音效。
:* <code>keep</code> — 仅当原方块是[[空气]]类方块时才进行更改。
:* <code>replace</code> — 原方块不掉落物品，且不播放方块被破坏的音效。
:* <code>strict</code> — 在放置方块时不触发自身及紧挨着的方块的方块更新和形状更新。
: 如果未指定，默认为<code>replace</code>。

== 示例 ==
* 在你脚的位置上放置一个朝北的[[箱子]]：
** {{el|je|short=1}}：<code>setblock ~ ~ ~ chest[facing=north]</code>
** {{el|be|short=1}}：<code>setblock ~ ~ ~ chest ["facing_direction"=2]</code>
* 在你的头上放置一个位于上半格的[[石英台阶]]：
** {{el|je|short=1}}：<code>setblock ~ ~2 ~ quartz_slab[type=top]</code>
** {{el|be|short=1}}：<code>setblock ~ ~2 ~ stone_block_slab ["stone_slab_type"="quartz","top_slot_bit"=true]</code>
* {{in|je}}在你位置的北边一格处放置第一行写有“我的箱子”且第二行写有“请勿打开！”的[[告示牌]]：
** <code>setblock ~ ~ ~-1 birch_sign{front_text:{messages:["我的箱子","请勿打开！","",""]<nowiki>}}</nowiki></code>（告示牌即使有几行空着也要把总共四行写全，否则无法正确解析）
* {{in|je}}放置一块内含一个苹果的[[可疑的沙砾]]：
** <code>setblock ~ ~ ~ minecraft:suspicious_gravel{item:{id:"minecraft:apple",count:1<nowiki>}}</nowiki></code>
