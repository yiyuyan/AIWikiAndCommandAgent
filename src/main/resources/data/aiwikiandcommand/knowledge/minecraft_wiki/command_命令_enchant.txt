为一个实体手持的物品添加[[魔咒]]。受限于[[铁砧机制]]。<ref>{{bug|MC-261942}}</ref>

== 语法 ==
* '''Java版'''
: <code>enchant <targets> <enchantment> [<level>]</code>

* '''基岩版'''
: <code>enchant <player: target> <enchantmentId: int> [level: int]</code>
: <code>enchant <player: target> <enchantmentName: Enchant> [level: int]</code>

== 参数 ==
{{argument|targets|entity|player: target|CommandSelector<Actor>}}
: 指定目标。
: {{arg desc|je=entity|amount=multiple|type=entities|be=actor}}

{{el|je|short=1}}：{{argument|enchantment|resource}}<br>
{{el|be|short=1}}：{{argument|be=1|enchantmentId: int|int}}或{{argument|enchantmentName: Enchant|enum}}
: 指定要添加到实体主手持有物品上的[[魔咒]]。
: {{arg desc|je=resource|registry=minecraft:enchantment|be=enum}}

{{argument|level|integer|level: int|int}}
: 指定魔咒的等级。此值不应当大于指定魔咒的[[魔咒#魔咒属性|最大等级]]。若未指定则默认为1。
: {{arg desc|be=int|je=integer|min=0}}{{in|be}}应当大于等于1。

== 示例 ==
* 给所有手持弓的玩家的主手物品添加无限：<code>enchant @a 22</code>{{only|bedrock}}或<code>enchant @a infinity</code>
* 给所有手持剑的盔甲架的主手物品添加锋利：<code>enchant @e[type=armor_stand] 9</code>{{only|bedrock}}或<code>enchant @e[type=armor_stand] sharpness</code>
