'''彩色火把（Colored torch）'''是被[[氯化物]]染色的[[火把]]，目前有蓝色、红色、紫色和绿色。

== 生成 ==
彩色火把不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|showdescription=1
|B2=Cerium Chloride; Mercuric Chloride; Potassium Chloride; Tungsten Chloride
|B3=Torch
|Output=Blue Torch; Red Torch; Purple Torch; Green Torch
|description={{only|be|ee}}<br>氯化铈：蓝色<br>氯化汞：红色<br>氯化钾：紫色<br>六氯化钨：绿色
|type=Decoration block
}}

== 破坏 ==
彩色火把被挖掘时会立刻被破坏。

{{Breaking table|only=be}}

彩色火把被破坏后会掉落自身。

== 用途 ==
彩色火把可以被放置于大多数固体方块的顶端或侧面，不过有个别的需要{{control|潜行}}（例外情况见[[#放置|放置]]）。彩色火把为非固体方块，没有碰撞箱。

如果在[[沙子]]或[[沙砾]]这种受重力影响的方块正下方有一个彩色火把，它将不会下落。如果它下落到彩色火把的位置，它将被破坏。

彩色火把会不时发出与自身对应颜色相同颜色的火焰形状粒子。

=== 放置 ===
彩色火把只能被放置于方块[[方块支撑形状|中心完整]]的上表面上方或方块完整的侧面。

彩色火把发出亮度为14的[[光]]。彩色火把能融化[[曼哈顿距离]]2格内的[[雪]]和[[冰]]。
