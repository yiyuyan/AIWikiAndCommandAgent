'''26.1.2-rc-1'''是[[Java版26.1.2]]的唯一一个发布候选版本，发布于2026年4月8日<ref>{{article|minecraft-26-1-2-release-candidate-1|Minecraft 26.1.2 Release Candidate 1|Apr 08, 2026}}</ref>，修复了一些严重漏洞。

== 更改 ==
=== 常规 ===
==== UI ====
* 现在复选框的消息提示框仅在文本超过2行溢出时才会显示。
* 「举报玩家」界面中的确认复选框，现在会显示与消息文本一致的提示框。
