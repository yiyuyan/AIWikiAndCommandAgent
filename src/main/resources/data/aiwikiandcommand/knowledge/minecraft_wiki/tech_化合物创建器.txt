'''化合物创建器（Compound Creator）'''是一种在[[化学]]中用到的方块。它允许通过元素组合来创建37种[[化合物]]。这包括某些在通常游戏中可用的[[物品]]。

== 生成 ==
化合物创建器不会生成在世界中。

== 获取 ==
化合物创建器不能在生存模式中正常获得，但可以通过[[创造模式物品栏]]、[[创造模式]]中使用{{ctrl|选取方块}}或{{cmd|give}}[[命令]]获得。

== 破坏 ==
挖掘化合物创建器的合适工具是镐。

{{Breaking table|only=be}}

化合物创建器被破坏后会掉落自身。

== 用途 ==
{{main|化合物}}
对化合物创建器使用{{ctrl|使用}}键可打开其界面，界面中3×3的表格可放入元素以创建化合物。通过放入适当类型和数量的元素，元素创建器会在网格右侧的槽位输出化合物。所有化合物的合成表都是无序的，与[[工作台]]不同，堆叠数量也要考虑在内。化合物创建器的输出栏可以无限拿取化合物，不会消耗原材料。

当化合物创建器顶部着火时，其将无法使用。

虽然化合物创建器的模型上有一个凹槽，但化合物创建器的碰撞箱和完整方块相同。

若化合物创建器在关闭教育版选项的世界被放置，其模型会正常被调用，但纹理会变成数据更新方块。
