'''方块（Block）'''是[[Minecraft]]世界里最基本的组成单位。

== 行为 ==
[[File:Forest beside Plains.png|thumb|由多种自然方块组成的景观，能看到[[草方块]]、[[树叶]]、[[矮草丛]]等方块]]
在游戏中，存在由无数单元组成的[[wzh:立方体堆砌|网格]]，每个单元为1立方米，方块就存在于这些单元里。一个单元内通常只能有一个方块，但[[台阶]]、[[海龟蛋]]、[[蜡烛]]、[[海泡菜]]等方块是例外。

游戏内的环境由方块构成，玩家能以多种方式对其进行收集和利用。

[[空气]]是一种特殊方块，无法被破坏，不阻挡移动，是一个单元格内没有方块时的替代物。{{in|je}}它有两个变种：[[洞穴空气]]和[[虚空空气]]。

部分方块能发出[[亮度|光亮]]，如[[火把]]和[[荧石]]，不同方块的亮度有所不同，从低到高依次为0（不发光）至15。

大多数方块不受重力影响，例外的有[[沙子]]、[[红沙]]、[[沙砾]]、[[铁砧]]、[[龙蛋]]、[[混凝土粉末]]、没有支撑的[[脚手架]]、{{only|be|for=[[雪]]}}、[[可疑的沙子]]和[[可疑的沙砾]]。

方块被破坏后会发出相应的[[声音]]和[[粒子]]，但以下情况除外：
* {{in|je}}方块受重力影响，且掉落到无效位置<ref>{{bug|MC-135869}}</ref>
* 坠落或用到损坏的[[铁砧]]（仅无粒子出现）<ref>{{bug|MC-135868}}</ref>
* 方块被流体冲掉<ref>{{bug|MC-25976}}</ref>
* 方块被其他方块占据其位置<ref>{{bug|MC-136703}}</ref>
* [[铁轨]]（所有种类）、[[火把]]、[[灵魂火把]]、[[红石线]]、[[红石中继器]]和[[红石比较器]]的支持方块被移除<ref>{{bug|MC-123350}}</ref>
* [[树叶]]枯萎<ref>{{bug|MC-136693|||WAI}}</ref>

== 方块物品 ==
{{main|方块物品}}
'''[[方块物品]]（Block Item）'''是用于表示方块的一类[[物品]]，可以{{Control|放置}}为世界中的方块。

== 方块高度 ==
{{main|判定箱#碰撞箱}}

大多数方块都是1×1×1格的正方体，但也有一些例外（如[[台阶]]和[[楼梯]]），这类方块被称为不完整方块。

在一般情况下，若两个相邻方块之间的高度差小于0.6（{{frac|3|5}}）格，则生物无需跳跃就可直接[[走上方块|走上这个高度差]]。

== 纹理 ==
绝大部分方块表面的纹理都是16×16像素的。大多数方块默认为一立方米大小，但它们能使用[[模型]]来改变。

大多数方块的纹理是静态的，但[[水]]、[[熔岩]]、[[下界传送门（方块）|下界传送门]]、[[末地传送门（方块）|末地传送门]]及[[末地折跃门（方块）|末地折跃门]]方块、[[火]]、[[灵魂火]]、[[海晶灯]]、[[海晶石]]、[[岩浆块]]、[[菌柄]]、[[菌核]]、[[海草]]、[[海带]]、[[灯笼]]、[[灵魂灯笼]]、[[铜灯笼]]、[[幽匿块]]、[[幽匿感测体]]、[[校频幽匿感测体]]、[[幽匿尖啸体]]、[[幽匿脉络]]、点燃的[[营火]]和[[灵魂营火]]、{{only|be|ee|for=[[加热块]]}}、已充能的[[重生锚]]、燃烧中的[[高炉]]及[[烟熏炉]]、[[切石机]]、[[萤火虫灌木丛]]和[[命令方块]]的纹理是动态纹理。

通过使用[[资源包]]，玩家能够改变方块的纹理和分辨率，包括决定纹理是否为动态。资源包也能够使用[[模型]]来改变方块的形状或使方块等比例缩放，不过二次方长度的尺寸通常效果比较好。

=== 技术性方块 ===
技术性方块是指在游戏中的事件发生期间可用于各种目的的方块，或使用单独的命名空间ID以避免[[方块状态]]的不必要组合。{{in|je}}技术性方块通常没有对应的[[方块物品]]，它们不能通过正常游戏获得，且大部分都不能通过[[命令]]或者使用编辑器获得。{{in|be}}部分技术性方块则可以使用物品栏编辑器或[[附加包]]来获得。
{{in|je}}如果玩家获得技术性方块，它们的纹理通常是[[File:Missing Model.png|26px]] [[无效纹理]]。

== 你知道吗 ==
* 特定的方块可通过特殊手段放置在正常手段无法放置的位置里。例如，通过{{cmd|setblock}}或{{bug|MCPE-32689|漏洞}}在空中放置[[告示牌]]，它会保持在那个位置，直至其被破坏，或是收到方块更新使其检查自身是否应被破坏。
