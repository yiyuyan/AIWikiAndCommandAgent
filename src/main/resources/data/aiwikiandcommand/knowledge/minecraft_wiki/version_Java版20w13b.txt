'''20w13b'''是[[Java版1.16]]的第9个快照，发布于2020年3月26日<ref name="20w13b">{{snap|20w13b|March 26, 2020}}</ref>，修复了前2个快照中的一些严重漏洞。

== 修复 ==
{{fixes|fixedin=20w13b|showdesc=1
|;old
|102439|盾牌不同步。
|156306|村民在空闲或聚集期间不会扔面包。
|156600|盾牌抵御伤害后看起来停止了防御，但实际上仍在被使用。
|160020|正在拉附有经验修补魔咒的弓时，如果吸收到经验球使弓的耐久度上升，则其他未被拉弦的弓也会显示为被拉弦的纹理。
|;dev
|173013|在钓鱼竿抛竿抛钩后切换至另一根钓鱼竿时，钓鱼竿贴图显示为未抛钩状态。
|175177|耗尽、破坏或阻挡重生锚会使得在主世界破坏方块时生成幽灵方块。
|175241|地毯会阻挡重生锚。
|175315|重生锚不能正常工作。
|175604|铁傀儡并不总是在村庄中自然生成。
|;previous
|175988|在没有有效重生点的情况下死亡会造成“软锁”（softlock）。
|176004|在没有有效重生点的情况下在末地或下界死亡后无法与世界交互。
