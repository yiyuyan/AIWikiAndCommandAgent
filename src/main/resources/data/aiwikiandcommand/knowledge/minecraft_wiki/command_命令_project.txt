该命令包含用于管理[[编辑器]]项目的工具。

== 语法 ==
: <code>project export <exportType: ExportTypes></code>

== 参数 ==
{{argument|be=1|exportType: ExportTypes|enum}}
: 指定导出内容的类型，可用值有：
:* <code>project</code> — 项目
:* <code>template</code> — 世界模板
:* <code>world</code> — 世界
