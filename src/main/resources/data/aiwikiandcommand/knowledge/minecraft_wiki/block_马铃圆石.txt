'''马铃圆石（Taterstone）'''是[[马铃薯维度]]中常见的方块。

== 生成 ==
马铃圆石会以[[团簇]]的形式在马铃薯维度Y坐标5-81的范围中生成。每[[区块]]生成14次，团簇的大小为0-33个方块。

马铃圆石还会生成在[[马铃薯村庄]]、[[角斗场]]和所有维度的[[废弃马铃薯传送门]]。

== 获取 ==
没有被具有[[精准采集]]的工具挖掘破坏时，[[马铃石]]被破坏后会掉落1个马铃圆石。

== 破坏 ==
挖掘马铃圆石的合适工具是锄。马铃圆石需要木锄或品质更好的锄来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table/manual|only=je|nocopper=1|{{BlockSprite|Taterstone}} 马铃圆石|2|wooden hoe}}

马铃圆石被破坏后会掉落自身。

== 用途 ==
马铃圆石可替代[[圆石]]来合成石质工具、[[熔炉]]和[[酿造台]]。
