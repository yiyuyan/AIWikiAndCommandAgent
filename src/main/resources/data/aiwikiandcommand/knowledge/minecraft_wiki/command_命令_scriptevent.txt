通过ID和消息来触发-{}-脚本事件。

== 语法 ==
:<code>scriptevent <messageId: string> <message: message></code>

== 参数 ==
{{argument|messageId: string|string|be=1}}
:指定触发脚本事件的消息ID。
:{{arg desc|be=basic_string}}

{{argument|message: message|CommandMessage|be=1}}
:指定触发脚本事件的消息。
:{{arg desc|be=CommandMessage}}

== 结果 ==
{{Result table|onlybe=1}}
{{Result table|参数未正确指定||unparseable}}
{{Result table|指定ID不存在或使用<code>minecraft</code>命名空间||fail}}
{{Result table|消息长度超出256个字符}}
{{Result table|<code>message: message</code>未指定<ref name="MCPE-185429">{{bug|MCPE-185429|||Fixed}}</ref>||success}}
{{Result table|success}}
{{Result table}}

== 输出 ==
{{Output table|onlybe=1}}
{{Output table|edition=be|执行失败|0}}
{{Output table|执行成功|1}}
{{Output table}}

== 示例 ==
* 使用消息ID{{cd|foo:bar}}来触发脚本事件：<code>/scriptevent foo:bar</code>
* 使用消息ID{{cd|foo:bar}}来触发脚本事件，并传入消息{{cd|baz}}：<code>/scriptevent foo:bar baz</code>
