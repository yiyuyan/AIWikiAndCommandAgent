这篇指南是[[马匹更新]]（Java版1.6.x）的简要概述，本指南假定读者对[[红石更新]]（Java版1.5.x）的内容有基本了解。

== 生物 ==
=== 新内容 ===
{| class = "wikitable"
! 名称 !! 外观 !! 生成于 !! 掉落 !! 备注
|-
|[[马]] 
|[[File:White Horse JE1 BE1.png|128px]]
| 在平原生成
|{{Drop|Item|Leather|0|2}}
* {{xp|1|3}}（被玩家或驯服的狼杀死时）
|
* Mo' Creatures(更多生物mod)的作者DrZhark帮忙进行了创作。
* 通过右击来骑上它们，未驯服的马将不断将玩家踢下，驯服时会显示红心。
* 可以对驯服的马使用金苹果或金胡萝卜繁殖。
* 可以通过喂面包、糖、干草捆、小麦、苹果、金苹果或金胡萝卜回复生命值。
* 幼年马也可以通过这种方式加快生长。
* 玩家需要将鞍安上才能控制马的移动。
** 不同的马之间的颜色、样子、最大生命值、跳跃高度和速度有所不同。
* 驯服后通过潜行+右击或骑着时打开物品栏来安上/取下鞍和马铠。
* 成群生成。
|-
|[[驴]]
|[[File:Donkey JE1 BE1.png|128px]]
| 在平原生成
|{{Drop|Item|Leather|0|2}}
* {{xp|1|3}}（被玩家或驯服的狼杀死时）
|
* 与马相似，但比马小而且是灰色的。
* 可以安上箱子，箱子会有15个物品槽。
|-
|[[骡]]
|[[File:Mule JE1 BE1.png|128px]]
| 只能通过将马和驴交配来生出
|{{Drop|Item|Leather|0|2}}
* {{xp|1|3}}（被玩家或驯服的狼杀死时）
|
* 和驴一样能安上箱子。
* 无法与马、驴或其他骡进行交配。
|-
|[[骷髅马]]和[[僵尸马]]
|{{Animate|Skeleton Horse JE1 BE1.png; Zombie Horse JE1 BE1.png|128px}}
| 只能通过第三方程序在游戏中生成
| 无
|
* 存在于马的代码中，可以通过第三方程序在游戏中生成。
|}

=== 更改 ===
{| class = "wikitable"
! 名称 !! 外观 !! 更改
|-
|所有生物
|
|
* 名字为“Dinnerbone”或“Grumm”的生物将看上去上下颠倒（参见：[[彩蛋#倒立的生物|彩蛋]]）。
* 现在又可以成群生成了。
|-
|[[僵尸]]
|[[File:Zombie JE1 BE1.png|128px]]
|
* 现在有概率在被攻击或是没被注视时生成更多的僵尸。
* 锁定玩家的距离为40米（以前是16米）。
* 被激怒的僵尸即使在玩家32米外仍能行动。
|-
|[[凋灵]]
|[[File:Wither JE1 BE1.png|128px]]
|
* 重制了盔甲效果。
|}
