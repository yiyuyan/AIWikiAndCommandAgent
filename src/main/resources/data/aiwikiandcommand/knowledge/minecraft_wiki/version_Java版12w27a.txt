'''12w27a'''是[[Java版1.3.1]]的第14个快照，发布于2012年7月5日<ref>{{cite|url=http://mojang.com/2012/07/minecraft-1-3-info-snapshot-w27/|archive-url=1|archive=1|title=Minecraft 1.3 Info + Snapshot w27|author=Jens Bergensten|website=Mojang.com|date=Jul 5, 2012}}</ref>，加入了{{cmd|debug}}命令，并修复了一些漏洞。

== 新内容 ==
=== 命令格式 ===
'''{{cmd|debug <start{{!}}stop>}}'''
* 开始或结束调试分析。

== 更改 ==
=== 方块 ===
'''[[下界疣]]'''
* 下界疣现在能种植在[[主世界]]和[[末地]]里。

'''[[告示牌]]'''
* 现在可以堆叠至16个。
* 合成告示牌现在能获得3个而不是1个，配方与之前一样。

'''[[活塞]]'''
* 减少了出错的可能，但它们激活状态的更新变慢了，这也改变了活塞的工作方式，使得玩家不得不改变使用[[红石中继器]]等装置的属性。
** 关于这个更改，活塞现在需要2红石刻（4游戏刻）来伸展，但它们仍会瞬间收回。

=== 非生物实体 ===
'''[[船]]'''
* 船现在被玩家摧毁时会掉落物品。

=== 游戏内容 ===
'''[[创造模式物品栏]]'''
* 现在会在创造模式物品栏下显示玩家当前拥有的[[状态效果]]。

'''[[经验]]'''
* 采矿获得的经验现在不同了（采集[[煤矿石]]获得的经验较少，而采集[[钻石矿石]]和[[绿宝石矿石]]获得的经验较多）。

== 修复 ==
; 修复了13个漏洞
: 新加入的木楼梯现在会燃烧了。
: 修复了{{cmd|kill|link=none}}命令不能工作的漏洞。
: 修复了给特定的有漏洞的活塞充能时导致游戏崩溃的漏洞。
: 修复了导致活塞部分不可见和暂时处于错误位置的视觉漏洞。
: 修复了在下界放置下界传送门并通过时，其在主世界对应位置的门可以生成在非法位置上的漏洞。
: 修复了使用特定语言时，向局域网开放单人游戏会导致崩溃的漏洞。
: 修复了在矿车、船和猪上的玩家以及蜘蛛骑士不被显示在正确位置上的漏洞。
: 修复了一个关于发射器的漏洞。
: 修复了{{cmd|say|link=none}}命令不接受某些来自控制台的字符串，从而显示帮助文本的漏洞。
: 修复了可以使用依赖于方向的绊线，将方块原有数据值变为特定数据值的漏洞。
: 修复了在创造模式中喝药水不消耗药水，但是仍然会给予空玻璃瓶的漏洞。
: 修复了告示牌有时不会保存放置它们时写入的文本内容的漏洞。
: 修复了火把不会照亮其本身所附着的1×1 Y轴上的方块的漏洞。</onlyinclude>
