{{in|java|nc=1}}重新加载[[数据包]]，{{in|bedrock|nc=1}}重新加载[[行为包]]中的[[基岩版函数|函数]]和脚本。

== 用法 ==
如果数据包或行为包含有无效数据（例如错误的配方格式），更改将不会应用，游戏会使用先前的数据。{{Needs testing|bedrock=1}}

{{in|java}}数据包的{{cd|d=pretty|damage_type|dimension|dimension_type|enchantment|jukebox_song|trim_material|trim_pattern|worldgen}}等实验性注册项的数据必须依赖于世界加载。<ref>{{bug|MC-187938|||Invalid}}</ref><ref>{{bug|MC-260446|||Invalid}}</ref><ref>{{bug|MC-260452|||Invalid}}</ref><ref>{{bug|MC-272540|||WAI}}</ref><ref>{{bug|MC-273807|||Invalid}}</ref>这些注册项不能使用<code>/reload</code>命令重新加载，只能在重新进入世界时加载。

== 语法 ==
* '''Java版'''
: <code>reload</code>
* '''基岩版'''
: <code>reload [all: reload_all]</code>

== 参数 ==
{{el|be|short=1}}：{{argument|be=1|all: reload_all|enum}}
: 必须为<code>all</code>，使玩家退出并重新加入世界，同时重载所有行为包和[[资源包]]。仅非[[BDS]]可用。
