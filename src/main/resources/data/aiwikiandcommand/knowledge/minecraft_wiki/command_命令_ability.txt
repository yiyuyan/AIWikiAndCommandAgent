赋予或撤销玩家的能力。玩家退出游戏后，所有的能力均被撤销。

== 语法 ==
: <code>ability <player: target> <ability: Ability> <value: Boolean></code>
: <code>ability <player: target> [ability: Ability]</code>

== 参数 ==
{{argument|be=1|player: target|CommandSelector<Player>}}
: 指定要赋予或剥夺能力的玩家。
:{{arg desc|type=players|be=player}}

{{argument|be=1|ability: Ability|enum}}
: 指定要操作的能力。必须是下面几项的其中之一：
:* <code>worldbuilder</code>给予玩家成为世界建造者的能力。
:* <code>mayfly</code>给予飞行的能力。
:* <code>mute</code>将玩家禁言。聊天时其他人将无法看见或听见目标。

{{argument|be=1|value: Boolean|enum}}
: 指定此能力是否对玩家可用。
:{{arg desc|be=bool}}
