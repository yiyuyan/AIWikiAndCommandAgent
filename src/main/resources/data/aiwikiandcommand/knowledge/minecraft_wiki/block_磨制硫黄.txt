'''磨制硫黄（Polished Sulfur）'''是[[硫黄]]制作的装饰性方块。

== 生成 ==
磨制硫黄不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|A2=Sulfur
|A3=Sulfur
|B2=Sulfur
|B3=Sulfur
|Output=Polished Sulfur,4
|type=Building block
}}

=== 切石 ===
{{stonecutting
|Sulfur
|Polished Sulfur
}}

== 破坏 ==
挖掘磨制硫黄的合适工具是镐。磨制硫黄需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

磨制硫黄被破坏后会掉落自身。
