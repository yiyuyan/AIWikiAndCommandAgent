'''1.21.10'''是{{el|je}}的一次热修复更新，发布于2025年10月7日<ref>{{article|minecraft-java-edition-1-21-10|Minecraft Java Edition 1.21.10|Oct 07, 2025}}</ref>，修复了一些漏洞。此版本不兼容1.21到1.21.8的服务端，兼容1.21.9的服务端。

== 修复 ==
{{fixes|fixedin=1.21.10 Release Candidate 1|showdesc=1|new=1
|;old
|211096|蜘蛛网中的实体会卡进活塞。
|278182|物品被推入细雪或蜘蛛网时会卡在活塞头内。
|;1.21.9的漏洞
|301916|风弹与某些方块发生碰撞时的行为不同。
|302321|玩家被传送时区块不加载。
|302383|不能在地毯所在的竖直面上的物品展示框中放置地图。
|302405|连锁型或循环型命令方块执行<code>/tp [player]</code>形式的命令时不会将玩家反复传送到一个位置。
|;other
|1.|气泡柱上的实体会飞到高空中。<ref>{{article|minecraft-1-21-10-release-candidate-1|Minecraft 1.21.10 Release Candidate 1|Oct 02, 2025}}</ref>
}}
