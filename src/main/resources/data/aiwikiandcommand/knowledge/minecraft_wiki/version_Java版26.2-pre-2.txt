'''26.2-pre-2'''是[[Java版26.2]]的第2个预发布版，发布于2026年5月28日<ref>{{article|minecraft-26-2-pre-release-2|Minecraft 26.2 Pre-Release 2|May 28, 2026}}</ref>，修复了一些漏洞。

== 更改 ==
=== 常规 ===
'''[[数据包]]'''
* 将数据包版本号更改为<code>107.0</code>。

== 修复 ==
{{fixes|fixedin=26.2 Pre-Release 2|showdesc=1|new=1
|;26.2前正式版的漏洞
|305475|跳跃时，玩家头上方的绊线会被触发两次。
|308363|在少数情况下，雪屋生成会使服务端死锁。
|;dev
|307662|调试叠加层的图形后端版本行不支持换行符。
|307759|游戏刻速率较低时让硫方怪快速吸收和移除方块会导致不同步。
|308033|盾牌的格挡动画过快。
|308135|使用Vulkan渲染后端时，较大的核心着色器文件会加载失败。
|308207|可以在替换硫方怪吸收的方块的同时点燃其吸收的TNT。
|308281|元素缓冲区绑定缺失，导致OpenGL MultiDraw崩溃。
|;prev
|308439|启用“Programmer Art”资源包时，床的尾部显示为无效模型。
|308442|信标的辅助效果选择为II级效果时，切换信标的主效果会导致玩家被踢出游戏。
|308452|游戏在Mac上启动时崩溃。
|308457|游戏在不支持Vulkan的系统上启动时崩溃。
|308465|存档文件夹不存在时，尝试创建新的世界会导致游戏崩溃。
}}</onlyinclude>
