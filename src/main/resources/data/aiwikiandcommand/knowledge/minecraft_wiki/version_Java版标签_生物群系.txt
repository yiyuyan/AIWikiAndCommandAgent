'''生物群系标签（Biome Tags）'''是[[生物群系]]的组合。

{{TOC|right}}

== 使用 ==
生物群系标签控制了结构生成、生物生成等许多功能。命令{{cmd|locate biome}}、{{cmd|execute if biome}}等也可以调用生物群系标签。
