'''有色玻璃（Tinted Glass）'''是由[[玻璃]]制作的装饰性方块。

== 生成 ==
有色玻璃不会生成在世界中。

== 破坏 ==
没有工具可以加速对有色玻璃的挖掘。
{{Breaking table/manual
| only = je
| {{BlockSprite|All Tinted Glass}} 有色玻璃
| 0.3
| none
}}

没有被具有[[精准采集]]的工具挖掘破坏时，有色玻璃被破坏后不会掉落。

被具有精准采集的工具挖掘破坏时，有色玻璃被破坏后会掉落自身。

== 用途 ==
有色玻璃是一种视觉透明方块，可以透过它看到后面的物体，但被其遮住的临近同种有色玻璃会隐形。

[[生物]]无法生成于有色玻璃顶部。

红石粉和其他红石装置可以放置在有色玻璃上，但不能为有色玻璃充能。有色玻璃不会切断竖直方向上连接的红石线，红石粉也可以在有色玻璃上竖直连接。
