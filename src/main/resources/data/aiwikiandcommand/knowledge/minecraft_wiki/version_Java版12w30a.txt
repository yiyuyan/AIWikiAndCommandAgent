'''12w30a'''是[[Java版1.3.1]]的第15个快照，发布于2012年7月23日<ref>{{cite|url=http://mojang.com/2012/07/mincraft-snapshot-12w30a/|archive-url=1|archive=1|title=Minecraft Snapshot 12w30b|author=Jens Bergensten|website=Mojang.com|date=Jul 23, 2012}}</ref>，优化了游戏性能，并修复了一些漏洞。

== 新内容 ==
=== 常规 ===
'''[[选项]]'''
* 匿名信息反馈
** 允许用户调整需要向[[Mojang]]发送哪些匿名数据，以便用于分析和改进Minecraft，并显示哪些数据将被发送。
* 在视频选项中加入了垂直同步。
** 需手动在{{filename|options.txt}}里调整。
* 全屏模式现在是长期有效的。
** 需手动在{{filename|options.txt}}里调整。

== 更改 ==
=== 方块 ===
'''[[楼梯]]'''
* 现在放置在方块的上半部时会被倒置。

=== 生物 ===
'''[[苦力怕]]'''
* 根据难度，苦力怕的伤害会发生变化。
** 简单：伤害减少50%
** 一般：与之前相同
** 困难：伤害比之前增加33%
** “全套钻石盔甲+困难难度，一只苦力怕能把玩家炸伤得只剩下4点生命值"<ref>{{tweet|dinnerbone|227339500941082626}}</ref>
* 苦力怕、[[火焰弹]]和[[TNT]]的爆炸可以击退生物了。

=== 世界生成 ===
'''[[下界]]'''
* 减少下界的卡顿程度。

=== 命令格式 ===
'''{{cmd|gamemode}}'''
* 切换游戏模式至生存模式的命令由{{cmd|gamemode 3}}更改为{{cmd|gamemode 0}}。

=== 常规 ===
'''[[调试屏幕]]'''
* 按{{key|F3}}打开调试屏幕后，Y坐标现在会显示脚的高度和眼睛的高度。

'''性能'''
* 加快区块加载速度。
* 降低卡顿频率，使得在[[下界]]的延迟减少。即便[[服务器]]存在延时，聊天仍能流畅工作。
* 减少不必要的世界更新。
* 减少客户端和服务器之间发送的数据包。

== 修复 ==
; 修复了19个漏洞
: 修复了先前存在的告示牌不显示文字的漏洞。
: 修复了所有刷怪笼中显示的旋转生物都是猪的漏洞。
: 修复了在macOS上{{key|Cmd+C}}、{{key|Cmd+X}}和{{key|Cmd+V}}三个组合键不能正常使用的漏洞。
: 修复了加载有潜行中的玩家的区块时其名牌不隐藏的漏洞。
: 修复了多个区块经常不显示的漏洞。
: 修复了服务器侧可视范围设置的很大时导致玩家加入游戏时被立即踢出的漏洞。
: 修复了在加载世界时高于Y=191的区域不显示的漏洞。
: 修复了玩家走入未完全生成的区块时区块不在视觉上更新的漏洞。
: 修复了在重生后，指南针指向的是X=8,Z=8的位置而不是出生点的漏洞。
: 修复了玩家使用钓鱼竿时，钓线看起来是从玩家脚的位置上延伸出去的漏洞。
: 修复了一个关于使用具有耐久魔咒的工具破坏方块的漏洞。
: 修复了可以在服务器列表移动局域网服务器并导致游戏崩溃的漏洞。
: 修复了像局域网开放一个单人世界时保存并退出后服务器仍然运行并显示在服务器列表中的漏洞。
: 修复了使用移动键移动矿车导致视角在所按方向上晃动的漏洞。
: 修复了跨维度后药水效果在视觉上不显示的漏洞。
: 修复了卸载含有恶魂的区块时其发射的火球会被卡在半空中的漏洞。可能也适用于火焰弹和烈焰人发射出的火球。
: 修复了在已打开的创造模式物品栏中的所有页面（除了生存模式物品栏）的快捷栏的最后一个槽位比正常情况要短一个像素，而生存模式物品栏短了几个像素的漏洞。
: 修复了在跳跃时向脚下放置方块导致此方块消失的漏洞。<ref>{{tweet|dinnerbone|226702479449026560}}</ref>
: 修复了踩踏农作物的相关计算是在客户端处理而不是在服务端处理的漏洞。</onlyinclude>
