杀死[[生物]]，清除[[实体|非生物实体]]。

== 用法 ==
受影响的非生物实体会被直接移除。

受影响的生物会受到3.40282×10<sup>38</sup>（{{healthbar|2|9px}} × 1.70141×10<sup>38</sup>）的[[伤害]]，此伤害无视生物的所有伤害防护效果（{{in|je|nc=1}}[[末影龙]]除外），生物不能因受到此伤害触发[[不死图腾]]。

{{in|java}}被该伤害杀死的[[末影龙]]会跳过死亡动画，立即结束[[末影龙战斗]]并开启[[返回传送门]]。

即使玩家是在[[旁观模式]]或{{only|for=[[创造模式]]|java}}下，也会受到这一伤害。而{{in|be}}尝试使用该命令杀死创造模式下的玩家，只会提示“{{tr|玩家在创造模式下无法被杀死。|玩家處於創造模式時不會被殺死。}}”若选择器未找到其他目标则还会提示“{{tr|没有与选择器匹配的目标|無符合選擇器的目標}}”。

== 语法 ==
* '''Java版'''
: <code>kill [<targets>]</code>

* '''基岩版'''
: <code>kill [target: target]</code>

== 参数 ==
{{argument|targets|entity|target: target|CommandSelector<Actor>}}
: 指定要杀死/清除的目标实体。未指定时，目标为命令的执行者。
: {{arg desc|je=entity|amount=multiple|type=entities|be=actor}}

== 示例 ==
* 杀死命令执行者：<code>kill</code>或<code>kill @s</code>
* 杀死名为“Steve”的玩家：<code>kill Steve</code>
* 清除所有物品实体：<code>kill @e[type=item]</code>
* 杀死执行者半径10个方块内的所有实体，包括自己：<code>kill @e[distance=..10]</code>{{only|je}}或<code>kill @e[r=10]</code>{{only|be}}
* 清除玩家以外的实体（物品实体、动物等）：<code>kill @e[type=!player]</code>
* 杀死所有敌对生物：<code>kill @e[family=monster]</code>{{only|be}}
