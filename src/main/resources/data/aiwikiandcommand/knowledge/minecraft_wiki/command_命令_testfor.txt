检测并统计符合指定条件的实体（玩家、生物、物品等）。

== 语法 ==
: <code>testfor <victim: target></code>

== 参数 ==
{{argument|be=1|victim: target|CommandSelector<Actor>}}
: 指定计数的目标。
: {{arg desc|be=CommandSelector<Actor>}}

== 结果 ==
{{Result table|onlybe=1}}
{{Result table|参数未正确指定||unparseable}}
{{Result table|<code>victim: target</code>未能选中一个或多个实体（指定的玩家必须在线上）||fail}}
{{Result table|succeed}}
{{Result table}}

== 输出 ==
{{Output table|onlybe=1}}
{{Output table|执行失败|0}}
{{Output table|执行成功|指定实体的数量}}
{{Output table}}

== 示例 ==
* 检测Alice是否在线上：{{cmd|testfor Alice|link=none}}
* 统计圆心为(0,64,0)、半径为3米的区域内的生存玩家数量：{{cmd|testfor <nowiki>@a[x=0,y=64,z=0,r=3,m=0]</nowiki>|link=none}}
* 统计圆心为(0,64,0)、半径为20米的区域内的僵尸数量：{{cmd|testfor <nowiki>@e[x=0,y=64,z=0,r=20,type=zombie]</nowiki>|link=none}}
* 检测掉落物：{{cmd|testfor <nowiki>@e[type=item]</nowiki>|link=none}}
