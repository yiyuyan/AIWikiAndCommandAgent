在当前维度中添加、移除或列出功能域。

== 语法 ==
:<code>volumearea add <identifier: string> <from: x y z> <to: x y z> <name: string></code>
::在指定范围内添加功能域。
:<code>volumearea list [all-dimensions: VolumeAreaAllDimensions]</code>
::列出当前维度中的功能域。若指定可选参数<code>[all-dimensions: VolumeAreaAllDimensions]</code>，则会列出当前已定义的所有功能域。
:<code>volumearea remove <name: string></code>
::移除指定名称的功能域。
:<code>volumearea remove <position: x y z></code>
::移除指定位置上的功能域。
:<code>volumearea remove_all</code>
::移除所有功能域。

== 参数 ==
{{argument|identifier: string|basic_string|be=1}}
:指定标识符的名称。
:{{arg desc|be=basic_string}}
{{argument|from: x y z|CommandPosition|be=1}}和{{argument|to: x y z|CommandPosition|be=1}}
:指定添加功能域范围的两组对角方块坐标。
:{{arg desc|be=CommandPosition}}
{{argument|name: string|basic_string|be=1}}
:指定功能域的名称。
:{{arg desc|be=basic_string}}
{{argument|position: x y z|CommandPosition|be=1}}
:指定功能域的位置。
:{{arg desc|be=CommandPosition}}
{{argument|all-dimensions: VolumeAreaAllDimensions|enum|be=1}}
:指定是否列出其他维度的功能域。
