'''12w05b'''是[[Java版1.2.1]]的第4个快照，发布于2012年2月3日<ref>{{cite|url=http://mojang.com/2012/02/03/minecraft-snapshot-12w05b/|archive-url=1|archive=1|title=Minecraft Snapshot 12w05b|author=Jens Bergensten|website=Mojang.com|date=Feb 3, 2012}}</ref>，略微改动了生物AI，并修复了一些漏洞。

== 更改 ==
=== 生物 ===
'''[[苦力怕]]'''
* 略微改进了AI。
* 现在会逃离[[猫]]和[[豹猫]]。

'''[[村民]]'''
* 现在可以开关门。

=== 常规 ===
'''[[死亡消息]]'''
* 按钮变为活动状态之前，死亡屏幕会稍微出现延迟，以免在被杀时意外点击按钮。

== 修复 ==
; 修复了2个漏洞
: 修复了按住{{key|Shift}}单击会只提供一半物品和消耗所有的剩余材料的结果。
: 修复了猫在空手右击时无法坐下的问题。</onlyinclude>
