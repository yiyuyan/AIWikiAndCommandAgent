'''凝灰岩砖墙（Tuff Brick Wall）'''是[[凝灰岩砖]]制作的[[墙]]。

== 生成 ==
凝灰岩砖墙不会生成在世界中。

== 获取 ==

|Output=Tuff Brick Wall,6
|type= Decoration block
}}

== 破坏 ==
挖掘凝灰岩砖墙的合适工具是镐。其需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

凝灰岩砖墙被破坏后会掉落自身。

== 用途 ==
{{main|墙#用途}}
凝灰岩砖墙可用于装饰，并有与其他墙相似的特性。
