'''19w38b'''是[[Java版1.15]]的第6个快照，发布于2019年9月18日<ref name="19w38b">{{snap|19w38b|September 18, 2019}}</ref>，修复了一些漏洞（包括[[Java版19w38a|上个快照]]中的一个严重漏洞）。

== 修复 ==
{{fixes|fixedin=19w38b|showdesc=1
|;old
|997|玩家在内部或上方观察时，云层是透明的，但在下方观察时并不透明。
|;previous
|161268|嵌入方块模型时报错<code>java.lang.IndexOutOfBoundsException</code>；游戏会在破坏方块时崩溃。
|161312|在生存模式下破坏方块时不显示方块的损坏动画。
