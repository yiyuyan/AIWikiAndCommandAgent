以指定位置为生成原点，放置[[已配置的地物]]、[[结构地物]]、[[结构模板]]或[[结构池]]。

== 语法 ==
* '''Java版'''
: <code>place feature <feature> [<pos>]</code>
:: 放置[[已配置的地物]]。
: <code>place jigsaw <pool> <target> <max_depth> [<position>]</code>
:: 放置[[结构池]]并展开至指定深度。
: <code>place structure <structure> [<pos>]</code>
:: 放置[[结构地物]]。
: <code>place template <template> [<pos>] [<rotation>] [<mirror>] [<integrity>] [<seed>] [strict]</code>
:: 放置[[结构模板]]。与[[结构方块]]功能基本一致。
* '''基岩版'''
: <code>place feature <feature: features> [position: x y z]</code>
: <code>place featurerule <featurerule: featureRules> [position: x y z]</code>
:: 放置[[地物]]。
: <code>place jigsaw <pool: filepath> <jigsawTarget: string> <maxDepth: int> [pos: x y z] [keepJigsaws: Boolean] [includeEntities: Boolean] [liquidSettings: LiquidSettings]</code>
:: 放置[[结构池]]并展开至指定深度。
: <code>place structure <structure: string> [pos: x y z] [ignoreStartHeight: Boolean] [keepJigsaws: Boolean] [includeEntities: Boolean] [liquidSettings: LiquidSettings]</code>
:: 放置[[结构地物]]。

{{argument|pool|resource_key|pool: filepath|CommandFilePath}}

:{{arg desc|je=resource_key|registry=minecraft:worldgen/template_pool}}

{{argument|target|resource_location|jigsawTarget: string|basic_string}}
: 指定放置结构池时的结构中的起始[[拼图方块]]。
:{{in|je}}{{arg desc|je=resource_location}}
:{{in|be}}{{arg desc|be=basic_string}}

{{argument|max_depth|integer|maxDepth: int|int}}
: 指定要展开拼图方块的最大深度。
:{{arg desc|je=integer|min=1|max=7}}

{{el|je|short=1}}：{{argument|template|resource_location}}
: 指定要放置的结构模板（结构文件）。
:{{arg desc|je=resource_location}}

{{el|je|short=1}}：{{argument|pos|block_pos}}和{{argument|position|block_pos}}<br>
{{el|be|short=1}}：{{argument|be=1|position: x y z|CommandPosition}}和{{argument|be=1|pos: x y z|CommandPosition}}
: 指定放置时使用的生成原点。
:{{arg desc|je=block_pos|be=commandposition}}

{{el|je|short=1}}：{{argument|rotation|template_rotation}}
: 指定放置模板时应当旋转的角度，旋转方向以Y轴俯视角为基准。可用值如下：
:* <code>none</code>（默认值）：不旋转。
:* <code>clockwise_90</code>：顺时针旋转90°。
:* <code>180</code>：旋转180°。
:* <code>counterclockwise_90</code>：逆时针旋转90°。

{{el|je|short=1}}：{{argument|mirror|template_mirror}}
: 指定放置模板时应当采取的镜像方式。可用值如下：
:* <code>none</code>（默认值）：不镜像。
:* <code>front_back</code>：前后翻转。
:* <code>left_right</code>：左右翻转。

{{el|je|short=1}}：{{argument|integrity|float}}
: 指定被放置结构的完整度。默认值为1。
:{{arg desc|je=float|min=0.0|max=1.0}}

{{el|je|short=1}}：{{argument|seed|integer}}
: 指定要被用于结构随机不完整放置的种子。0代表随机种子。如不指定，则默认为0，即使用随机种子。
: {{arg desc|je=integer}}

{{el|je|short=1}}：{{cd|strict}}
: 使命令在放置方块时不触发自身及紧挨着的方块的方块更新和形状更新。

{{el|be|short=1}}：{{argument|be=1|feature: features|enum}}
: 指定地物。
: {{arg desc|be=enum}}

{{el|be|short=1}}：{{argument|be=1|featurerule: featureRules|enum}}
: 指定地物规则。
: {{arg desc|be=enum}}

{{el|be|short=1}}：{{argument|be=1|ignoreStartHeight: Boolean|enum}}
: 指定放置结构时是否忽略起始高度，默认为<samp>false</samp>。
: {{arg desc|be=bool}}

{{el|be|short=1}}：{{argument|be=1|keepJigsaws: Boolean|enum}}
: 指定被放置结构是否保留拼图方块，默认为<samp>false</samp>。
: {{arg desc|be=bool}}

{{el|be|short=1}}：{{argument|be=1|includeEntities: Boolean|enum}}
: 指定被放置结构是否包含实体，默认为<code>false</code>。
: {{arg desc|be=bool}}

{{el|be|short=1}}：{{argument|be=1|liquidSettings: LiquidSettings|enum}}
: 指定流体处理方式，默认为{{cd|apply_waterlogging}}。
: 必须为以下其中之一：
:* {{cd|apply_waterlogging}} — 允许[[含水]]。
:* {{cd|ignore_waterlogging}} — 忽略含水。
: {{arg desc|be=enum}}

== 示例 ==
* 以命令执行者当前坐标为原点，在合适的位置放置一处试炼密室：{{cmd|link=none|place structure minecraft:trial_chambers ~ ~ ~}}
* {{in|je}}以命令执行者当前坐标为原点，放置一项金合欢树地物：{{cmd|link=none|place feature acacia ~ ~ ~}}
* {{in|je}}以命令执行者当前坐标为原点，以远古城市中心为模板池抽取模板，并向外生成7层结构：{{cmd|link=none|place jigsaw ancient_city/city_center empty 7 ~ ~ ~}}
* {{in|je}}以命令执行者当前坐标为原点，放置一个<code>ancient_city/city_center/city_center_1</code>（顺时针旋转90°；左右翻转；50%完整度；种子随机）：{{cmd|link=none|place template ancient_city/city_center/city_center_1 ~ ~ ~ clockwise_90 left_right 0.5 0}}
