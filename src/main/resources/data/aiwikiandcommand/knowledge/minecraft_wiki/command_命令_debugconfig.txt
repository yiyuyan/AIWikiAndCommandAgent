控制玩家进出配置阶段。

== 语法 ==
: <code>debugconfig config <target></code>
:: 将玩家的网络阶段切换为配置阶段。

: <code>debugconfig dialog <target> <dialog></code>
:: 向网络阶段处于配置阶段的玩家发送对话框。

: <code>debugconfig unconfig <target></code>
:: 将网络状态处于配置阶段的玩家加入世界。

== 参数 ==
{{argument|target|entity}}（在<code>/debugconfig config</code>中）
: 指定要切换到配置阶段的玩家。
: {{arg desc|je=entity|type=players|amount=single}}

{{argument|target|uuid}}（不在<code>/debugconfig config</code>中）
: 指定一个玩家UUID，将尝试根据此UUID解析为在配置阶段中的玩家。
: {{arg desc|je=uuid}}

{{argument|dialog|dialog}}
: 指定要展示的对话框。由于网络阶段为配置阶段，事实上只有内联定义的对话框才可被解析。
: {{arg desc|je=dialog}}
