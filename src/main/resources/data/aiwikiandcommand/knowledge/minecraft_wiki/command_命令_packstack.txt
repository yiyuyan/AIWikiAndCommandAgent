显示[[附加包|资源包]]、[[行为包]]和脚本模块数据。

== 语法 ==
: <code>packstack <stackType: stackType> [verbose: verbose] [exclude-vanilla: exclude-vanilla]</code>

== 参数 ==
{{argument|be=1|stackType: stackType|Enum}}
: 指定包的类型，必须为{{cd|client}}（资源包）或{{cd|server}}（行为包和脚本模块）。
{{argument|be=1|verbose: verbose|Enum}}
: 指定是否显示未启用的包和包的详细信息，必须为{{cd|verbose}}。
{{argument|be=1|exclude-vanilla: exclude-vanilla|Enum}}
: 指定是否排除原版包，必须为{{cd|exclude-vanilla}}。
