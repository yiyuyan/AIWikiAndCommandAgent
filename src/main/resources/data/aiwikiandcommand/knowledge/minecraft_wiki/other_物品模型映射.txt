'''物品模型映射'''，官方称之为'''物品模型（Item Model）'''<ref>{{snap|24w45a}}</ref>、'''客户端物品信息（client-side item info）'''<ref>{{article|minecraft-1-21-4-pre-release-1|Minecraft 1.21.4 Pre-Release 1}}</ref>，是根据物品堆叠的各项条件以选择物品{{tr|应用|套用}}哪种[[烘焙模型]]的机制。

== 定义格式 ==
物品模型映射定义文件都在{{filepath|assets/<''命名空间''>/items}}目录内，且均为JSON文件。如果物品模型映射文件定义无效，则游戏会自动使用[[无效模型]]渲染。在原版游戏下，每个物品都使用{{filepath|assets/minecraft/items/<''物品ID''>}}作为自己的模型映射。

物品模型映射定义文件包含两部分：物品模型的选择机制和客户端物品的基础属性。此文件的格式如下：

<div class="treeview">
* {{nbt|compound}} JSON文件根元素
** {{nbt|bool|hand_animation_on_swap}}：（默认为<code>true</code>）玩家在快捷栏切换到此物品堆叠时是否应该渲染切换过渡动画。如果物品堆叠只有耐久度属性不同（以<code>damege</code>组件判定），则始终不会渲染切换过渡动画。
** {{nbt|boolean|oversized_in_gui}}：（默认为<code>false</code>）在GUI内渲染时是否允许物品渲染超出槽位大小。
** {{Nbt|float|swap_animation_scale}}：（默认为1）玩家切换手持物品至该物品时切换动画的速度倍率。模型更大的物品设置为更大值可以保证物品能完整展示。
** {{nbt|compound|model|required=1}}：一个物品模型映射，决定游戏如何选择物品的[[烘焙模型]]。
*** 见下文。
</div>

很多时候，需要根据堆叠物品的某个数据或状态来选取不同烘焙模型。物品模型映射将一个与堆叠物品有关的条件和一个烘焙模型建立关联，从而实现了堆叠物品模型的条件性选取。

*** {{nbt condition|若为{{nbt|list}}：使用矩阵形式。其中包含16个浮点数元素，描述一个{{tr|行主序（Row-major）|列主序（Row-major）}}矩阵：}}

**** {{nbt|float}}：四元数中的一个元素。
**** {{nbt condition|若为{{nbt|compound}}：使用轴-角度形式表示旋转。必须包含下列所有标签：}}
**** {{nbt|float|angle|required=1}}：表示绕旋转轴的旋转角度（以弧度为单位）。

== 类型 ==
物品模型映射有下列类型，不同的映射类型决定了游戏在渲染指定物品堆叠时将使用的物品模型和参数。

{| class="wikitable"
! 命名空间ID !! 物品模型映射行为
|-
! colspan=2 | 复合物品模型映射
|-
| [[#composite|composite]] || 按照数组次序依次渲染物品模型映射
|-
| [[#condition|condition]] || 根据指定的物品堆叠，计算给定的谓词，选择物品模型映射
|-
| [[#range_dispatch|range_dispatch]] || 根据指定的物品堆叠，计算数值并查找数值区间，选择物品模型映射
|-
| [[#select|select]] || 根据指定的物品堆叠，计算属性值并查找枚举，选择物品模型映射
|-
! colspan=2 | 渲染物品模型映射
|-
| [[#bundle/selected_item|bundle/selected_item]] || 渲染收纳袋内选中的物品堆叠
|-
| empty || 不渲染任何物品模型
|-
| [[#model|model]] || 按照指定的参数渲染指定的物品模型
|-
| [[#special|special]] || 使用指定的特殊模型渲染物品
|}

=== bundle/selected_item ===
此物品模型映射类型会让游戏渲染当前收纳袋内被选中的物品堆叠。

此渲染器要求渲染的物品堆叠必须具有<code>bundle_contents</code>组件，否则这个渲染器不会渲染任何东西。

<div class="treeview">
* {{nbt|compound|model|required=1}}
** {{nbt|string|type|required=1}}：<code>bundle/selected_item</code>。
</div>

=== composite ===
此物品模型映射类型会先计算数组内所有物品模型映射，再根据数组次序从后向前依次渲染。

由于此物品模型映射包含子节点，故变换在子节点的变换之上进行。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
* <section begin="codec_item_model_composite" />
** {{nbt|string|type|required=1}}：<code>composite</code>。
** {{nbt|list|models|required=1}}：从后向前依次渲染的物品模型映射。
*** {{nbt|compound}}：一个物品模型映射。
**** 递归定义物品模型映射。
** {{nbt collapsed link|物品模型变换}}
* <section end="codec_item_model_composite" />
</div>

在原版资源包中，该类型的物品模型映射用于将收纳袋的前、中、后三层纹理进行组合。其中，中间层纹理由{{cd|bundle/selected_item}}类型的物品模型映射定义。

{{collapse|title=示例|content=
收纳袋物品模型映射JSON文件的部分代码如下，该部分代码会在玩家选取收纳袋中某物品时生效：
{{syntaxhighlight|lang="json"|
            ... 此处省略部分代码
            "type": "minecraft:composite",
            "models": [
              {
                "type": "minecraft:model",
                "model": "minecraft:item/bundle_open_back"
              },
              {
                "type": "minecraft:bundle/selected_item"
              },
              {
                "type": "minecraft:model",
                "model": "minecraft:item/bundle_open_front"
              }
            ]
            ... 此处省略部分代码
}}
}}

=== condition ===
布尔条件型物品模型映射类型。此物品模型映射类型会先计算物品堆叠内给定的谓词，当属性为真时选择一个物品模型映射，为假时选择另一个。

由于此物品模型映射包含子节点，故变换在子节点的变换之上进行。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** <section begin="codec_item_model_condition" />
** {{nbt|string|type|required=1}}：<code>condition</code>。
** {{nbt|compound|on_false|required=1}}：谓词为假时选择的物品模型映射。
*** 递归定义物品模型映射。具体格式详见上文。
** {{nbt|compound|on_true|required=1}}：谓词为真时选择的物品模型映射。
*** 递归定义物品模型映射。具体格式详见上文。
** {{nbt collapsed link|物品模型变换}}
** <section end="codec_item_model_condition" />
** {{nbt|string|property|required=1}}：（命名空间ID）检查给定的物品模型映射谓词类型。
** 其他元素见下文。
</div>

{{collapse|title=示例1|content=
收纳袋物品模型映射JSON文件的部分代码如下，根据玩家是否选中收纳袋内物品切换模型：
<syntaxhighlight lang="json">
       ...
        "model": {
          "type": "minecraft:condition",
          "property": "minecraft:bundle/has_selected_item",
          "on_false": {
            "type": "minecraft:model",
            "model": "minecraft:item/bundle"
          },
          "on_true": {
            "type": "minecraft:composite",
            "models": [
              {
                "type": "minecraft:model",
                "model": "minecraft:item/bundle_open_back"
              },
              {
                "type": "minecraft:bundle/selected_item"
              },
              {
                "type": "minecraft:model",
                "model": "minecraft:item/bundle_open_front"
              }
            ]
          }
        },
        ...
</syntaxhighlight>
}}

{{collapse|title=示例2|content=
原版鞘翅物品模型映射JSON文件如下，当鞘翅即将损坏时将更换为破损鞘翅模型：
<syntaxhighlight lang="json">
{
  "model": {
    "type": "minecraft:condition",
    "property": "minecraft:broken",
    "on_false": {
      "type": "minecraft:model",

    },
    "on_true": {
      "type": "minecraft:model",
      "model": "minecraft:item/elytra_broken"
    }
  }
}
</syntaxhighlight>
}}

|-

|-
| using_item || 否 || 检查物品堆叠是否正在被使用，比如食用食物
|-
| view_entity || 否 || 检查持有此物品堆叠的生物是否为当前作为摄像机的实体，即非旁观模式下是否为当前玩家，旁观模式下是否为当前旁观的实体

==== custom_model_data ====
读取物品堆叠的<code>custom_model_data</code>组件其中的{{nbt|list|flags}}，将给定下标的布尔值作为谓词结果。

如果物品堆叠没有<code>custom_model_data</code>组件，或下标超过了{{nbt|list|flags}}的长度范围，则返回假。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|布尔条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>custom_model_data</code>。
** {{nbt|int|index}}：（{{interval|left=0}}，默认为0）检查给定物品堆叠<code>custom_model_data</code>组件中{{nbt|list|flags}}对应下标的元素是否为真。
</div>

==== has_component ====
检查物品堆叠是否有给定的物品堆叠组件。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|布尔条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>has_component</code>。
** {{nbt|string|component|required=1}}：（物品堆叠组件类型）检查物品堆叠是否具有此组件。
** {{nbt|bool|ignore_default}}：（默认为<code>false</code>）若当前的物品堆叠组件内容与物品默认物品堆叠组件内容一致时是否认为此组件不存在而返回假。
</div>

{{collapse|title=示例|content=
原版指南针物品模型映射JSON文件的部分代码如下：

    "type": "minecraft:condition",
    "property": "minecraft:has_component",

    "on_false": {
      ...  当lodestone_tracker组件不存在时，若维度为主世界，则获取获取指南针相对玩家出生点的朝向；否则，获取随机朝向。最后根据朝向选取不同的烘焙模型。
    },
    "on_true": {
      ... 当lodestone_tracker组件存在时，指南针相对磁石的朝向，根据朝向选取不同的烘焙模型。
    }
  }
}
}}
}}

=== model ===
指定游戏使用哪一个物品模型进行渲染，并且指定各个着色索引使用的颜色。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt|string|type|required=1}}：<code>model</code>。
** {{nbt|string|model|required=1}}：用于渲染的物品模型，游戏解析时转换为{{filepath|-{}-assets/<''命名空间''>/models/<''路径''>.json}}。
** {{nbt|list|tints}}：（默认为空数组）指定物品模型各个着色索引使用的颜色，数组下标对应着色索引。
*** {{nbt|compound}}：颜色提供器。
**** {{nbt|string|type|required=1}}：颜色来源。
**** {{nbt condition|如果<code>type</code>为<code>custom_model_data</code>，游戏将使用<code>custom_model_data</code>组件信息作为着色颜色。}}
**** {{nbt|int}}{{nbt|list|default|required=1}}：当物品堆叠不存在<code>custom_model_data</code>组件，或下标超过{{nbt|list|colors}}范围时使用的着色颜色。
***** {{nbt inherit/rgb color}}
**** {{nbt|int|index}}：（{{interval|left=0}}，默认为0）将给定物品堆叠<code>custom_model_data</code>组件中{{nbt|list|colors}}对应下标的元素作为着色颜色。

=== range_dispatch ===
值调配型物品模型映射类型。此物品模型映射类型会先计算并返回物品堆叠内给定的一个数值属性，游戏会按照给定阈值从小到大排序，找到数值属性第一个超过或等于的阈值，并使用对应物品模型映射。如果数值属性小于所有阈值，则使用回落映射。

由于此物品模型映射包含子节点，故变换在子节点的变换之上进行。

** {{nbt|list|entries|required=1}}：定义各个阈值和对应的物品模型映射，此列表不需要排序，游戏会在运行时对这个列表排序。
*** {{nbt|compound}}：一项阈值和对应的物品模型映射。
**** {{nbt|compound|model|required=1}}：阈值对应的物品模型映射。
***** 递归定义物品模型映射。具体格式详见上文。
**** {{nbt|float|threshold|required=1}}：阈值。
** {{nbt|compound|fallback}}：回落物品模型映射。如果检查数值小于所有阈值则使用此映射。如果此项不存在，且检查数值小于所有阈值，则使用无效模型。
*** 递归定义物品模型映射。具体格式详见上文。
** {{nbt|float|scale}}：（默认为1）与获取的数值属性相乘获得最后的检查数值。
** {{nbt collapsed link|物品模型变换}}
** <section end="codec_item_model_range_dispatch" />
** {{nbt|string|property|required=1}}：（命名空间ID）检查给定的物品模型映射数值属性类型。

=== select ===
枚举条件型物品模型映射类型。此物品模型映射类型会先计算物品堆叠内给定的一个枚举属性，游戏会使用枚举属性值对应的物品模型映射。如果没有{{tr|匹配|相符}}的枚举值，则使用回落物品模型映射。

**** {{nbt|any}}{{nbt|list|when|required=1}}：匹配此映射的枚举值。
***** {{nbt|any}}：一项枚举值。
** {{nbt|compound|fallback}}：回落物品模型映射。如果读取结果不匹配任何一个枚举值，则使用此映射。如果此项不存在，且读取结果不匹配任何一个枚举值，则使用无效模型。

带有附加元素的类型如下所示：

==== block_state ====
读取物品堆叠的<code>block_state</code>组件，并获取指定方块属性的值作为返回值。如果物品堆叠不存在此组件，或方块不具有对应方块属性，则返回null，无法匹配。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|枚举条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>block_state</code>。
** {{nbt|string|block_state_property|required=1}}：获取方块的指定方块属性。
</div>

          "model": "minecraft:block/bee_nest_honey"
        },
        "when": "5"
      }
    ],
    "fallback": {
      "type": "minecraft:model",
      "model": "minecraft:block/bee_nest_empty"

    "property": "minecraft:block_state"

==== component ====
读取物品堆叠的可持久化组件数据，获取此组件的数据作为返回值。指定不可持久化的组件或枚举值不符合对应组件的数据要求时此模型映射会直接加载失败。

游戏会完全匹配物品模型映射指定的组件值和物品的组件值。例如，对于<code>[[数据组件#custom_data|custom_data]]</code>组件而言，<code>{a:data,b:true}</code>和<code>"{\"a\":\"data\",\"b\":true}"</code>最终会转变为相同的内容（SNBT导出均为<code>{a: data,b :true}</code>），因此这两种写法尽管形式不同，但会被视为相同的组件值：枚举值同时指定会被游戏警告重复的枚举值，物品数据定义和枚举值定义使用任何一种形式都被视为匹配成功。由于游戏会完全匹配，因此不能单独筛选组件中某个键值对的精确值<ref>{{bug|MC-279557|||Invalid}}</ref>，例如枚举值<code>{"a":"data"}</code>不会匹配上述示例。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|枚举条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>component</code>。
** {{nbt|string|component|required=1}}：获取物品堆叠的指定组件。
</div>

==== custom_model_data ==== 
读取物品堆叠的<code>custom_model_data</code>组件中的{{nbt|list|strings}}，获取指定下标的字符串。如果下标超过{{nbt|list|strings}}的长度范围，或物品堆叠不存在<code>custom_model_data</code>组件，则返回null，无法匹配。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|枚举条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>custom_model_data</code>。
** {{nbt|int|index}}：（{{interval|left=0}}，默认为0）获取给定物品堆叠<code>custom_model_data</code>组件中{{nbt|list|strings}}对应下标的字符串。
</div>

====  local_time ==== 
读取当前时间，并根据指定时区、地区设置和日期格式获得日期字符串。此字符串每秒最多获取一次。

<div class="treeview">
* {{nbt|compound|model|required=1}} 物品模型映射
** {{nbt collapsed link|枚举条件型物品模型共通字段}}
** {{nbt|string|property|required=1}}：<code>local_time</code>。
** {{nbt|string|locale}}：（默认为空字符串）时间格式化为字符串时使用的地区设置。格式可参照[https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/util/ULocale.html#ULocale-java.lang.String- 此文档]和[https://www.ietf.org/rfc/rfc3066.txt RFC3066]。
** {{nbt|string|pattern|required=1}}：根据时区获取当前时间后，游戏将时间格式化为字符串的日期格式。日期格式可参照[https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/text/SimpleDateFormat.html 此文档]。
** {{nbt|string|time_zone}}：（默认为系统设置的时区）获取时间使用的时区。格式可参照[https://unicode-org.github.io/icu-docs/apidoc/dev/icu4j/com/ibm/icu/util/TimeZone.html#getTimeZone-java.lang.String- 此文档]和[[wikipedia:List of tz database time zones|此条目]]。
</div>

{{collapse|title=示例|content=
原版箱子的物品模型JSON文件如下。这里pattern为MM-dd，表示“月-日”格式。通过when设定仅在每年12月24到26日使用圣诞箱子模型，否则使用普通箱子模型。
<syntaxhighlight lang="json">
{
  "model": {
    "type": "minecraft:select",
    "pattern": "MM-dd",
    "property": "minecraft:local_time",
    "cases": [
      {
        "model": {
          "type": "minecraft:special",
          "base": "minecraft:item/chest",
          "model": {
            "type": "minecraft:chest",
            "texture": "minecraft:christmas"
          }
        },
        "when": [
          "12-24",
          "12-25",
          "12-26"
        ]
      }
    ],
    "fallback": {
      "type": "minecraft:special",
      "base": "minecraft:item/chest",
      "model": {
        "type": "minecraft:chest",
        "texture": "minecraft:normal"
      }
    }
  }
}
</syntaxhighlight>
}}
