'''1.21.11-rc3'''是[[Java版1.21.11]]的第3个，也是最后一个发布候选版本，发布于2025年12月8日<ref>{{article|minecraft-1-21-11-release-candidate-3|Minecraft 1.21.11 Release Candidate 3|Dec 8, 2025}}</ref>，修复了一些漏洞。

此版本也额外发布了未经混淆的版本，称为'''1.21.11 Release Candidate 3 Unobfuscated'''（启动器内称'''1.21.11-rc3_unobfuscated'''），旨在过渡至后续小更新时移除混淆。<ref>{{article|removing-obfuscation-in-java-edition|Removing obfuscation in Java Edition|Oct 29, 2025}}</ref>
