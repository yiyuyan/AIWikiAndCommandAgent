'''1.21.11-pre5'''是[[Java版1.21.11]]的第5个，也是最后一个预发布版，发布于2025年12月3日<ref>{{article|minecraft-1-21-11-pre-release-5|Minecraft 1.21.11 Pre-Release 5|Dec 3, 2025}}</ref>，修复了一些漏洞。

此版本也额外发布了未经混淆的版本，称为'''1.21.11 Pre-Release 5 Unobfuscated'''（启动器内称'''1.21.11-pre5_unobfuscated'''），旨在过渡至后续小更新时移除混淆。<ref>{{article|removing-obfuscation-in-java-edition|Removing obfuscation in Java Edition|Oct 29, 2025}}</ref>
