'''<samp>leaves_carried</samp>'''<ref>https://www.minecraftforum.net/forums/minecraft-pocket-edition/mcpe-discussion/1968560-my-report-on-3-strange-new-blocks?comment=8</ref>是一种用于渲染[[树叶]]物品模型的方块。

== 获取 ==
leaves_carried只能通过编辑物品栏获得。

== 破坏 ==
没有工具可以加速对leaves_carried的挖掘。

{{Breaking table/manual|{{BlockLink|id=oak-leaves|leaves_carried}}|0.2|}}

没有被[[剪刀]]挖掘破坏时，leaves_carried被破坏后不会掉落。

被剪刀挖掘破坏时，leaves_carried被破坏后会掉落1个[[树叶]]。

== 外观 ==
leaves_carried的基础状态与常规的橡树树叶极其相似，但有一些差异：主要的差异在于leaves_carried比橡树树叶更暗，因为leaves_carried在树叶的基础上进行了染色，但树叶的纹理是已经上色过的，而非染色方块通常使用的灰度图像。染色所使用的具体的颜色是{{color|#48b518}}。

然而，leaves_carried元数据值更高的版本的行为与上文不一致。最为显眼的是元数据为1的种类，对应云杉树叶，使用[[工作台]]的侧面纹理。可以通过检查<samp>[[terrain.png]]</samp>解释这一点。

元数据为1的种类使用{{color|#619961}}着色，元数据为2的使用{{color|#80a755}}着色，元数据为3的使用{{color|#48b518}}着色。

== 用途 ==
尽管使用了相似的外观，leaves_carried在行为上与树叶几乎没有任何相同之处，如leaves_carried不会像树叶一样枯萎。{{info needed}}
