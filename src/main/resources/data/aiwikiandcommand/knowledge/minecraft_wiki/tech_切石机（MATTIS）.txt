'''切石机（Stonecutter'''，下文称'''旧的切石机）'''是一种除装饰外无其他功能的方块。

== 生成 ==
旧的切石机不会生成在世界中。

== 获取 ==
{{see also|Tutorial:获取任意物品}}
旧的切石机只能通过升级从[[携带版0.13.0.b1]]前包含切石机的世界获得，无法在其他未开启[[作弊]]的[[生存模式]]的世界中获取，不存在于[[创造模式物品栏]]中，且是不可通过{{cmd|give}}获取的物品。在[[创造模式]]中对已有的旧的切石机使用{{ctrl|选取方块}}可以获得旧的切石机；否则，旧的切石机只能通过存档编辑或[[附加包]]获得。

=== New Nintendo 3DS版 ===
除上述方法外，旧的切石机还可以从[[创造模式物品栏]]中获取。

== 破坏 ==
挖掘旧的切石机的合适工具是镐。旧的切石机需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table|only=be}}

旧的切石机被破坏后会掉落自身。

== 用途 ==
旧的切石机只有装饰用途。

== 你知道吗 ==
* 在[[携带版]]中，切石机是因为MATTIS合成屏幕缺乏位置而被加入的，直到[[携带版Alpha 0.9.0|Alpha 0.9.0]]的重新设计。
* 在[[New Nintendo 3DS版]]中，切石机一直是纯粹的装饰性方块，这是因为该版本最初是基于[[携带版Alpha 0.15.4]]开发的。
