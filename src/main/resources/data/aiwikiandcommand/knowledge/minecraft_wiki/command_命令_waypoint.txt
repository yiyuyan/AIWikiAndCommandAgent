列出或更改[[路径点]]。

== 语法 ==
: <code>waypoint list</code>
:: 列出路径点。
: <code>waypoint modify <waypoint> color <color></code>
: <code>waypoint modify <waypoint> color hex <color></code>
:: 更改路径点颜色。
: <code>waypoint modify <waypoint> color reset</code>
:: 重置路径点颜色。
: <code>waypoint modify <waypoint> style set <nowiki><style></nowiki></code>
:: 设置[[路径点样式]]。
: <code>waypoint modify <waypoint> style reset</code>
:: 重置路径点样式为默认值。

== 参数 ==
{{argument|waypoint|entity}}
: 指定要更改的路径点。
: {{arg desc|je=entity|amount=single|type=entities}}

{{argument|color|team_color}}（在{{cd|color <color>}}中）
: 指定路径点颜色。
: {{arg desc|je=team_color}}

{{argument|color|hex_color}}（在{{cd|color hex <color>}}中）
: 指定路径点颜色代码。
: {{arg desc|je=hex_color}}

{{argument|style|resource_location}}
: 指定路径点样式名。
: 若指定的路径点样式不存在，将显示为[[无效纹理]]。
: {{arg desc|je=resource_location}}

== 示例 ==
* 列出所有路径点所追踪的生物：{{cd|/waypoint list}}
* 将最近一只猪的路径点传输距离属性基值设置为32.0，并将其路径点颜色设置为金色。
: <syntaxhighlight lang="mcfunction">
tag @n[type=pig] add waypoint_test
attribute @n[tag=waypoint_test] minecraft:waypoint_transmit_range base set 32.0
waypoint modify @n[tag=waypoint_test] color gold
</syntaxhighlight>
