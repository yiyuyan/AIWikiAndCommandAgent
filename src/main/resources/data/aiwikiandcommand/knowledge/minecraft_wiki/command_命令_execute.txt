{{cmd|link=none|execute}}是各不同功能的子命令的集合，用于改变[[命令上下文|命令执行上下文]]（[[#修饰子命令|修饰子命令]]），执行逻辑判断（[[#条件子命令|条件子命令]]）和{{only|for=管理并存储命令返回值（[[#存储子命令|存储子命令]]）|je}}，并在此基础上执行任意其他命令。

== 用法 ==
=== 子命令 ===
<code>/execute</code>命令有{{only|for=14|java}}/{{only|for=11|bedrock}}条子命令。子命令按功能可分为以下几类：
* [[#修饰子命令|修饰子命令]]：修改命令上下文以改变命令执行时的状态，从而以特定的执行位置、执行基准点、执行者、执行朝向、执行维度执行后续子命令。
* [[#条件子命令|条件子命令]]：检测特定条件是否成立并输出结果，或限制子命令执行的条件。
* [[#存储子命令|存储子命令]]{{only|JE}}：将命令返回值存储至[[方块实体]]、[[实体]]或存储容器的NBT数据中，[[记分板]]的记分项中，或[[Boss栏]]的当前值或最大值中。
* [[#run子命令|{{cd|run}}子命令]]：执行其他命令。

子命令可以在{{cmd|link=none|execute}}后串连在一起使用，可出现在命令的任意位置及重复任意次数。但{{cd|run}}子命令除外，其只能位于{{cmd|link=none|execute}}末尾且只能使用一次，同时可用于嵌套执行{{cmd|link=none|execute}}。

{{cmd|link=none|execute}}命令的结尾必须为条件子命令或{{cd|run}}子命令，否则命令不可解析。

各子命令按其在命令中的顺序被依次处理，下列命令中子命令虽然一致，但由于顺序不同，会产生不同效果：
* {{cmd|link=none|execute '''as @e at @s''' run tp @s ^ ^ ^1}}：所有实体向各自所朝方向移动一格。
* {{cmd|link=none|execute '''at @s as @e''' run tp @s ^ ^ ^1}}：所有实体移动到执行者前方一格。

=== 执行分支 ===
有些子命令，可以将命令的执行过程'''分叉（Fork）'''为多个'''分支（Branch）'''，也就是使得后续的子命令被多次执行。例如，如果{{cd|as}}子命令选中了多个实体，那么每个实体都会执行一次后续的子命令。

如果一个{{cmd|link=none|execute}}命令没有被分叉，我们称它只有一个分支——'''主分支'''。

有些情况下，一个分支会'''执行中断'''，并且什么也不做（不执行{{cd|run}}子命令和{{only|je|for=存储子命令}}）。例如，条件子命令的条件没有达成，或是{{cd|as}}子命令没有选中实体，等等。{{in|be}}一个分支中断时会显示一条红色的消息。如果所有的分支都中断了，我们就说这个{{cmd|link=none|execute}}命令本身[[命令#结果|执行中断]]。

注意：<code>... run execute ...</code>在任何情况下都不会起任何作用。例如下面的两个命令，效果都是一样的：
* {{cmd|long=1|link=none|execute as @e[type{{=}}armor_stand] as @e[type{{=}}armor_stand] run summon armor_stand}}
* {{cmd|long=1|link=none|execute as @e[type{{=}}armor_stand] run execute as @e[type{{=}}armor_stand] run execute run execute run summon armor_stand}}

然而，{{el|je}}和{{el|be}}的分叉方式并不一样。<ref>{{bug|MC-125067|||Won't Fix}}</ref><ref>{{bug|MCPE-165278}}</ref>
* {{in|je}}游戏会[[wzh:广度优先搜索|广度优先]]地处理子命令，也就是按顺序逐个处理子命令。所以游戏会在处理<code>run</code>子命令之前处理完其他的子命令，于是，<code>run</code>子命令无法影响到其他的子命令。
* {{in|be}}游戏会[[wzh:深度优先搜索|深度优先]]地处理子命令。也就是说，命令执行分叉以后，后续的所有子命令会作为一个整体，每个分支执行一次。
* 例如，如果世界上有两个盔甲架（A和B），一个玩家执行了<code>execute as @e[type=armor_stand] as @e[type=armor_stand] run summon armor_stand</code>，{{el|je}}和{{el|be}}的行为如图所示：

* 世界上有两个盔甲架，一个玩家执行了<code>/execute as @e[type=armor_stand] run function test</code>，其中函数<samp>test</samp>的内容是：

* 这样的效果和{{el|be}}中的<code>/execute as @e[type=armor_stand] as @e[type=armor_stand] run summon armor_stand</code>是一样的。
{{in|be}}暂时无法做到广度优先地执行子命令。

==== 储存值 ====
{{exclusive|java|section=1}}
{{IN|java}}一条分支在完整执行后（没有发生执行中断）会输出<code>success</code>值和<code>result</code>值（另见[[命令#输出]]）。这两个输出值：
* 是各执行分支的输出值，而非{{cd|/execute}}命令本身的；
* 均来自结尾的条件子命令或{{cd|run}}子命令中的命令；
* 均为整数，{{cd|result}}遇小数时向下取整，{{cd|success}}总为0或1；
* 如果结尾的子命令在一个分支中执行失败，则此分支的这两个值均为0；
* 均可由存储子命令存储。

请注意，这两个值来自结尾的条件子命令或{{cd|run}}子命令中的命令，是每个分支的输出值，而非整条{{cd|/execute}}命令的。

若使用{{cd|run}}子命令执行{{cmd|function}}命令，在某些条件下没有这两个输出值。详细信息参见{{cmd|function}}。

如果在储存子命令之后命令执行被分叉，则储存操作将应用于每个分支。每个分支的输出值都会在此分支执行完后被储存。如果所有分支的存储位置相同，则后执行的分支的输出会直接覆盖先执行分支的输出，而不是累加，所以在执行整个{{cd|/execute}}命令后，此存储位置最后的值是最后执行的分支的输出。

==== 成功次数 ====
像大多数命令一样，<code>/execute</code>命令（无论是否执行中断）本身也有一个'''[[命令#输出|成功次数]]'''。成功次数：
* 是{{cd|/execute}}命令本身的输出值，而非各执行分支的；
* 来自结尾的条件子命令或{{cd|run}}子命令；
* 各分支的值会被累加；
* 为大于等于0的整数；
* 当使用命令方块执行<code>/execute</code>时，成功次数会返回到命令方块中，可用条件制约的命令方块检查，或用[[红石比较器]]读取成功次数。

== 修饰子命令 ==
可用子命令：
* {{cd|[[#align|align]]}}：将执行位置转换为方块坐标。
* {{cd|[[#anchored|anchored]]}}：将执行基准点设置为实体的脚部或眼部。
* {{cd|[[#as|as]]}}：将执行者设置为特定实体。
* {{cd|[[#at|at]]}}：将执行位置、执行朝向和执行维度设置为指定实体的坐标、朝向和维度。
* {{cd|[[#facing|facing]]}}：将命令的执行朝向设置为面向指定坐标或指定实体。
* {{cd|[[#in|in]]}}：将命令执行维度设置为特定维度。
* {{cd|[[#on|on]]}}{{only|java}}：将执行者设置为与当前执行者有指定类型的关系的实体。
* {{cd|[[#positioned|positioned]]}}：将执行位置设置为指定坐标或指定实体位置。
* {{cd|[[#rotated|rotated]]}}：将执行朝向设为特定方向或设为指定实体的朝向。
* {{cd|[[#summon|summon]]}}{{only|JE}}：立即创建一个实体，并将此实体设置为执行者。

=== align ===
改变命令上下文中的[[命令上下文#执行位置|执行位置]]<math>(x,y,z)</math>，将其中的x或y或z向下取整，以转换为[[坐标#方块坐标|方块坐标]]。

; 语法
: {{el|je|short=1}}：{{cd|align <axes> ''-> execute''}}
: {{el|be|short=1}}：{{cd|align <axes: string> ''<chainedCommand: ExecuteChainedOption_0>''}}

; 参数
: {{el|je|short=1}}：{{argument|axes|swizzle}}
: {{el|be|short=1}}：{{argument|be=1|axes: string|basic_string}}
:: 需要转换的坐标轴。
:: {{arg desc|je=swizzle}}

; 结果
: 参数未正确指定时，视为语法错误。

'''示例'''
* {{cmd|link=none|execute positioned -1.8 2.3 5.9 '''align xz''' run tp ~ ~ ~}}：把自己从(-1.8, 2.3, 5.9)传送至(-2, 2.3, 5)。
* {{cmd|link=none|execute positioned 2.4 -1.1 3.8 '''align yxz''' run spawnpoint @p ~ ~ ~}}：当前执行位置为(2.4, -1.1, 3.8)，将最近玩家的出生点设置为(2, -2, 3)。
* {{cmd|link=none|execute '''align y''' run tp ~ ~ ~}}：把自己的Y坐标微调，向下取整。

=== anchored ===
将命令上下文中的[[命令上下文#执行锚点|执行锚点]]设置为眼{{cd|eyes}}或脚{{cd|feet}}。默认为脚。
{{cd|facing}}子命令会根据锚点计算执行朝向；局部坐标{{cd|^ ^ ^}}会根据锚点计算起始位置。

; 语法
: {{el|je|short=1}}：{{cd|anchored <anchor> ''-> execute''}}
: {{el|be|short=1}}：{{cd|anchored <eyes{{!}}feet> ''<chainedCommand: ExecuteChainedOption_0>''}}

; 参数
: {{el|je|short=1}}：{{argument|anchor|entity_anchor}}
: {{el|be|short=1}}：{{argument|be=1|eyes{{!}}feet}}
:: 需要设置的锚点位置。
:: {{arg desc|je=entity_anchor}}{{cd|eyes}}为眼部，{{cd|feet}}为脚部。

; 结果
: 参数未正确指定时，视为语法错误。

'''示例'''
* {{cmd|tp}}的效果是通过将脚部移动到指定的位置来移动实体。
* {{cmd|link=none|execute '''anchored eyes''' run tp ^ ^ ^}}：将命令执行者的腿部移动到原眼部位置。
* {{cmd|link=none|execute '''anchored eyes''' run tp ^5 ^ ^}}：将命令执行者的腿部移动到原眼部位置左边5格的位置上。

=== as ===
将命令上下文中的[[命令上下文#执行者|执行者]]设置为指定实体。

; 语法
: {{el|je|short=1}}：{{cd|as <targets> ''-> execute''}}
: {{el|be|short=1}}：{{cd|as <origin: target> ''<chainedCommand: ExecuteChainedOption_0>''}}
: {{in|je}}将按照广度优先顺序产生执行分支：以每个目标实体为执行实体建立执行分支，形成包含所有目标实体的命令上下文列表后才会执行后续子命令。

; 参数
: {{el|je|short=1}}：{{argument|targets|entity}}
: {{el|be|short=1}}：{{argument|be=1|origin: target|CommandSelector<Actor>}}
:: 设置执行者，影响后续子命令。
:: {{arg desc|je=entity|be=actor|amount=multiple|type=entities}}

; 结果
: 参数未正确指定时，视为语法错误。
: 若{{cd|<targets>}}或{{cd|origin: target}}无法选中一个或多个有效实体（指定玩家必须{{tr|在线|在線上}}）时，命令终止执行。

'''示例'''
* {{cmd|link=none|execute '''as @e[type{{=}}sheep]''' run data get entity @s}}{{only|JE}}：获取所有[[绵羊]]的数据。
* {{cmd|link=none|execute '''as @a[gamemode{{=}}spectator]''' run spectate}}{{only|JE}}：使所有[[旁观模式]]的玩家从其附身的实体上退出。

=== at ===
将命令上下文中的[[命令上下文#执行维度|执行维度]]、[[命令上下文#执行位置|执行位置]]、[[命令上下文#执行朝向|执行朝向]]设置为指定实体的执行维度、执行位置和执行朝向。

; 语法
: {{el|je|short=1}}：{{cd|at <targets> ''-> execute''}}
: {{el|be|short=1}}：{{cd|at <origin: target> ''<chainedCommand: ExecuteChainedOption_0>''}}
: {{in|je}}将按照广度优先顺序产生执行分支：以每个目标实体为执行实体建立执行分支，形成包含所有目标实体的命令上下文列表后才会执行后续子命令。

; 参数
: {{el|je|short=1}}：{{argument|targets|entity}}
: {{el|be|short=1}}：{{argument|be=1|origin: target|CommandSelector<Actor>}}
:: 指定目标实体。
:: {{arg desc|je=entity|be=actor|amount=multiple|type=entities}}

; 结果
: 参数未正确指定时，视为语法错误。
: 若{{cd|<targets>}}或{{cd|origin: target}}无法选中一个或多个有效实体（指定玩家必须{{tr|在线|在線上}}）时，命令终止执行。

'''示例'''
* {{cmd|link=none|execute '''at @r''' run setblock ~ ~-1 ~ stone}}：在一名随机玩家脚下放置一块[[石头]]。
* {{cmd|link=none|execute '''as @e[type{{=}}sheep] at @s''' run tp ~ ~1 ~}}：将所有绵羊向上移动1格。
* {{cmd|link=none|execute '''at @e[type{{=}}sheep]''' run kill @s}}：杀死执行者而非所有绵羊（{{cd|at}}子命令不修改执行者）。

=== facing ===
将起点为[[命令上下文#执行锚点|执行锚点]]，终点为指定位置的向量转换为命令上下文中的[[命令上下文#执行朝向|执行朝向]]。
确定朝向终点<math>(x2, y2, z2)</math>：
* 若命令设置了坐标，则直接将该坐标设置为朝向终点。
* 若命令设置了目标实体及实体锚点，则对目标实体应用实体锚点，然后将得到的坐标设置为朝向终点。
确定朝向起点<math>(x1, y1, z1)</math>：
* 对当前命令上下文应用其自身存储的[[命令上下文#执行锚点|执行锚点]]，将得到的坐标设置为朝向起点。
然后按照下述步骤计算执行朝向：
# 计算面向方向向量<math>dir = (dx, dy, dz) = (x2 - x1, y2 - y1, z2 - z1)</math>。
# 计算面向方向向量在水平面的投影<math>dir_{prj} = \sqrt{dx^2 + dz^2}</math>。
# 计算朝向的垂直面角度：<math>-(atan2(dy, dir_{prj}) \cdot \frac{180}{\pi})</math>，其中<math>atan2</math>为双参反正切函数。
# 计算朝向的水平面角度：<math>(atan2(dz, dx) \cdot \frac{180}{\pi}) - 90</math>，其中<math>atan2</math>为双参反正切函数。
# 将垂直面角度和水平面角度构造为一个二维向量即得到执行朝向。
当起点和终点的距离约为0时，朝向被计算为固定值<math>(-90, 0)</math>。

; 语法
: {{el|je|short=1}}：{{cd|facing <pos> ''-> execute''}}
: {{el|be|short=1}}：{{cd|facing <position: x y z> ''<chainedCommand: ExecuteChainedOption_0>''}}
:: 将命令的执行朝向设置为执行锚点到指定坐标的射线方向。
: {{el|je|short=1}}：{{cd|facing entity <targets> <anchor> ''-> execute''}}
: {{el|be|short=1}}：{{cd|facing entity <origin: target> <eyes{{!}}feet> ''<chainedCommand: ExecuteChainedOption_0>''}}
:: 将命令的执行朝向设置为执行锚点到指定实体的指定锚点的射线方向。
:: {{in|je}}将按照广度优先顺序产生执行分支：以每个目标实体为执行实体建立执行分支，形成包含所有目标实体的命令上下文列表后才会执行后续子命令。对于每一个分支，都以当前命令上下文中的执行锚点为起点，当前分支中实体的锚点为终点计算一次执行朝向。

; 参数
: {{el|je|short=1}}：{{argument|pos|vec3}}
: {{el|be|short=1}}：{{argument|be=1|position: x y z|CommandPositionFloat}}
:: 需要面向的坐标。
:: {{arg desc|je=vec3|be=CommandPositionFloat}}
: {{el|je|short=1}}：{{argument|targets|entity}}
: {{el|be|short=1}}：{{argument|be=1|origin: target|CommandSelector<Actor>}}
:: 需要面向的实体。
:: {{arg desc|je=entity|be=actor|amount=multiple|type=entities}}
: {{el|je|short=1}}：{{argument|anchor|entity_anchor}}
: {{el|be|short=1}}：{{argument|be=1|eyes{{!}}feet}}
:: 需要面向实体的眼部还是脚部。
:: {{arg desc|je=entity_anchor}}

; 结果
: 将执行朝向设置为面向指定的坐标或目标实体。
: 参数未正确指定时，视为语法错误。
: 若{{cd|<targets>}}或{{cd|origin: target}}无法选中一个或多个有效实体（指定玩家必须{{tr|在线|在線上}}）时，命令终止执行。

=== in ===
将命令上下文中的[[命令上下文#执行维度|执行维度]]设置为指定[[维度]]，同时也将[[命令上下文#执行位置|执行位置]]设置为在该维度中的坐标。

== 条件子命令 ==
{{anchor|if}}{{anchor|unless}}
条件子命令包括{{cd|if}}和{{cd|unless}}两种，用于测试特定类型的条件。两者的语义相反但参数结构一致，{{cd|if}}表示“如果……就”，{{cd|unless}}表示“除非……否则”。

条件子命令可以单独使用，也可以与其他子命令一起使用，根据其处于整条命令中的位置，其行为也有区别：
* 位于整条命令的末尾时，条件子命令会直接输出测试结果。
* 不位于整条命令的末尾时，条件子命令会根据自身语义与测试结果，决定后续子命令是否执行。
** 若由多个变量（如执行者、执行位置、执行朝向）执行多次时，可作为变量过滤器使用。

可用条件类型：
* {{cd|[[#ifunlessbiome|biome]]}}{{only|JE}}：检测给定位置上的生物群系是否为特定生物群系。
* {{cd|[[#ifunlessblock|block]]}}：检测给定位置上的方块是否是特定的方块或方块状态。
* {{cd|[[#ifunlessblocks|blocks]]}}：检测给定区域内的方块是否匹配另一个同等大小区域内的方块。
* {{cd|[[#ifunlessdata|data]]}}{{only|JE}}：检测方块、实体或存储容器是否拥有给定的NBT标签。
* {{cd|[[#ifunlessdimension|dimension]]}}{{only|JE}}：检测命令执行时所处的维度是否为特定维度。
* {{cd|[[#ifunlessentity|entity]]}}：检测一个或多个特定实体是否存在。
* {{cd|[[#ifunlessfunction|function]]}}{{only|JE}}：检测函数是否有非零返回值。
* {{cd|[[#ifunlessitems|items]]}}{{only|JE}}：检测方块或实体的给定物品栏槽位或槽位区间内是否拥有指定物品。
* {{cd|[[#ifunlessloaded|loaded]]}}{{only|JE}}：检测给定位置是否已被加载。
* {{cd|[[#ifunlesspredicate|predicate]]}}{{only|JE}}：检测谓词计算结果是否为正。
* {{cd|[[#ifunlessscore|score]]}}：检测指定目标的记分板中的记分项的分数是否与另一个（或同一个）目标的记分板的记分项的分数是否符合指定的关系，或者是否在给定的范围之内。
* {{cd|[[#ifunlesssslots|slots]]}}{{upcoming|JE 26.3}}：检测方块或实体是否具有能匹配给定[[槽位源]]的槽位。
* {{cd|[[#ifunlessstopwatch|stopwatch]]}}{{only|JE}}：检测指定ID的秒表的时间是否在给定的范围之内。

=== (if|unless) function ===
{{anchor|ifunlessfunction}}
{{exclusive|section=1|java}}
执行并检测函数是否有非零的[[Java版函数#返回|函数返回值]]。若给定的函数返回0或没有返回值，测试失败。
若给定[[函数标签]]，则其中任意一个函数返回非零值都将通过测试。当遍历到一个这样的函数后，标签的执行终止，不会再执行其他函数。
与其他条件子命令不同，此子命令不能置于子命令链的末尾<ref>{{bug|MC-267799|||Invalid}}</ref>。

; 语法
: {{el|je|short=1}}：{{cd|(if{{!}}unless) function <name> ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|name|function}}
:: 要检测的函数。必须为一个[[命名空间ID]]，指向一个单独的函数或者是以{{cd|#}}作为前缀的函数标签。

; 结果
: 参数未正确指定时，视为语法错误。
: 若给定的函数或函数标签不存在，或函数标签为空（其中没有任何函数），则终止整个<code>/execute</code>命令：
: 当仅给出一个函数时，如果该函数不是宏函数，也不是 Void函数，并且其[[函数#返回值|返回值]]不为 0：
:* <code>if</code>不会执行任何操作，而<code>unless</code>会终止当前分支。
: 当给定包含多个函数的函数标签时，会按照标签文件中定义的顺序依次检查并调用每个函数：
:* 如果该函数是宏函数：则结束此子命令的执行，同时<code>if</code>会终止当前分支，而<code>unless</code>不会执行任何操作。
:* 如果该函数是Void函数：则会检查并调用下一个函数。如果没有下一个函数，则<code>if</code>会终止当前分支，而<code>unless</code>不会执行任何操作。
:* 如果该函数返回失败结果，或者返回值为0的成功结果，则结束此子命令的执行，同时<code>if</code>会终止当前分支，而<code>unless</code>不会执行任何操作。
:* 如果该函数返回成功结果且其返回值不为0：则结束此子命令的执行，同时<code>if</code>不会执行任何操作，而<code>unless</code>会终止当前分支。

'''示例'''
* {{cmd|link=none|execute '''unless function generic:test''' run say 1}}：执行函数{{cd|generic:test}}，若其返回值非0，则不执行{{cd|say 1}}。

检测指定[[秒表存储格式|秒表]]的时间是否在指定范围内。

; 语法
: {{cd|(if{{!}}unless) stopwatch <id> <range> ''-> execute''}}

; 参数
: {{argument|id|resource_location}}
:: 需要检测的秒表。
:: {{arg desc|je=resource_location}}
: {{argument|range|float_range}}
:: 被检测秒表需要符合的范围。
:: {{arg desc|je=float_range}}

; 结果
: 参数未正确指定时，视为语法错误。
: 若未通过测试或出现下列情形，终止执行后续子命令（不位于末尾）或执行失败（位于末尾）：
:* ID为{{cd|<id>}}的秒表不存在。

; 输出
: 若位于末尾且执行成功，{{cd|d=pretty|success|result}}均返回1。

== 存储子命令 ==
{{anchor|store}}
{{exclusive|section=1|JE}}
存储子命令可以将最后一个子命令执行后产生的{{cd|result}}或{{cd|success}}值存储到指定位置。

它与其他子命令一起处理，先行记录存储位置，不影响其他子命令。它能够将最后一个子命令执行后产生的返回值存储到指定位置（可以是[[记分板]]、NBT数据或[[Boss栏]]）。

可用存入位置：
* {{cd|[[#storeblock|block]]}}：将{{cd|result}}或{{cd|success}}存入指定方块实体的指定NBT标签内。
* {{cd|[[#storebossbar|bossbar]]}}：将{{cd|result}}或{{cd|success}}存为Boss栏的当前值或最大值。
* {{cd|[[#storeentity|entity]]}}：将{{cd|result}}或{{cd|success}}存入指定实体的指定NBT标签内。
* {{cd|[[#storescore|score]]}}：将{{cd|result}}或{{cd|success}}存入指定分数持有者的指定记分项上。
* {{cd|[[#storestorage|storage]]}}：将{{cd|result}}或{{cd|success}}存入指定存储容器的指定NBT标签内。

=== store (result|success) block ===
{{anchor|storeblock}}
将{{cd|result}}或{{cd|success}}存入指定[[方块实体]]的指定NBT标签内。

; 语法
: {{el|je|short=1}}：{{cd|store (result{{!}}success) block <target> <path> (int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte) <scale> ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|target|block_pos}}
:: 返回值需要存入的目标方块实体的坐标。
:: {{arg desc|je=block_pos}}
: {{el|je|short=1}}：{{argument|path|nbt_path}}
:: 返回值需要存入的NBT路径。
:: {{arg desc|je=nbt_path}}
: {{el|je|short=1}}：{{cd|(int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte)}}
:: 返回值及目标NBT的数据类型。
:: 只能为{{cd|d=pretty|int|float|short|long|double|byte}}之一。分别表示整型、单精度浮点型、短整型、长整型、双精度浮点型和字节型。
: {{el|je|short=1}}：{{argument|scale|double}}
:: 返回值存储时的倍率。
:: {{arg desc|je=double}}

; 结果
: 参数未正确指定时，视为语法错误。
: 路径不存在时不进行操作。
: 执行成功时，将返回值向下取整并乘以{{cd|<scale>}}后存储在{{cd|<target>}}处方块实体的{{cd|<path>}}NBT标签处，并存储为指定的[[NBT格式]]。

=== store (result|success) bossbar ===
{{anchor|storebossbar}}
将{{cd|result}}或{{cd|success}}存为Boss栏的当前值或最大值。

; 语法
: {{el|je|short=1}}：{{cd|store (result{{!}}success) bossbar <id> (value{{!}}max) ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|id|resource_location}}
:: 返回值需要存入的目标Boss栏的命名空间ID。
:: {{arg desc|je=resource_location}}
: {{el|je|short=1}}：{{cd|(value{{!}}max)}}
:: 返回值需要存入的是Boss栏的当前值（{{cd|value}}）或是最大值（{{cd|max}}）。

; 结果
: 参数未正确指定时，视为语法错误。
: 执行成功时，将返回值向下取整，存为命名空间ID为{{cd|<id>}}的Boss栏的当前值或最大值。

'''示例'''
* {{cmd|long=1|link=none|execute '''store result bossbar minecraft:test value''' run scoreboard players get boss_health var}}：将虚拟玩家{{cd|boss_health}}的{{cd|var}}记分项中的分数转换为{{cd|minecraft:test}}Boss栏的当前值。

=== store (result|success) entity ===
{{anchor|storeentity}}
将{{cd|result}}或{{cd|success}}存入指定[[实体]]的指定NBT标签内。与{{cmd|data}}一样，此命令不能修改玩家的NBT。

; 语法
: {{el|je|short=1}}：{{cd|store (result{{!}}success) entity <target> <path> (int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte) <scale> ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|target|entity}}
:: 返回值需要存入的目标实体。
:: {{arg desc|je=entity|amount=multiple|type=entities}}
: {{el|je|short=1}}：{{argument|path|nbt_path}}
:: 返回值需要存入的NBT路径。
:: {{arg desc|je=nbt_path}}
: {{el|je|short=1}}：{{cd|(int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte)}}
:: 返回值及目标NBT的数据类型。
:: 只能为{{cd|d=pretty|int|float|short|long|double|byte}}之一。分别表示整型、单精度浮点型、短整型、长整型、双精度浮点型和字节型。
: {{el|je|short=1}}：{{argument|scale|double}}
:: 返回值存储时的倍率。
:: {{arg desc|je=double}}

; 结果
: 参数未正确指定时，视为语法错误。
: 路径不存在时不进行操作。
: 执行成功时，将返回值向下取整并乘以{{cd|<scale>}}后存储在{{cd|<target>}}实体的{{cd|<path>}}NBT标签处，并存储为指定的[[NBT格式]]。

'''示例'''
* <code>/execute store result entity @n[type=pig] Motion[1] double 0.5 run scoreboard players get #temp var</code>：将虚拟玩家{{cd|#temp}}的{{cd|var}}记分项中的分数转换为{{nbt|double|双精度浮点数}}数据（同时乘以倍率0.5），作为最近一只猪的{{nbt|list|Motion}}内的第二个元素。

=== store (result|success) score ===
{{anchor|storescore}}
将{{cd|result}}或{{cd|success}}存入指定分数持有者的指定记分项上。

; 语法
: {{el|je|short=1}}：{{cd|store (result{{!}}success) score <targets> <objective> ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|targets|score_holder}}
:: 返回值需要存入的目标分数持有者。
:: {{arg desc|je=score_holder}}
: {{el|je|short=1}}：{{argument|objective|objective}}
:: 返回值需要存入的目标记分项名称。
:: {{arg desc|je=objective}}

; 结果
: 参数未正确指定时，视为语法错误。
: 执行成功时，将返回值向下取整后存储在{{cd|<targets>}}持有的{{cd|<objective>}}分数中。

'''示例'''
* {{cmd|link=none|execute '''store result score #temp var''' run data get entity @s Motion}}：将执行者实体{{nbt|list|Motion}}内的元素数量存储在虚拟玩家{{cd|#temp}}的{{cd|var}}记分项中。

=== store (result|success) storage ===
{{anchor|storestorage}}
根据{{cd|<path>}}确定{{cd|<target>}}[[命令存储]]中的NBT标签并存入来自子命令的[[#输出|输出值]]（{{cd|success}}或{{cd|result}}）。输出值将被乘以{{cd|<scale>}}后再存储。可存储为byte、short、int、long、float或double。若不存在{{cd|<target>}}命令存储，则创建一个新的{{cd|<target>}}命令存储。
对于{{cmd|data}}等在聊天消息中提示为小数的命令，小数值都将在内部被向下取整为整数作为输出值。

; 语法
: {{el|je|short=1}}：{{cd|store (result{{!}}success) storage <target> <path> (int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte) <scale> ''-> execute''}}

; 参数
: {{el|je|short=1}}：{{argument|target|resource_location}}
:: 输出值需要存入的目标命令存储的命名空间ID。
:: {{arg desc|je=resource_location}}
: {{el|je|short=1}}：{{argument|path|nbt_path}}
:: 输出值需要存入的目标[[NBT路径]]。
:: {{arg desc|je=nbt_path}}
: {{el|je|short=1}}：{{cd|(int{{!}}float{{!}}short{{!}}long{{!}}double{{!}}byte)}}
:: 输出值及目标NBT的数据类型。
:: 只能为{{cd|d=pretty|int|float|short|long|double|byte}}之一。分别表示整型、单精度浮点型、短整型、长整型、双精度浮点型和字节型。
: {{el|je|short=1}}：{{argument|scale|double}}
:: 输出值存储时的倍率。
:: {{arg desc|je=double}}

; 结果
: 参数未正确指定时，视为语法错误。

== run子命令 ==
{{anchor|run}}
要被执行的目标命令。

; 语法
: {{el|je|short=1}}：{{cd|run ...}}
: {{el|be|short=1}}：{{cd|run <command: command>}}

; 参数
: {{el|je|short=1}}：{{cd|...}}
: {{el|be|short=1}}：{{argument|be=1|command: command|unique_ptr<Command>}}
:: 一条完整的[[命令]]。{{in|je}}不能以斜杠开头。

; 技术细节{{only|JE}}
: 将命令节点重置为[[Brigadier|命令调度器]]的根节点。
: 注意：
:: 命令调度器是在玩家开始输入以斜杠{{cd|/}}开头的消息时开始的。
:: 命令节点是光标正在编辑的特定词（word）或项（entry），是一个命令或参数。
:: 根节点在当前命令的第一个词之前出现。

; 结果
: 执行此命令。指定的命令执行成功时成功，失败时失败。

== 更多示例 ==
* 将所有快捷栏第一槽位物品带有[[效率]]魔咒的玩家传送到0, 64, 0：
*: {{cmd|long=1|link=none|execute as @a if data entity @s Inventory[{Slot:0b}].components."minecraft: enchantments".levels."minecraft:efficiency" run tp @s 0 64 0}}{{only|JE}}
* 在所有玩家眼睛前方三格召唤烟雾粒子效果：
*: {{cmd|link=none|execute as @a at @s anchored eyes run particle smoke ^ ^ ^3}}{{only|JE}}
* 让所有在[[水]]中的玩家在聊天框里说：“我的脚湿了！”：
*: {{cmd|link=none|execute as @a at @s if block ~ ~ ~ water run say "我的脚湿了！"}}
* 让所有“test”记分板未设置的玩家在聊天框里说：“分数已重置”：
*: {{cmd|link=none|execute as @a unless score @s test {{=}} @s test run say "分数已重置"}}
* 将距离最近的玩家3格内的所有猪扔向天空：
*: {{cmd|long=1|link=none|execute at @p as @e[type{{=}}pig,distance{{=}}..3] run data merge entity @s {Motion:[0.0,2.0,0.0]} }}{{only|JE}}
* 杀死所有没有头盔的僵尸：
*: {{cmd|link=none|execute as @e[type{{=}}zombie] unless data entity @s equipment.head.id run kill @s}}{{only|JE}}
