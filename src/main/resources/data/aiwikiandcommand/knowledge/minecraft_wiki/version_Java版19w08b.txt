'''19w08b'''是[[Java版1.14]]的第23个快照，发布于2019年2月21日<ref>{{snap|19w08b|February 20, 2019}}</ref>，修复了一些漏洞。

== 修复 ==
{{fixes|fixedin=19w08b|prefix=Minecraft|showdesc=1
|;old
|46094|使用{{cmd|fill|link=none}}或{{cmd|clone|link=none}}命令将刷怪笼替换掉，其火苗粒子仍会保留。
|81202|当浮漂不在视野中时，钓鱼竿线不显示。
|87942|当末影龙不在视野中时，末地水晶发出的光柱不会显示。
|91858|当末地水晶不在视野中时，末地水晶发出的光柱不会显示。
|;dev
|137511|熊猫在吃东西或者遮住它们的脸时会移动。
|141929|营火粒子在未加载区块仍然激活。
|;previous
|144463|有一些纹理缺失。
