'''马铃薯木按钮（Potato Button）'''是一种可提供短暂[[红石信号]]的非[[固体方块]]，是[[马铃薯木板]]制作的[[按钮]]。

== 生成 ==
马铃薯木按钮不会生成在世界中。

== 破坏 ==
挖掘马铃薯木按钮的合适工具是斧。
{{Breaking table/manual|only=je|nocopper=1|{{BlockSprite|Potato Button}} 马铃薯木按钮|0.5|axe}}
马铃薯木按钮被破坏后会掉落自身。

== 用途 ==
{{see also|红石元件}}

在以下情况时，马铃薯木按钮会被破坏并掉落自身：
* 马铃薯木按钮的附着方块移动、消失或被摧毁；
* 有[[水]]流过；
* [[活塞]]尝试推动马铃薯木按钮或把方块推到马铃薯木按钮所在的方块。

如果[[熔岩]]流过马铃薯木按钮，马铃薯木按钮将会被摧毁且不会掉落物品。

=== 红石电源 ===
马铃薯木按钮可用作单稳态[[红石元件#电源|电源]]（在被打开后很快自动变成关闭状态）。

; 放置
: 对着要放置的马铃薯木按钮的面{{ctrl|放置}}即可放置马铃薯木按钮。
: 只要一个表面碰撞箱完整，马铃薯木按钮就可以附着在该表面，[[树叶]]和[[紫颂花]]除外。
: 如果将马铃薯木按钮放置在方块的顶部或底部，马铃薯木按钮可以朝向任何方向。
; 激活
: 马铃薯木按钮通常处于关闭状态。
: 玩家对着马铃薯木按钮{{ctrl|使用}}可以使之暂时打开；[[爆炸#风爆|风爆]]也能使之暂时打开。
: 射出去的[[箭]]和投掷出的[[三叉戟]]如果落在马铃薯木按钮上，马铃薯木按钮会一直保持打开状态，直到箭或三叉戟被拾起或在1分钟后消失；先射箭或投掷三叉戟再放置按钮，按钮不会自动打开，但手动按一次这个按钮，它就会一直保持打开，直到箭或三叉戟消失。
: 马铃薯木按钮会保持打开状态15个红石刻（1.5秒）。
; 行为
: 当打开时，马铃薯木按钮会：
:* 激活任何毗邻的[[红石线]]至[[红石电路#信号强度|信号强度]]15。
:* 激活任何四周的背对马铃薯木按钮的[[红石比较器]]或[[红石中继器]]至信号等级15。
:* 强充能它的附着方塊，充能等级15。
:* 激活任何毗邻的（包括上面的或下面）的[[机械元件]]（例外：活塞不会被其活塞臂朝向的电源激活）。
: 当马铃薯木按钮更改状态时，它会向其毗邻提供一个[[方块更新]]（同时提供PP更新和NC更新），以及向马铃薯木按钮附着方块的毗邻提供一个NC更新。
