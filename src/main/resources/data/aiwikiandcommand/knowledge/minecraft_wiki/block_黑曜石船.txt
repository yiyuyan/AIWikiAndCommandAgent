'''黑曜石船（Obsidian Boat）'''是由[[黑曜石]]制作的[[船]]。

== 获取 ==
由于无法直接攻击生物，玩家无法通过回收黑曜石船实体来获取其物品。

| Olink = none
| ignoreusage = 1
}}

== 行为 ==
黑曜石船在[[水]]和[[熔岩]]中会沉没而不会漂浮。

黑曜石船从高处掉落时会损毁，并掉落3个[[橡木木板]]和2根[[木棍]]。

== 音效 ==
黑曜石船的音效在“友好生物”分类播放，即使它没有任何音效。
