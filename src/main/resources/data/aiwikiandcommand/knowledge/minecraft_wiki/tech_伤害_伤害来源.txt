此页面记录了游戏中所有可以产生伤害的情况。

== 近战攻击 ==
{{main|近战攻击}}

通过极近距离接触目标，生物可以通过[[近战攻击]]来直接造成伤害。

== 弹射物 ==
一些生物使用[[弹射物]]作为其攻击手段，其中的一部分可以被玩家发射以造成伤害。

所有弹射物也都可以被[[发射器]]或{{cmd|summon}}生成而无需发射者。

下表中包含所有能造成'''弹射物伤害'''的弹射物的伤害值，不包括任何施加的状态效果或爆炸造成的伤害。

=== 火球 ===
恶魂火球和小火球直接命中造成的伤害同时属于弹射物伤害和火焰伤害，并同时受到[[弹射物保护]]和[[火焰保护]]的减免，若其中任一类型伤害被实体免疫也会无效化。

=== 箭 ===
[[箭]]的伤害受到其基础伤害、{{only|je|for=速度}}和“暴击箭”状态的影响。具有[[力量（魔咒）|{{tr|力量|強力}}]]魔咒的弓能够发射具有更高基础伤害的箭。

{{in|je}}被[[爆炸]]加速的箭会造成更高伤害，被[[水]]减速的箭会造成更少伤害。

=== 三叉戟 ===
基础伤害为{{hp|8}}。[[三叉戟]]上提供[[近战攻击#魔咒攻击力|魔咒攻击力]]的魔咒（包括[[锋利]]、[[亡灵杀手]]、[[节肢杀手]]、[[穿刺]]）会增加三叉戟造成的弹射物伤害。

=== 水瓶 ===
被[[喷溅型水瓶]]或[[滞留型水瓶]]效果影响的[[烈焰人]]、[[末影人]]、[[雪傀儡]]或[[炽足兽]]会受到{{hp|1}}伤害。

=== 烟花火箭 ===
{{Main|烟花火箭}}
合成时加入[[烟火之星]]的[[烟花火箭]]爆裂时会杀伤周围的生物，其伤害范围覆盖约{{frac|4|1|2}}格半径以内。在范围的边界处，爆裂只会造成{{hp|1}}伤害，但随着距离的靠近伤害会增加，在2格或以内，由1个[[烟火之星]]合成的[[烟花火箭]]至多能造成{{hp|5}}伤害。

如果由烟火之星合成的火箭被{{ctrl|使用}}于[[鞘翅]]加速，则会在加速结束后像正常一样爆裂，且对玩家造成伤害。

烟花火箭发生的''爆裂''并不是''[[爆炸]]''，不能破坏方块，不会杀伤任何非生物实体，其伤害产生击退效果而非[[爆炸击退]]，相关的[[死亡消息]]也与爆炸不同。

== 摔落 ==
{{main|摔落}}
实体在滞空时从一定高度以上摔落即会受到伤害。

== 着火 ==
{{Main|着火}}
着火的实体会每{{convert|1|秒}}会受到{{hp|1}}火焰伤害。

== 窒息 ==
{{main|窒息}}
生物的头部处于窒息方块内时会窒息，持续受到{{hp|1}}伤害。

== 溺水和脱水 ==
{{main|呼吸}}
多数生物无法呼吸一段时间后氧气值会耗尽，氧气值耗尽后会持续受到伤害。{{in|je}}所有生物每{{convert|20}}受到{{hp|2}}伤害；{{in|be}}玩家每{{convert|20}}受到{{hp|2}}伤害，除玩家以外的所有生物每{{convert|10}}受到{{hp|2}}伤害。

== 动能 ==
{{main|鞘翅#动能伤害}}
使用鞘翅滑翔高速撞击方块侧面{{only|java|for=或[[世界边界]]}}时会受到伤害。

== 世界边界 ==
{{main|世界边界}}
{{exclusive|je|section=1}}
处于世界边界外5格或更远（由{{cmd|worldborder damage buffer}}设置）的玩家会持续受到伤害。

== 挤压 ==
{{main|挤压}}
{{exclusive|je|section=1}}
当[[游戏规则]]{{gamerule|max_entity_cramming}}不为0时，同一位置有过多实体会引发[[挤压]]，并导致其中的所有生物每游戏刻有25%的概率受到{{hp|6}}伤害。

== 荆棘 ==
{{main|荆棘}}
当生物对荆棘魔咒[[盔甲]]的穿戴者造成伤害时，攻击者会受到来自荆棘魔咒的魔法伤害，其伤害取决于魔咒等级（<code>-{}-等级*15</code>%概率造成{{only|for={{hp|1}}–{{hp|5}}|je}}或{{only|for={{HpRange|1|4}}（等级高于10后为<code>-{}-''等级''-10</code>）|be}}伤害）。

== 闪电 ==
{{main|闪电束}}
闪电束劈下时会对落下的区域反复造成{{hp|5}}伤害，通常会因伤害免疫而只能造成有限的伤害。这一伤害可以被[[护甲值]]减免。

== 下落的方块 ==
{{main|下落的方块}}
下落的[[铁砧]]在1格后伤害值为{{hp|2}}每格（如从4格高处下落时会造成{{hp|6}}伤害）。无论方块落下多高，其造成的伤害最高为{{hp|40}}。穿戴[[头盔]]可减少其伤害，但头盔的[[物品耐久|耐久]]会大量消耗。

下落的[[滴水石锥#钟乳石|钟乳石状态的滴水石锥]]在1格后伤害值为{{only|je|for={{hp|6}}}}或{{only|be|for={{hp|1}}}}每格（如从4格高处下落时会造成{{only|je|for={{hp|18}}}}或{{only|be|for={{hp|3}}}}伤害）。无论方块下落多高，其造成的伤害最高为{{hp|40}}。穿戴头盔可减少其伤害，但头盔的耐久会大量消耗。

== 潮涌核心 ==
{{main|潮涌核心#攻击}}
安装在完整的启动框架上的[[潮涌核心]]会攻击附近环境内处于[[水]]或[[雨]]内的[[敌对生物]]（{{in|be|nc=1}}除了[[猪灵]]、[[猪灵蛮兵]]和[[疣猪兽]]）和{{only|je|for=[[巨人]]}}，每{{convert|2|秒}}造成{{hp|4}}魔法伤害。

== 危险环境 ==
与[[仙人掌]]接触的实体会持续受到{{hp|1}}伤害。

站在[[营火]]顶部的实体会持续受到{{hp|1}}火焰伤害，除非生物穿着具有[[冰霜行者]]魔咒的物品。

站在[[灵魂营火]]顶部的实体会持续受到{{hp|2}}火焰伤害，除非生物穿着具有[[冰霜行者]]魔咒的物品。

站在[[岩浆块]]顶部的实体会持续受到{{hp|1}}火焰伤害，除非生物正在潜行或穿着具有[[冰霜行者]]魔咒的物品。

与[[火]]接触的实体会持续受到{{hp|1}}火焰伤害。

与[[灵魂火]]接触的实体会持续受到{{hp|2}}火焰伤害。

与[[熔岩]]接触的实体会持续受到{{hp|4}}火焰伤害。

与[[水]]或[[雨]]接触的[[烈焰人]]、[[末影人]]、[[雪傀儡]]或[[炽足兽]]会持续受到{{hp|1}}伤害。

除[[狐狸]]和[[蜜蜂]]外的生物在超过第一生长阶段的[[甜浆果丛]]中移动会持续受到{{hp|1}}伤害。[[玩家]]受到此伤害时，会发出独特的伤害音效。

== 生物受伤 ==
破坏[[末地水晶]]会使其正在治疗的[[末影龙]]受到{{hp|10}}伤害。

身处于温度高于1.0的[[生物群系]]内的[[雪傀儡]]会持续受到{{hp|1}}{{only|je|for=火焰伤害}}/{{only|be|for=伤害}}。

[[海豚]]超过{{convert|2400}}没有接触过[[水]]会持续受到{{hp|1}}伤害。

失去螫针的[[蜜蜂]]每{{convert|5}}有<code>-{}-1/clamp(1200-失去螫针到现在的刻数,1,1200)</code>的概率受到等于当前生命值的伤害。

由[[唤魔者]]召唤的[[恼鬼]]会在生成后的第30秒至第119秒后，每{{convert|20}}受到{{hp|1}}饥饿伤害。

{{in|java}}给[[鹦鹉]]喂[[曲奇]]吃会使其受到3.4×10<sup>38</sup>（{{healthbar|2|9px}} × 1.7×10<sup>38</sup>）伤害。

== 状态效果 ==
{{Main|状态效果|瞬间伤害|瞬间治疗|中毒|中毒（致命）|凋零}}
[[中毒]]和{{only|be|for=[[中毒（致命）]]}}效果会持续对生物造成魔法伤害。[[凋零]]效果会持续对生物造成伤害类型为{{cd|wither}}的伤害。[[瞬间伤害]]效果会在生效时对非[[亡灵生物]]造成一次魔法伤害。[[瞬间治疗]]效果会在生效时对亡灵生物造成一次魔法伤害。

中毒效果不会致死，但会使生物的生命值降到{{Hp|1}}，其面对其他伤害源时非常脆弱。

[[女巫]]会投掷的药水中包括[[中毒]]和[[瞬间伤害]]，作为其主要攻击手段。

[[蜜蜂]]和[[洞穴蜘蛛]]在普通或困难模式对生物造成伤害时会造成[[中毒]]。食用[[蜘蛛眼]]、[[毒马铃薯]]、[[河豚]]也会造成此效果。

[[凋灵骷髅]]的攻击会造成凋零I效果。[[凋灵]]发射的凋灵之首在普通或困难模式会造成凋零II效果。

{{in|be}}给[[鹦鹉]]喂食[[曲奇]]会造成[[中毒（致命）]]效果。

== 冰冻 ==
{{Main|细雪}}
未受保护进入细雪而被冰冻的生物每{{convert|2|秒}}会受到{{hp|1}}伤害，对于[[烈焰人]]、[[炽足兽]]或[[岩浆怪]]则是{{convert|2|秒}}会受到{{hp|5}}伤害。

玩家受到冰冻伤害时，会发出带有冻结声音的伤害音效。

== 爆炸 ==
{{Main|爆炸}}
[[爆炸]]能够对一个范围内的所有生物造成伤害，并产生显著的冲击力。

爆炸的伤害由接触率和爆炸威力控制。

爆炸会造成的冲击会击飞周围的所有生物，但这一效果并非其伤害的击退效果，不受伤害免疫的影响。

== 饥饿 ==
当玩家的[[饥饿值]]降为{{hunger|0|total=20}}时，玩家将每{{convert|4|秒}}受到{{hp|1}}的伤害，直到玩家进食。

来自饥饿的伤害在简单难度中至多能将玩家的生命值降到{{hp|10}}，或在普通难度中生命值降到{{hp|1}}。来自饥饿的伤害在困难难度中可以致命。

饥饿伤害无视生物的所有防护效果，但可以触发[[不死图腾]]。

== 虚空 ==
{{Main|虚空}}
坠入虚空中位置低于建造高度{{only|je|fro=64米}}/{{only|be|for=18米}}（对于高度下限为0的维度则是-64/-18及以下、对于高度下限为-64的维度则是-128/-82及以下）的生物会持续受到{{hp|4}}伤害。

虚空伤害无视生物的所有防护效果，且不触发[[不死图腾]]。

{{in|java}}即使玩家是在创造模式或旁观模式下，也会受到虚空伤害。{{in|be}}创造模式玩家免疫虚空伤害。

== kill ==
{{Main|命令/kill}}

{{cmd|kill}}会使目标生物受到3.4×10<sup>38</sup>（{{hp|2|notag=1}} × 1.7×10<sup>38</sup>）伤害。

此伤害无视生物的所有防护效果，且不触发[[不死图腾]]。

{{in|java}}即使玩家是在创造模式或旁观模式下，也会受到这一伤害。{{in|be}}该命令无法杀死创造模式下的玩家，只会提示“玩家在创造模式下无法被杀死”，若选择器未找到其他目标则还会提示“无效的目标选择器参数”。

== damage ==
{{Main|命令/damage}}
{{cmd|damage}}会使目标生物受到指定来源的指定伤害类型的指定量伤害。
