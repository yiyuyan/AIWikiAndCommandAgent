'''13w05b'''是[[Java版1.5]]的第8个快照，发布于2013年2月1日<ref>{{cite|url=http://mojang.com/2013/01/minecraft-snapshot-13w05a/|archive-url=1|archive=1|title=Minecraft Snapshot 13w05a|author=Dinnerbone|website=Mojang.com|date=Jan 31, 2013}}</ref>，发布以修复[[13w05a]]里的漏洞和崩溃。

== 更改 ==
=== 方块 ===
'''[[龙蛋]]'''
* 再次更改了下落时的纹理和模型。
