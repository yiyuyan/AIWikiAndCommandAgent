'''凝灰岩楼梯（Tuff Stairs）'''是[[凝灰岩]]制作的[[楼梯]]。

== 生成 ==
凝灰岩楼梯不会生成在世界中。

== 获取 ==

|type= Building block
}}

{{Stonecutting
|Tuff
|Tuff Stairs

== 破坏 ==
挖掘凝灰岩楼梯的合适工具是镐。凝灰岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

凝灰岩楼梯被破坏后会掉落自身。
