'''Ore UI'''是一套专为使用{{w|Web技术}}构建{{w|电子游戏}}{{w|用户界面}}而设计的开源包集合。它基于{{w|React}}和{{w|TypeScript}}开发，为{{w|电子游戏开发}}和通用{{w|web应用}}提供可复用的构建模块。<ref name="ore-ui-github">{{cite|url=https://github.com/Mojang/ore-ui|title=Mojang/ore-ui: 💎 Building blocks to construct game UIs using web tech.|website=GitHub}}</ref>目前，Ore UI已被应用于[[基岩版]]和[[Minecraft Legends]]等游戏中。

[[File:Ore UI Design System.png|缩略图|{{el|bedrock}}的新UI设计系统大改<ref>{{tweet|pirelenito|1452914034605494277|Thanks for everyone that attended my talk live at @ReactAdvanced. For anyone that couldn't attend, I'll post a link here once it is available for everyone. It was a developer conference, but if you were waiting for a sneak peek on the new UI components... here it is ☺️}}</ref>]]

开发团队正采用Coherent Labs<ref name="react-advanced-2021-ore-ui"/><ref name="dotjs-hummingbird-tech-preview">{{ytl|qDevZETe8OE|dotJS 2018 - Tobias Ahlin - Adding JavaScript to Minecraft|March 4, 2019}}</ref><ref name="powered-by-coherent-labs">{{cite|url=https://www.coherent-labs.com/powered-by-coherent-labs/|title=Powered by Coherent Labs|website=Coherent Labs}}</ref>研发的Gameface引擎（前身为Hummingbird）<ref name="gameface-former-hummingbird">{{cite|url=https://wiki.bedrock.dev/meta/gametest-qna.html#hummingbird-ui|title=GameTest Q&A 2021/08/06|website=Bedrock Wiki}}</ref>构建全新UI设计系统，这使得运行{{w|JavaScript}}、{{w|HTML}}和{{w|CSS}}等现代Web技术成为可能。

与JSON UI不同，Ore UI是硬编码的，不能被[[附加包]]修改。<ref name="bedrock-wiki-json-ui-intro">{{cite|url=https://wiki.bedrock.dev/json-ui/json-ui-intro.html#introduction|title=Intro to JSON UI|website=Bedrock Wiki}}</ref>

== 历史 ==
=== 基岩版UI的全面改造 ===
2018年11月9日，Mojang工作室的首席体验设计师[[Tobias Ahlin]]宣布将对基于Hummingbird引擎的{{el|bedrock}}UI进行大改，它运行HTML和CSS的子集，并且基于React框架构建设计系统。<ref name="dotjs-hummingbird-tech-preview"/> {{el|bedrock}}标题屏幕重新设计的技术预览展示了对用户更为友好的触摸、控制器和键盘输入方式。该公告在2018年dotJS开发者大会上发布。

[[File:DotJS 2018 Bedrock's UI redesign tech preview.png|缩略图|在dotJS2018开发者大会上展示的{{el|bedrock}}重新设计技术预览]]
技术预览版的新标题屏幕有两个页面。顶部界面显示了玩家最近游玩的世界，背景会随着世界缩略图的变化而变化；底部界面设有五个交互式功能按钮：

* “Play”可能用于启动已存储的世界；
* “Store”可能用于打开市场页面（类似于现在的[[市场]]）；
* “Skins”可能用于玩家自定义个人皮肤（类似于现在的[[角色创建器]]）；
* “Achievements”和“Settings”可以让玩家查看自己的成就和打开设置。

界面右上角有一个包含玩家头像的档案按钮，推测为[[档案|个人资料]]界面入口。

[[Minecraft]] JavaScript API技术文档曾通过特定链接开放访问，这个链接可以在演讲结束时看到，文档提供了技术预览界面，用户可以在其中自由地与重新设计的UI交互。<ref name="dotjs-hummingbird-tech-preview"/>原始链接现已重定向至无关站点，技术文档目前处于完全不可获取状态，已被视为{{w|散失媒体}}。

2018年年中，Minecraft官方网站（[[Minecraft.net]]和[[Minecraft Feedback]]）开始接收一些基于新UI设计系统的用户界面更新。{{citation needed}}

2020年7月31日，[[基岩版1.16.100.50]]首次展示了新的[[成就]]屏幕，并逐步向5%的玩家推出。<ref name="achievement-new-ui-rollout">{{tweet|Volgar|1289257749751058432|Uh-oh! I think I pressed something, and now 5% of #Minecraft beta users will see the new achievements screen. Well, might as well ask for feedback here: https://aka.ms/mcAchievementBeta.|July 31, 2020}}</ref>在接下来的9周内，可以使用新成就界面的玩家数量从5%缓慢增加到75%。<ref name="achievement-new-ui-rollut-75">{{tweet|Volgar|1337166293431169024|I'll provide more context later, but... jam. It gets everywhere. Hence a whopping 75% of #Minecraft players have a chance to see the new achievements screen both in the latest release and the latest beta. Stay tuned! Ta-tah!}}</ref>

=== React Facet ===
2021年10月18日，React Facet源代码在{{w|MIT许可证|MIT许可}}下的[https://github.com/Mojang/ore-ui Ore UI GitHub存储库]上发布。<ref name="github-ore-ui-react-facet">{{cite|url=https://github.com/Mojang/ore-ui/commit/96c107cea826379efbd76342fdf1e37789b53b36|title=Importing codebase from internal repository (#1) · Mojang/ore-ui@96c107c|website=GitHub}}</ref>

2021年10月25日，<ref name="react-advanced-ragonha-talk-date">{{cite|url=https://reactadvanced.com/2021/#schedule|title=Schedule|website=React Advanced}}</ref>在React Advanced 2021开发者大会上，Mojang Studios的技术主管Paulo Ragonha宣布推出React Facet，这是一种基于{{w|观察者模式|可观察模式}}的React内置电子游戏用户界面状态管理。<ref name="react-advanced-2021-ore-ui">{{ytl|Vyg1oQI1VaA|Using React to Build Performant Game UIs in Minecraft - Paulo Ragonha, React Advanced 2021|December 27, 2021}}</ref>在演讲中Ragonha展示了React Facet如何通过引入一个连接{{w|Frontend and backend|后端}}C++游戏引擎（游戏状态所在的位置）和{{w|Frontend and backend|前端}}JavaScript UI的系统来桥接游戏数据。这种连接依赖于一个称为'''分面'''的概念，它是表示游戏状态切片的轻量级可观察对象。这些分面允许UI订阅来自游戏引擎的特定数据，例如玩家运行状况、库存或环境变化，并在游戏中的状态发生变化时接收实时更新。

在[[基岩版1.20.30.22]]中，游戏界面经过重新设计，采用了类似于成就菜单的新设计元素。

在[[基岩版1.21.20]]和[[基岩版1.21.30.23]]中，成就按钮已更改为个人资料按钮，并且出现新的个人资料屏幕，它显示了玩家的[[统计信息]]、[[成就]]和[[截图]]。
