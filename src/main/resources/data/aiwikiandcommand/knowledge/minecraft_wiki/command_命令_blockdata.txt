更改[[方块]]的NBT标签。

== 语法 ==
: <code>-{}-blockdata <''x''> <''y''> <''z''> <''NBT标签''></code>

== 参数 ==
<code>''x y z''</code>
: 指定要修改的方块实体的坐标。可使用[[相对坐标]]来指定与命令执行处的相对距离。

<code>-{}-''NBT标签''</code>
: 指定要对方块实体添加或覆盖的[[NBT标签]]元素。必须是一个复合[[NBT标签]]（例如<code>{CustomName:Fred}</code>）。

== 示例 ==
* 将（0, 64, 0）处信标的主增益效果更改为[[急迫]]：<code>blockdata 0 64 0 {Primary:3}</code>
