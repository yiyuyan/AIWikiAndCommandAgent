'''14w04b'''是[[Java版1.8]]的第7个快照，发布于2014年1月24日<ref>{{cite|url=http://mojang.com/2014/01/minecraft-snapshot-14w04a/|archive-url=1|archive=1|archive-time=20140131052758|title=Minecraft snapshot 14w04b|author=Dinnerbone|website=Mojang.com|date=Jan 23, 2014}}</ref>，修复了[[14w04a]]的漏洞和崩溃。

== 修复 ==
{{fixes|fixedin=14w04b|prefix=Minecraft|showdesc=1
|;dev
|45082|进入传送门后，外层皮肤不显示。
|45238|在任何模式下，掉落的铁砧对玩家都没有伤害。
|45281|利用{{cmd|clone|link=none}}命令复制的命令方块导致游戏崩溃。
|;previous
|45482|杀死生物总是可以得到稀有掉落（100%概率）。
|45496|玩家受到生物伤害时被服务器断开连接。
|45516|熔炉在游戏重启或在切换维度后停止熔炼。
|45528|被雪覆盖的草方块上不显示雪的纹理。
|45552|世界加载或重加载导致物品展示框被复制。
|45605|物品展示框放置在雪上时不输出信号。
|45628|不生成地牢。
|45689|时钟在物品展示框中不显示。
|;hotfix
|45747|物品展示框不能被放置，原先放置的也会掉落。
}}

== 重新上传 ==
该版本于15:54（UTC）被重新上传，以修复无法放置物品展示框与物品实体不会旋转的问题。<ref>{{tweet|simnico971|426746133864808448|@Dinnerbone we cannot place item frames and items on the ground don’t rotate !|24 Jan 14}}: {{tweet|Dinnerbone|426746265335234560|@simnico971 Redownload it. Sorry.|24 Jan 14}}</ref></onlyinclude>
