'''15w35c'''是[[Java版1.9]]的第16个快照，发布于2015年8月28日<ref>{{cite|url=http://mojang.com/2015/08/minecraft-snapshot-15w35a/|archive-url=1|archive=1|title=Minecraft 1.9 snapshot 15w35e|author=Dinnerbone|website=Mojang.com|date=Aug 24, 2015}}</ref>，发布以修复一些在[[15w35b]]中导致崩溃的漏洞。这些漏洞中主要是关于村庄和区块的。

== 修复 ==
{{fixes|fixedin=15w35c|prefix=Minecraft|showdesc=1

|;1.8开发版本的漏洞
|66376|史莱姆生成时不受<code>Rotation</code>实体标签的影响。

|;dev
|87078|进行横扫攻击后游戏会向日志中输出<code>lasdjfhlsdhjflsdij</code>信息。
|87194|在15w35b中放置的橡木和圆石楼梯不能被看见。
|87196|重新进入世界后之前放置的门的上半部分或整个门会消失不见。

|;previous
|87223|更改命令方块类型会使游戏崩溃。
|87524|循环型命令方块的连锁机制与其他类型不一致。
}}</onlyinclude>
