'''发光的黑曜石（Glowing Obsidian）'''是[[基岩版]]、[[New Nintendo 3DS版]]、[[树莓派版]]和[[教育版]]独有的方块，除了用于装饰外没有任何用处。

== 生成 ==
发光的黑曜石不会生成在世界中。

== 获取 ==
{{see also|Tutorial:获取任意物品}}
发光的黑曜石只能通过从[[携带版0.12.1.b1]]前包含发光的黑曜石并升级了的世界中获得，无法在其他未开启[[作弊]]的[[生存模式]]的世界中获取，不存在于[[创造模式物品栏]]中，且是不可通过{{cmd|give}}获取的物品。在[[创造模式]]中对已有的发光的黑曜石使用{{ctrl|选取方块}}可以获得发光的黑曜石；否则，发光的黑曜石只能通过存档编辑或[[附加包]]获得。

== 破坏 ==
挖掘发光的黑曜石的合适工具是镐。发光的黑曜石需要钻石镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table|only=be}}

发光的黑曜石被破坏后会掉落自身。

== 用途 ==
发光的黑曜石会发出[[亮度]]为12的光。
