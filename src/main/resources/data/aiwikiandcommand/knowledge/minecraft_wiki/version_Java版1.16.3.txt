'''1.16.3'''是{{el|je}}的一次次要更新，发布于2020年9月10日<ref>{{article|minecraft-java-edition-1-16-3|Minecraft Java 1.16.3 Released|September 10, 2020}}</ref>，修复了一些漏洞。此版本不兼容1.16到1.16.2的服务端。

1.16.3的游戏内容与其发布候选版本一致<ref>{{tweet|adrian_ivl|1304065323369459713|We're now releasing 1.16.3. There are no changes from the release candidate. Enjoy your Thursday :)|September 10, 2020}}</ref>，两者仅在协议版本和数据版本上有所不同。

== 修复 ==
{{Fixes|fixedin=1.16.3,1.16.3 Release Candidate 1|showdesc=1
|;1.16前正式版的漏洞
|135164|生物死亡时会继续手持其原先持有的方块或物品，导致方块和物品看起来被复制了。
|158131|玩家蹲在潜影贝上时，下蹲动画不显示。
|159335|从生物身上掉落的盔甲的耐久度可以是负值。
|;1.16.2的漏洞
|196449|猪灵、猪灵蛮兵、疣猪兽和僵尸疣猪兽攻击玩家时无法正确寻路。
|198678|将金锭和另一件物品扔给幼年猪灵并将其杀死，会掉落两份该物品。
|201331|墙上的绯红木告示牌和墙上的诡异木告示牌在地图上的颜色有误。
}}
