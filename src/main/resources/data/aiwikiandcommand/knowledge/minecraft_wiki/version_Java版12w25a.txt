'''12w25a'''是[[Java版1.3.1]]的第12个快照，发布于2012年6月21日<ref>{{cite|url=http://mojang.com/2012/06/minecraft-snapshot-week-25/|archive-url=1|archive=1|title=Minecraft Snapshot Week 25|author=Jens Bergensten|website=Mojang.com|date=Jun 21, 2012}}</ref>，为LAN游戏加入了更多选项，加入了3种楼梯，并修复了一些漏洞。

== 新内容 ==
=== 方块 ===
'''[[楼梯]]'''
* 加入了3种[[木头]]对应的楼梯（云杉木、白桦木和丛林木）。

=== 游戏内容 ===
'''[[LAN]]'''
* 加入了“广播到局域网”选项至游戏内的菜单，允许玩家向其他玩家开放世界。
* 玩家可以选择打开或关闭[[命令]]和选择[[游戏模式]]。

== 更改 ==
=== 方块 ===
'''[[台阶]]和[[楼梯]]'''
* [[红石元件]]（包括[[红石中继器]]、[[红石火把]]、[[拉杆]]和[[压力板]]）和铁轨现在能够放置在上半部分台阶的顶部和上下颠倒的楼梯的顶部。

=== 物品 ===
'''[[箭]]'''
* 在[[创造模式]]下射箭后靠近箭时可以将其捡起，但是玩家不能获得它们。
* 潜在改善内存使用。

=== 生物 ===
'''[[猪]]'''
* 猪被杀死时现在会掉落1–3个[[生猪排]]而不是0–2个。

'''[[史莱姆]]'''
* 减少了史莱姆在[[超平坦世界]]里的生成概率。

=== 世界生成 ===
'''[[末地]]'''
* 末地的“天空”被更改了，现在是紫色的而不是呈现绿色。

=== 游戏内容 ===
'''[[溺水]]'''
* 移除了溺水时向下的击退效果。

'''LAN'''
* [[多人游戏]]菜单现在会扫描LAN服务器。

'''[[交易]]'''
* [[村民]]可能在使用至少3次同样的交易后移除该选项。

=== 命令格式 ===
'''{{cmd|tp}}'''
* 现在允许玩家传送至指定坐标。
** 语法为{{cmd|tp [目标玩家] <x> <y> <z>}}。
** {{cmd|tp}}的其余功能保留。

== 修复 ==
; 修复了9个漏洞
: 修复了玩家重生后末影箱中物品被清除的漏洞。
: 修复了活塞不能推动玩家的漏洞。
: 修复了执行{{cmd|time set day|link=none}}命令时导致崩溃的漏洞。
: 修复了从游戏内打开纹理包文件夹时导致游戏卡死的漏洞。
: 修复了当存档所有者退出局域网游戏后，游戏仍然对其他玩家开放的漏洞。
: 修复了村民繁殖时，它们旁边的心不显示的漏洞。
: 修复了玩家在重生后皮肤被设置为默认皮肤，而玩家除非重新进入游戏才能恢复正常的漏洞。
: 修复了不能在16格外听到TNT声音的漏洞。
: 修复了可以在黑暗房间里使用骨粉的漏洞。<ref>{{tweet|Dinnerbone|216694545314885632}}</ref></onlyinclude>
