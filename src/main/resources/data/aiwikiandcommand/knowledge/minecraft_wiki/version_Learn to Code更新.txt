'''Learn to Code更新（Learn to Code Update）'''是{{el|ee}}的一次次要更新，其正式版[[教育版1.14.50|1.14.50]]发布于2020年11月10日。加入了新的Learn to Code功能，以及开启了Hour of Code: A Minecraft Tale of Two Villages。<ref>{{cite|url=https://web.archive.org/web/20201113025525/https://educommunity.minecraft.net/hc/en-us/articles/360051237012-What-s-New-Learn-to-Code-Update-version-1-14-50-|title=What's New: Learn to Code Update (version 1.14.50)|website=Minecraft: Education Edition Support|author=Kyle M|date=November 10, 2020}}</ref><ref>{{cite|url=https://web.archive.org/web/20201027025357/https://educommunity.minecraft.net/hc/en-us/articles/360049494792-Feature-Walkthrough-Minecraft-Education-Edition-Learn-to-Code-Beta-Version-1-14-40-|title=Feature Walkthrough Minecraft: Education Edition Learn to Code Beta (Version 1.14.40)|website=educommunity.minecraft.net}}</ref><ref>https://education.minecraft.net/en-us/blog/explore-empathy-and-inclusion-with-the-new-hour-of-code-a-minecraft-tale-of-two-villages</ref>

== 重要特性 ==
'''[[代码构建器]]'''
* 重新构建菜单，为编码提供更多空间，菜单选项更容易理解。
* “Home”和“Reset Editor”按钮已添加到“Code Builder”菜单中。

'''Hour of Code课程'''
* 加入了Hour of Code: A Tale of Two Villages课程内容。
** 可以通过游戏内图书馆访问，或登录使用免费演示版。

'''图书馆更新'''
* Mac和iPad用户现在可以通过谷歌教室或电子邮件分享或分配图书馆课程。

'''单点登录'''
* 学校现在可以将Google和Microsoft的账户连接起来，这样就可以方便教师和学生在Chromebook上同时登录。

'''允许URL列表'''
* 所有身份验证目前都使用*.minecrafteduservices.com完成。
