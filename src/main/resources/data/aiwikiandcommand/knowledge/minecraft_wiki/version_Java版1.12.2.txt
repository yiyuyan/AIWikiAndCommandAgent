'''1.12.2'''是{{el|je}}的一次次要更新，发布于2017年9月18日<ref>{{article|minecraft-1122-released|MINECRAFT 1.12.2 RELEASED|September 18, 2017}}</ref>，修复了一些漏洞，并且这是Java版本显示新的官方标题“Minecraft: Java Edition”，而非原来的“Minecraft”的首个版本。此版本不兼容1.12和1.12.1的服务端。

== 更改 ==
'''[[徽标]]'''
* 更改了游戏徽标，其现在有了副标题“{{tooltip|Java Edition|Java版}}”。
** 以区分{{el|be}}，由于[[独乐不如众乐更新]]，所有使用基岩引擎的平台（包括原{{el|pe}}），都被统一命名为了没有副标题的[[File:Mclogo.svg|90px|Minecraft|link=基岩版]]。
