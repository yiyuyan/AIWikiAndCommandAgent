控制[[实体]]的手臂挥动。

== 语法 ==
: <code>swing <targets> [mainhand|offhand]</code>
:: 挥动实体的指定手臂。
: <code>swing [<targets>]</code>
:: 挥动实体的主手。

== 参数 ==
{{argument|targets|entity}}
: 指定挥臂的实体，默认为命令的执行者。
: 只有[[生物]]才具有挥臂这一行为，且客户端只会在特定的生物上渲染挥臂动作。
: {{arg desc|je=entity|amount=multiple|type=entities}}
<code>mainhand|offhand</code>
: 指定挥动的手臂，默认为{{cd|mainhand}}。
: {{cd|mainhand}}为主手，{{cd|offhand}}为副手。
