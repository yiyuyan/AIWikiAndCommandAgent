为特定玩家设置出生点。

== 语法 ==
* '''Java版'''
: <code>spawnpoint [<targets>] [<pos>] [<rotation>]</code>

* '''基岩版'''
: <code>spawnpoint [player: target] [spawnPos: x y z]</code>

== 参数 ==
{{argument|targets|entity|player: target|CommandSelector<Player>}}
: 指定被更改出生点的玩家。如果没有指定，默认为命令执行者。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{argument|pos|block_pos|spawnPos: x y z|CommandPositionFloat}}
: 指定玩家新的出生点的坐标。若没有指定，默认为{{only|je|for=命令执行点}}或{{only|be|for=所指定玩家的位置}}。
: {{IN|java}}<code><''x''></code>或<code><''z''></code>应在[-30000000, 30000000)区间内，<code><''y''></code>应在[-20000000, 20000000)区间内。
: {{in|be}}大于30,000,000和小于-30,000,000的<code><''x''></code>和<code><''z''></code>值会分别被设置为30,000,000和-30,000,000，大于319和小于-64的<code><''y''></code>值会被分别设置为319和-64。
: {{in|je}}{{arg desc|je=block_pos}}
: {{in|be}}{{arg desc|be=CommandPositionFloat}}

{{el|je|short=1}}：{{argument|rotation|rotation}}
: 指定玩家重生时的旋转角，默认为{{cd|0 0}}。
: {{arg desc|je=rotation}}

== 示例 ==
* 设置所有玩家的出生点为<code>0 -60 0</code>：<code>/spawnpoint @a 0 -60 0</code>
* 设置自己的出生点为<code>0 -60 0</code>并面朝北方：<code>/spawnpoint @s 0 -60 0 180 0</code>{{only|je}}
