'''16w21a'''是[[Java版1.10]]的第2个快照，发布于2016年5月25日<ref>{{cite|url=http://mojang.com/2016/05/minecraft-snapshot-16w21a/|archive-url=1|archive=1|title=Minecraft snapshot 16w21b|author=Searge|website=Mojang.com|date=May 25, 2016}}</ref>，加入了新的NBT标签，并修复了一些漏洞。

== 新内容 ==
=== 命令格式 ===
'''NBT标签'''
* <code>FallFlying</code>
** 允许怪物使用鞘翅飞行。
*** 怪物会在接触地面后失去飞行能力。

== 更改 ==
=== 方块 ===
'''[[结构方块]]'''
* 向加载模式加入了“结构完整性和种子”选项。

'''[[骨块]]'''
* 不再透明。

'''[[紫颂果]]'''
* 现在可以正常传送骑着动物的玩家（被骑乘的动物不会被传送）。

'''[[发射器]]'''
* 现在可以给实体装备盾牌。

'''[[铁轨]] （任何种类）'''
* 上坡铁轨的碰撞箱现在为1个方块。（以前只有{{frac|5|32}}格高）。

=== 物品 ===
'''[[末影珍珠]]'''
* 现在可以正常传送骑着动物的玩家（被骑乘的动物不会被传送）。

'''[[末地传送门]]'''
* 在激活时会替换任何被末地传送门框架围着的方块。

'''[[钓鱼竿]]'''
* 现在可以将物品拉向玩家。

'''[[矿车]]'''
* 碰撞到实体时会再次乘载实体了。

=== 生物 ===
'''[[狼]]'''
* 不再消失。

=== 世界生成 ===
'''[[村庄]]'''
* 生成在热带草原的村庄铁匠铺会生成圆石以避免被熔岩烧毁。

=== 命令格式 ===
'''NBT标签'''
* <code>IsVillager</code>和<code>VillagerProfession</code>标签被完全移除，它们被在[[16w20a]]中首次加入的<code>ZombieType</code>代替。

=== 游戏内容 ===
'''[[粒子]]'''
* <code>fallingdust</code>现在可以被生成了，利用像<code>blockcrack</code>等一些粒子类型的<code>params</code>参数。
** 使用命令{{cmd|particle fallingdust ~ ~ ~ 0 0 0 0 1 0 @p 10}}会生成熔岩颜色的粒子。
