对指定实体造成指定类型的伤害。

== 语法 ==
* '''Java版'''
: <code>damage <target> <amount> [<damageType>] [at <location>]</code>
: <code>damage <target> <amount> [<damageType>] [by <entity>] [from <source>]</code>

* '''基岩版'''
: <code>damage <target: target> <amount: int> <cause: DamageCause> entity <damager: target></code>
: <code>damage <target: target> <amount: int> [cause: DamageCause]</code>

== 参数 ==
{{argument|target|entity|target: target|CommandSelector<Actor>}}
: 指定要被伤害的目标实体。
: {{arg desc|je=entity|amount=single|type=entities|be=actor}}
{{argument|amount|float|amount: int|int}}
: 指定要造成的伤害值。
: {{in|je}}{{arg desc|je=float}}{{in|be}}{{arg desc|be=int}}
{{argument|damageType|resource|cause: DamageCause|enum}}
: 指定伤害的成因，即要造成的[[伤害类型]]，默认为{{only|for=<code>minecraft:generic</code>|je}}或{{only|for=<code>none</code>|be}}，其会影响的游戏内容如[[死亡消息]]。
: {{in|je}}{{arg desc|je=resource|registry=minecraft:damage_type}}
: {{in|be}}{{arg desc|be=enum}}所有伤害类型参见[https://learn.microsoft.com/en-us/minecraft/creator/reference/content/vanillalistingsreference/addonentitydamagesources 官方附加包文档]。
{{el|je|short=1}}：{{argument|location|vec3|je=1}}
: 指定伤害来源的位置。
: {{arg desc|je=vec3}}
{{argument|entity|entity|damager: target|CommandSelector<Actor>}}
: 指定伤害的直接来源，这会影响伤害造成的击退方向。可用于指定[[弹射物]]或[[被激活的TNT]]为伤害的直接来源，同时指定其发射者为伤害的实际来源。
: {{arg desc|je=entity|amount=single|type=entities|be=actor}}
{{el|je|short=1}}：{{argument|source|entity|je=1}}
: 指定伤害的实际来源，视为由该生物造成此伤害并增加相关[[统计]]，导致生物反击或声望下降，且造成死亡时为击杀者。没有指定时，<code><entity></code>参数指定的实体视为实际来源。
: {{arg desc|je=entity|amount=single|type=entities}}
