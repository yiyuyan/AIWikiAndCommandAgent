'''代码构建器更新（Code Builder Update）'''是{{el|ee}}的一次主要更新，其正式版[[教育版1.7|1.7]]发布于2018年11月12日，加入了[[水域更新]]第二阶段（[[基岩版1.5.0]]和[[基岩版1.6.0|1.6.0]]）的内容，并改进了游戏内编程。 <ref>{{cite|url=https://web.archive.org/web/20190308191631/https://minecrafteducation.zendesk.com/hc/en-us/articles/360018290372-What-s-New-November-Release-Version-1-7-|title=What's New: November Release (Version 1.7.1)|website=Minecraft: Education Edition Support}}</ref><ref>https://minecrafteducation.zendesk.com/hc/en-us/articles/360001429323-Code-Builder-in-Minecraft-Education-Edition-version-1-7-</ref><ref name="update">{{cite|url=https://education.minecraft.net/blog/download-the-code-builder-update-to-learn-coding-in-minecraft/|title=Download the Code Builder Update to Learn Coding in Minecraft|date=November 13, 2018}}</ref>

== 重要特性 ==
{{main|基岩版1.5.0|基岩版1.6.0}}

=== 新内容 ===
'''[[智能体]]'''
* {{cmd|remove}}
** 移除世界上的所有智能体。
* 玩家能够在HUD上看到智能体的坐标。
* {{cmd|summon agent}}现在可以生成或传送使用该命令的玩家的智能体到该玩家的位置。
* 新的[[目标选择器]]。
** <code>@c</code>用于选择用户的智能体，<code>@v</code>用于选择所有智能体。
** 只有拥有<code>worldbuilder</code>权限的玩家才能选择所有智能体。所有用户的<code>worldbuilder</code>权限默认都设置为false。
* 普通的目标选择器也可用于选择特定的智能体，因此{{cmd|tp @e<nowiki>[type=Agent,name=Steve.Agent]</nowiki> @s}}可以查找所有名称为“Steve.Agent”、类型为智能体的实体，并将它们传送到命令执行者的位置。玩家还可以用更简单的{{cmd|tp @v<nowiki>[name=Steve.Agent]</nowiki> @s}}来选择一个并非自己拥有的特定玩家的智能体。
* 为智能体加入了刷怪蛋。

'''Library Beta'''
* 允许玩家在游戏中查看和下载世界，而无需{{tr|访问|造訪|訪問}}教育版网站。玩家将在主屏幕上看到一个名为“Library”的新按钮，该按钮会生成一个由教师调整的“必须拥有”世界的列表。

'''[[HUD]]'''
* 在游戏中的HUD中加入了鼠标和键盘控制提示，以帮助玩家学习如何移动、破坏、放置方块等。
** 这些提示会为教师默认打开，学生则默认为关闭，这可以在设置菜单中进行调整。

'''游戏指南'''
* 在游戏指南菜单中加入了教育版内容。

'''Educator Resources'''
* 主菜单上的一个按钮（仅教师显示），教师可以访问官方网站上的新资源，旨在将这些资源与最新、最好的培训、课程与社区内容联系起来。

=== 更改 ===
'''编程'''
* [[代码构建器]]现在可以在游戏中使用，而不用通过单独的应用程序。如果在用鼠标/键盘时使用键盘上的{{key|C}}按键，或者在触屏模式时按下屏幕顶部中间、暂停/聊天旁边的智能体图标，玩家可以启动[[代码连接]]。
* [https://code.org Code.org]和[https://scratch.mit.edu Scratch]将不会出现在游戏中，TBD则将在它们不在时出现。代码连接应用程序仍可用于这些应用。
* 移除了{{cmd|code}}。
