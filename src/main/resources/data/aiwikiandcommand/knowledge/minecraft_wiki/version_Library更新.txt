'''Library更新（Library Release）'''是{{el|ee}}的一次次要更新，其正式版[[教育版1.12.5|1.12.5]]发布于2019年11月12日。<ref name=release>{{cite|url=https://web.archive.org/web/20191212034004/https://minecrafteducation.zendesk.com/hc/en-us/articles/360035255232-What-s-New-The-Library-Release-Version-1-12-5-|title=What's New: The Library Release (Version 1.12.5)|website=Minecraft: Education Edition Support}}</ref><ref>https://education.minecraft.net/en-us/blog/the-library-update-is-now-available-for-minecraft-education-edition</ref>

== 重要特性 ==
{{main|教育版1.12.5}}

'''Library'''
* 经用户的反馈，更新了Library菜单。可将课程内容引入游戏中，提供课程的计划及分类，以简化课程、世界、建筑挑战和教程。

'''演示课程'''
* 为没有Office 365教育版账号的使用者加入了演示模式。
* 拥有Office 365教育版账号的使用者可以在world library中存取演示课程中的世界。

== 跟进版本 ==
* [[教育版1.12.60|1.12.60]]发布以修复一些漏洞。
