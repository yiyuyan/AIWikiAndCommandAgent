'''莉娜·雷恩（Lena Raine'''（[[wikipedia:Help:IPA|/ˈleɪ.nə/]] [[wikipedia:Help:Respell|LAY-nah]] 或 [[wikipedia:Help:IPA|/ˈlɛ.nə/]] [[wikipedia:Help:Respell|LEN-ah]]）<ref>{{tweet|kuraine|1283492191231291392|lay-nuh or len-uh, either is fine I just don't like 'lee-nuh' cos that's "Lina" or "Leena" to me.|15 July 20}}</ref>'''）'''（或称'''Lena Chappelle'''、'''kuraine'''）是一名音乐制作人，她为Minecraft的[[下界更新]]创作了专辑''[[Minecraft: Nether Update (Original Game Soundtrack)]]''<ref>{{article|the-sound-scary|The Sound of Scary}}</ref>，并参与制作了专辑''[[Minecraft: Caves & Cliffs (Original Game Soundtrack)]]''、''[[Minecraft: The Wild Update (Original Game Soundtrack)]]''和''[[Minecraft: Tricky Trials (Original Game Soundtrack)]]''。<ref>{{cite|url=http://lena.fyi/|title=Lena Chapelle - Composer, Author|website=lena.fyi}}</ref>

== 生平 ==
莉娜·雷恩在年轻时参加了合唱团，并接触到了音乐。她的父亲是个小提琴家<ref>{{cite|url=http://www.originalsoundversion.com/interview-composer-lena-raine-talks-celeste-soundtrack-working-in-game-audio/|title=Lena Raine talks Celeste soundtrack and working in game audio}}</ref>。通过Sonic粉丝社区，她被介绍了MIDI编曲。在那里她开始再创作她已知的歌曲，到最后她开始创作原创音乐<ref>{{cite|url=https://super.magfest.org/mages-blog/interview-with-lena-raine|title=Interview with Lena Raine}}</ref> 。她后来就读于康沃尔艺术学院（Cornish College of the Arts），并获得了音乐创作学位。<ref>{{cite|url=http://www.originalsoundversion.com/interview-composer-lena-raine-talks-celeste-soundtrack-working-in-game-audio/|title=Lena Raine talks Celeste soundtrack and working in game audio}}</ref>雷恩以创作《[[wzh:蔚藍_(遊戲)|蔚蓝]]》（Celeste）和《[[wzh:激戰2|激战2]]》（Guild Wars 2）游戏的配乐而闻名。在2019年，她获得了英国电影电视艺术学院奖的提名，并获得了[[wzh:美國作曲家、作家和發行商協會|美国作曲家、作家和发行商协会]]（ASCAP）年度电子游戏奖项<ref>{{cite|url=http://www.bafta.org/games/awards/bafta-games-awards-nominations-winners-2019|title=BAFTA Game Awards winners 2019}}</ref><ref>{{cite|url=https://www.ascap.com/news-events/awards/2019/screen-awards|title=2019 ASCAP Screen Music Awards}}</ref>。她是跨性别人士<ref>[https://web.archive.org/web/20200703171934/https://pinkfae.org/2015/09/03/interview-a-conversation-with-lena-chappelle/ Interview: A Conversation with Lena Chappelle] - PinkFae Gaming: September 3, 2015</ref>。

在Minecraft的[[下界更新]]中，她创作的四首新曲目被包含在内<ref>Winslow, Jeremy (April 15, 2020). [https://www.gamespot.com/articles/minecraft-update-adds-new-blocks-and-more-for-java/1100-6476073/ "Minecraft Update Adds New Blocks And More For Older PC Version"]. ''[[wikipedia:GameSpot|Gamespot]]''. [https://web.archive.org/web/20211012163831/https://www.gamespot.com/articles/minecraft-update-adds-new-blocks-and-more-for-java/1100-6476073/ Archived] from the original on October 12, 2021. Retrieved April 15, 2020.</ref>。一年后，她又重新返回了Minecraft，并与另一位电子游戏作曲家[[谷冈久美]]（Kumi Tanioka）一起为[[洞穴与山崖]]更新创作了六首曲目<ref>Leston, Ryan (October 20, 2021). [https://www.nme.com/news/gaming-news/minecraft-just-added-some-new-music-3075321 " 'Minecraft' just added some new music"]. [[wikipedia:NME|NME]]. [https://web.archive.org/web/20211020201018/https://www.nme.com/news/gaming-news/minecraft-just-added-some-new-music-3075321 Archived] from the original on October 20, 2021.</ref>。2022年，她还为[[荒野更新]]创作了三首新曲目。2024年，她为[[棘巧试炼]]创作了五首新曲目。

== 参与制作的游戏原声集 ==

* ''[[Minecraft: Caves & Cliffs (Original Game Soundtrack)]]''（2021年10月20日）
* ''[[Minecraft: The Wild Update (Original Game Soundtrack)]]''（2022年4月20日）
* ''[[Minecraft: Tricky Trials (Original Game Soundtrack)]]''（2024年4月26日）
