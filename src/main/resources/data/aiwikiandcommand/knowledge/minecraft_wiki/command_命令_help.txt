获取可用命令列表或单个命令的帮助信息。

== 用法 ==
命令执行者无法使用的命令（因为权限等级不足或其他限制）不会被显示。

{{in|je}}对一些复杂命令可能只会显示基本的语法，可以通过添加更具体的参数来获取附加信息。

{{in|je}}重定向命令节点（如{{cmd|help xp|link=none}}）不会显示内容。

== 语法 ==
* '''Java版'''
: <code>help</code>
:: 列出所有可用命令。
: <code>help <command></code>
:: 显示指定命令的语法帮助。

* '''基岩版'''
: <code>help <command: CommandName></code>
: <code>? <command: CommandName></code>
:: 显示指定命令的语法帮助。
: <code>help [page: int]</code>
: <code>? [page: int]</code>
:: 列出所有可用命令。

== 参数 ==
{{argument|command|string|command: CommandName|basic_string}}
: {{arg desc|je=string|type=greedy|be=string}}必须为一个英文单词（不含空格）。
: 指定要提供帮助的命令名称。{{IN|java}}还可以进一步提供该命令更精确的参数来获取更精确的信息。

{{el|be|short=1}}：{{argument|be=1|page: int|int}}
: {{arg desc|be=int}}
: 指定要展示的命令列表的页码。小于1的数字会被视为1，大于总页数会被默认为展示最后一页。

== 示例 ==
* 显示命令列表（{{only|be|for=第一页}}）：<code>/help</code>
* 显示{{cmd|give}}命令的语法帮助：<code>/help give</code>
* 显示{{cmd|scoreboard}}命令中{{cd|add}}子命令的语法帮助：<code>/help scoreboard add</code>{{only|je}}
