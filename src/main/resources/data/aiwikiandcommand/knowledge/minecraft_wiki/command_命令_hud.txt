修改[[HUD]]的可见性。

== 语法 ==
:<code>hud <target: target> <visible: HudVisibility> [hud_element: HudElement]</code>

== 参数 ==
{{argument|target: target|CommandSelector<Player>|be=1}}
:指定将被修改HUD可见性的目标。
:{{arg desc|type=players|be=CommandSelector<Player>}}

{{argument|visible: HudVisibility|enum|be=1}}
:指定将对HUD可见性做出的修改。
:必须为<code>hide</code>（隐藏）或<code>reset</code>（重置）。

{{argument|hud_element: HudElement|enum|be=1}}
:指定将被修改的HUD元素。
:必须为以下之一：
:* <code>air_bubbles</code> － [[氧气值]]
:* <code>all</code> － 所有的HUD
:* <code>armor</code> － [[护甲值]]
:* <code>crosshair</code> － 屏幕上的十字准星
:* <code>health</code> － [[生命值]]
:* <code>horse_health</code> － 骑乘坐骑时坐骑的生命值
:* <code>hotbar</code> － [[快捷栏]]
:* <code>hunger</code> － [[饥饿值]]
:* <code>item_text</code> － 物品文本
:* <code>paperdoll</code> － [[HUD#纸娃娃|纸娃娃]]
:* <code>progress_bar</code> － [[经验条]]
:* <code>status_effects</code> － [[状态效果]]图标
:* <code>tooltips</code> － [[提示框]]
:* <code>touch_controls</code> － [[HUD#触屏按键|触控按键]]
:如果未指定，默认为<code>all</code>。

== 示例 ==
* 隐藏所有玩家的所有HUD：<code>/hud @a hide all</code>
* 使附近的[[生存模式]]玩家的生命值重新显示：<code>/hud @p[m=s] reset health</code>
