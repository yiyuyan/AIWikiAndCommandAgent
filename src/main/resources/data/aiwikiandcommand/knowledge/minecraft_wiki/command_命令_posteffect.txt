管理[[玩家]]使用的[[着色器#后处理管线|后处理效果]]。

== 语法 ==
: {{cmd|posteffect add <targets> <posteffect>|link=none|/=0}}
:: 添加后处理效果。
: {{cmd|posteffect clear <targets>|link=none|/=0}}
:: 清除所有后处理效果。
: {{cmd|posteffect list <target>|link=none|/=0}}
:: 列出所有后处理效果。
: {{cmd|posteffect remove <targets> <posteffect>|link=none|/=0}}
:: 移除后处理效果。

== 参数 ==
{{argument|targets|entity}}
: 指定单个或多个玩家。
: {{arg desc|je=entity|amount=multiple|type=player}}
{{argument|target|entity}}
: 指定单个玩家。
: {{arg desc|je=entity|amount=single|type=player}}
{{argument|posteffect|resource_location}}
: 指定后处理效果，游戏内已有{{cd|minecraft:blur}}（模糊）、{{cd|minecraft:creeper}}（苦力怕）、{{cd|minecraft:entity_outline}}（实体轮廓）、{{cd|minecraft:invert}}（颜色反转）和{{cd|minecraft:spider}}（蜘蛛）。
: {{arg desc|je=resource_location}}
