'''1.14.2-pre4'''是[[Java版1.14.2]]的第4个，也是最后一个预发布版，发布于2019年5月24日<ref>{{article|minecraft-1-14-2-pre-release-1|Minecraft 1.14.2 Pre-Release 4|May 24, 2019}}</ref>，修复了一个漏洞。

== 更改 ==
=== 游戏内容 ===
'''光照'''
* 现在第一次打开以前版本保存的世界时会重新计算光照。

=== 常规 ===
'''[[闪烁标语]]'''
* 移除了“Woo, minecraftforum!”。

== 修复 ==
{{fixes|fixedin=1.14.2 Pre-Release 4|prefix=Minecraft|showdesc=1
|;1.14的漏洞
|147715|实体在通过一个末地折跃门传送时会被卡在方块中。
}}

== 重新上传 ==
该版本于5月27日07:20（UTC）被重新上传，移除了[[闪烁标语]]“Woo, minecraftforum!”<ref>[https://www.diffchecker.com/Z6LB24NV Difference between the splashes.txt of both the original and reupload] via DiffChecker.com</ref>，因为此论坛宣布关闭。<ref>{{link|url=https://www.minecraftforum.net/news/60727-important-minecraft-forum-archive-announcement|title=Important Minecraft Forum Announcement|website=[[Minecraft Forums]]|date=May 21, 2019}}</ref></onlyinclude>
