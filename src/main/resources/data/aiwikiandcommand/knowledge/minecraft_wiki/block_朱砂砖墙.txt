'''朱砂砖墙（Cinnabar Brick Wall）'''是[[朱砂砖]]制作的[[墙]]。

== 生成 ==
朱砂砖墙不会生成在世界中。

== 获取 ==

== 破坏 ==
挖掘朱砂砖墙的合适工具是镐。朱砂砖墙需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

朱砂砖墙被破坏后会掉落自身。

== 用途 ==
{{main|墙#用途}}
朱砂砖墙可用于装饰，并有与其他墙相似的特性。
