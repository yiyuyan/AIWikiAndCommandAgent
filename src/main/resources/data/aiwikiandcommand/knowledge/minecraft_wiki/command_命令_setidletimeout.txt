设置玩家空闲不动被踢出的时间。玩家无操作世界持续<code><minute></code>分钟即被踢出服务器。

== 语法 ==
:<code>setidletimeout <minutes></code>

== 参数 ==
{{argument|minutes|integer}}
: 指定被踢出的分钟数。若为0，则禁用自动踢出无操作的玩家。
: {{arg desc|je=integer|min=0}}

{{Output table}}
{{Output table|edition=je|执行成功|N/A|1|指定的{{cd|<minutes>}}的值}}
{{Output table}}

== 示例 ==
* 设定玩家允许的最大空闲时间为20分钟，超出则踢出游戏：<code>setidletimeout 20</code>
* 禁用自动踢出无操作的玩家：<code>setidletimeout 0</code>
