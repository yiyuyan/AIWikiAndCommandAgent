将单人游戏世界开放到多人游戏。

== 语法 ==
:<code>publish [<allowCommands>] [<gamemode>] [<port>]</code>

== 参数 ==
{{argument|allowCommands|bool}}
: 是否允许[[作弊]]。若未指定，默认为<code>false</code>。
: {{arg_desc|je=bool}}

{{argument|gamemode|gamemode}}
: 新玩家进入世界后的默认[[游戏模式]]。若未指定，新玩家进入世界后的游戏模式为此单人世界的游戏模式。
: {{arg_desc|je=gamemode}}

{{argument|port|integer}}
: 主机所在的[[wzh:端口|端口]]。若未指定，则自动分配端口，一般会自动分配在临时端口范围。
: {{arg desc|je=integer|min=0|max=65535}}

== 示例 ==
* 对局域网开放，禁用作弊：<code>publish false</code>
* 对局域网开放，启用作弊，其他玩家以旁观模式加入游戏，指定端口为65531：<code>publish true spectator 65531</code>
