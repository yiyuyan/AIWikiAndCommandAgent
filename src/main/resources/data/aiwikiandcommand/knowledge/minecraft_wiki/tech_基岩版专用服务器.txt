'''基岩版专用服务器（Bedrock Dedicated Server, BDS）'''是一款供免费下载的服务器软件，其允许玩家在[[wzh:Windows|Windows]]或[[wzh:Linux|Linux]]系统上搭建自己的专用服务端。目前，BDS提供了正式版与测试版两种软件版本。

== 描述 ==
基岩版专用服务器是一个类似于Java版[[服务器]]的服务器托管工具，附带{{filename|bedrock_server_how_to.html}}文件作为使用说明。和Java版一样，它有一个{{filename|[[server.properties]]}}和{{filename|allowlist.json}}文件。不过服务器的权限清单存储在{{filename|permissions.json}}文件中，而不是{{filename|[[ops.json]]}}。[[资源包]]和[[行为包]]分别存储于根目录或世界的文件夹中的{{filename|resource_packs}}和{{filename|behavior_packs}}文件夹，世界的文件夹中与之对应的JSON文件可配置要使用的附加包。新生成的世界能在服务端文件夹中的{{filename|worlds}}文件夹找到。第一次启动时，如果{{filename|worlds}}文件夹中没有{{filename|server.properties}}配置中的世界，将会由基岩版专用服务器按{{filename|server.properties}}配置中的<code>level-seed</code>为种子生成一个名为{{filename|server.properties}}配置中的<code>level-name</code>的世界。基岩版专用服务器与基岩版的世界格式互相兼容，但不会使用部分单机玩家数据。基岩版专用服务器与[[Realms]]使用的服务器软件相同。<ref name=":0">{{tweet|_b4njo|1039495573089542145|We just released the dedicated server for Bedrock on minecraft.net. This is the server we run on Realms. Go download it now!|2018-09-11T12:47:12.000Z}}</ref>

=== 教育版 ===
特别地，教育版BDS默认禁用，启用条件如下：<ref>{{cite|url=https://edusupport.minecraft.net/hc/en-us/articles/46370720373908|title=The Dedicated Server Admin Portal is here!|website=Minecraft Education Support|date=2026-02-17T22:08:45Z}}</ref>
* 在Microsoft Entra租户中拥有全局管理员角色。
* 访问[https://aka.ms/dedicatedservers https://aka.ms/dedicatedservers]并登录，然后开启“Allow Servers”设置项。
** 若希望服务器允许跨租户进入或被教师与合作伙伴管理，可以参考该页面的其他设置项。

运行教育版BDS后，会自动生成登录会话文件，并提供用于进入服务器的ID（共12位，由字母和数字组成，不区分大小写），在客户端中输入此ID即可添加服务器。

== 系统需求 ==
根据[https://www.minecraft.net/download/server/bedrock 官方BDS下载页面]底部及[https://edusupport.minecraft.net/hc/articles/46913335157140 教育版服务器系统要求页面]：

; 操作系统
: '''Windows'''：Windows 10版本1703（build 15063.0）或更高、Windows 11、Windows Server 2016或更高。
: '''Linux'''：官方仅支持Ubuntu 18.04（建议Ubuntu 22.04）或更高，但该程序可在任何安装了正确库文件的x86及x64架构Linux发行版上运行（含glibc 2.35或更高）。

; 处理器
: 最低配置要求为双核处理器，建议使用64位四核处理器。运行频率至少3 GHz或更高，推荐Intel i5 Ivy Bridge、AMD FX-4100或更高型号。最低配置要求为Intel Core i3 3210、AMD A8 7600 APU及同等性能产品。

; 内存
: 最低要求1 GB，建议配备4 GB。若同时在线玩家超过10人，可能需要更多内存。BDS不像[[server.jar|Java版服务器软件]]那样会消耗大量内存，但无法指定内存的最小值和最大值。

; 传输网速
: 每10名玩家需要5 Mbps上传速度和10 Mbps下载速度。DSL连接通常无法提供足够带宽来运行互联网服务器。在局域网内托管服务器无需互联网连接。

; 网络
: 以太网连接通常比Wi-Fi连接更快、更稳定。100 Mbps以太网即可满足需求，无需千兆LAN。
: 用于托管服务器的计算机在网络中应分配一个静态IP地址，而不是使用DHCP。
: 若要允许客户端通过互联网连接到服务器，需要转发服务器使用的端口。

; 存储空间
: 最少需要180 MB可用存储空间，建议配备1 GB空间。

== 连接 ==
{{see also|基岩版#平台差异}}
与使用TCP协议的Java版不同，基岩版使用UDP协议。其IPv4的默认端口为19132，IPv6的默认端口为19133。这些可以在{{filename|server.properties}}的<code>server-port</code>与<code>server-portv6</code>配置项中更改。使用Xbox、PlayStation和Nintendo Switch设备的基岩版玩家只能通过自定义DNS或LAN连接加入服务器。

== 允许名单 ==
'''允许名单'''亦称'''白名单'''。目前默认启用允许名单，禁用/启用允许名单需要修改{{filename|[[server.properties]]}}文件的<code>allow-list</code>配置项的布尔值。启用后，服务器将只允许{{filename|allowlist.json}}文件列出的玩家加入游戏，且你需要知道所有想加入服务器的玩家的Xbox Live玩家代号或XUID并添加进{{filename|allowlist.json}}文件。无法在不开启允许名单且未安装拒绝名单插件的服务器里封禁玩家。

如果你在自己的服务器上遇到了恶意玩家，开启允许名单可能是解决问题的好方法。

* [https://github.com/LiteLDev/LeviLamina LeviLamina]是一个非官方的模组加载器，旨在为基岩版提供必不可少的API支持。它拥有全面的API，一系列的实用接口，一个强大的事件系统，以及对基本接口的全面支持。它提供了一个广泛的API，一个强大的事件系统，以及丰富的封装开发基础设施接口，为增强基岩版的附加游戏特征和功能提供了坚实的基础。利用模组，扩展游戏功能的过程变得轻而易举，具有用户友好的开发过程和灵活的方法。开发者可以轻松地用C++编写模组。这种无缝集成赋予了轻松扩展和个性化游戏功能的能力，促进了直观的学习体验和无与伦比的灵活性。同时支持Windows版客户端和服务端。
* [https://github.com/LiteLDev/LegacyScriptEngine LegacyScriptEngine]是一个用于在[https://github.com/LiteLDev/LeviLamina LeviLamina]上运行LLSE插件的插件引擎。
* [https://github.com/LiteLDev/LeviStone LeviStone]是一个用于在[https://github.com/LiteLDev/LeviLamina LeviLamina]上运行[https://github.com/EndstoneMC/endstone Endstone]插件的运行时。
* [https://github.com/EndstoneMC/endstone Endstone]是一个现代化的插件加载器，为基岩版专用服务器提供高级插件API，支持Python和C++。它允许开发人员扩展基岩版专用服务器，而无需处理低级钩子的麻烦。Endstone用户将受益于所有原版特性和对Windows和Linux的原生支持。
* [https://github.com/bdsx/bdsx BDSX]基于官方BDS软件修改，支持Node.js。包含原版的所有功能，同时具备其他辅助功能，例如可以通过钩子函数和数据包改变行为。

== 缺陷 ==
此服务器软件仍然存在很多缺陷以及缺少Java版服务端中许多的自带功能。<ref>{{cite|url=https://feedback.minecraft.net/hc/en-us/community/posts/360059965732|title=Expand Bedrock Dedicated Server (BDS) Configuration/Customization Options|website=Minecraft Feedback|date=2020-03-25}}</ref>

* {{cmd|reload}}命令并不能像Java版服务端那样重载服务器，导致每次重新调整服务端设置或添加/移除附加包都需要重启服务器。
* 缺少类似于[[Realms]]的，允许主机用户连接服务器的邀请系统。
* 不能直接运行在非amd64架构的处理器上。
* 默认无法使用类似于{{cmd|wsserver}}的websocket服务器。
* 缺少远程控制台。
* 经常会出现各种漏洞，且官方修复恶性漏洞的积极性非常低。
* 基岩版专用服务器在某些多核多线程低频率的服务器CPU上的性能表现不佳，反而单核性能更强的高主频消费级CPU更适合基岩版专用服务器。
* 在高负载的情况下（例如大量生物实体堆积/加载复杂区块），有时会出现服务器突然卡顿但是CPU占用率很低的情况。
* 在1.19.80及以下版本中存在一个高危漏洞，其允许恶意用户以其他人的身份登录并使用操作员权限。因此强烈建议不要在生产环境中使用任何旧版本。
* 不支持为域名配置SRV记录。
* 不支持设置[[MOTD]]。尽管默认[[服务器列表]]中的服务器均有使用。
* 对社区[[模组]]和插件的支持较差，与社区更庞大的Java版拥有的Spigot和Paper等成熟框架不同。但可以使用[https://geysermc.org/ Geyser]实现跨版本兼容，使基岩版玩家得以加入Java版服务器。
