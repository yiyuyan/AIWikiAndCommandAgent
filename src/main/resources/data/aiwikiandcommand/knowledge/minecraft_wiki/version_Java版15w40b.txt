'''15w40b'''是[[Java版1.9]]的第30个快照，发布于2015年9月30日<ref>{{cite|url=http://mojang.com/2015/09/minecraft-snapshot-15w40a/|archive-url=1|archive=1|title=Minecraft 1.9 snapshot 15w40b|author=Dinnerbone|website=Mojang.com|date=Sep 30, 2015}}</ref>，以修复[[服务器]]连接失败的漏洞。

== 修复 ==
{{fixes|fixedin=15w40b|prefix=Minecraft|showdesc=1
|;old
|16487|玩家放置的落沙与生成的落沙有差异。
|48023|玩家死后，不能与有自定义名称的村民交易。
|53912|堆叠起来的TNT矿车不能正确爆炸。
|56648|在命令方块中执行{{cmd|execute|link=none}}命令的含<code>replace</code>参数的<code>fill</code>子命令失败。
