'''末地折跃门（End Gateway）'''是出现在[[末地折跃门|末地折跃门结构]]的一种方块，用来把玩家传送到[[末地]]的另一个空岛上。

== 生成 ==
{{main|末地折跃门#生成}}

=== 末地折跃门 ===
末地折跃门方块会作为[[末地折跃门]]结构的一部分生成。

== 获取 ==
{{in|java}}末地折跃门方块没有对应的物品形式。

{{in|bedrock}}末地折跃门方块的物品形式只能通过编辑物品栏获得。

== 破坏 ==
末地折跃门不能被挖掘破坏。

{{Breaking table|末地折跃门}}

末地折跃门被破坏后不会掉落。

== 用途 ==
[[File:Endgatewaycommand.jpg|thumb|{{only|je|for=通过命令放置的末地折跃门}}]]
末地折跃门可以将进入其中的实体或对其投掷了[[末影珍珠]]的实体传送到预设的目的地。末地折跃门的目的地由其方块实体数据值定义，自然生成的末地折跃门的目的地取决于其生成方式：
* 主岛末地折跃门会将实体传送至对应的外岛末地折跃门。
* 外岛末地折跃门会将实体传送至对应的主岛末地折跃门。
* 回归折跃门会将实体传送至黑曜石平台。

如果在末地以外的维度不指定方块数据<code>exit_portal</code>{{only|je}}或<code>ExitPortal</code>{{only|be}}，它不会传送实体{{only|je|for=，但仍然会在实体进入时激活其光柱效果}}。

{{in|be}}若熔岩流过末地折跃门，末地折跃门会被破坏。

{{in|be}}末地折跃门会阻挡实体通过其自身；{{in|je}}末地折跃门对实体没有阻挡作用。

{{in|je}}放置在末地中且没有设置目的地的末地折跃门会尝试将玩家传送至外岛最靠近主岛的位置上，并在必要时生成[[末地浮岛]]。具体来说，当末地传送门方块开始传送实体时，若其处在末地中且方块数据<code>exit_portal</code>不存在，则会遵循以下流程确定传送的目的地<math>P</math>并生成指向自身的[[末地折跃门|末地折跃门结构]]：

# 按照以下方法确定目标位置<math>P_0</math>。注意：在此步骤的计算中，忽视高度，只使用x与z两个坐标进行平面计算：
## 选择坐标原点（x=0, z=0）到末地折跃门所在位置的方向，距离坐标原点1024格远位置，作为起始位置；
## 从起始位置开始，检查当前位置所在区块是否为空区块（即没有任何方块的区块）。如果是，以当前位置进入下一步；否则，将当前位置向接近坐标原点方向移动16格，并再次执行该检查，直到找到一个空区块，或当前位置距离起始位置达256格，以当前位置进入下一步；
## 将上一步的位置作为起始位置，从起始位置开始，检查当前位置所在的区块是否非空。如果是，以当前位置进入下一步；否则，将当前位置向远离坐标原点方向移动16格，并再次执行该检查，直到找到一个非空区块，或当前位置距离起始位置达256格，以当前位置进入下一步；
## 当前位置即为目标位置<math>P_0</math>。
# 在目标位置<math>P_0</math>所在的区块中，找到同时满足以下条件的，且离坐标原点（x=0, y=0, z=0）最近的一个位置<math>P_1</math>：
## 位置的高度不低于30，或者位置的高度是整个区块中方块高度的最大值；
## 位置上的方块是[[末地石]]；
## 位置上方1～2格的方块不是完整方块。
# 如果<math>P_1</math>不存在，则令位置<math>P_2</math>为水平坐标（x与z）与<math display="inline">P_0</math>相同，且高度（y）为75的位置，并在该位置生成[[末地浮岛]]；否则令<math>P_2</math>等于<math>P_1</math>；
# 找到位置在水平方向上与<math>P_2</math>的[[切比雪夫距离]]不超过16，且高度最高的完整方块。将该方块的位置作为传送目的地<math>P</math>；
## 如果这样的完整方块无法找到（例如末地浮岛被禁用导致无法生成），则将<math>P_2</math>作为传送目的地<math>P</math>；
# 在<math>P</math>上方10格的位置生成指向自身的[[末地折跃门|末地折跃门结构]]；
# 如果实体数据<code>ExactTeleport</code>为{{Code|true}}，则按照[[末地折跃门#行为|自然生成的末地折跃门的传送逻辑]]，修正传送目的地<math>P</math>。

=== 光柱 ===
当通过自然生成{{only|je|for=或通过{{cmd|setblock}}生成时}}，末地折跃门分别同时向其上方终点为上方253格和下方终点为下方254格竖直发射出两束{{color|#C354CD|品红色}}的光柱，持续{{convert|200|刻|秒}}。

当有一个实体进入折跃门方块时，它会发出两束{{color|#7B2FBE|紫色}}光柱，在{{convert|40|刻|秒}}内可见，此时不能传送第二个实体。

{{only|je|for=在没有实体传送的情况下，折跃门方块每隔{{convert|2400|刻|分钟}}会发出两束{{color|#7B2FBE|紫色}}光柱。<ref>{{bug|MC-107824|||WAI}}</ref>}}

如果末地折跃门在发射光柱的过程中被破坏，则光柱会停止延伸并立即消失。

光柱前进速度约2.854格/刻，上方光柱的起点是末地折跃门所在位置，下方光柱的起点是末地折跃门所在位置的下方1格，被发射时先向远离末地折跃门的方向前进，纹理向下作加速运动，达到终点并等待一段时间（{{only|je|for=仅{{color|#C354CD|品红色}}光柱}}或{{only|be|for=均适用}}）后向末地折跃门方向前进，纹理向上作加速运动。

对于{{color|#7B2FBE|紫色}}光柱：{{in|java}}该光柱分为自末地折跃门方块之下49格位置至末地折跃门方块之下1格位置和自末地折跃门方块至末地折跃门方块之上48格位置；{{in|be}}该光柱长度同{{color|#C354CD|品红色}}光柱。在与看见一个垂直堆叠方块的大致相同的距离可以看见光柱。如果渲染距离设置为16区块，那么光柱至多可以在255方块以外的距离看到。与[[信标]]的光柱不同，在光柱上面放置染色玻璃并不会改变光柱的颜色，光柱不会被[[遮挡形状|完全固体渲染方块]]阻挡。

=== 光源 ===
末地折跃门会发出[[亮度]]等级为15的光。

== 你知道吗 ==
* {{in|je}}若玩家的视线与指令放置的末地折跃门处在同一格，则末地折跃门本身将不可见，但玩家仍能看见其发出的光束。
* {{in|be}}末地中由玩家放置的末地折跃门会将玩家传送至坐标（0,0,0）。
* {{in|be}}玩家可以站在主世界和下界中的末地折跃门上，且不会被传送到任何地方。
* {{in|be}}虽然末地折跃门具有碰撞箱，但手持末地折跃门物品的玩家可以将末地折跃门放置在与实体碰撞箱相交的位置，并且在非末地维度还会挤开实体。
