'''创建新的世界（Create New World）'''界面是一个允许玩家预先设置[[世界]]选项的[[菜单屏幕]]。

== Java版 ==
{{filetr|NewWorld.png|thumb|创建世界屏幕中的“游戏”选项卡}}
“创建新的世界”屏幕的主页允许玩家在创建世界之前选择一个世界名称并更改各种选项。界面包含3个标签页，选项多为可单击循环切换的按钮。

=== 游戏 ===
; {{tp|selectWorld.enterName}}（编辑框）
: 允许将世界名称设置为自定义字符串。该名称与{{filepath|[[.minecraft]]/saves}}中的文件夹名称相关，在该文件夹中可以找到世界存档。默认名称为“{{tr|新的世界|新的世界|新嘅世界}}”。

; {{tp|selectWorld.gameMode}}
: 允许更改世界的默认的[[游戏模式]]。可选[[生存]]（默认）、[[极限]]和[[创造]]。

; {{tp|options.difficulty}}
: 允许更改默认的[[难度]]设置。可选和平、简单、普通（默认）和困难。

; {{tp|selectWorld.allowCommands.new}}
: 决定是否可以使用[[命令]]和[[游戏模式切换器]]。选择创造模式后默认为打开，其他模式下默认为关闭。

; {{tp|selectWorld.experiments}}
: 打开一个界面以供玩家选择需要启用的[[实验性内容]]。
: 此处的按钮仅快照版本显示。

=== 世界 ===
; {{tp|selectWorld.mapType}}
: 控制[[世界预设|世界类型]]。可选默认、[[超平坦]]、[[巨型生物群系]]、[[放大化]]、[[单一生物群系]]；当按住{{key|Alt}}时，亦可以选择[[调试模式]]。选择超平坦或单一生物群系时，可点击“自定义”按钮，并修改该世界类型的设置。对于超平坦的世界类型，自定义按钮选项会显示“自定义超平坦世界”界面；若使用单一生物群系，单击按钮可进入选择生物群系的界面。

; {{tp|selectWorld.enterSeed}}（编辑框）
: 允许更改创建[[世界]]时使用的[[种子（世界生成）|{{tr|种子|種子碼}}]]。任何字符串都可以放在这里，若留空将随机生成。

; {{tp|selectWorld.mapFeatures}}
: 控制[[结构]]（例如[[村庄]]和[[沉船]]等）是否应该在世界中生成，默认为打开。

; {{tp|selectWorld.bonusItems}}
: 决定玩家第一次进入世界时是否应该在玩家附近生成一个装满新手战利品的[[奖励箱]]，默认为关闭。

=== 更多 ===
; {{tp|selectWorld.gameRules}}
: 打开一个界面以供玩家设置将默认启用或禁用的[[游戏规则]]，即使允许命令被禁用。

;{{tp|selectWorld.experiments}}
: 打开一个界面以供玩家选择需要启用的[[实验性内容]]。

; {{tp|selectWorld.dataPacks}}
: 打开一个界面以供玩家选择需要启用的[[数据包]]。

== 基岩版 ==
{{UsesInGameTranslations|bedrock|section=1}}

{{filetr|Create new world.png|thumb|“创建新世界”界面的“{{tr|通用|一般}}”选项卡}}

“创建新世界”界面允许玩家更改各种设置并启用[[附加包|资源包]]和[[行为包]]。

开启作弊或[[实验性玩法]]、使用任何不来自[[市场]]的[[附加包]]、选择创造模式或创建为[[超平坦世界]]会导致该世界无法获取[[成就]]。
