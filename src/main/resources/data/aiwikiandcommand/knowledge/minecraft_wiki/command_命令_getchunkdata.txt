获取指定区块的像素。

== 语法 ==
: <code>-{}-getchunkdata <dimension: Dimension> <chunkX：int> <chunkZ：int> <height: int></code>

== 参数 ==
{{argument|be=1|dimension: Dimension|enum}}
: 指定维度。
: {{arg desc|je=dimension}}{{cd|minecraft}}命名空间下的维度默认有{{cd|d=pretty|overworld|nether|the_end}}。

{{argument|be=1|chunkX: int|int}}
: 指定区块的X轴坐标。
: {{arg desc|be=int}}

{{argument|be=1|chunkZ: int|int}}
: 指定区块的Z轴坐标。
: {{arg desc|be=int}}

{{argument|be=1|height: int|int}}
: 指定区块的高度。
: {{arg desc|be=int}}

== 示例 ==
* 获取主世界(0,-60,0)处的区块像素：<code>/getchunkdata overworld 0 0 -60</code>
