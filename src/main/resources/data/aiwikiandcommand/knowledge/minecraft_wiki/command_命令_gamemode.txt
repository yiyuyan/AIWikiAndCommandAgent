设置玩家的[[游戏模式]]。

== 语法 ==
* '''Java版'''
: <code>gamemode <gamemode> [<target>]</code>

* '''基岩版'''
: <code>gamemode <gameMode: GameMode> [player: target]</code>
: <code>gamemode <gameMode: int> [player: target]</code>

== 参数 ==
{{el|je|short=1}}：{{argument|gamemode|gamemode}}<br>
{{el|be|short=1}}：{{argument|be=1|gameMode: GameMode|enum}}和{{argument|be=1|gameMode: int|int}}
: 指定玩家的新游戏模式，必须为以下其中之一：
:* <code>survival</code>（{{IN|be}}可简写为{{cd|s}}或{{cd|0}}）代表[[生存模式]]
:* <code>creative</code>（{{IN|be}}可简写为{{cd|c}}或{{cd|1}}）代表[[创造模式]]
:* <code>adventure</code>（{{IN|be}}可简写为{{cd|a}}或{{cd|2}}）代表[[冒险模式]]
:* <code>default</code>（可简写为{{cd|d}}或{{cd|5}}）代表世界默认模式{{only|be}}
:* <code>spectator</code>代表[[旁观模式]]
: [[极限模式]]不是一个有效选项，因为它作用于世界，而不是玩家。

{{argument|target|entity|player: target|CommandSelector<Actor>}}
: 指定要被修改游戏模式的玩家。如果未指定，默认为命令执行者。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

== 示例 ==
* 使执行者进入创造模式：
*: <code>gamemode creative</code>
*: <code>gamemode c</code>{{only|bedrock}}
*: <code>gamemode 1</code>{{only|bedrock}}

* 使所有玩家进入生存模式：
*: <code>gamemode survival @a</code>
*: <code>gamemode s @a</code>{{only|bedrock}}
*: <code>gamemode 0 @a</code>{{only|bedrock}}
