使[[智能体]]在指定的方向上攻击。

== 语法 ==
: <code>-{}-attack <''方向：字符串''></code>

== 参数 ==
<code>-{}-''方向：字符串''</code>
: 指定智能体攻击的方向。
: 字符串必须为以下之一：
:* <code>forward</code>——向前攻击。
:* <code>back</code>——向后攻击。
:* <code>left</code>——向左攻击。
:* <code>right</code>——向右攻击。
:* <code>up</code>——向上攻击。
:* <code>down</code>——向下攻击。

== 结果 ==
永远执行成功。
