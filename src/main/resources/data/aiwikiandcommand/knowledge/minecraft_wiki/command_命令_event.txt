触发实体事件。

== 语法 ==
: <code>event entity <target: target> <eventName: string></code>

== 参数 ==
{{cd|<target: target>}}
: 必须为玩家名称或[[目标选择器]]。
: 指定实体事件的作用对象。

{{cd|<eventName: string>}}
: 必须为单词（其间不能夹杂空格）或用引号标记的字符串。
: 指定命令触发的实体事件。应使用[[生成事件]]。

== 示例 ==
* 所有[[炽足兽]]重新自然生成：<code>/event entity @e[type=strider] minecraft:entity_spawned</code>

* 所有的[[村民]]变成[[僵尸村民]]：<code>/event entity @e[type=villager] become_zombie</code>
