'''朱砂台阶（Cinnabar Slab）'''是[[朱砂]]制作的[[台阶]]。

== 生成 ==
朱砂台阶不会生成在世界中。

== 获取 ==
=== 合成 ===

|C3= Cinnabar

|type= Building block
}}

}}

== 破坏 ==
挖掘朱砂台阶的合适工具是镐。朱砂台阶需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

朱砂台阶被破坏后会掉落自身。
