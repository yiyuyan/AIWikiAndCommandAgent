这篇指南简要概述了[[红石更新]]（Java版1.5.x）更新的内容。本指南假定读者对[[骇人更新]]（Java版1.4.x）的内容有基本了解。

== 生物 ==
=== 更改 ===
{| class = "wikitable"
! 名称 !! 外观 !! 更改
|-
|所有生物
|
|
* 如果不是在追赶玩家，所有生物不再会自行跨越铁轨。
|-
|[[骷髅]]
|[[File:Skeleton JE4 BE2.png|128px]]
|
* 现在射程为15格（以前为10格）。
* 目标越接近，攻击速度越快，取决于难度。
|-
|[[史莱姆]]
|[[File:Slime JE2 BE1.png|128px]]
|
* 现在史莱姆在沼泽生物群系的生成率与月相有关。
|-
|[[僵尸]]
|[[File:Zombie JE1 BE1.png|128px]]
|
* 会共同攻击目标。
* 着火时也会波及接触的玩家。
* 增加攻击伤害。
* 提升察觉玩家的范围。
|}

=== 更改 ===
{| class = "wikitable"
! 名称 !! 外观 !! 更改
|-
|[[信标]] 
|[[File:Beacon JE4.png|84px]]
|
* 更改了作用范围。
|-
|[[酿造台]]、[[箱子]]、[[探测铁轨]]和[[唱片机]] 
|{{Animate|Brewing Stand JE1 BE1.png;Chest JE2 BE3.png;Detector Rail (NS) JE1 BE1.png;Jukebox JE1 BE1.png|84px}}
|
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号强度取决于它的装载量。
|-
|[[发射器]] 
|[[File:Dispenser (S) JE2 BE1.png|84px]]
|
* 可以为1格内的玩家装备[[盔甲]]。
* 可以放置并同时激活TNT。
* 可以使用骨粉催熟前方的作物或树苗。
* 可以使用打火石在前方点火，但会消耗耐久。
* 能够朝向6个方向。朝上或朝下时纹理不同。
* 更新时不再发射，而是当它们的输入被激活时触发。
* 当一个红石比较器被直接放在它的对面时，会发出信号——信号强度取决于它的装载量。
|-
|[[熔岩]] 
|[[File:Lava JE19.gif|84px]]
|
* 在下界流动更快。
* 更新了纹理。
|-
|[[下界砖块]] 
|[[File:Nether Bricks JE1 BE1.png|84px]]
|
* 现在可以用4个下界砖合成而得。
|}
