修改命令执行者玩家在一个[[记分板#准则|准则]]为“触发器”的[[记分板#记分项|记分项]]上的分数。此命令使得非管理员玩家能够通过记分板激活管理员或地图制作者设计的系统，一般配合[[文本组件]]使用。

== 语法 ==
<code>trigger <objective></code>
: 将执行者的分数增加1。
<code>trigger <objective> add <value></code>
: 将执行者的分数增加指定的<code><value></code>数值。
<code>trigger <objective> set <value></code>
: 将执行者的分数设置为指定的<code><value></code>数值。

== 参数 ==
{{argument|objective|objective}}
: 指定一个已启用的、准则为“触发器”的记分项。
: {{arg desc|je=objective}}

{{argument|value|integer}}
: 指定要设为或要增加的数值。
: {{arg desc|je=integer}}

== 示例 ==
* 高频执行，设定触发型记分项{{cd|trigger_test}}并为所有玩家开启触发权限。
: <syntaxhighlight lang=mcfunction>
scoreboard objectives add trigger_test trigger
scoreboard players enable @a trigger_test
execute as @a[scores={trigger_test=1..}] run tellraw @s "(>_<)"
execute as @a[scores={trigger_test=1..}] run scoreboard players set @s trigger_test 0
</syntaxhighlight>
* 为最近的一位玩家输出一个可以点击的“按钮”（使用文本组件点击事件实现），点击后将触发型记分项{{cd|trigger_test}}的分数设定为1，玩家将在聊天栏看到信息{{chat text|(>_<)|inline=1}}。
: <syntaxhighlight lang=mcfunction>
tellraw @p {text:"按钮", click_event:{action:"run_command",command:"execute as @s run trigger trigger_test set 1"}}
</syntaxhighlight>
