'''铜水槽（Copper Sink）'''是一种可以摧毁铜制物品的方块，外观类似于[[炼药锅]]。

== 生成 ==
铜水槽不会生成在世界中。

== 获取 ==

== 破坏 ==
没有工具可以加速对铜水槽的挖掘。

{{Breaking table/manual|only=je|nocopper=1|
{{BlockSprite|Copper Sink}}铜水槽|2|null required
}}

当{{cd|copper_sink}}规则启用时，铜水槽被破坏后会掉落自身。

== 用途 ==
{{In rule|copper_sink|section=1}}

=== 物质储存 ===
{{see also|炼药锅#用途}}
铜水槽的用途与炼药锅基本相同。不同的是，铜水槽只能盛装一整格水，玻璃瓶不能与铜水槽交互，滴水石锥也不能填充铜水槽。

=== 销毁物品 ===
未装水时，铜水槽能销毁落入其中的铜质方块和物品（[[铜枝叶]]和[[避雷针]]除外）。{{fn|由标签{{code|#copper}}控制}}

== 你知道吗 ==
* 铜水槽的名称是“sink”一词的双关：既指水槽，又喻指需要投入大量资源的游戏内容（游戏开发术语）。
** 社区曾建议为铜加入“sink”，以免玩家的铜囤积过多而用途过少。
