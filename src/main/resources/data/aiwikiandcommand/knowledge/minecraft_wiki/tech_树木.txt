== 描述 ==
{{for|详细的结构图示和方块构成|树木/结构}}
<div style="text-align:center">[[File:Arrangement of all tree types.png|500px]]<br>Minecraft中的一些树木</div>
树木的高度各不相同，最矮仅有1格高（倒下的树木），最高能达到32格（大型丛林树）。

树木的顶部由[[树叶]]组成，树冠最低可以碰到地面。树冠上的树叶大致是聚集在一个直径为5-7格，以树干部分为中心的球形中。树叶的旁边必须有树干或者其他树叶相邻着，否则它将会枯萎并消失。原木和树叶被破坏后不会重新生长回来。

深色橡树、苍白橡树、金合欢树、大型珍异橡树、大型丛林树和红树会长出树枝分杈（以斜向、横向或纵向连接树干或其他树枝的原木）。

自然生成或特定条件下由树苗长成的[[橡树]]、[[白桦]]、[[红树]]或[[樱花树]]有概率携带[[蜂窩]]。

== 生成 ==
{{main|树苗#生长}}
{{See also|Tutorial:树木种植}}

树木在[[区块]]生成时一并产生。树木也可由对应的[[树苗]]、[[杜鹃花丛]]、[[盛开的杜鹃花丛]]或[[红树胎生苗]]长成。

== 你知道吗 ==
* 露天[[湖泊]]的上方有很小的概率生成悬空树。这是因为在区块生成时，树木的生成顺序先于湖，当湖泊出现在已生成树木的区域时，树木就悬空了。
* 靠近露天[[熔岩湖]]的树木有可能会被火点燃烧毁，甚至引发一场林火。
* Minecraft中的橡树基于现实中的[[wzh:北美白橡|白橡]]，云杉基于[[wzh:白云杉|白云杉]]，深色橡树基于[[wzh:北美黑橡|黑橡]]，金合欢树基于[[wikipedia:Vachellia tortilis|伞刺金合欢]]，丛林树很可能基于[[wikipedia:Aniba rosaeodora|玫瑰木]]。
