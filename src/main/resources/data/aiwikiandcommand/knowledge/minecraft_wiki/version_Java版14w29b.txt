'''14w29b'''是[[Java版1.8]]的第37个快照，发布于2014年7月16日<ref>{{cite|url=http://mojang.com/2014/07/minecraft-snapshot-14w29a/|archive-url=1|archive=1|title=Minecraft snapshot 14w29b|author=Searge|website=Mojang.com|date=Jul 16, 2014}}</ref>，修复了快照[[14w29a]]中的一些漏洞和崩溃，但是该快照主要更新了多线程区块加载。

== 更改 ==
=== 常规 ===
'''优化'''
* 优化了多线程区块加载。
