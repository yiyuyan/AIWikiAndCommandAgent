== 服务器安装与配置 ==
要获取建立Minecraft服务器的完整指导，请阅读[[Tutorial:架设Java版服务器|安装与配置向导]]。

== 服务器需求 ==
* 配置需求视服务器软件而改变，例如使用Bukkit以及/或[[Mod]]。
* Java运行时环境（JRE）为8或更高版本。JDK包含了JRE，因此也可以使用JDK。从[[Java版1.17|1.17]]开始，需要Java 16。从[[Java版1.18|1.18]]，需要Java 17。从[[Java版1.20.5|1.20.5]]，需要Java 21。从[[Java版26.1|26.1]]，需要 Java 25。
* 至少1GB的服务器内存。服务器的内存越大越好。推荐计算机拥有至少3GB的物理内存。这样会将大量的内存预留给操作系统，也就有按需向Minecraft服务器分配更多内存的可能性。
* Minecraft服务器在1.1.0版本之后能够使用多个处理器内核，提升服务器性能。
* 你可以使用[http://CanIHostAMinecraftServer.com CanIHostAMinecraftServer]对托管的玩家数目进行粗略计划。
