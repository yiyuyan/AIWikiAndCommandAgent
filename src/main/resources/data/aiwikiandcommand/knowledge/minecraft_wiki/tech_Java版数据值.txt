这些'''数据值（Data Values）'''决定了[[Java版]]内不同种类的方块和物品。它们在Minecraft中有很多用处。[[#方块|方块ID]]用于定义放置在世界的方块和其物品形式（包括物品栏、箱子里的和作为掉落物的）；[[#物品|物品ID]]只对物品有效；[[#实体|实体ID]]只对例如生物和弹射物的实体有效。[[#方块状态|方块状态]]则是进一步定义一个方块所需的附加数据值。

== ID ==
以下ID若无特殊说明都是省略了<code>minecraft:</code>命名空间前缀的[[命名空间ID]]。
