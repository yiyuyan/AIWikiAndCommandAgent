下面介绍了[[Java版Infdev 20100327|Infdev 20100327]]至[[Java版Beta 1.7.3|Beta 1.7.3]]的边境之地。

== 位置 ==
边境之地会在X/Z=+12,550,821和X/Z=-12,550,824开始向外生成。

== 结构 ==
=== 边境之地 ===
[[File:FarLandsCorner.png|缩略图|两个边境之墙的交汇处，形成了边境之角]]

在边境之地，任何在海平面以下的区域都会被[[水]]淹没（不包括[[洞穴]]），树木一般只会在上部生成草地的空间中出现。与世界其他区域类似，边境之地中[[生物群系]]和天气系统可以正常运作，小型[[洞穴]]、[[地牢]]和湖泊也可以在固体区域中生成，水泉和熔岩泉也可以在洞穴中出现甚至流出洞穴外，[[矿石]]也可以在对应的海拔高度生成。但由于海平面之下几乎都被水淹没，因此除了煤矿石外，其他种类的矿石都很难得到。

边境之地大多数开阔地都缺乏光照，因此怪物会大量生成，使边境之地变得格外危险，这在边境之角中因为其堆叠状的地形显得尤为明显。

边境之地同时伴随着延迟或卡顿。这种卡顿伴随着帧率的大幅下降和CPU占用率奇高，甚至还可能会导致游戏未响应。在[[多人游戏]]中，客户端不会出现帧率下降，但会使服务器本身性能下降，具体依赖于服务器的内存大小。边境之地中的卡顿主要是因为存在大量的掉落中的沙子和沙砾实体。这些实体会导致更多的实体位置坐标出现错误，这反过来会引起更大的浮点数精度误差。

边境之地具有两种形态——边境之墙和边境之角，皆为十分奇怪的地形，但两者在地形上有很明显的差别。
{{-}}

==== 边境之墙 ====
[[File:12550821line.png|缩略图|边境之墙]]

从正常世界来看，边境之墙看上去就是一堵高墙，一直延伸到地图最大高度限制（当时为Y=127）。墙上有许多垂直墙面的洞，这些洞会延伸得很长，可能是无限的，而且这些洞的形态变化都很小。这些洞可能会被堵塞，但很稀有并且只是暂时的。这样的“蜂窝乳酪式”高墙在地表之下一直到地图底部都会出现。边境之墙像是由于地图生成器输出错误导致在一个方向上地形扭曲的结果。这个区域有时被称为“循环”。

边境之墙的平均方块数量分数：36%[[石头]]、25%[[空气]]、23%[[水]]、10%[[泥土]]或[[草方块]]、2%[[基岩]]以及4%的其他方块（基于14×14个区块）。

==== 边境之角 ====
[[File:Far Lands Cartograph.png|缩略图|边境之墙和边境之角]]
[[File:Farlandsstacktop.png|缩略图|边境之角俯瞰图]]

两个边境之墙的交汇处即为边境之角。相较于边境之墙的蜂窝高墙，边境之角的地形要正常一些。边境之角以一个较为正常的地形为基础，一个一个地往上堆叠，中间留下空气夹层，成为一个巨大的“三明治”。每一层地形都像是一个巨大的浮空岛，但除了最顶端的一层，其余各层都是几乎黑暗的。

边境之角的堆叠层数不是固定的，有可能是5层到7层。这些堆叠层可以分为3类：

* 最顶层：这一层在边境之角的最高处。由于地形较高，几乎达到了世界的高度限制，因此这一层很少会出现树木和动物，不过这一层的下陷处会出现一些树木和被动型生物。
* 干燥层：这一类层会稍微平坦一些，也会出现树木，但整体是几乎处于黑暗当中的，所以攻击性生物在这里很常见。在很稀有的情况下，上层会留下空洞使得阳光可以照进这一层。这些堆叠层都有类似洞穴的天花板，由石头、沙砾和泥土构成，在海平面附近还会出现大量的浮空沙滩。
* 淹没层：跟干燥层相似，这些堆叠层会稍微平坦一些，但主要由石头构成。沙子和砂岩也会出现，甚至在海平面以下30米处。除了煤矿石外，其他矿石都只能在淹没层中找到。

有时候边境之角存在从世界底部直通顶部的柱子，其天花板或底部也可能会出现几乎完美的对角线。这可能说明了边境之角和边境之墙的地形都有共通点（对角线与边境之墙的长洞相似），但不同点更明显。

边境之角的平均方块数量分数：40%[[石头]]、16%[[空气]]、28%[[水]]、10%[[泥土]]/[[草方块]]、2%[[基岩]]以及4%的其他方块（基于14×14个区块）。

=== 遥远之地 ===
{{conjecture|section=1|type=漏洞}}
[[File:Corner farlands at 1,004,065,811.png|缩略图|遥远之地的起始点附近：X/Z=±1,004,065,811]]

'''遥远之地（Farther Lands）'''，即第二组边境之地，生成在约X坐标和Z坐标大约±1,004,065,920处，到±8.175×10<sup>48</sup>为止，是原本边境之地的80倍远。

遥远之地完全覆盖了已有的第一组边境之地和边境之墙，并比第一组边境之地拥有更细长且更呈线条型的地形。遥远之地非常平坦的地形与几乎只有蜂窝高墙式的第一组边境之地形成了对比。遥远之地只会在假区块内生成。

== 其他维度 ==
下界和天域的边境之地都与主世界边境之地大同小异。

=== 下界 ===
[[File:NetherFarLands.png|缩略图|[[下界]]边境之地]]

下界边境之地与主世界边境之地现象几乎相同，只是主要由[[下界岩]]和少量[[灵魂沙]]构成，Y=31以下的方块都会被熔岩海淹没。

在下界中，严重的卡顿现象不会出现。因为下界中受重力影响的方块极少（没有沙子，且沙砾也没有多少），且下界大多数地方都足够暗以至满足生物的首次生成条件。

若在主世界边境之地中建立传送门并进入，传送后会处于普通的下界里。因为如果位于X/Z=32,000,000时（即方块物理和亮度停止运作的限制），由于传送到下界的位置会被除以8（在下界内1格距离相当于在主世界内8格），进入下界传送门只会被传送到X/Z=4,000,000，远远无法达到X/Z=12,550,820（边境之地的生成位置）。反过来，建在下界边境之地的下界传送门不会工作，因为在12,550,820（即边境之地开始的地方）建立传送门会把玩家传送到X/Z=100,406,560，远远超过X/Z 32,000,000。如果在下界进入坐标大于X/Z=4,000,000的传送门，游戏会崩溃，因为在下界进入坐标为X/Z=4,000,000的传送门后，游戏将会把玩家传送到X/Z=32,000,000限制以外。

=== 天域 ===
[[File:Sky Dimension Far Lands Edge.jpg|缩略图|天域边境之地]]

[[天域]]边境之地不会生成水或熔岩，基岩也不会生成。与常规的主世界边境之地相比，天域边境之地存在拉伸。

这是玩家最有可能找到钻石的地方，因为天域这种浮岛地形的高度不足以使钻石矿石生成。天域边境之地会一直生成到Y=0，所以玩家很容易就能在其中找到稀有矿石。

== 生成原因 ==
{{see also|噪声生成器}}
游戏的地形是通过16倍频[[wzh:Perlin噪声|Perlin噪声]]（又称柏林噪声）函数生成的，具体用于[[噪声生成器#高噪声|高噪声]]和[[噪声生成器#低噪声|低噪声]]。每个噪声生成器输入一个浮点值，并使用该浮点值对各个整数的噪声值进行插值，过程如下：

# 将原始输入向0取整（即去除小数部分），得到一个32位整数。
# 如果该整数大于原始输入值，则将该整数减1，以向下取整。
# 将原始输入与该整数相减，获得一个[0,1]区间内的余数作为插值。

问题在于，许多倍频函数的涵盖范围比一个方块还要小，每个方块可能有多达171.103个噪点，而一旦噪声值溢出超过[−2{{^|31}},2{{^|31}}]就会引发问题。由于2{{^|31}}≈171.103×12550824.053，而一旦坐标超越该值，噪声值将永远是2{{^|31}}−1，从而造成每一个轴上每次都会生成相同的噪声值，这就是边境之墙和边境之角的地形能够保持不变的原因。遥远之地则是由[[噪声生成器#选择器噪声|选择器噪声]]溢出而得。

正坐标方向的余数通常从一个相当小的值开始，但在通常情况下比1要大得多，并以每个方块171.103的速度递增；负坐标方向的余数则从−2{{^|32}}开始。余数通过((6x−15)x+10)x{{^|3}}调整，以进行五次样条曲线拟合函数。在每个方块的正坐标一侧，调整后的值就已经在10{{^|11}}附近，并且负数端将总会从-10{{^|49}}附近开始。而边境之角就是边境之地的值相乘而得。试图以这么大的数字插值（其实就是外推法）时，会产生同样巨大的输出。这个输出令赋予地形形状的其他规则失效，而地形也会因为该噪声函数的输出而崩坏。

边境之地的移除是通过将输入值对2{{^|24}}{{tr|求余|求餘}}以阻止噪声溢出。噪声算法每2{{^|8}}单位就会重复，因此该修复不会对正常地形生成造成影响。在当前游戏版本中可以通过移除上述修复的方式，再现边境之地现象。<ref name="reddit explanation">[https://www.reddit.com/r/Minecraft/comments/2su65c/i_resurrected_the_far_lands_in_181/cnsuqnt 我让边境之地在1.8.1中复活了]</ref>

以下因素会使边境之地情况更复杂：
* 噪声每4个方块只采样一次，并在其中线性插值。这就是边境之地起始于12,550,824而不是坐标12,550,821的原因。
* 每个噪声生成器会为自己的输入加上一个在[0,256]内的随机偏移量。一般而言，这会导致界限点在12550824以内，让边境之地从12550821开始生成。但某些种子的界限点可能会超越12550824，造成边境之地在12550825出现。更加罕见的是，如果界限点的位置非常接近但小于12550824，那么边境之地的头几个方块可能比较正常。边境之地南部和东部的该现象互相独立；在负数的那一端，边境之地总是在坐标-12550825的方块开始，正方向的边缘在12550824。
* 选择器噪声将低噪声和高噪声混合，以实现两条隧道和或两片平原之间的平滑过渡。在一些情况下，可能出现其中一个噪声生成器使用不同的偏移量而比另一个噪声生成器提前生成边境之地，从而会造成不协调的地形。

== 你知道吗 ==
* 边境之地占据了一个世界中的绝大部分区域。
* 在超出一亿格的遥远之地中地形可能会一直保持不变。
* 尽管在[[Java版Beta 1.6|Beta 1.6]]之后玩家无法在Y=128处放置方块，但边境之地的“天花板”仍会在该处生成。
