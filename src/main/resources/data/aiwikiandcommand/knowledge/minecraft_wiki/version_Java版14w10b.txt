'''14w10b'''是[[Java版1.8]]的第15个快照，发布于2014年3月6日<ref>{{cite|url=http://mojang.com/2014/03/minecraft-snapshot-14w10a/|archive-url=1|archive=1|archive-time=20140314091137|title=Minecraft snapshot 14w10c|author=Dinnerbone|website=Mojang.com|date=Mar 6, 2014}}</ref>，发布以修复[[14w10a]]里的漏洞和崩溃。

== 修复 ==
{{fixes|fixedin=14w10b|prefix=Minecraft|showdesc=1
|;old
|4410|在第三人称视角下下蹲会在地面上悬空。
|32284|在铁砧的第一格中放入附魔了不存在的魔咒ID的物品会导致崩溃。
|;dev
|48461|酿造台不复制它们的NBT标签。
|50155|农作物在耕地上悬空。
|50226|当唱片机中有音乐唱片时，纹理丢失。
|;previous
|50220|在物品栏中的下界砖栅栏渲染不正确。
|50222|草方块中的泥土部分纹理是绿色的。
|50223|14w10a专用服务器在启动时崩溃。
|50229|当不带<code>option</code>参数执行{{cmd|scoreboard team option deathMessageVisibility|link=none}}命令时，显示的错误信息显示了不正确的选项。
|50232|小麦显示为无效纹理。
|50233|双层石台阶显示为无效纹理。
|50241|不能为离线玩家或“假”玩家添加或设置计分值。
|50242|被充能的红石中继器中的红石火把周围不能发出粒子。
|50246|当床的左边或右边有一个箱子，另一边有一个实心的木块时，床的腿会消失。
|50250|下界疣的纹理损坏。
|50254|雪方块显示为无效纹理。
|50259|朝上的发射器显示为无效纹理。
