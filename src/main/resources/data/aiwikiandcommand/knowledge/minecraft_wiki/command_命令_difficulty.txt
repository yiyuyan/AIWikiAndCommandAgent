{{about|命令|在Minecraft中直接影响游戏的难易程度的一个[[选项]]|难度}}
{{Infobox command
|name=difficulty
|oplevel=2\1
|becheat=1
}}
设定[[世界难度]]等级。

== 语法 ==
* '''Java版'''
: <code>difficulty [easy|hard|normal|peaceful]</code>

* '''基岩版'''
: <code>difficulty <difficulty: Difficulty></code>
: <code>difficulty <difficulty: int></code>

== 参数 ==
{{el|je|short=1}}：{{code|peaceful{{!}}easy{{!}}normal{{!}}hard}}<br>
{{el|be|short=1}}：{{argument|be=1|difficulty: Difficulty|enum}}，或{{argument|be=1|difficulty: int|int}}
: 新的游戏难度。必须为以下之一：
:* <code>peaceful</code>（{{in|be|nc=1}}可简写为<code>p</code>或<code>0</code>）为[[和平]]难度
:* <code>easy</code>（{{in|be|nc=1}}可简写为<code>e</code>或<code>1</code>）为[[简单]]难度
:* <code>normal</code>（{{in|be|nc=1}}可简写为<code>n</code>或<code>2</code>）为[[普通]]难度
:* <code>hard</code>（{{in|be|nc=1}}可简写为<code>h</code>或<code>3</code>）为[[困难]]难度
{{in|je}}若未指定参数，则查询当前游戏难度。

* 难度更改为困难：<code>difficulty hard</code>、<code>difficulty h</code>{{only|bedrock}}或<code>difficulty 3</code>{{only|bedrock}}
