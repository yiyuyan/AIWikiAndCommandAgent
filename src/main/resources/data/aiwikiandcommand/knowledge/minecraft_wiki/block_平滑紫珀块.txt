'''tile.deprecated_purpur_block_2.name'''，下文称'''平滑紫珀块（Smooth Purpur）'''，是未使用的[[紫珀块]]变种。

== 生成 ==
平滑紫珀块不会生成在世界中。

== 获取 ==
{{see also|Tutorial:获取任意物品}}
平滑紫珀块不能在生存模式中正常获得，但可以通过[[创造模式]]中使用{{ctrl|选取方块}}或[[命令]]获得。

== 破坏 ==
挖掘平滑紫珀块的合适工具是镐。平滑紫珀块需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table/manual|only=be|{{BlockSprite|Purpur Block}} 平滑紫珀块|1.5|wooden pickaxe}}

平滑紫珀块被破坏后不会掉落。

== 用途 ==
{{main|紫珀块}}
平滑紫珀块具有与紫珀块相同的合成和切石用途。
