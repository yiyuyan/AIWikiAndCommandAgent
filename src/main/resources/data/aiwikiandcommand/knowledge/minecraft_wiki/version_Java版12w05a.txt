'''12w05a'''是[[Java版1.2.1]]的第3个快照，发布于2012年2月2日<ref>{{cite|url=http://mojang.com/2012/02/02/minecraft-snapshot-12w05a/|archive-url=1|archive=1|title=Minecraft Snapshot 12w05a|author=Jens Bergensten|website=Mojang.com|date=Feb 2, 2012}}</ref>，略微修改了生物AI，更改了熔岩流动的音效，并修复了一个漏洞。

== 更改 ==
=== 方块 ===
'''[[枯萎的灌木]]'''
* 现在能够通过使用[[剪刀]]获得。

=== 物品 ===
'''[[火焰弹]]'''
* 现在能够用[[木炭]]合成。

=== 生物 ===
'''[[苦力怕]]'''
* 现在会跑离[[豹猫]]。
* 苦力怕有了新的AI——它们会跟随玩家。

'''[[豹猫]]'''
* 变得更容易被驯服，并且驯服后可以坐下。

'''[[村民]]'''
* 现在会寻找[[村庄]]并且居住下来。

'''音效'''
* [[熔岩]]有了流动时特有的声音。

=== 世界生成 ===
'''[[废弃矿井]]'''
* [[废弃矿井]]如果经过悬空的地方，会生成桥梁。

=== 常规 ===
'''[[语言]]文件'''
* 更新了语言文件。
** 移除了一些令人反感的翻译文本。

'''[[附魔台]]'''
* 在[[创造模式]]下，使用附魔台附魔不再需要[[经验值]]。

'''[[音效]]'''
* 熔岩的声音现在会正常播放。

== 修复 ==
; 修复了1个漏洞
: 修复了一个利用下界传送门复制物品的漏洞。</onlyinclude>

== 重新上传 ==
该版本于14:42（UTC）被重新上传，以修复空手右键豹猫使其坐下时的崩溃和语言翻译上的漏洞。<ref>{{tweet|jeb|165083905773412354|Snapshot is back online! http://mojang.com/2012/02/02/minecraft-snapshot-12w05a/|02 Feb 12}}</ref>
