与{{cmd|execute}}相似，但执行命令的是执行者自身。

== 语法 ==
: <code>-{}-executeasself <''命令：字符串''></code>

== 参数 ==
<code>-{}-''命令：字符串''</code>
: 指定需要执行的命令，命令必须是有效的。
