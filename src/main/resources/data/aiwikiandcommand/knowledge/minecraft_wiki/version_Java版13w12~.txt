'''13w12~'''{{sic}}是[[Java版1.5.1]]的第2个，也是最后一个快照，发布于2013年3月19日<ref>{{bug|MC-8824#comment-55414}}</ref>，修复了一个漏洞。

== 修复 ==
{{fixes|showdesc=1
|;1.5的漏洞
|8824|开启平滑光照会使帧数严重降低。<ref group="注">该漏洞在漏洞追踪器中被标记为修复于Java版1.5.1。</ref>
}}

== 重新上传 ==
该版本在14:39（UTC）被重新上传以成功修复开启平滑光照会使帧数严重降低的漏洞<ref name="13w12 debug">{{bug|MC-8824#comment-55456}}</ref>，因为原始版本未能成功修复该漏洞。<ref>{{tweet|jeb|314026805415772160}}</ref>

== 你知道吗 ==
* 该版本在Mojira上作为临时快照被发布，这是该快照不遵循常规命名方式的原因。
