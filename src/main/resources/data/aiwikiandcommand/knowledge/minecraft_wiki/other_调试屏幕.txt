'''调试屏幕（Debug screen）'''默认使用{{keys|F3}}呼出，是一种在游戏内显示调试信息的屏幕，包括[[区块]]缓存、内存使用、玩家的当前[[坐标]]、当前游戏帧率图表等各种参数。调试屏幕会在需要向其他玩家描述自己位置或监测游戏性能时发挥很大用处。

'''调试组合键（Debug hotkey）'''控制了调试屏幕部分元素的显示，它也提供了多种调试信息。

== 调试选项屏幕 ==
{{Filetr|Debug Options.png|thumb|调试选项屏幕}}

按下{{key|F3+F6}}可以打开调试选项屏幕，该屏幕用于配置哪些调试信息需隐藏/仅在调试屏幕中显示/始终可见。其他的一些调试组合键也可通过此屏幕开关。

该屏幕顶部有搜索框和一串警告文字。底部有“{{tp|debug.options.profile.default}}”和“{{tp|debug.options.profile.performance}}”两种配置。其中后者会在前者的基础上只保留某些选项及其元素，具体见下方表格。

根据具体用途，各个选项在调试选项屏幕中被分为“调试屏幕文本”和“调试渲染器”两部分，并按首字母顺序排列。

若[[游戏规则]]{{gamerule|reduced_debug_info}}设为<code>true</code>，或者在[[选项#聊天设置|聊天设置]]中开启了“{{tp|options.reducedDebugInfo}}”选项，则调试屏幕只显示下面表格里带<code>*</code>标记的元素，并在调试选项屏幕内在不显示的元素上显示“{{tp|debug.options.notAllowed.tooltip}}”。

调试选项的配置存储在{{filename|[[debug-profile.json]]}}中。

所有的调试快捷键均可在[[控制]]中重新绑定，本文将以默认配置描述。

==== NoiseRouter ====
显示用于生成地形和生物群系的噪声值。

* T（Temperature）：温度。用于生物群系的放置，不影响地形。

* V（Vegetation）：植被，即湿度。用于生物群系的放置，不影响地形。

* C（Continents）：大陆性。用于区分海洋与陆地，决定生物群系的放置。

* E（Erosion）：侵蚀度。决定地形的平缓程度，此值越高表示地形越平缓。

* D（Depth）：深度，随高度变化，用于生物群系放置。

* W（Weirdness）：奇异性。此值影响山脊性进而影响了地形的起伏，也用于决定一些生物群系的放置位置，例如向日葵平原和冰刺之地。

* PV（Peaks and Valleys）：山脊性。即地形为山谷或山峰，与奇异性有关。

* AS：原始密度值（即不加粗糙度）。

* N：最终密度值（即加粗糙度）。

==== Biome builder ====
显示噪声值所对应的类别。

* PV（Peaks and Valleys）：地形类型，与山脊性有关。值可为Valley（仅河流生物群系）、Low、Mid、High或Peak。

* C（Continents）：陆地类型，与大陆性有关。值可为Mushroom fields、Deep ocean、Ocean、Coast、Near inland、Mid inland或Far inland。

* E（Erosion）：侵蚀度。值可为0-6。

* T（Temperature）：温度。值可为0-4。

* H（Humidity）：湿度。值可为0-4。

==== SC ====
显示生物生成的详细信息。

* SC：当前可生成生物的区块数。

* MO（Monster）：当前生物容量中敌对生物的数量。

* C（Creature）：当前生物容量中动物的数量。

* AM（Ambient）：当前生物容量中环境生物的数量。

* AX（Axolotls）：当前生物容量中美西螈的数量。

* U（Underground water creature）：当前生物容量中地底水生动物的数量。

* WC（Water creature）：当前生物容量中水生动物的数量。

* WA（Water ambient）：当前生物容量中水生环境动物的数量。

* MI（Misc）：当前生物容量中其他生物的数量。

==== CH ====
客户端[[高度图]]。描述当前在玩家当前X/Z坐标处存在的最高特定方块的Y坐标。

* CH：指客户端高度图。

* S：在此X/Z坐标处最高非空气方块的Y坐标。

* M：在此X/Z坐标处最高的'''任意液体'''或'''材料阻止运动的方块'''的Y坐标。

==== SH ====
服务端[[高度图]]。描述当前在玩家当前X/Z坐标处存在的最高特定方块的Y坐标。

* SH：指服务端高度图。

* S：在此X/Z坐标处最高非空气方块的Y坐标。若非内置服务端，此值以问号显示。

* O：该X/Z坐标处最高的'''[[材料]]阻止运动的方块'''的Y坐标。若非内置服务端，此值以问号显示。

* M：在此X/Z坐标处最高'''任意液体'''或'''[[材料]]阻止运动的方块'''的Y坐标。若非内置服务端，此值以问号显示。

* ML：该X/Z坐标处最高'''任意液体'''或'''[[材料]]阻止运动且非树叶的方块'''的Y坐标。若非内置服务端，此值以问号显示。

* 子区块未计算天空光照时为<code>2</code>，计算天空光照且子区块内全部为空气且天空光均为15时为<code>1</code>，无天空光照计算时为<code>n/a</code>，其他条件下为<code>0</code>。
* 如果方块位置上的方块光不为0，则以黄色到红色字渲染光照等级。
* 游戏只会渲染摄像机周围切比雪夫距离小于10的信息。
{{-}}

==== visualize_chunks_on_server ====
[[File:Debug Feature debug chunks.png|thumb|300px]]
启用时，若调试屏幕正在渲染（即必须有一个调试屏幕的元素正在渲染），则显示玩家周围区块的状态，颜色与[[世界加载屏幕]]中的颜色图相同，并使用红框标记玩家所在区块。同时，在每个区块上方渲染带有区块信息的文字，按照行的顺序分别为：
* 客户端区块信息：如果区块还没有获取到信息，为<code>0n/a</code>；如果区块为空，则为<code>E</code>；其他情况下此项为空字符串。
* 服务端区块加载等级。
* 服务端区块状态。
* 服务端区块当前持久化到存储的区块状态。
* 服务端区块当前的计算状态。

专用服务端中此调试渲染器无效。
{{-}}

==== visualize_entity_supporting_block ====
[[File:Debug Feature debug support blocks.png|thumb|300px]]
实体支撑方块是用于计算方块对实体效果的数据，例如受伤行为和行走速度等。游戏以红色画出玩家自身的主支撑方块，以绿色画出周围实体的主支撑方块，以青色画出实体下方0.2格的方块（如果此方块与主支撑方块不一致）。如果实体没有支撑方块则不进行渲染。
{{-}}

* <code><s>WORLD_SURFACE_WG</s></code>：{{color|#FFFF00}}（<code>[1, 1, 0]</code>）

== 图表 ==
=== {{tp|key.debug.profilingChart}} ===
使用{{key|F3+1}}会在屏幕右侧呼出这个图表。

[[File:F3 Profiler Graph.png|150px|缩略图|饼图]]
'''{{tp|key.debug.profilingChart}}（Profiler graph）'''，亦称'''性能分析器图表'''或'''饼图（Pie chart）'''，可用于实时显示各项分析信息。使用1-9键放大查看某一项的详细信息。使用0键返回至上一视图。目前无法查看序号高于9的选项，同时或依次按下两个数字键都只会进入序号不高于9的选项。<ref>{{bug|MC-215458}}</ref>
{{-}}

=== {{tp|key.debug.fpsCharts}}{{anchor|FPS/TPS图表}} ===
使用{{key|F3+2}}会在屏幕下方呼出这两个图表，其中刻速率图表只有在玩家游玩[[单人游戏]]或作为一个[[服务器]]里的[[管理员]]时才会出现。

[[File:F3 Frametime Graph.png|150px|缩略图|帧生成时间图表]]
左下角的是'''帧生成时间图表（Frame rate graph）'''，亦称'''{{text anchor|FPS图表}}（FPS graph）'''，附有每帧1/60秒和1/30秒的参考线。数据柱形的颜色从绿色到黄色再到红色，表示帧生成时间越来越长。
{{-}}

[[File:TPS.png|150px|缩略图|刻速率图表]]
右下角的是'''刻速率图表（Tick rate graph）'''，亦称'''{{text anchor|TPS图表}}（TPS graph）'''，在其顶部附有最后240刻的最小、平均和最大刻时间。该柱状图显示了游戏的最后的240刻，数据柱形从低到高，表示游戏运行越来越慢。
{{-}}

=== {{tp|key.debug.networkCharts}} ===
也被称为'''网络性能图表'''。使用{{key|F3+3}}会在屏幕下方呼出这两个图表。

[[File:F3 Bandwith Graph.png|150px|缩略图|传输速率柱状图]]
左下角的是'''传输速率柱状图（Bandwidth graph）'''，附有64B/s、1.0KiB/s、16.0KiB/s、1.0MiB/s参考线以及最小、平均、最大速率。数据柱形的颜色取决于上行和下行数据所占比例，颜色越接近紫色表示下行数据占比越高，越接近蓝色表示上行数据占比越高。
{{-}}

[[File:F3 Ping Graph.png|150px|缩略图|网络延迟柱状图]]
右下角的是'''网络延迟柱状图（Ping graph）'''，附有500ms的参考线以及最小、平均、最大延迟。数据柱形的颜色从绿色到黄色再到红色，表示网络延迟越来越大。
{{-}}

=== {{tp|key.debug.lightmapTexture}} ===
[[File:F3 Lightmap Texture.png|150px|缩略图|]]
使用{{key|F3+4}}会在屏幕右下角呼出这个图表。此图表与{{tp|key.debug.fpsCharts}}和{{tp|key.debug.networkCharts}}互斥。

此图标会显示当前的光照纹理。纵轴代表天空光照强度，从下到上依次代表0至15级；横轴代表方块光照强度，从左到右依次代表0至15级。每个像素的颜色代表将对应方块光照和天空光照下要应用到方块和实体的光照颜色。具体详见{{slink|亮度|渲染亮度}}。
{{-}}

== 调试组合键 ==
按下大部分调试组合键时，聊天框会显示提示信息。注意使用某些组合键，如{{keys|F3+N}}、{{keys|F3+B}}等不会打开调试屏幕。

* {{key|F3+A}}：重新加载所有[[区块]]。
* {{key|F3+B}}：打开或关闭显示[[实体]]的[[判定箱#实体|判定箱]]。如果实体被其他实体骑乘，还会显示乘客的着落点。
* {{key|F3+C}}：以{{cmd|execute in ''维度'' run tp}}的形式复制玩家当前的坐标及旋转角度。
** 按住{{key|F3+C}}10秒会导致调试性的游戏崩溃，并生成Minecraft崩溃报告。
** 按住{{key|Ctrl+F3+C}}10秒会强制Java虚拟机崩溃，生成虚拟机崩溃报告，而不是常规的Minecraft崩溃报告。然而，对于某些键盘，它只能使用右侧{{key|Ctrl}}触发，而使用左侧只会产生普通的崩溃。
** 一些键盘可能不允许同时按下{{key|F3+C}}（可能是因为它们在同一竖列中）。
* {{key|F3+D}}：清除聊天记录。
* {{key|F3+G}}：打开或关闭显示玩家周边区块的边界。
* {{key|F3+H}}：打开或关闭显示物品栏中物品的ID、工具的耐久度、[[物品堆叠组件]]数量、染色物品的颜色值和[[地图]]的放大尺寸。
* {{key|F3+I}}：将玩家注视的方块/实体的数据复制到剪贴板。
* {{key|F3+L}}：评估游戏各项性能数据，保存到[[性能分析报告文件]]。
* {{key|F3+N}}：在上一个[[游戏模式]]与旁观模式间切换。
* {{key|F3+P}}：开启或关闭Minecraft失去窗口焦点时的自动暂停功能。
* {{key|F3+S}}：将动态纹理转储到{{samp|screenshots/debug/}}目录中，具体见下。
* {{key|F3+T}}：重新加载纹理、模型、声音及所有其他[[资源包]]内容。
* {{key|F3+V}}：输出客户端的版本信息。
* {{key|F3+F4}}：打开游戏模式切换器。按住{{key|F3}}并多次按{{key|F4}}，玩家选定的游戏模式可以在四种游戏模式间循环。松开{{key|F3}}即载入选定的游戏模式。
* {{key|F3+F6}}：打开或关闭调试选项屏幕。
* {{key|F3+1}}：显示或隐藏{{tp|key.debug.profilingChart}}。
* {{key|F3+2}}：显示或隐藏{{tp|key.debug.fpsCharts}}。
* {{key|F3+3}}：显示或隐藏{{tp|key.debug.networkCharts}}。
* {{key|F3+4}}：显示或隐藏{{tp|key.debug.lightmapTexture}}。

当[[游戏规则]]{{gamerule|reduced_debug_info}}设为<code>true</code>时，{{key|F3+B}}（显示实体碰撞箱）和{{key|F3+G}}（区块边界）{{key|F3+C}}（复制坐标）和{{key|F3+I}}（复制方块/实体数据）无效。但长按{{key|F3+C}}和{{key|Ctrl+F3+C}}仍然可以导致崩溃。

使用{{key|F3+S}}时，游戏会导出下列{{vanchor|动态纹理}}：
* [[纹理图集]]纹理，以及对应的MipMap版本（若有）和纹理映射文件；
* 游戏使用的[[字体]]纹理；
* 服务器图标；
* [[资源包]]和[[数据包]]图标；
* 在线获取的[[皮肤]]和[[披风]]纹理；
* [[地图]]显示的地图内容；
* [[无效纹理]];
* 用于字体Lightmap的1像素大小的空白纹理。
* {{inUpcoming|je 26.3}}实体盔甲纹饰图集。
