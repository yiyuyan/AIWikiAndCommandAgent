'''26.1.2'''是{{el|je}}的一次热修复更新，发布于2026年4月9日，修复了一些严重漏洞。<ref>{{article|minecraft-java-edition-26-1-2|Minecraft Java Edition 26.1.2|Apr 09, 2026}}</ref>此版本兼容26.1和26.1.1的服务端。

== 更改 ==
=== 常规 ===
==== UI ====
* 现在复选框的消息提示框仅在文本超过2行溢出时才会显示。
* 「举报玩家」界面中的确认复选框，现在会显示与消息文本一致的提示框。
