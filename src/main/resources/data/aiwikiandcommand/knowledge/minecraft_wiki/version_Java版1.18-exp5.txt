'''1.18-exp5（1.18 experimental snapshot 5）'''是[[Java版1.18]]的第5个实验性快照，发布于2021年8月25日<ref>{{article|new-world-generation-java-available-testing|New world generation in Java available for testing|August 25, 2021|Henrik Kniberg}}</ref><ref>{{reddit|pbd2pr/minecraft_118_experimental_snapshot_5_is_out||Minecraft 1.18 experimental snapshot 5 is out!|MrHenrik2|August 25, 2021}}</ref>，调整了一些[[地形特征]]、[[生物群系]]的生成。此版本单独发布，故不出现在[[启动器]]版本列表中。

此版本由[[Java版1.17.1]]分叉而来，独立于Minecraft开发的主分支。

== 更改 ==
=== 生物 ===
'''常规'''
* 撤回了[[Java版1.18-exp3|1.18-exp3]]关于[[生物]]生成的更改，现在生物的生成速度又会像以前那样在低处增大、在高处减小。
** 生物生成与海拔[[高度]]的关系今后仍可能进一步调整。

=== 世界生成 ===
'''[[恶地]]'''
* 略微降低了平均大小。

'''[[溶洞]]'''
* 现在洞口处的[[草方块]]由[[石头]]取代。

'''[[丛林边缘]]'''
* 重新加入，但其不再起过渡功能。

'''[[繁茂洞穴]]'''
* 现在[[涌泉]]会在此生成。

'''[[山地]]<!--Mountains-->'''
* 山顶的地形现在会更陡峭、崎岖。
* 略微增加了[[山脉]]和[[尖峭山峰]]、[[冰封山峰]]、[[裸岩山峰]]生物群系的平均大小。
* 提高了整体的海拔高度。

'''[[蘑菇岛]]'''
* 调整了生成方式，使其与岛屿的形状更加一致。

'''[[河流]]'''
* 调整了河流的深度和河岸的坡度，降低了河流过深或过浅（甚至在平坦区域干涸）的可能性。
* 河流会与沼泽更好地融合，而不会直接穿过沼泽（两者间的界限不再过于明显）。

'''[[沼泽]]'''
* 现在更倾向于在内陆生成，以防止其与[[海洋]]交界而使[[水]]的色差过大。
* 沼泽[[橡树]]现在能生成在更深的水中。

'''[[洞穴]]'''
* [[雕刻器洞穴]]现在可以覆盖[[红沙]]和[[方解石]]生成，以避免这两种方块在洞穴中悬空。

'''常规'''
* 小型[[湖泊]]不再在干燥且炎热的[[生物群系]]中生成（[[沙漠]]、恶地和[[热带草原]]）；减少了其他生物群系中湖泊生成的数量。
* [[涌泉]]可以在更多种类的方块中生成（例如[[泥土]]和[[雪块]]），增加了小山泉和瀑布的生成概率。
* 减少了{{tr|破|零}}碎地形和[[破碎的热带草原]]生物群系的数量，且部分区域由更加平坦的沙滩代替。

== 修复 ==
* 主世界Y=0以上的化石中不再错误生成深层钻石矿石。
* 修复了1.18-exp4中使山地地形更加低缓的意外更改。
* 修复了1.18-exp4中平坦地形的突起（技术名称为“3D噪声”）过少的意外更改。</onlyinclude>
