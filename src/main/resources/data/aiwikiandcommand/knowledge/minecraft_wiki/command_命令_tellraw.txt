向一个或多个玩家发送一条以[[文本组件]]表示的消息。

== 语法 ==
* '''Java版'''
: <code>tellraw <targets> <message></code>
* '''基岩版'''
: <code>tellraw <target: target> <raw json message: json></code>

== 参数 ==
{{argument|targets|entity|target: target|CommandSelector<Player>}}
: 指定该消息的接收玩家。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{argument|message|component|raw json message: json|Json::Value}}
: 指定要发送的[[文本组件]]消息。（例：<code>{"text":"Hi there!","bold":"true"}</code>{{only|JE}}；<code>{"rawtext":[{"text":"Hello world"}]}</code>{{only|be}}）
: {{arg desc|je=component|be=Json::Value}}

== 示例 ==
* 向所有玩家发送蓝色消息“Hello everyone!”：
** {{el|je|short=1}}：<code>tellraw @a {"text":"Hello everyone!", "color":"blue"}</code>
** {{el|be|short=1}}：<code>tellraw @a {"rawtext":[{"text":"§9Hello everyone!"}]}</code>
