使用此命令可以使得处于旁观模式的玩家进入另一个实体的视角。

== 语法 ==
:<code>spectate <target> [<player>]</code>
:: 让一个玩家旁观另一个实体。
: <code>spectate</code>
:: 停止旁观实体。

== 参数 ==
{{argument|target|entity}}
: 玩家要旁观的实体。
: {{arg desc|je=entity|amount=single|type=entities}}

{{argument|player|entity}}
: 要旁观的玩家。若未指定，则使用命令执行者。
: {{arg desc|je=entity|amount=single|type=players}}

== 示例 ==
* 令自己旁观Steve：<code>/spectate Steve</code>
* 令Steve旁观最近的猪：<code>/spectate @n[type=pig] Steve</code>
* 令自己停止旁观实体：<code>/spectate</code>
