'''朱砂楼梯（Cinnabar Stairs）'''是[[朱砂]]制作的[[楼梯]]。

== 生成 ==
朱砂楼梯不会生成在世界中。

== 获取 ==
=== 合成 ===

|C3= Cinnabar
|Output= Cinnabar Stairs,4
|type= Building block
}}

{{Stonecutting

|Cinnabar Stairs
}}

== 破坏 ==
挖掘朱砂楼梯的合适工具是镐。朱砂楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

朱砂楼梯被破坏后会掉落自身。
