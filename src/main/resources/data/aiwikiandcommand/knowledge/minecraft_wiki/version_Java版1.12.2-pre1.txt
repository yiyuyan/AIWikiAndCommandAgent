'''1.12.2-pre1'''是[[Java版1.12.2]]的首个预发布版，发布于2017年9月13日<ref>{{article|minecraft-java-edition-1122-pre-release|Minecraft: Java Edition 1.12.2 Pre-release 1|September 13, 2017}}</ref>，加入了一个新的徽标，略微优化了游戏性能，并修复了一些漏洞。

== 更改 ==
=== 常规 ===
'''[[徽标]]'''
* 有了新的徽标——''Minecraft Java Edition''。

== 修复 ==

|86850|向下界传送门中投掷末影珍珠，会使得玩家被传送到与主世界坐标一致的下界坐标上。
