# 原始 Wikitext 内容:

大多数方块都有对应的物品，可以用来放置这个方块，或者是仅仅用来表示这个方块。比如[[超平坦]]的自定义屏幕、[[末影人]]搬运方块时的掉落物。下方表格中使用不同的颜色来表示不同情况，如果方块具有对应的物品但ID不同，则会在“物品形式”一列中标明其对应的物品ID。

{| class="wikitable" data-description="Color coding for Java Edition block IDs"
! 默认
| 该方块具有ID相同物品形式。
|-
! style="background-color:light-dark(#80ff80, #4d9b4d)" | 绿色
| 该方块具有ID
相同的物品形式，但无法使用{{control|选取方块}}直接获取。
|-
! style="background-color:light-dark(#a0a0ff, #554fa4)" | 蓝色
| 该方块具有ID不同的物品形式。
|-
! style="background-color:light-dark(#ccaaff, #694a9b)" | 紫色
| 该方块是某一方块的特殊变种，且原方块具有ID相同的物品形式。
|-
! style="background-color:light-dark(#ffff80, #b0b053)" | 黄色
| 该方块的物品形式没有被定义，但存在可以放置该方块的物品。
|-
! style="background-color:light-dark(#ffa0a0, #a94f4f)" | 红色
| 该方块没有物品形式。
|-
! style="background-color:light-dark(#ffccdd, #cb9aaa)" | 粉红色
| 其他情况
|}
