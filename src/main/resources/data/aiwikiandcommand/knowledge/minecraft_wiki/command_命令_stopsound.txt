停止[[声音事件]]播放。

== 语法 ==
* '''Java版'''
: <code>stopsound <targets> * <sound></code>
:: 停止指定的声音（省略类别）。
: <code>-{}-stopsound <targets> [<''类别''>] [<sound>]</code>
:: 停止所有（指定类别）的声音。

* '''基岩版'''
: <code>stopsound <player: target> [sound: string]</code>

== 参数 ==
{{argument|targets|minecraft:entity|player: target|CommandSelector<Player>}}
: 指定声音的接收者。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{el|je|short=1}}: {{cd|-{}-<''类别''>}}
: 指定要停止的声音所属的类别，对应于游戏选项中“音乐和声音”设置的分类。
: 必须为以下之一：<code>master</code>、<code>music</code>、<code>record</code>、<code>weather</code>、<code>block</code>、<code>hostile</code>、<code>neutral</code>、<code>player</code>、<code>ambient</code>、<code>voice</code>、<code>ui</code>。

{{argument|sound|minecraft:resource_location|sound: string|basic_string}}
: 指定要停止的声音。若未指定，则停止所有声音。
: {{in|java}}{{arg desc|je=resource_location}}应为一个声音事件（例如，<code>entity.pig.ambient</code>）。
: {{in|bedrock}}{{arg desc|be=string}}应为一个声音事件（例如，<code>mob.pig.say</code>）。

== 示例 ==
* 对所有玩家停止播放下雨声：
** {{el|je|short=1}}：<code>stopsound @a * weather.rain</code>
** {{el|be|short=1}}：<code>stopsound @a ambient.weather.rain</code>
** 该命令在雨天执行时会暂时消除雨声。
* 停止所有玩家的所有声音：<code>stopsound @a</code>
