'''1.20-rc1'''是[[Java版1.20]]的唯一一个发布候选版本，发布于2023年5月31日<ref>{{article|minecraft-1-20-release-candidate-1|Minecraft 1.20 Release Candidate 1|May 31, 2023}}</ref>，修复了一些漏洞。

== 新内容 ==
=== 常规 ===
'''[[闪烁标语]]'''
* 加入了以下闪烁标语：
** Joule is neat too!

== 更改 ==
=== 方块 ===
'''[[雕纹书架]]'''
* [[知识之书]]现在可以放在雕纹书架中。

=== 常规 ===
'''[[Java版标签|标签]]'''
* 向{{cd|#bookshelf_books}}物品标签中加入了{{cd|knowledge_book}}。

== 修复 ==
