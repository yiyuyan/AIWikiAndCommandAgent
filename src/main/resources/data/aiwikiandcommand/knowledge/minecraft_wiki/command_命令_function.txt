运行[[函数]]。

== 用法 ==
{{in|je}}运行1个[[Java版函数|函数]]或者[[数据包]]内1个[[Java版标签/函数|函数标签]]的所有函数。{{in|be}}运行[[行为包]]内的1个[[基岩版函数|函数]]。

函数中的[[命令上下文]]参数（如执行者、执行位置、执行朝向等）直接继承{{cmd|function ...|link=none}}所在的命令上下文。

{{in|je}}{{cmd|return run function ...}}（或{{cmd|return run execute ... run function ...}}）的行为不同于直接调用{{cmd|link=none|function}}命令。如果{{cmd|return run function ...}}运行了多个函数，整个执行会在任意函数首次执行{{cmd|link=none|return}}后停止。如果直接调用{{cmd|function ...|link=none}}运行多个函数，所有的函数都会执行，且返回值会累加起来后作为该{{cmd|function ...|link=none}}命令的<code>result</code>输出值。

== 语法 ==
* '''Java版''': 
: <code>function <name></code>
:: 运行一个函数或一个函数标签中的函数。
: <code>function <name> <arguments></code>
: <code>function <name> with (block <sourcePos>|entity <-{}-source>|storage <-{}-source>) [<path>]</code>{{until|JE 26.3}}
: <code>function <name> with (block|entity|storage) <-{}-source> [<path>]</code>{{upcoming|JE 26.3}}
:: 运行一个函数或一个函数标签中的函数，并使用一个NBT复合标签提供用于[[Java版函数#宏|宏]]的参数。

* '''基岩版'''
: <code>function <name: filepath></code>
:: 运行一个函数。

== 示例 ==
* Java版中：
** 运行<code>data/custom/functions/example/test.mcfunction</code>处的函数：{{cmd|function custom:example/test|link=none}}
** 运行所有<code>data/custom/tags/functions/example/test.json</code>标签下的函数：{{cmd|function #custom:example/test|link=none}}
** 执行某个宏函数时传入参数a=42，b="example"：<code>/function custom:example/test {a: 42, b: "example"}</code>
** 执行某个宏函数时传入来自命令存储<code>custom:storage</code>的参数：<code>/function custom:example/test with custom:storage</code>
