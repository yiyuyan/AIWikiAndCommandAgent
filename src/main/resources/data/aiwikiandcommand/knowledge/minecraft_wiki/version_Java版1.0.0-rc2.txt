'''1.0.0-rc2'''是[[Java版1.0.0]]的第2个，也是最后一个候选版本，发布于2011年11月13日，更改了[[物品栏]]中方块的照明，并修复了一个漏洞。

== 更改 ==
'''[[物品栏]]'''
* 改进了物品栏中方块的照明。

== 修复 ==
; 修复了1个漏洞
: 修复了在RC1中加载旧存档时，存档中的所有工具很快就被使用至损坏的漏洞。

== 重新上传 ==
该版本于16:49（UTC）被第一次重新上传，以修复无法进行多人游戏的漏洞。

该版本于16:56（UTC）被第二次重新上传，以修复版本号未随版本号更改的漏洞。<ref>{{tweet|notch|135762958759362562}}</ref></onlyinclude>
