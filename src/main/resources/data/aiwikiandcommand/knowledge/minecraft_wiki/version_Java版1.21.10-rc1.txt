'''1.21.10-rc1'''是[[Java版1.21.10]]的唯一一个发布候选版本，发布于2025年10月2日<ref>{{article|minecraft-1-21-10-release-candidate-1|Minecraft 1.21.10 Release Candidate 1|Oct 02, 2025}}</ref>，修复了一些漏洞。

== 修复 ==
{{fixes|fixedin=1.21.10 Release Candidate 1|showdesc=1|new=1
|;old
|211096|蜘蛛网中的实体会卡进活塞。
|278182|物品被推入细雪或蜘蛛网时会卡在活塞头内。
|;1.21.9的漏洞
|301916|风弹与某些方块发生碰撞时的行为不同。
|302321|玩家被传送时区块不加载。
|302383|不能在地毯所在的竖直面上的物品展示框中放置地图。
|302405|连锁型或循环型命令方块执行<code>/tp [player]</code>形式的命令时不会将玩家反复传送到一个位置。
|;other
|1.|气泡柱上的实体会飞到高空中。
