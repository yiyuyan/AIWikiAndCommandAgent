'''1.21.11-pre3'''是[[Java版1.21.11]]的第3个预发布版，发布于2025年11月25日<ref>{{article|minecraft-1-21-11-pre-release-3|Minecraft 1.21.11 Pre-Release 3|Nov 25, 2025}}</ref>，修复了一些漏洞。

此版本也额外发布了未经混淆的版本，称为'''1.21.11 Pre-Release 3 Unobfuscated'''（启动器内称'''1.21.11-pre3_unobfuscated'''），旨在过渡至后续小更新时移除混淆。<ref>{{article|removing-obfuscation-in-java-edition|Removing obfuscation in Java Edition|Oct 29, 2025}}</ref>

== 更改 ==
=== 物品 ===
'''[[矛]]'''
* 冲刺时，矛击中时的动画和音效只会在先前的击中动画结束时播放。
* 冲刺时，在第一人称视角下，矛头会逐渐旋转到竖直的位置，以同步第三人称视角下的行为。

=== 常规 ===
'''[[选项]]'''
* 现在视频设置使用“流畅”预设时，“{{tr|可透视树叶|透視樹葉|可透視樹葉}}”选项会关闭。
