'''铜枝叶（Copper Spleaves）'''是一种仅生成于[[月球基地]]的方块。

== 生成 ==
铜枝叶会在月球基地展开时生成于展开后的月球基地的主干上。

== 获取 ==
铜枝叶不能在生存模式中正常获得，但可以通过[[创造模式物品栏]]、[[创造模式]]中使用{{ctrl|选取方块}}或{{cmd|give}}[[命令]]获得。

== 破坏 ==
没有工具可以加速对铜枝叶的挖掘。

{{Breaking table/manual|only=je|nocopper=1|
{{BlockSprite|Copper Spleaves}} 铜枝叶|0.1
}}

铜枝叶被破坏后不会掉落。

== 行为 ==
铜枝叶与实体接触时，若自身方块状态<code>falling</code>为<code>false</code>，则会将此值设为<code>true</code>并在短时间后破碎。
