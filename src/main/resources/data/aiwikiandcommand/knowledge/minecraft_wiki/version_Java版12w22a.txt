'''12w22a'''是[[Java版1.3.1]]的第8个快照，发布于2012年5月31日<ref>{{cite|url=http://mojang.com/2012/05/minecraft-snapshot-week-22/|archive-url=1|archive=1|title=Minecraft Snapshot Week 22|author=Jens Bergensten|website=Mojang.com|date=May 31, 2012}}</ref>，加入了绿宝石块以及绊线钩，加入了丛林神庙以及冒险模式，并修复了一些漏洞。

== 新内容 ==
=== 方块 ===
'''[[绿宝石块]]'''
* 装饰性的储存方块，由9个[[绿宝石]]合成。

'''[[绊线]]和[[绊线钩]]'''
* 线现在可以放置，变成绊线，如果绊线钩与它首尾相连的话，生物经过绊线会激活红石信号。

=== 命令格式 ===
'''{{cmd|defaultgamemode}}'''
* 设置新玩家加入[[多人游戏]]时默认的[[游戏模式]]。

=== 世界生成 ===
'''[[丛林神庙]]'''
* 生成于丛林生物群系。
* 主要由[[圆石]]和[[苔石]]构成。
* 拥有发射器、绊线陷阱和战利品箱子。

=== 游戏内容 ===
'''[[冒险模式]]'''
* 新的游戏模式，只能通过{{cmd|gamemode 2}}切换。
* 玩家不能打破和放置任何方块。
* 玩家可以与任意方块互动，例如门和拉杆，并且可以从[[村民]]交易获得。
* 玩家仍然可以伤害生物。

'''[[创造模式]]物品栏'''
* 药水加入进创造模式物品栏中，位于“酿造”类别。
* 在创造模式中加入删除[[物品]]或[[盔甲]]和[[合成]]系统到删除模式物品栏中。
* 在创造模式物品栏中加入了圆石和石砖[[怪物蛋]]。

== 更改 ==
=== 方块 ===
'''[[附魔台]]'''
* 重新平衡了附魔台。
** 附魔台提供的最大附魔等级从50降至30。
*** 因此现在附魔台只需要放置15个书架在其周围就能获得最大附魔等级。
** 拥有至少15书架围着附魔台提供的3个附魔选项中，第3个选项总是30级。
** 使用30级附魔，玩家会变得更幸运；几乎所有物品可得到至少2种魔咒。

'''[[树叶]]'''
* 现在暴露在[[雨]]中时，底部会缓慢出现水滴[[粒子]]。

'''[[炼药锅]]'''
* 现在暴露在雨中时会缓慢填充[[水]]。

'''[[台阶]]'''
* 现在单个台阶能直接放置在方块旁边的上半部分。

'''[[绿宝石矿石]]'''
* 现在1个[[矿团]]只生成1个矿石。

'''[[上锁的箱子]]'''
* 更改了纹理。

=== 游戏内容 ===
'''[[经验]]'''
* 现在各种动作会给予玩家[[经验值]]，例如挖矿（除了[[金矿石]]和[[铁矿石]]）、使用[[熔炉]]和获得[[成就/Java版|成就]]。
* 经验等级现在呈线性，每升一级需要多17经验。

'''[[交易]]'''
* 村民现在可以和玩家交易各种物品（例如：1绿宝石 + 10沙砾 → 3燧石）。
* 一些村民会出售已附魔的物品（例如：3绿宝石 + 1铁镐 → 1时运I铁镐）。

'''[[烧炼]]'''
* 使用熔岩桶烧炼现在会返还玩家一个空桶。

'''[[单人游戏]]'''
* 暂停机制现在在单人游戏重新工作。

'''[[下界传送门]]'''
* 在其附近拥有很小的概率生成[[僵尸猪人]]。

'''[[物品栏]]'''
* 物品栏中看到的方块现在面向右侧，而不是左侧。

'''调试特性'''
* 按下{{key|F}}会重新加载区块。

== 修复 ==
; 修复了10个漏洞
: 现在创造模式物品栏中红石标签页里的红石火把现在显示的是其亮着的样子，而不是暗的。
: 现在把红石火把从创造模式物品栏的装饰方块页上删掉了。
: 修复了在上一个快照中，史莱姆大小有时有错误的漏洞。
: 完全蓄力的箭矢现在能再次显示它们的粒子效果了。
: 箭矢现在会正确卡在它们射入方块的位置上了。
: 语言“English (US)”现在再次可用了。
: 修复了末影人被看到时它们不摇动和打开下颚的漏洞。<ref>{{tweet|evilseph|207996349088673792}}</ref>
: 修复了加载含有中继器的区块时，中继器有时会被卡住的漏洞。<ref>{{tweet|dinnerbone|207933814641659905}}</ref>
: 现在除非玩家按了聊天键，否则搜索页不会自动打开。这允许玩家可以使用背包键关闭背包。
: 修复了使用一叠铁桶挤奶时它们会消失的漏洞。</onlyinclude>
