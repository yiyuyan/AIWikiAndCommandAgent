设置或查询游戏规则。

== 语法 ==
* '''Java版'''
: {{cd|-{}-gamerule <''规则名称''> [<value>]}}
:: 规则参数在Java版中区分大小写。

* '''基岩版'''
: {{cd|gamerule}}
: {{cd|gamerule <rule: BoolGameRule> [value: Boolean]}}
: {{cd|gamerule <rule: IntGameRule> [value: int]}}
: {{cd|gamerule [[游戏规则/playerWaypoints|playerWaypoints]] <value: playerwaypointsValues>}}
:: 规则参数在基岩版中输入时不区分大小写。本wiki通常采用小驼峰命名，以便理解含义。

== 参数 ==
{{see also|游戏规则#游戏规则列表}}

{{el|je|short=1}}：{{argument|-{}-''规则名称''}}<br>
{{el|be|short=1}}：{{argument|be=1|rule: BoolGameRule|enum}}或{{argument|be=1|rule: IntGameRule|enum}}
: 指定要设置或查询的游戏规则。只有某些预设的游戏规则会影响游戏玩法（见[[游戏规则#游戏规则列表|预设游戏规则]]）。

{{el|je|short=1}}：{{argument|value}}<br>
{{el|be|short=1}}：{{argument|be=1|value: Boolean|enum}}或{{argument|be=1|value: int|int}}
: 指定游戏规则设置的值。

{{el|be|short=1}}：{{argument|be=1|value: playerwaypointsValues|enum}}
: 指定游戏规则[[游戏规则/playerWaypoints|playerWaypoints]]设置的值，必须为以下其中之一：
:* {{cd|off}} — 玩家不会在定位栏上显示。
:* {{cd|everyone}} — 所有玩家均会在定位栏上显示。

== 示例 ==
* 禁止玩家互相攻击：{{cd|gamerule pvp false}}

=== Java版 ===
* 停止昼夜更替：{{cd|gamerule advance_time false}}
* 停止自然恢复生命值：{{cd|gamerule natural_health_regeneration false}}
* 禁止破坏性生物行为（如苦力怕、恶魂等生物炸毁方块）：{{cd|gamerule mob_griefing false}}
* 在玩家死亡时保留物品栏：{{cd|gamerule keep_inventory true}}
* 禁止TNT爆炸：{{cd|gamerule tnt_explodes false}}
* 屏蔽命令方块执行成功后在控制台显示的文本内容：{{cd|gamerule command_block_output false}}
* 设置一格内最大实体堆叠数量为100：{{cd|gamerule max_entity_cramming 100}}
* 设置玩家重生半径为25格：{{cd|gamerule respawn_radius 25}}
* 禁用聊天框命令反馈：{{cd|gamerule send_command_feedback false}}

=== 基岩版 ===
* 列出所有游戏规则：{{cd|gamerule}}
* 停止昼夜更替：{{cd|gamerule doDaylightCycle false}}
* 停止自然恢复生命值：{{cd|gamerule naturalRegeneration false}}
* 禁止破坏性生物行为（如苦力怕、恶魂等生物炸毁方块）：{{cd|gamerule mobGriefing false}}
* 在玩家死亡时保留物品栏：{{cd|gamerule keepInventory true}}
* 禁止TNT爆炸：{{cd|gamerule tntExplodes false}}
* 屏蔽命令方块执行成功后在控制台显示的文本内容：{{cd|gamerule commandBlockOutput false}}
* 设置玩家重生半径为25格：{{cd|gamerule spawnRadius 25}}
* 禁用聊天框命令反馈：{{cd|gamerule sendCommandFeedback false}}
