清除玩家的重生点。

== 语法 ==
: <code>clearspawnpoint [player: target]</code>

== 参数 ==
{{argument|be=1|player: target|CommandSelector<Player>}}
: 指定被删除出生点的玩家。如果没有指定，默认为命令执行者。
: {{arg desc|be=player}}

{{Result table|参数未正确指定||unparseable}}

{{Result table|{{cd|player: target}}未指定且该命令执行者不是一个玩家}}

* 删除半径5格内的所有玩家的出生点：<code>/clearspawnpoint @a[r=5]</code>
