'''雕纹硫黄（Chiseled Sulfur）'''是[[硫黄]]制作的装饰性方块，每个面都有一个类似[[硫磺史萊姆|硫方怪]]的图案。

== 生成 ==
雕纹硫黄不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|B2=Sulfur Slab
|B3=Sulfur Slab
|Output=Chiseled Sulfur
|type=Building block
}}

=== 切石 ===
{{stonecutting
|Sulfur
|Chiseled Sulfur
}}

== 破坏 ==
挖掘雕纹硫黄的合适工具是镐。雕纹硫黄需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

雕纹硫黄被破坏后会掉落自身。

== 用途 ==
雕纹硫黄目前仅用于装饰。
