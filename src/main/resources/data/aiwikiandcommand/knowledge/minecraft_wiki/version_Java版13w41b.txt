'''13w41b'''是[[Java版1.7.2]]的第11个快照，发布于2013年10月11日<ref>{{cite|url=http://mojang.com/2013/10/minecraft-snapshot-13w41a/|archive-url=1|archive=1|archive-time=20140122053110|title=Minecraft snapshot 13w41b (Updated!)|author=Dinnerbone|website=Mojang.com|date=Oct 10, 2013}}</ref>，以修复[[13w41a]]里的漏洞和崩溃。

== 修复 ==
{{fixes|fixedin=13w41b|prefix=Minecraft|showdesc=1
|;old
|14865|地毯不可燃。
|;dev
|29588|部分生物群系会使游戏崩溃：<code>java.lang.NullPointerException – Invalid biome id</code>.
|30811|无法使用{{keys|tab}}键补全{{cmd|tellraw|link=none}}的参数。
|;previous
|34641|暂停游戏功能失效。
|34642|白色染色玻璃板的英文“White Stained Glass Pane Pane”中有错别字。
|34679|使用染色玻璃只能合成6个对应颜色的染色玻璃板而不是16个。
|34705|登录服务器时会{{tr|抛出|丟擲|投擲}}空指针异常。
|34645|最大渲染距离仅为8个区块。
|34647|启用资源包会导致游戏崩溃：<code>java.lang.NullPointerException</code>。
|34650|某些实体的碰撞会使游戏崩溃：<code>java.lang.NullPointerException</code>。
|34676|铁栏杆的渲染异常。
}}

== 重新上传 ==
* 13w41b于2013年10月11日晚些时候重新上传以修复一个有关服务器图标的漏洞。<ref>{{tweet|Dinnerbone|388686645295595520}}</ref></onlyinclude>

== 你知道吗 ==
* 此版本与[[13w41a]]的协议版本相同，但不相互兼容。
* 此版本曾经在[[启动器]]中移除，但在2018年9月重新加入。
* 该版本的宣传截图中出现了[[Grum]]的Minecraft皮肤。
