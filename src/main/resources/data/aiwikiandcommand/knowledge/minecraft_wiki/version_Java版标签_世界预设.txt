'''世界预设标签（World Preset Tags）'''是[[世界预设]]的组合。

{{TOC|right}}

== 使用 ==
世界预设标签不可被主动调用，它们被游戏用来控制[[创建新的世界|创建世界屏幕]]上可供选择的世界预设。

== 標籤清單 ==
{{tag list|mode=missing|worldgen/world_preset}}<!--自动检查缺失的模板，请勿移除-->

=== extended ===
* 按住{{key|Alt}}键时，在“{{tp|createWorld.tab.world.title}}”按钮中展示的世界预设。

{{tag list|worldgen/world_preset|extended}}

=== normal ===
* 默认情况下，在“{{tp|createWorld.tab.world.title}}”按钮中展示的世界预设。

{{tag list|worldgen/world_preset|normal}}
