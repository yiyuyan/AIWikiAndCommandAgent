'''13w42b'''是[[Java版1.7.2]]的第13个快照，发布于2013年10月18日<ref>{{cite|url=http://mojang.com/2013/10/minecraft-snapshot-13w42a/|archive-url=1|archive=1|title=Minecraft snapshot 13w42b (Updated!)|author=Dinnerbone|website=Mojang.com|date=Oct 17, 2013}}</ref>，加入了一个新的选项，并修复了[[13w42a]]里的漏洞和崩溃。

== 新内容 ==
=== 常规 ===
'''[[选项]]'''
* “强制使用Unicode字体”按钮被加入到语言选项中。
** 允许改变Unicode字体是否被强制用于文本上。

== 更改 ==
'''[[选项]]'''
* {{filename|ascii.png}}代码页437字体的前32个字符被替换以支持更多的语言而不需要更换字体。
