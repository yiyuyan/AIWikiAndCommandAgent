管理和运行[[游戏测试]]。

== 语法 ==
: <code>test (clearall [<radius>]|clearthat|clearthese)</code>
:: 清除测试的结构和方块。
: <code>test create <id> [<width>] [<height> <depth>]</code>
:: 创建测试。
: <code>test locate <tests></code>
:: 在已加载区块中寻找测试的位置。
: <code>test pos [<nowiki><var></nowiki>]</code>
:: 在半径250格内寻找并显示准星所指方向10格内第一个方块处对于测试的局部坐标。
: <code>test (resetclosest|resetthat|reseetthese)</code>
:: 重置测试结构。
: <code>test run <tests> [<numberOfTimes>] [<untilFailed>] [<rotationSteps>] [<testsPerRow>]</code>
: <code>test (runclosest|runthat|runthese) [<numberOfTimes>] [<untilFailed>]</code>
: <code>test runmultiple <tests> [<amount>]</code>
:: 运行一个或多个测试。
: <code>test runfailed [<numberOfTimes>] [<untilFailed>] [<rotationSteps>] [<testsPerRow>]</code>
: <code>test runfailed [<onlyRequiredTests>] [<numberOfTimes>]</code>
:: 运行已失败的测试。
: <code>test stop</code>
:: 停止所有测试。
: <code>test verify <tests></code>
:: 验证测试。
: <code>test (export <test>|exportclosest|exportthat|exportthese)</code>
:: 导出测试结构。仅在[[wzh:集成开发环境|IDE]]中可用。

== 参数 ==
{{cd|clearall}}
: 对指定半径内的所有测试进行清除。

{{cd|d=pretty|resetclosest|runclosest|exportclosest}}
: 分别对半径15格内最近的测试进行重置、运行和导出。

{{cd|d=pretty|clearthat|resetthat|runthat|exportthat}}
: 分别对准星所指处的测试进行清除、重置、运行和导出。

{{cd|d=pretty|clearthese|resetthese|runthese|exportthese}}
: 分别对半径250格内所有的测试进行清除、重置、运行和导出。

{{argument|radius|integer}}
: 指定清除的半径。默认为250。
: {{arg desc|je=integer}}

{{argument|id|resource_location}}
: 指定测试的ID。
: {{arg desc|je=resource_location}}

{{argument|width|integer}}
: 指定测试结构的宽度。默认为5。
: {{arg desc|je=integer}}

{{argument|height|integer}}
: 指定测试结构的高度。默认为{{cd|<width>}}的值。
: {{arg desc|je=integer}}

{{argument|depth|integer}}
: 指定测试结构的深度。默认为{{cd|<width>}}的值。
: {{arg desc|je=integer}}

{{argument|tests|resource_selector}}
: 指定测试的ID。
: {{arg desc|je=resource_selector|registry=test_instance}}

{{argument|var|string}}
: 指定复制代码段中使用的变量名。默认为{{cd|pos}}。
: {{arg desc|je=string|type=word}}

{{argument|numberOfTimes|integer}}
: 指定每个测试在不同批次内的重复次数。默认为1。
: {{arg desc|je=integer}}

{{argument|untilFailed|bool}}
: 指定测试是否应该在一次迭代失败后立即停止。默认为{{samp|false}}。
: {{arg desc|je=bool}}

{{argument|rotationSteps|integer}}
: 指定测试的额外90度旋转步数。默认为0。
: {{arg desc|je=integer}}

{{argument|testsPerRow|integer}}
: 指定在网格布局中每行放置的测试数量。默认为8。
: {{arg desc|je=integer}}

{{argument|amount|integer}}
: 指定每个测试在同一批次内的重复次数。默认为1。
: {{arg desc|je=integer}}

{{argument|onlyRequiredTests|bool}}
: 指定是否仅需必要测试。默认为{{samp|false}}。
: {{arg desc|je=bool}}

{{argument|test|resource}}
: 指定测试的ID。
: {{arg desc|je=resource|registry=minecraft:test_instance}}
