'''1.14.1-pre1'''是[[Java版1.14.1]]的首个预发布版，发布于2019年5月7日<ref>{{article|minecraft-1-14-1-pre-release-1|Minecraft 1.14.1 Pre-Release 1|May 7, 2019}}</ref>，加入了新的闪烁标语，并修复了一些漏洞。

== 新内容 ==
=== 常规 ===
'''[[控制]]'''
* 在按住{{key|F3}}时按下{{key|Esc}}会暂停游戏，并不会打开暂停菜单。

'''[[闪烁标语]]'''
* 加入“Awesome game design right there!（精彩的游戏设计就在那里！）”

== 更改 ==
=== 物品 ===
'''[[皮革马铠]]'''
* 根据[[纹理更新]]更改了纹理。
'''[[铁马铠]]'''
* 微调了颜色。

=== 世界生成 ===
'''[[村庄]]'''
* 许多结构为了改进光照而有所更改。
