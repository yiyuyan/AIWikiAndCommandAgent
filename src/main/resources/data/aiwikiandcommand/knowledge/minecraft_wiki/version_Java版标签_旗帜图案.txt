'''旗帜图案标签（Banner Pattern Tags）'''是旗帜图案的组合。

{{TOC|right}}

== 使用 ==
旗帜图案标签用于控制[[织布机]]可绘制的图案。

对于旗帜图案物品而言，这些标签也是它们[[数据组件#provides_banner_patterns|<code>provides_banner_patterns</code>]]组件的默认值。
