'''15w36b'''是[[Java版1.9]]的第20个快照，发布于2015年9月2日<ref>{{cite|url=http://mojang.com/2015/09/minecraft-snapshot-15w36a/|archive-url=1|archive=1|title=Minecraft 1.9 snapshot 15w36d|author=Dinnerbone|website=Mojang.com|date=Sep 2, 2015}}</ref>，补全了鸡蛋和雪球落地时的粒子，并修复了[[15w36a]]中的漏洞与崩溃。

== 更改 ==
=== 物品 ===
'''[[雪球]]'''
* 扔出后落地会产生相应粒子。

'''[[鸡蛋]]'''
* 扔出后落地会产生相应粒子。
