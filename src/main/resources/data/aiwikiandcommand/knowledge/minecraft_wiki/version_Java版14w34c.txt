'''14w34c'''是[[Java版1.8]]的第51个快照，发布于2014年8月19日<ref>{{cite|url=http://mojang.com/2014/08/minecraft-snapshot-14w34a/|archive-url=1|archive=1|title=Minecraft snapshot 14w34d|author=Dinnerbone|website=Mojang.com|date=Aug 18, 2014}}</ref>，修复了一些漏洞和[[14w34a]]和[[14w34b]]的崩溃问题。

== 更改 ==
=== 常规 ===
'''[[虚空迷雾]]'''
* 移除了虚空迷雾<ref>{{tweet|TheMogMiner|501766046681153536}}</ref>和虚空[[粒子]]。
