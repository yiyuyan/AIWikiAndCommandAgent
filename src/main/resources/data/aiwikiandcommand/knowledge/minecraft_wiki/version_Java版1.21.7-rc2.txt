'''1.21.7-rc2'''是[[Java版1.21.7]]的第2个，也是最后一个发布候选版本，发布于2025年6月26日<ref>{{article|minecraft-1-21-7-release-candidate-2|Minecraft 1.21.7 Release Candidate 2|Jun 26, 2025}}</ref>，修复了一些漏洞。

== 更改 ==
=== 常规 ===
'''[[数据包]]'''
* 将数据包版本号更改为{{cd|81}}。

'''[[资源包]]'''
* 将资源包版本号更改为{{cd|64}}。

== 修复 ==
{{fixes|fixedin=1.21.7 Release Candidate 2|showdesc=1|new=1
|;1.21.6的漏洞
|298879|在某些使用AMD显卡的设备上，游戏在启动时崩溃。
|299110|强制升级不会在被转换的数据中写入新的<code>DataVersion</code>。
|299126|某些生物骑乘海龟时服务端崩溃。
|;prev
|299130|1.21.7-rc1中发生了破坏性更改，但包格式没有增长。
