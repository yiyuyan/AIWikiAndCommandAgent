'''14w21b'''是[[Java版1.8]]的第26个快照，发布于2014年5月22日<ref>{{cite|url=http://mojang.com/2014/05/minecraft-snapshot-14w21a/|archive-url=1|archive=1|title=Minecraft snapshot 14w21b|author=Dinnerbone|website=Mojang.com|date=May 22, 2014}}</ref>，用于修复[[14w21a]]中有关物品展示框的崩溃问题。

== 修复 ==
{{fixes|fixedin=14w21b|prefix=Minecraft|showdesc=1
|;old
|78|村民挤进一栋建筑。
|3668|带有（药水）效果时通过下界传送门，动画效果（粒子、火焰、可见度和额外的心）会不显示。
|5612|玩家隐身时，生物仍然会朝玩家看。
|11023|正在收回的活塞臂的光照显示不正确。
|36103|在一个下界传送门前观看另一个下界传送门，另外一个的下界传送门方块不可见。
|41234|使用{{cmd|summon LeashKnot ...|link=none}}生成的拴绳结总是生成在坐标为0,0,0的地方。
|42312|命令方块的范围有不明显的误差。
|44039|被隐藏的披风在通过传送门时重新出现。
|51970|玩家在床外面睡觉。
|55529|Realm服务器在从小游戏切换到普通世界时崩溃。
|56363|记分项的自动补全名称崩溃。
|;dev
|49110|发射到某些方块中时，箭矢的<code>inGround</code>NBT标签不会更新。
|49361|牵引马匹的拴绳不能被正确的系到栅栏上的绳结上。
|50528|克隆含有可腐烂叶子的树时，会导致被复制的树上的叶子的数据值被更改。
|50698|生成物品会造成FPS大幅下降。
|50904|末影人的奇怪动作。
|51080|末影螨忽略<code>PersistenceRequired</code>标签。
|54228|在世界边界外死亡后，会在Y{{=}}256处复活。
|54858|当黏液块或活塞向侧面推动时，可以造成0.5的窒息伤害。
|54864|旁观模式为默认的游戏模式时，会导致游戏在世界列表中发射崩溃。
|55333|<code>selector</code>在命令{{cmd|tellraw|link=none}}和{{cmd|title|link=none}}的参数<code>translate</code>中不可用。
|;previous
|55627|<code>Hopper: java.lang.IllegalArgumentException: Duplicate id value for 3!</code>，放置物品展示框时游戏崩溃。
