'''世界加载屏幕（Loading World Screen）'''是生成或加载[[世界]]时显示的屏幕，显示了世界加载的进度。

== Java版 ==
[[File:Chunk colormap.gif|thumb|使用“0”为种子时生成的区块颜色图]]

{{in|Java}}世界加载屏幕显示了一张'''颜色图'''和上方的世界加载进度条。颜色图可视化地显示了玩家周围区块的状态。区块加载时，其中的彩色像素点不断变色并扩展。每个像素点都代表着一个区块，其颜色显示了区块的状态。

== 基岩版 ==
{{filetr|Bedrock Loading Screen.png|alt=|thumb|基岩版的加载屏幕}}
{{filetr|Bedrock Loading Screen Modified_World.png|thumb|启用了行为包的世界的加载屏幕}}
{{in|bedrock}}世界加载屏幕以[[菜单屏幕]]背景全景图为背景，徽标下方的白色区域会显示带有加载动画的“{{tr|正在加载…|正在載入 …}}”文本，若启用了[[行为包]]则会变为“{{tr|改造后的世界|已改造的世界}}”；黑色区域顶部会显示[[加载提示]]，黑色区域底部会显示一个[[经验]]进度条表示加载进度。进度条加载完毕后，加载提示和进度条消失。若游戏模式为[[生存模式]]或[[创造模式]]，则黑色区域顶部会短暂显示玩家的游戏模式；若为创建新的世界时无法选择的模式，则会短暂显示“{{tr|出发吧！|我們開始吧！}}”文本。
{{-}}

== 原主机版 ==
[[File:Loading Screen Legacy Console Edition.png|alt=|thumb|原主机版的加载屏幕]]
{{in|console|nocat=1}}世界加载屏幕以[[菜单屏幕]]背景全景图为背景，在其上显示一个纯绿进度条以及一些文字，屏幕底部也会显示[[加载提示]]。
{{-}}
