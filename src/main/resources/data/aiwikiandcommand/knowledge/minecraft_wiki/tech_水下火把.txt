'''水下火把（Underwater torches）'''是一种可以在水下发[[光]]的非固体[[方块]]。

== 生成 ==
水下火把不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|B2= Magnesium
|B3= Torch
|Output= Underwater Torch
|type= Decoration block
|description={{only|be|education}}
}}

== 破坏 ==
水下火把被挖掘时会立刻被破坏。

{{Breaking table|only=be}}

水下火把被破坏后会掉落自身。

== 用途 ==
{{see also|火把#用途}}
水下火把必须放置于方块[[方块支撑形状|中心完整]]的上表面上方或方块完整的侧面，不过有个别的需要{{ctrl|潜行}}放置，详情见下文表格。

当水下火把所附着的方块变得不可附着（被移动、破坏、替换等）时，水下火把会立即掉落。

如果在[[沙子]]或[[沙砾]]这种受重力影响的方块正下方有一个水下火把，它将不会下落。如果它下落到水下火把的位置，它将被破坏。

不同于[[火把]]，水下火把可以[[含水]]。

水下火把会不时发出与普通火把不同的白色粒子。

=== 光源 ===
水下火把发出亮度为14的[[光]]。水下火把能融化[[曼哈顿距离]]2格内的[[雪]]和[[冰]]。

== 你知道吗 ==
* 现实中如果要在水下点燃物品一般不会使用镁。镁确实可以和热的水剧烈反应，而且不需要氧气，但将点燃的镁放入水中，火依然会快速熄灭，因为水的比热容大，吸热快速。
