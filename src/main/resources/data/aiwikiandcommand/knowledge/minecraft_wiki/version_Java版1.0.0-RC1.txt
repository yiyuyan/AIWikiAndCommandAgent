'''1.0.0-rc1'''是[[Java版1.0.0]]的首个发布候选版本，发布于2011年11月13日，加入了新的音效和新的[[闪烁标语]]，并修复了一些漏洞。

== 新内容 ==
=== 常规 ===
'''[[音效]]'''
* 玩家：
** 玩家受伤时的音效变成了无性别的骨头碎裂声。
** 吃和喝东西时有了声音。
* 生物：
** [[烈焰人]]有了呼吸声。
** [[末影人]]会发出奇怪的低语声和咕噜声。
*** 在它们传送时，它们的声音像下界传送门的缩短版声音。
** [[岩浆怪]]现在会发出声音。
** [[蠹虫]]现在会发出声音。
* 玩家和所有生物受到坠落伤害时都会发出同样的骨头碎裂声。
* [[箭]]落地时更清晰的声音。
* [[工具]]和[[盔甲]]现在会发出破裂的声音，并且有了破裂时的动画。

'''[[主菜单]]'''
* 加入了28个新的[[闪烁标语]]并更改了原有的8个。

== 更改 ==
=== 方块 ===
'''[[红石线]]'''
* 更改了单个红石线的形状，由“+”变为“•”。

=== 物品 ===
'''[[弓]]'''
* 现在有了耐久度，最多可使用385次。
* 现在在[[创造模式]]下不需要箭就能发射。

'''[[鸡蛋]]'''
* [[掷出的鸡蛋]]现在有概率生成[[鸡|幼年鸡]]。

=== 常规 ===
'''[[主菜单]]'''
* “退出游戏”按钮现在总是出现，忽略游戏的启动方式。

== 修复 ==
; 修复了7个漏洞
: 修复了物品栏中方块右侧的阴影漏洞，回到了Beta 1.7的样子。
: 修复了Beta 1.9-pre6中木门的漏洞。
: 修复了在使用32位Java时开启远渲染距离出现的警告会与“粒子”选项重叠漏洞。
: 修复了Beta 1.9-pre6中播放完胜利屏幕后玩家的经验等级会被清零的漏洞。
: 制作人员名单里面Scaevolus和Hippoplatimus名字现在使用的是他们的全名。
: 现在在多人游戏中，玩家可以在进入下界传送门过程中说话了。
: 黑曜石的挖掘时间从Beta 1.9-pre6的大约3秒增加到8秒。</onlyinclude>
