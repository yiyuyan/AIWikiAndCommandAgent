'''15w35b'''是[[Java版1.9]]的第15个快照，发布于2015年8月24日<ref>{{cite|url=http://mojang.com/2015/08/minecraft-snapshot-15w35a/|archive-url=1|archive=1|title=Minecraft 1.9 snapshot 15w35e|author=Dinnerbone|website=Mojang.com|date=Aug 24, 2015}}</ref>，修复了[[15w35a]]中僵尸AI的问题，并修复了一些漏洞。

== 更改 ==
=== 生物 ===
'''[[僵尸]]'''
* 修复了僵尸无AI的问题。<ref>{{bug|MC-87193|||Fixed}}</ref><ref>{{tweet|Dinnerbone|635839698481598464}}</ref>
** [[15w35a]]中生成的僵尸仍然无AI。
