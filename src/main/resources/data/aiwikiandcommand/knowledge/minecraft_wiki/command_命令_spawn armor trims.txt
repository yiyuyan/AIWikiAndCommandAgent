生成整齐排列的[[盔甲架]]，用于展示各种[[盔甲]]{{note|仅包括人形生物可穿戴的装备，即所有头盔、所有胸甲、所有护腿、所有靴子和鞘翅，动物的装备不在此列。}}不同锻造原材料时的[[盔甲纹饰]]。

== 语法 ==
: <code>spawn_armor_trims *_lag_my_game</code>
:: 展示所有盔甲纹饰图案。
: <code>spawn_armor_trims <pattern></code>
:: 展示一种盔甲纹饰图案。
