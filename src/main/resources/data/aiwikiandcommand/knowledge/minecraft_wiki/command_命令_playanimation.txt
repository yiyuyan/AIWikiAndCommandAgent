在一个或多个实体上播放一次性[[动画]]。

== 语法 ==
:<code>playanimation <entity: target> <animation: string> [next_state: string] [blend_out_time: float] [stop_expression: string] [controller: string]</code>

== 参数 ==
{{argument|be=1|entity: target|CommandSelector<Actor>}}
: 指定目标。
: {{arg desc|be=CommandSelector<Actor>}}

{{argument|be=1|animation: string|basic_string}}
: 指定动画。
: 由{{filepath|<''资源包''>/entity/<''实体名称''>.entity.json}}文件内<code>"minecraft:client_entity"."animations"</code>的参数定义。
: {{arg desc|be=basic_string}}

{{argument|be=1|next_state: string|basic_string}}
: 指定动画播放完毕后的状态。
: 由{{filepath|<''资源包''>/animation_controllers/<''控制器''>.json}}文件内<code>-{}-"animation_controllers"."<''控制器名称''>"."states"</code>的参数定义。
: {{arg desc|be=basic_string}}

{{argument|be=1|blend_out_time: float|float}}
: 指定动画渐变的持续时间。
: {{arg desc|be=float}}

{{argument|be=1|stop_expression: string|basic_string}}
: 指定动画播放终止的条件。
: 应为[[基岩版Molang文档|Molang表达式]]。{{info needed}}
: {{arg desc|be=basic_string}}

{{argument|be=1|controller: string|basic_string}}
: 指定动画控制器。
: 由{{filepath|<''资源包''>/entity/<''实体名称''>.entity.json}}文件内<code>"minecraft:client_entity"."render_controllers"</code>的参数定义。
: {{arg desc|be=basic_string}}

== 示例 ==
* <code>/playanimation @p animation.player.attack.rotations none 1 "v.attack_body_rot_y=180;"</code>
** 将最近玩家的身体翻转180度。
* <code>/playanimation @p animation.armor_stand.riposte_pose</code>
** 使最近的玩家开始盔甲架回刺反击动作的动画。
