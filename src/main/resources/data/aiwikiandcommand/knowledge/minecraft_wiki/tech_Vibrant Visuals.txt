'''{{pa}}{{tr|（Vibrant Visuals）||}}'''<ref name="vv"/>是一种高级图形模式，允许游戏使用默认或第三方资源包提升画面表现。

== 介绍 ==
{{pa}}允许游戏通过资源包提供如定向光源、阴影、反射和PBR<ref group="注">即“基于物理的渲染（'''P'''hysically '''B'''ased '''R'''endering）”。</ref>纹理等功能的支持。启用时默认使用游戏内置资源包，玩家也可以通过添加其他第三方{{pa}}资源包来获得不同的视觉效果。

{{pa}}仅影响客户端的画面表现，不影响游戏的玩法和服务端计算。<ref>{{Citation|url=https://www.linkedin.com/posts/adrien-givry_minecraft-live-march-2025-vibrant-visuals-activity-7309393437089243136-TnuB/?rcm=ACoAADdy8wsBcTksodH13v_sRKlptiHH1ZyFhRI|title=Happy (and proud) to finally share what I’ve been working on with SkyBox Labs and Microsoft! Minecraft: Bedrock Edition is looking better than ever!|author=Adrien Givry|website=LinkedIn|date=March 22, 2025}}</ref>

== 特色功能 ==
=== 水 ===
[[File:BE vibrant visuals water reflections.jpeg|thumb|水面的反射效果]]
[[File:BE vibrant visuals underwater with caustics.jpeg|thumb|水下的散射和焦散效果]]
水面使用屏幕空间反射（SSR<ref group="注">即“'''S'''creen '''S'''pace '''R'''eflection”。</ref>）来反射周围的环境。水面还会反射部分光源和[[云]]。

阳光、月光和末地闪光照射到水下的方块和实体时其表面上会出现焦散效果。

=== PBR纹理 ===
游戏通过访问PBR纹理（根据所存储的参数名称，亦称为'''MERS'''纹理）获取额外参数用于渲染：
* R通道存储'''金属度'''（'''M'''etalness），0为非金属、255为完全金属。
* G通道存储'''自发光值'''（'''E'''missive），0为完全不发光、255为最大发光。
* B通道存储'''粗糙度'''（'''R'''oughness），0为完全平滑、255为完全粗糙。
* A通道存储'''次表面散射值'''（'''S'''ubsurface scattering）。

金属度和次表面散射值'''互斥'''。游戏会使用两者中较大的值，并将较小的值视为0。如果两者大小相同，游戏会使用后者。

==== 光照反射 ====
通过PBR纹理提供的金属度和粗糙度为方块和实体（如[[铁块]]）的表面计算光照反射，使得它们对光线有不同的反射程度或效果。

==== 自发光 ====
[[File:BE vibrant visuals drowned.jpeg|thumb|发光的[[溺尸]]]]
通过PBR纹理提供的自发光值为方块、实体和粒子（如[[幽匿块]]和[[蜘蛛]]）提供在黑暗中发光的效果，使得它们即使处于完全黑暗的环境中也能被看见。此效果不会照亮周围的环境。

==== 次表面散射 ====
通过PBR纹理提供的次表面散射值为方块和实体（如[[草丛]]）计算内部的光线散射，使得它们接近光的部分略显透明。

=== 体积雾 ===
[[File:BE vibrant visuals swampland.jpeg|thumb|沼泽绿色的雾气]]
阳光、月光和末地闪光被方块遮挡时会产生[[wzh:廷得耳效應|丁达尔现象]]，分散出数道光柱。

玩家处于部分生物群系中时天空会出现不同程度和颜色的雾。比如，[[沼泽]]中充满了蒙蒙的绿雾；[[蘑菇岛]]的整体环境都轻微发紫；在[[苍白之园]]中时，天空会完全被浓雾覆盖住，光线也会减弱。

=== 定向光源和阴影 ===
[[File:BE_vibrant_visuals_end_flash.jpeg|thumb|末地闪光的效果]]
阳光、月光和[[末地闪光]]会产生阴影，阴影的方向会随光源的位置而变化。与大多数现有着色器中的阴影不同，使用默认资源包时阴影会与方块的像素对齐。光线穿过建筑中的玻璃和部分透明方块时会更明显。

光线和阴影只影响视觉效果，不影响[[光照等级]]的计算。

阳光和月光不会照亮光照等级为0的位置。<ref>{{bug|MCPE-217248|||WAI}}</ref>

在[[末地]]维度中，天空会不时在某个地方出现紫色的闪光，它会用紫色的光照亮末地并产生阴影，且发出独特的音效。{{tr|可访问性|協助工具}}设置中的“隐藏天空闪光”选项可用于控制是否显示末地闪光。

在[[下界]]维度中，红色的光照亮了基岩层上方，但天空是完全黑暗的，也不会产生阴影。

[[File:Vibrant_Visuals_point_lights_comparison.png|thumb|启用点光源与未启用点光源画面的对比（上：未启用点光源 下：启用点光源）]]
若在[[实验性玩法]]中启用了“{{tr|为创建者提供的渲染龙功能|為創作者提供的渲染龍功能}}”并在“{{tr|灵动视效选项|絢麗視覺選項}}”中启用了“点光源”和“点光源阴影”，则部分其他光源发出的光也会产生阴影，一些光源还会发出彩色的光。如果启用了“体积雾”，它们的光也会产生[[wzh:廷得耳效應|{{tr|丁达尔效应|廷得耳效應}}]]。

=== 泛光 ===
物品和方块发出的光会轻微向外扩散，使它们在视觉效果上显得更亮。

=== 色调 ===
游戏画面的整体颜色会根据玩家所在的生物群系的温度和特征而轻微改变。在温度较高的生物群系中偏暖，在温度较低的生物群系中偏冷。

== 使用方式 ==
{{pa}}在部分[[#设备支持|支持的设备]]上为默认图形模式。

在主菜单将{{tr|视频|視訊}}设置中的“{{tr|图像模式|圖形模式}}”切换为“{{tr|灵动视效|絢麗視覺}}”即可使用{{pa}}。
* 若在{{tr|视频|視訊}}设置中启用了“{{tr|允许游戏内图形模式切换|允許在遊戲中切換圖形模式}}”选项，则也可以在世界中切换。

{{pa}}的部分视觉效果可以在视频设置中调整，另一部分视觉效果需要使用{{pa}}资源包调整。

因为光线追踪资源包所需资源是{{pa}}资源包的一部分，其也可以用于激活{{pa}}。

{{pa}}无法在[[分屏|分屏游戏]]时使用。若在使用{{pa}}时进入分屏游戏，游戏会自动将{{tr|图像模式|圖形模式}}切换回“{{tr|简约|簡單}}”或“{{tr|花式|華麗}}”。<ref>{{cite|url=https://www.minecraft.net/article/chase-the-skies-coming|title=Our next game drop has a name|website=Minecraft.net|date=june 1, 2025|quote='''Splitscreen multiplayer is not supported with Vibrant Visuals''' and the game will switch to Fancy or Simple rendering if multiple players are joined locally.}}</ref>

只有部分来自[[市场]]的世界和纹理包可以与{{pa}}一同使用；而[[行为包]]、[[皮肤]]和角色物件不受影响。类似地，只有[[清单文件]]中指定“pbr”的纹理包才可以与{{pa}}同时使用。

{{pa}}是客户端功能，因此在多人游戏中，玩家只能为自己启用{{pa}}。

服务端可通过{{filename|[[server.properties]]}}中的属性{{cd|disable-client-vibrant-visuals}}控制是否禁止客户端使用{{pa}}。除Mob Maze以外的所有[[精选服务器]]均禁止客户端使用{{pa}}。

== 画面选项 ==
切换“图形模式”至{{pa}}后，{{tr|视频|視訊}}设置中的“亮度”设置会被锁定，“{{tr|能见度{{sic}}|呈現距離}}”会更名为“{{tr|延迟能见度{{sic}}|延遲渲染距離}}”并减少可选择的区块数量（因设备而异），同时在下方的“{{tr|灵动视效选项|絢麗視覺選項}}”中提供以下选项，并提供“{{tr|性能优先|偏好效能}}”和“{{tr|视觉优先|偏好視覺效果}}”2个预设。

== 你知道吗 ==
* {{pa}}并非作为一个独立功能，而是作为Minecraft的一部分加入游戏，且会在之后的游戏更新中持续获得改进。<ref>{{ytl|NTOLOErWN4w|t=3m48s||Minecraft|channelid=@minecraft|June 14, 2025}}</ref>
* 据[[Jasper Boerstra]]所说，{{pa}}没有添加动态光源功能是为了平衡开启了和未开启{{pa}}的玩家之间的游戏体验。<ref>{{ytl|vso1iMwDuDk|t=24m19s||Grian|channelid=@Grian|April 2, 2025}}</ref>
* 尽管{{pa}}目前仅支持部分设备，但[[Mojang]]称可能会在未来添加对更多设备的支持。<ref>{{cite|url=https://www.minecraft.net/article/take-a-vibrant-test-flight|title=Take a vibrant test flight|website=Minecraft.net|date=April 2, 2025|quote=Our team is hard at work testing Vibrant Visuals on even more Minecraft: Bedrock Edition devices, and we hope to be able to update this list of supported devices in the future.}}</ref>
** Mojang还宣称{{pa}}在Java版正式上线时，会尽可能支持所有能够运行Java版的平台和设备。<ref>{{cite|url=https://www.minecraft.net/article/vibrant-visuals-java-edition|title=Vibrant Visuals on Java Edition|website=Minecraft.net|date=April 16, 2025|quote=Our goal is to bring Vibrant Visuals to all Java Edition players, across all supported devices. We are working on a viable solution that works across the Java platforms: Windows, Mac, Linux and are committed to continuing to support these platforms.}}</ref>
** 官方称正在开发Java版的{{Pa}}，但不会与基岩版完全一致。
*** 为此，官方计划在2026年夏季更换现有的Java版渲染API为Vulkan。
* 据Vibrant Vanguard Discord服务器上的问答环节所说，Java版{{pa}}将不会支持彩色光源功能。<ref>{{cite|url=https://discord.com/channels/1362331987666403328/1362335022782087389/1362744378539511931|title=LowSkillCamper在Vibrant Vanguard Discord服务器上的FAQ环节|website=Discord.com|date=April 18, 2025|quote=<br>Q: Colored light?<br>
A: No.}}</ref>
* 在[[基岩版1.21.90.26|1.21.90.26]]后，使用{{pa}}时游戏主菜单的全景图也会随之改变。
* Minecraft.net上的短篇故事系列''[[:en:Overworld Adventures|Overworld Adventures]]''均使用了启用{{pa}}时的插图。
