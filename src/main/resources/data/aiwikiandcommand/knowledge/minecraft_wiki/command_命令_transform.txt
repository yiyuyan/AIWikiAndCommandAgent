控制实体进行[[变身]]。

== 语法 ==
: <code>transform clear</code>
:: 恢复原形。
: <code>transform into <entity> [<nbt>]</code>
:: 变身为指定实体。
: <code>transform into player <player></code>
:: 切换至指定玩家的皮肤。
: <code>transform scale <scale></code>
:: 更改尺寸。

== 参数 ==
{{argument|entity|resource}}
: 指定要变身的实体类型。
: {{arg desc|je=resource|registry=minecraft:entity_type}}

{{argument|nbt|nbt_compound_tag}}
: 指定该实体的[[实体数据格式|NBT]]。
: {{arg desc|je=nbt_compound_tag}}

{{argument|player|game_profile}}
: 指定要切换的玩家。
: {{arg desc|je=game_profile}}

{{argument|scale|float}}
: 指定尺寸。
: {{arg desc|je=float|min=0.1|max=16}}
