'''''RubyDung'''''是在一个未知时间被[[Notch]]制作出来，并一直开发到2009年2月或更早以前的一个游戏。<ref group="注">早期的Minecraft构建中包含了RubyDung的代码库，也同时包含了来自其中的terrain.png文件，这个文件的修改日期为2009年2月。</ref>

除了它是受矮人要塞影响之外没有多少已知信息，且其在早期阶段就被停止了开发。游戏内的纹理被随机上色。其中的[[树]]和[[Minecraft]]中的树不同。游戏中使用的[[草方块]]和[[石头]]最初的纹理后来被用在Minecraft上，这是Notch创造方块风格的游戏的一个灵感，后来实现成为Minecraft。

在Minecraft有一个合适的名字之前，也就是十分早期的pre-Classic版本的Minecraft在内部代码中也被称为“RubyDung”。

Notch本想使''RubyDung''能够拥有第一人称视角的游戏模式，但他测试后认为观感过于模糊和扭曲。在Notch编写''RubyDung''代码后的几天，他玩了一个名为[[无尽矿工]]的游戏，这款游戏给予了他制作Minecraft的灵感来源。

2009年10月30日，Notch在博客谈到''RubyDung''是[{{notch|227922045}} Minecraft的起源]。

== 名字 ==
[[File:rubylands.png|thumb|250px|一张“rubylands”的游戏截图]]
“RubyDung”是名为“'''dung'''eon game in the '''ruby'''lands”游戏的占位符，“rubylands”起源于Notch对一个地下城游戏世界的粗略想象。<ref>{{tweet|notch|1019752622947950592|Dunno if I told anyone this, but that version was called "rubydung", as a placeholder name for a dungeon game in the rubylands rough gameworld i had in my head.|July 18, 2018}}</ref>其于2008年早期由Notch立项并开发。<ref>https://jvm-gaming.org/t/rubylands-teaser-very-alpha/31375</ref><ref>https://web.archive.org/web/20080807172134/http://www.rubylands.com/</ref>

== 创造Minecraft ==
Notch在玩了无尽矿工之后获得了制作Minecraft的灵感。一段时间后，Notch创造了Minecraft。

Minecraft的源代码来自''RubyDung''，因此早期Minecraft的[[Java版pre-Classic|pre-Classic]]版本有“ rd”（'''''R'''uby'''D'''ung''）前缀。

Minecraft的早期版本是无尽矿工（Infiniminer），地下城守护者（Dungeon Keeper）二者与''RubyDung''源代码的混合体。
