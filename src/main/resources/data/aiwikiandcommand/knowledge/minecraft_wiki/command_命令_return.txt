此命令可以被写入一个[[Java版函数|函数]]中，以控制函数执行。它可作为其所在函数的结束点，并设定该函数[[Java版函数#返回|成败标志和返回值]]，函数的成败标志和返回值将会返回值调用此函数的命令，将会作为{{cmd|function}}命令的[[命令/function#输出|输出]]值，或被{{cmd|execute if function ...}}测试。它还可以使得有多个[[命令/execute#执行分支|执行分支]]的{{cmd|execute}}命令在其第一个分支结束。

== 用法 ==
该命令可在函数中使用，使得此函数的执行特定位置停止，与此同时，设定了该函数的'''返回值'''和'''成败标志'''。
* 如果该函数是由{{cmd|function}}命令调用的，那么该函数的返回值和成败标志将传入该{{cmd|function}}命令作为其[[命令/function#输出|输出]]值，以用于使用{{cmd|execute store}}来存储。
* 如果该函数是由{{cmd|execute if function}}调用的，将检查该函数的'''返回值'''是否不是<code>0</code>。

同其他命令一样，若该命令接在{{cmd|execute (if{{!}}unless) ... run}}后或其他可能[[命令/execute#执行分支|执行中断]]的{{cmd|execute}}命令之后，则可能因{{cmd|execute}}的中断而不被执行，故可利用此机制，限制该命令仅在特定条件下执行。这样，函数就可以在不同的条件下（也即在不同的位置）结束，从而实现更复杂的行为。例如，以下是一个模拟条件分支语句的函数：
{{syntaxhighlight|lang=mcfunction|<nowiki>
# 若执行者带有"test1"标签(@s[tag=test1])则执行函数"test1"
execute if entity @s[tag=test1] run return run function test1
# 否则若执行者为玩家(@s[type=player])则执行函数"test2"
execute if entity @s[type=player] run return run function test2
# 若以上皆不满足，执行函数"test3"
return run function test3
</nowiki>}}

如果此命令接在带有多个[[命令/execute#执行分支|分支]]的{{cmd|execute}}命令之后，{{cmd|execute}}命令也会在首次执行该{{cmd|return|link=none}}命令后结束执行，因此只会执行第1个分支。借此可以确保命令仅执行1次，例如：<code>execute as @e[type=zombie] at @s if block ~ ~-1 ~ grass_block run '''return run''' tp @s Steve</code>只会把1只在草方块上的僵尸（若有，即使世界中不止1只）传送到Steve。注意：该命令在函数中也会造成该函数执行到此行后停止。

如果有多个分支的{{cmd|execute}}命令接在此命令之后，{{cmd|execute}}命令同样会在执行首个分支之后结束执行。

<code>return run execute ... run <''command''></code>和<code>execute ... run return run <''command''></code>的唯一区别在于：前者的{{cmd|return|link=none}}命令一定会执行，若{{cmd|execute}}命令执行中断则返回“失败”和<code>0</code>值；而后者的{{cmd|return|link=none}}命令在{{cmd|execute}}命令执行中断时就不会执行了。

如果通过标签调用了多个函数的{{cmd|function}}命令接在此命令之后，整个{{cmd|function}}命令也会在任意一个函数首次执行{{cmd|return|link=none}}命令后结束执行。参见{{cmd|function}}条目。

{{cmd|return|link=none}}命令在函数中被执行时，会设置此函数的成败标志和返回值，并返回到调用此函数的{{cmd|function}}或{{cmd|execute if function ...}}命令中。但是，{{cmd|return|link=none}}命令本身也有[[#输出|输出值]]，若其接在{{cmd|execute store ... run}}命令之后，则在其使得{{cmd|execute}}命令和函数结束执行的同时，该{{cmd|return|link=none}}命令的<code>success</code>或<code>result</code>输出值将被储存在指定位置。直接在命令方块里执行此命令，其成功次数会被命令方块记录。

== 语法 ==
: <code>return <value></code>
:: 结束其所在函数的执行，并设置函数返回值为整型数值<code><value></code>，成败标志为“成功”。
: <code>return fail</code>
:: 结束其所在函数的执行，并设置函数返回值为<code>0</code>，成败标志为“失败”。
: <code>return run <''command''></code>
:: 执行<code><''command''></code>命令后，结束其所在函数的执行，并将其所在函数的'''成败标志'''和'''返回值'''设为<code><command></code>命令的'''<code>success</code>值'''和'''<code>result</code>值'''。若<code><''command''></code>为一个多分支的{{cmd|execute}}，则仅第一个分支命令会被执行。

== 参数 ==
{{argument|value|int|je=1}}
: 一个整数值，将作为其所在[[Java版函数|函数]]的[[Java版函数#返回|返回值]]。
: {{arg desc|je=integer}}

{{argument|command|je=1}}
: 要执行的命令。

上方的表格是{{cmd|return|link=none}}命令本身的输出值。而若在函数中使用，则还会设定了该函数的'''返回值'''和'''成败标志'''。所设置的函数成败标志等于表格中的<code>success</code>输出值，而函数返回值等于表格中的<code>result</code>值。

== 示例 ==
; 示例1：return fail的返回情况
若以下函数被非玩家实体执行，则会在执行完第一条命令后返回（返回值为0，成败标志为<code>false</code>（执行失败）），后续的{{cd|say}}命令将不会被执行。
{{file display|example/function/test1.mcfunction|mcfunction|mode=unwrap|
<syntaxhighlight lang="mcfunction">
execute if entity @s[type=!player] run return fail
say hello
say hi
</syntaxhighlight>}}

; 示例2：return run ...的返回情况
若以下函数被非玩家实体执行，则会在执行完第一条命令后返回（若成功执行{{cd|data get entity @s Pos[0]}}，则返回值为执行实体的{{nbt|double|Pos}}标签值，成败标志为<code>true</code>（执行成功）），不会执行后续的{{cd|tp}}命令。
{{file display|example/function/test2.mcfunction|mcfunction|mode=unwrap|
<syntaxhighlight lang="mcfunction">
execute if entity @s[type=!player] run return run data get entity @s Pos[0]
tp @s ~ ~0.5 ~
</syntaxhighlight>}}

; 示例3：Void函数的特征
以下函数是一个无返回行为的Void函数，无法获取其返回值和成败标识：
{{file display|example/function/test3.mcfunction|mcfunction|mode=unwrap|
<syntaxhighlight lang="mcfunction">
say 1
</syntaxhighlight>}}
在聊天栏执行以下命令后，执行者在test记分项中的分数无任何改变。
<syntaxhighlight lang="mcfunction">
/execute store success score @s test run function example:test3
/execute store result score @s test run function example:test3
</syntaxhighlight>

; 示例4：递归返回
{{file display|example/function/test4.mcfunction|mcfunction|mode=unwrap|
<syntaxhighlight lang="mcfunction">
scoreboard players add foo bar 1
return run function example:test4
</syntaxhighlight>}}
在聊天栏执行以下命令后，foo虚拟实体在bar记分项中的分数将等于最大递归深度32768。而在递归结束后，无法通过{{cd|execute store}}获取返回值和成败标识。
<syntaxhighlight lang="mcfunction">
/execute store result score foo bar function example:test4
</syntaxhighlight>
