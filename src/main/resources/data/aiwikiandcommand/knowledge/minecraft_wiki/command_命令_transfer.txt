将玩家转移到另一个服务器上。

{{in|je}}此命令只会发出转移请求，能否转移成功取决于目标服务器是否接受转移登录，即服务端配置文件中[[服务端配置文件格式#accepts-transfers|{{code|accepts-transfers}}]]属性是否设置为<code>true</code>。

== 语法 ==
* '''Java版'''
: <code>transfer <hostname> [<port>] [<players>]</code>

* '''基岩版'''
: <code>transfer <pfidOrMSA: string> <server: string> <port: int></code>

== 参数 ==
{{el|be|short=1}}：{{argument|be=1|pfidOrMSA: string|basic_string}}
: 要转移的玩家，可以为Microsoft账户名称（玩家名），或PlayFab ID（当玩家加入或断开与服务器的连接时显示）。
: {{arg desc|be=string}}

{{argument|hostname|string|server: string|basic_string}}
: 要连接到的服务器的主机名。
: {{arg desc|je=string|type=phrase|be=string}}

{{argument|port|integer|port: int|int}}
: 要连接到的服务器的端口编号。{{in|java}}若省略则为{{cd|25565}}。
: {{arg desc|je=integer|min=1|max=65535|be=int}}{{in|be}}应在0和65535之间（含）。

{{el|je|short=1}}：{{argument|players|entity}}
: 要转移的玩家，若省略则为执行者玩家。
: {{arg desc|je=entity|type=players|amount=multiple}}

== 示例 ==
* {{in|java}}将自己转移到服务器{{cd|localhost}}的{{cd|1630}}端口上：{{cd|/transfer localhost 1630}}。
* {{in|java}}将Steve转移到服务器{{cd|minecraft.server.example:25565}}：{{cd|/transfer minecraft.server.example 25565 Steve}}。
* {{in|bedrock}}将Steve转移到服务器{{cd|minecraft.server.example:19132}}：{{cd|/transfer Steve minecraft.server.example 19132}}
