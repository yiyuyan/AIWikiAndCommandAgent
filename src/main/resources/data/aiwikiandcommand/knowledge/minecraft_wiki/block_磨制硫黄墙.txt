'''磨制硫黄墙（Polished Sulfur Wall）'''是[[磨制硫黄]]制作的[[墙]]。

== 生成 ==
磨制硫黄墙不会生成在世界中。

== 获取 ==
=== 合成 ===

|B2=Polished Sulfur

|B3=Polished Sulfur
|C3=Polished Sulfur
|Output=Polished Sulfur Wall,6
|type= Decoration block
}}

{{Stonecutting

|Polished Sulfur Wall

== 破坏 ==
挖掘磨制硫黄墙的合适工具是镐。磨制硫黄墙需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

磨制硫黄墙被破坏后会掉落自身。

== 用途 ==
{{main|墙#用途}}
磨制硫黄墙可用于装饰，并有与其他墙相似的特性。
