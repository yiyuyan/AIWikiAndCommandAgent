用于更改玩家的[[迷雾]]效果。

== 用法 ==
不同的迷雾可以使天边交界处（包括水中）发生不同的模糊变化。

每个迷雾ID分别对应一个生物群系中水的颜色，水中的默认视野范围，天边交界处的颜色这3个特点，这其中包括部分未加入游戏的生物群系。

事实上，大部分的迷雾设置都只会影响水中的迷雾，只有下界和末地的生物群系对应的迷雾ID才会影响天边交界处的颜色。

== 语法 ==
: <code>fog <victim: target> push <fogId: string> <userProvidedId: string></code>
: <code>fog <victim: target> <mode: delete> <userProvidedId: string></code>

== 参数 ==
