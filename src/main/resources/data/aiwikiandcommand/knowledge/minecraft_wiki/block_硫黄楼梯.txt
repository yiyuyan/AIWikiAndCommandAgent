'''硫黄楼梯（Sulfur Stairs）'''是[[硫黄]]制作的[[楼梯]]。

== 生成 ==
硫黄楼梯不会生成在世界中。

== 获取 ==
=== 合成 ===

|Output= Sulfur Stairs,4
|type= Building block
}}

{{Stonecutting

|Sulfur Stairs
}}

== 破坏 ==
挖掘硫黄楼梯的合适工具是镐。硫黄楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

硫黄楼梯被破坏后会掉落自身。
