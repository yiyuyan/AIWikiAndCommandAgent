== 常规 ==
; [[附加包]]
* 用于改变游戏方块、物品以及实体的外观。
** 行为包，类似于Java版的数据包。可以添加或更改实体、物品、方块、脚本、生物生成规则等内容。
** [[资源包]]，拥有与Java版相近的用途。可以更改方块纹理；更改粒子纹理与配置；更改实体纹理、模型、动画；更改音效与音乐；更改语言文件。但暂时无法为原版方块添加自定义方块模型。
** 世界模板可以用于从外部导入一个世界。

; [[RenderDragon]]
* 基岩版独有的图形渲染引擎。
* 可以启用延迟渲染功能。
* 兼容Windows绝大多数的现代设备以及Android 9及更高版本的GLES 3.1设备。<ref>https://learn.microsoft.com/en-us/minecraft/creator/documents/deferredlighting?view=minecraft-bedrock-stable</ref>

; 光线追踪和PBR
* 仅在Windows版可用。
* 点击{{key|;}}键可以开启/关闭光线追踪。
* 允许内容创作者使用光线追踪和PBR功能创作。
* 兼容性：
# 显卡：支持DirectX以及实时光线追踪渲染的任何显卡，例如NVIDIA GeForce® RTX 20系列或更高，以及AMD Radeon™ RX 6000系列或更高。
# 操作系统：64位Windows 10操作系统，以及最新的硬件驱动。
# 硬件：仅PC平台可用，不支持VR和混合现实设备。
# CPU：Intel Core® i5或更高。
# 内存：8GB或更高。
# Minecraft版本：1.16.200或更高。

; UI
* 具有两个UI框架：Json UI与[[Ore UI]]。
** Json UI由数据驱动，并且可由资源包自定义；Ore UI暂不支持由资源包定义。
* 两种UI布局：携带版（Pocket）和经典（Classic）。

; 方块选择
* 有两种选择：方块高亮和显示方块轮廓。

; 教育版特性
* 来自{{el|ee}}[[化学更新]]中的特性。

; [[市场]]
* 支付货币[[File:MCoin.png|16px|link=]]Minecoin以购买社区作品。

== 游戏机制 ==
; 方块摆放机制
* 如果玩家距离地面一定高度，玩家面朝斜下方向时，可直接在脚下的方块前面摆放方块，而无需对准脚下方块的侧面再摆放。该特性是为了方便触屏操作的玩家而设计的。
* 如果玩家长按鼠标右键或手柄左扳机，可以朝玩家对应的一个方向连续摆放方块，不会因为视角转向而朝其他方向摆放方块。

; [[魔咒]]
* [[穿刺]]
** 位于雨中或水中的生物都受此影响，而不仅是水生生物。
* [[穿透]]
** 穿透V或更高的等级仍会使射出的箭穿过实体。
* [[激流]]
** 会造成喷溅伤害（可以多次进行）。
* [[锋利]]
** 每等级给予1.25的伤害。

; [[灾厄巡逻队]]
* {{tr|被称为“掠夺者巡逻队”|英文被稱為“Pillager Patrol”|被稱為“掠奪者巡邏隊”}}
* 在简单难度下，巡逻队只会生成亮度等级低于或等于7的地方；而在普通和困难难度下，会无视亮度生成。

; [[袭击]]
* 相比Java版，每波的生物数量有所不同。
* 袭击队长不会生成。
* 村庄里的[[钟]]会自动响起。

; [[状态效果]]
* [[袭击之兆]]
** 获得袭击之兆时会播放动画。
** 更高级别的效果不会影响袭击事件的生物生成。
* [[中毒（致命）]]
** [[鹦鹉]]食用[[曲奇]]后会获得。
** 能够伤害并杀死[[亡灵生物]]（[[凋灵]]除外）或非亡灵生物（[[末影龙]]除外）。
* [[村庄英雄]]
** 获得时会有动画效果。
** 正常获得时等级总为1。
** 村民不会给予玩家礼物。

== 图像 ==
* 与[[Java版]]相比，[[基岩版]]的游戏画质更生动、更流畅。
* [[着火]]的生物带有的火焰动画根据玩家视角而变换角度且燃烧较慢。
* 物理阴影的方向取决于太阳的位置。
* 日出、日落时分，云层会呈现橘红色。
* [[水]]带有平滑光照。
* 发光方块，例如正在工作的熔炉，发光的红石矿石，荧石和熔岩，在它们的四周没有光影。
* 窒息的动画不同。
* 下界传送门的进入动画不同。
* 玩家的着火动画不同。
* 熔岩的动画不同。
* 玩家睡眠动画不同。
* TNT爆炸的粒子效果更加有像素感，因为原有纹理被压缩成一个普通粒子效果的大小。

== 世界生成 ==
; [[埋藏的宝藏]]
* 可以生成在高海拔的[[石岸]]里。

; [[珊瑚礁]]
* 包含了安山岩、花岗岩、闪长岩、失活的珊瑚扇和失活的珊瑚块。
* 使用NBT结构生成。

; [[沙漠神殿]]
* 如果在一个峡谷或河流生成，神殿的地板会被峡谷或河流的底部替换，而不是TNT。
* 如果生成在[[条纹之地]]上，它的地基会高于基岩层，不像在沙漠中那样生成在空气中时不会有一个很高的地基。

; [[冻洋（旧版）]]
* 未使用的生物群系，和冻洋相似但不会生成冰山和兔子。

; [[丛林]]
* 会生成更少的高大丛林树。

; [[雪原]]
* 除[[流浪者]]和伴随[[僵尸马]]一同生成的[[僵尸]]以外的敌对生物不会自然生成。
** [[刷怪笼]]会照常运作。

; [[河流]]
* 除[[溺尸]]以外的敌对生物不会自然生成。

; [[巨型蘑菇]]
* 在沼泽自然生成。

; [[雪屋]]
* 携带着[[浮冰]]生成而不是冰。
* 如果在条纹之地上生成，它将在水下的海底的基岩层生成，替代了一些基岩，并用石砖替代Y=-64的基岩层。

; [[要塞]]
* 图书馆的吊灯使用橡木栅栏而不是桦木栅栏。
* 拥有更大的概率生成于村庄的水井下方，[[末影之眼]]追随终点在村庄时更容易发现要塞位置。
* 每个世界能够产生的要塞数量是随机的，而不是每个世界只有128个。
** 3个要塞生成于以0,0为中心的一环，其他地方要塞随机生成在世界各地。

; [[超平坦世界]]
* 名为'''{{tr|平坦的世界|平地世界}}{{sic}}'''，在[[创建新的世界]]屏幕的“{{tr|高级|進階}}”设置中开启该选项后可以选择超平坦世界预设，默认是“{{tr|经典平坦|經典平地}}”。
* 无法在游戏中自定义世界生成（但仍然可以通过使用外部编辑器在存档的{{filename|[[level.dat]]}}文件里更改<code>FlatWorldLayers</code>以实现自定义）。
* 主世界没有结构和地物生成。

; [[树]]
* 一棵树的树干上可能产生[[藤蔓]]，使它看起来好像垂死一般。
** 这包括由[[树苗]]长出的树。

; [[沼泽小屋]]
* 炼药锅装有随机药水。
** 有概率是喷溅药水。
* 药水装满了{{frac|2|3}}或{{frac|1|3}}。

== 方块和物品 ==
=== 方块 ===
; [[床]]
* 物品栏中显示2D物品模型。

; [[仙人掌]]
* 当一个告示牌放置在仙人掌旁边时，只有仙人掌会被破坏，而告示牌不会。

; [[炼药锅]]
* 共有六级水位，每级水位相当于Java版的一半。
* 水的颜色可以通过添加染料来改变。
** 颜色可混合。
* 可用于皮革套装的染色。
