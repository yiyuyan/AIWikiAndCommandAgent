'''1.19.3-rc3'''是[[Java版1.19.3]]的第3个，也是最后一个发布候选版本，发布于2022年12月6日<ref>{{article|minecraft-1-19-3-release-candidate-3|Minecraft 1.19.3 Release Candidate 3|December 6, 2022}}</ref>，修复了一些漏洞。

== 修复 ==
