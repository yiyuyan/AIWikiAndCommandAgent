'''破碎的铁砧（Deprecated Anvil）'''，游戏内显示名称为'''铁砧（Anvil）'''，是[[铁砧]]的未使用变种。

== 生成 ==
破碎的铁砧不会生成在世界中。

== 获取 ==
{{see also|Tutorial:获取任意物品}}
破碎的铁砧不能在生存模式中正常获得，但可以通过[[创造模式]]中使用{{ctrl|选取方块}}或[[命令]]获得。

== 破坏 ==
挖掘破碎的铁砧的合适工具是镐。破碎的铁砧需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table/manual|only=be|{{BlockSprite|Deprecated Anvil}} 破碎的铁砧|5|wooden pickaxe}}

破碎的铁砧被破坏后会掉落自身。

== 用途 ==
{{main|铁砧#用途}}
破碎的铁砧具有与铁砧相同的用途，且使用后会变成完好的铁砧。
