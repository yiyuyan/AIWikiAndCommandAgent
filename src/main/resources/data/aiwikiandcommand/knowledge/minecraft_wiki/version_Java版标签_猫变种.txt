'''猫变种标签（Cat Variant Tags）'''是[[猫#外观|猫变种]]的组合。

{{TOC|right}}

== 使用 ==
猫变种标签不可被主动调用，它们被游戏用来控制猫的变种选择。

== 已移除的标签 ==
=== default_spawns ===
* 在村庄中生成时，每天都可以生成的猫变种。该行为被{{nbt|list|[[猫变种定义格式|spawn_conditions]]}}替代。

添加于：[[22w13a]]。移除于：[[25w04a]]。

标签内容：
{{tag list|id=default_spawns|type=cat_variant|mode=manual
|tabby
|black
|red
|siamese
|british_shorthair
|calico
|persian
|ragdoll
|white
|jellie
}}

=== full_moon_spawns ===
* 在村庄中生成时，只在满月时可以生成的猫变种。该行为被{{nbt|list|[[猫变种定义格式|spawn_conditions]]}}替代。

添加于：[[22w13a]]。移除于：[[25w04a]]。

标签内容：
{{tag list|id=full_moon_spawns|type=cat_variant|mode=manual
|#default_spawns
|all_black
}}
