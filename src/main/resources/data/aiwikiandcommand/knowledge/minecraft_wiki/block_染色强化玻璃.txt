'''染色强化玻璃（Hardened Stained Glass）'''是一种在[[化学]]成分上增强的[[染色玻璃]]。

== 生成 ==
染色强化玻璃不会生成在世界中。

== 破坏 ==
没有工具可以加速对染色强化玻璃的挖掘。

{{Breaking table|only=be}}

染色强化玻璃被破坏后会掉落自身。

== 用途 ==
当透过染色强化玻璃看时，与该染色强化玻璃相邻的其他强化玻璃不可见，但在普通玻璃上能看见。

== 你知道吗 ==
* 染色强化玻璃的[[#合成|合成配方]]很可能取自现实中离子交换工艺的方法，这种玻璃强化的方法能够很大程度提高玻璃抵御外力破坏的能力。
