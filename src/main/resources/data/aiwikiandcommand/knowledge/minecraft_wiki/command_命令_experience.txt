给予玩家[[经验]]。

== 语法 ==
* '''Java版'''
: <code>experience add <targets> <amount> [levels|points]</code>
:: 增加或减少玩家的经验值或经验等级。
::* 若增加或减少经验值，则会计入玩家的[[经验#分数|分数]]。
::* 若增加或减少经验等级，则不会计入玩家的分数。当前经验条中的经验值按比例缩放，保持经验条的进度不变。
: <code>experience set <targets> <amount> [levels|points]</code>
:: 设置玩家的经验值或经验等级，不会改变玩家的分数。
::* 若设置经验值，则不会改变经验等级，若指定的经验值大于等于一玩家当前经验条的剩余容量，则无法设置该玩家的经验值。
::* 若设置经验等级，则当前经验条中的经验值按比例缩放，保持经验条的进度不变。
: <code>experience query <targets> (levels|points)</code>
:: 查询玩家的经验等级或当前经验条中的经验值。

* '''基岩版'''
: <code>xp <amount: int> [player: target]</code>
:: 增加玩家的经验值。
: <code>xp <amount: int>L [player: target]</code>
:: 增加或减少玩家的经验等级。当前经验条中的经验值按比例缩放，保持经验条的进度不变。

== 参数 ==
{{el|je|short=1}}：{{argument|amount|integer}}（仅<code>add</code>模式下）
: 指定要给予玩家的经验值或经验等级的数量。负数表示移除玩家的经验。
: {{arg desc|je=integer}}

{{el|je|short=1}}：{{argument|amount|integer}}（仅<code>set</code>模式下）
: 指定要设置成的经验值数量或经验等级。
: {{arg desc|je=integer|min=0}}

{{el|be|short=1}}：{{argument|be=1|amount: int|int}}
: 指定要给予玩家的经验值或经验等级的数量。
: 如果在后面加上<code>L</code>，则会给予或移除指定数量的经验等级，否则给予或移除经验值。负数表示移除玩家的经验。
: {{arg desc|be=int}}如果是经验值（没有<code>L</code>后缀），则应大于零0。

{{el|je|short=1}}：{{argument|targets|entity}}（在<code>add</code>和<code>set</code>模式下）<br>
{{el|be|short=1}}：{{argument|be=1|player: target|CommandSelector<Player>}}
: 指定命令作用的目标实体。{{IN|bedrock}}若未指定，默认为命令执行者。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{el|je|short=1}}：{{argument|targets|entity}}（<code>query</code>模式）
: 指定要查询的目标实体。
: {{arg desc|je=entity|amount=single|type=players}}

{{el|je|short=1}}: {{cd|levels{{!}}points}}
: 指定命令将影响获取经验等级还是经验值。<code>levels</code>表示经验等级，<code>points</code>表示经验值。

== 示例 ==
* 显示Steve当前的经验等级：<code>experience query Steve levels</code>{{only|je}}
* 为自己增加7点经验值：<code>experience add @s 7</code>{{only|je}}或<code>xp 7</code>{{only|be}}
* 将Alice的等级提升3级：<code>experience add Alice 3 levels</code>{{only|je}}或<code>xp 3L Alice</code>{{only|be}}
* 将所有玩家的等级归零：<code>experience set @a 0</code>{{only|je}}或<code>experience set @a 0 levels</code>{{only|je}}或<code>xp -2147483648L @a</code>{{only|be}}
