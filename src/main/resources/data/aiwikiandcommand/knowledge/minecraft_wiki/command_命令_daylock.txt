锁定或解锁终为白日。

== 语法 ==
: <code>daylock [lock: Boolean]</code>

== 参数 ==
{{argument|be=1|lock: Boolean|Enum}}
: 指定是否锁定终为白日。必须为<samp>true</samp>或<samp>false</samp>，默认为<samp>true</samp>。
: 若为<samp>false</samp>，将同时打开昼夜更替，反之亦然，并同时设置游戏时间为5000刻，游戏正午前1小时。
