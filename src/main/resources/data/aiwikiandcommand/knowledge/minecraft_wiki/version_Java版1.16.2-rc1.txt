'''1.16.2-rc1'''是[[Java版1.16.2]]的首个发布候选版本，发布于2020年8月7日<ref>{{article|minecraft-1-16-2-pre-release-2|Minecraft 1.16.2 Release Candidate 1|August 7, 2020}}</ref>，将资源包和数据包的版本提升至6，并修复了一些漏洞。

== 更改 ==
=== 常规 ===
'''[[资源包]]'''
* 由于{{bug|MC-197275}}，将资源包和数据包版本提升至6。

== 修复 ==
{{Fixes|fixedin=1.16.2 Release Candidate 1|showdesc=1
|;1.16的漏洞
|190103|使用下界传送门时会崩溃：<code>java.lang.IndexOutOfBoundsException: fromIndex < 0: -2368549</code>。
|;1.16.1的漏洞
|197275|由于对墙的更改，<code>pack_format: 5</code>的资源包实际上并不跨版本（1.15到1.16）兼容。
|;dev
|194933|游戏在尝试载入自定义生物群系时会崩溃：<code>java.lang.UnsupportedOperationException: Trying to add tag of type 8 to list of 10</code>。
|197197|在创建/进入一个无预设的超平坦世界后，游戏会崩溃/无响应。
|197225|当自定义生物群系的<code>spawners</code>参数为空时，游戏会崩溃：<code>java.util.concurrent.CompletionException: u: Exception generating new chunk</code>。
|;previous
|197258|特定自定义维度可以导致游戏崩溃。
|197263|末地天空和下界迷雾有时在服务器上不起作用。
}}</onlyinclude>
