用于给[[玩家]]拍照，或从玩家的视角拍照。

== 语法 ==
: <code>takepicture <targetCamera: target> <targetPlayer: target></code>
: <code>takepicture <cameraSpawnLocation: x y z> <targetPlayer: target></code>
: <code>takepicture <targetPlayer: target></code>

== 参数 ==
{{argument|be=1|targetPlayer: target|CommandSelector<Player>}}
: 指定一名被拍照的玩家。
: {{arg desc|be=CommandSelector<Player>}}
{{argument|be=1|targetCamera: target|CommandSelector<Player>}}
: 指定一名用于拍摄照片的相机视角的玩家。
: {{arg desc|be=CommandSelector<Player>}}
{{argument|be=1|cameraSpawnLocation: x y z|CommandPosition}}
: 指定用于拍摄照片的相机视角的坐标。
: {{arg desc|be=CommandPosition}}
