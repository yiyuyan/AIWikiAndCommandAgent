[[File:Dimensions.jpg|thumb|width=360x360|游戏中的维度，从左到右依次为[[下界]]，[[末地]]和[[主世界]]]]
'''维度（Dimension）''' 是Minecraft[[世界]]中的平行世界，每个维度在结构和生物群系的生成方式以及其他方面有独特的特征。每个维度都是独立的空间，不互相影响。玩家可以通过使用[[传送门]]探索和发现各种维度。内容创作者还可以制作[[自定义维度]]来深入探索。

在不同的维度中，[[昼夜更替]]和[[天气]]机制可能会有不同的运行模式（或者不存在这些机制），[[重生点#个人重生点|个人重生点]]的设置机制同理（比如[[床]]和[[重生锚]]的在不同维度点击时行为不同）。

== 主世界 ==
{{Main|主世界}}
[[File:Overworld VV.png|thumb|主世界中的不同草原生物群系和水域]]
主世界是Minecraft中的基础维度，其中有种类繁多且独特的[[生物群系]]供玩家探索，也是最具多样性的维度。玩家通常会在此维度中度过大部分的时间。

主世界独有的特点包括：
* 地表至地底的各类[[生物群系]]
* 含[[水]]的[[海洋]]
* [[矿石]]数量庞大
* 许多自然[[生成结构]]
* 具有最多的[[生物]]种类
* 具有[[昼夜更替]]
* 具有[[天气]]
* 在[[床]]上睡觉可以跳过夜晚并设置[[出生点]]（而在其他维度使用会导致其爆炸）
* 高达384格的垂直高度

== 下界 ==
{{Main|下界}}
[[File:Vibrant Visuals Nether.png|thumb|下界里被[[熔岩湖]]分割的[[绯红森林]]和[[诡异森林]]]]
下界是一个炎热的维度。在这里，[[熔岩]]的流動特征与[[水]]一致。由于过热，在这里{{control|放置}}的水或[[湿海绵]]会瞬间蒸发或变干。下界的地面主要由[[下界岩]]构成，但在[[灵魂沙峡谷]]则是由[[灵魂沙]]覆盖地表，[[玄武岩三角洲]]则是由[[玄武岩]]和[[黑石]]组成。玩家可以通过进入在[[主世界]]建造的[[下界传送门]]来到达下界。

下界独有的特点包括：
* 使用[[重生锚]]设置重生点并在重生时消耗一级能量（而在其他维度使用会导致其爆炸）
* 熔岩海
* 熔岩涌泉
* 类似洞穴的地形
* [[下界石英矿石]]、[[下界金矿石]]和[[远古残骸]]
* 顶部和底部由[[基岩]]构成
* [[绯红森林]]和[[诡异森林]]里的[[巨型下界菌]]
* 可进行[[以物易物]]的[[猪灵]]
* [[猪灵蛮兵]]守卫的[[堡垒遗迹]]
* [[凋灵骷髅]]和[[烈焰人]]守卫的[[下界要塞]]

== 末地 ==
{{Main|末地}}
[[File:The End Vibrant Visuals.png|thumb|末地的中央岛屿]]
末地是一个类似于太空的维度，是浮空的[[末地石]]组成的数个岛屿，只能通过[[要塞]]中的[[末地传送门]]进入。末地中央是一个大型孤岛，玩家会在这里与[[末影龙]]进行战斗。外岛距离它大约有一千格。末地的環境荒芜，但这里可以获得游戏中一些最独特且实用的物品，比如[[鞘翅]]和[[潜影盒]]。

末地独有的特点包括：
* [[虚空]]之上的浮空岛屿
* 点燃其所处方块的[[末影水晶]]
* [[終界閃光]]和漆黑的[[天空]]
* [[潜影贝]]守卫的[[末地城]]
* 可通往外岛的[[末地折跃门]]
* [[末影龙]]，游戏中主要的[[Boss]]

== 自定义维度 ==
[[File:Custom dimension custom plains biome.png|thumb|一个使用修改后的颜色並以[[方解石]]代替石头的自定义维度示例]]
{{Experimental|测试版 API|section=1}}
{{Main|自定义维度}}
{{in|je}}使用[[数据包]]可以创建自定义维度和[[维度类型]]，它们具有与常规维度不同的[[生物群系]]、世界生成方式和属性。

{{in|be}}使用[[附加包]]可以创建自定义维度，然而，目前只能控制[[腳本]]，且没有世界生成。每个自定义维度都类似于主世界的虚空世界，具有相同的最高高度限制。
{{-}}

== 未实现维度 ==
[[File:Sky Dimension 1.jpg|thumb|天域维度]]
=== 天域 ===
{{Main|天域}}
天域是一个被废弃的维度，原本会包含浮空陆地，计划在[[冒险更新]]中加入。最终，天域维度的代码被重新利用到了[[末地]]。<ref>{{tweet|jeb|124201530856452096|@JPwanabe It has been rebranded to be The End realm|October 12, 2011}}</ref>

=== 夢之維度 ===
{{Main|基岩版提及特性#世界生成}}
在一次Twitch直播中，开发者简要提到了一个“梦之维度”的想法，这个维度将独占于[[携带版]]。

== 愚人节玩笑维度 ==
有许多[[愚人节玩笑]]更新添加了它们特有的维度。

=== 无限维度 ===
{{Main|Java版20w14∞#世界生成}}
[[File:ShapesBuffet.png|thumb|20w14∞中的愚人节玩笑之一]]
愚人节玩笑快照[[20w14∞]]加入了大约21.474亿（2^31）个独有维度。还有一些彩蛋维度，每个都有其独特特征，包括“ant”、“sponge”、“library”、“bridges”和“slime”等维度。其他维度完全是随机的。

{{-}}

=== 月球 ===
{{Main|月球}}
[[File:Moon 1.png|thumb|月球维度里的一个[[月球基地]]]]
愚人节玩笑快照[[23w13a_or_b]]加入一个称为月球的维度。月球维度主要由[[芝士]]构成，还设有[[月球基地]]，激活时会膨胀成树状结构。
{{-}}

=== 马铃薯维度 ===
[[File:Arboretum.png|thumb|马铃薯维度里的[[植物园]]生態域]]
{{Main|马铃薯维度}}
愚人节玩笑快照[[24w14potato]]加入了马铃薯维度。其類似於未使用的天域维度，并具有马铃薯主题特色的生物、方块、结构和[[超级马铃薯怪|Boss]]。
{{-}}

=== 矿境 ===
{{Main|矿境}}
愚人节玩笑快照[[25w14craftmine]]加入了矿境维度。其是受[[矿境效果]]影响的维度，环境与矿境效果的生效情况直接关联。通常而言，矿境具有昼夜更替和天气变化，拥有多样的地形和多种生物群系，不会生成除[[矿境出口]]外的结构。矿境通常可以通过使用矿境合成台进入，由矿境出口离开。
