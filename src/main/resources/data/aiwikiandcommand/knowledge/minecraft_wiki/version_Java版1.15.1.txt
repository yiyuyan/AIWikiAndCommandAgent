'''1.15.1'''是{{el|je}}的一次次要更新，发布于2019年12月17日<ref>{{article|minecraft-java-edition-1-15-1|Minecraft Java Edition 1.15.1|December 17, 2019}}</ref>，优化了游戏性能，并修复了一些漏洞。此版本不兼容1.15的服务端。

== 更改 ==
=== 常规 ===
'''性能'''
* 优化了[[区块]]的渲染性能，特别是对于拥有很多不同的[[方块]]状态的区块。
'''网络处理'''
* 改进了无效的[[生物群系]]ID的网络处理。
