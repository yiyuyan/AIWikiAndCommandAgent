测试指定位置是否可被[[寻路]]。

游戏会尝试利用生物寻路算法计算一条使命令执行者通往指定位置的路径。这并不会让生物按照该路径的规划过程行进，它只会检验是否能够构建出这样的路径。

== 语法 ==
: <code>debugpath <to></code>

== 参数 ==
{{argument|to|block_pos}}
: 指定要寻路的终点。
: {{arg desc|je=block_pos}}
