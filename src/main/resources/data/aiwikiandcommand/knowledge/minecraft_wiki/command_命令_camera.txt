== 参数 ==
{{info needed section}}

{{argument|be=1|players: target|CommandSelector<Player>}}
: 指定将被修改相机视角的玩家。
: {{arg desc|be=CommandSelector<Player>}}

{{argument|be=1|entity: target|CommandSelector<Actor>}}
: 指定相机将要固定于的实体。
: {{arg desc|be=CommandSelector<Actor>}}

{{argument|be=1|red: int|int}}、{{argument|be=1|green: int|int}}和{{argument|be=1|blue: int|int}}
: 指定相机视角的RGB颜色。
: {{arg desc|be=int}}且必须在0和255之间（含）。

{{argument|be=1|fadeInSeconds: float|float}}、{{argument|be=1|holdSeconds: float|float}}和{{argument|be=1|fadeOutSeconds: float|float}}
: 指定相机视角的淡入、保持和淡出持续时间，单位为秒。
: {{arg desc|be=float}}且必须在0.0和10.0之间（含）。

{{argument|be=1|fov_value: float|float}}
: 指定相机视场角。
: {{arg desc|be=float}}由于游戏限制，实际的有效值范围在30和110之间（含）。

{{argument|be=1|fovEaseTime: float|float}}
: 指定相机视场角平滑过渡的持续时间（秒），默认为0。
: {{arg desc|be=float}}

{{argument|be=1|fovEaseType: Easing|enum}}
: 指定用于相机视场角的运镜函数/类型，默认为{{cd|linear}}。
: 必须是{{cd|d=pretty|in_back|in_bounce|in_circ|in_cubic|in_elastic|in_expo|in_out_back|in_out_bounce|in_out_circ|in_out_cubic|in_out_elastic|in_out_expo|in_out_quad|in_out_quart|in_out_quint|in_out_sine|in_quad|in_quart|in_quint|in_sine|linear|out_back|out_bounce|out_circ|out_cubic|out_elastic|out_expo|out_quad|out_quart|out_quint|out_sine|spring}}之一。

{{argument|be=1|name: string|basic_string}}
: 指定样条ID。只在使用{{cd|minecraft:free}}预设时有效。
: {{arg desc|be=basic_string}}

{{argument|be=1|preset: string|basic_string}}
: {{info needed}}
: 相机视角/预设。
: 必须为以下其中之一：
:* <code>minecraft:control_scheme_camera</code> — 控制方案相机。{{in exp|exg=cameras2}}
:* <code>minecraft:first_person</code> — 第一人称视角。
:* <code>minecraft:fixed_boom</code> — 固定镜头视角的轨道相机。
:* <code>minecraft:follow_orbit</code> — 轨道相机。
:* <code>minecraft:free</code> — 自由视角。
:* <code>minecraft:third_person</code> — 第三人称视角背面。
:* <code>minecraft:third_person_front</code> — 第三人称视角正面。

{{argument|be=1|easeTime: float|float}}
: 指定相机视角平滑过渡的持续时间（秒）。只在使用{{cd|minecraft:free}}预设时有效。
: {{arg desc|be=float}}

{{argument|be=1|easeType: Easing|enum}}
: 指定用于相机视角的运镜函数/类型。只在使用{{cd|minecraft:free}}预设时有效。
: 必须是{{cd|d=pretty|in_back|in_bounce|in_circ|in_cubic|in_elastic|in_expo|in_out_back|in_out_bounce|in_out_circ|in_out_cubic|in_out_elastic|in_out_expo|in_out_quad|in_out_quart|in_out_quint|in_out_sine|in_quad|in_quart|in_quint|in_sine|linear|out_back|out_bounce|out_circ|out_cubic|out_elastic|out_expo|out_quad|out_quart|out_quint|out_sine|spring}}之一。

{{argument|be=1|default: default|enum}}
: 指定将自由视角的位置和朝向改为默认值（相机位置（0,0,0），旋转角度<code>xRot</code>=0，<code>yRot</code>=0）{{info needed|默认的位置和朝向并不稳定设置为对应json文件中所指向的位置和朝向，需要找到这种不稳定是因何引起}}。只在使用<code>minecraft:free</code>预设时有效。
: 必须为<code>default</code>。

{{argument|be=1|lookAtEntity: target|CommandSelector<Actor>}}
: 指定相机视角朝向的实体。只在使用<code>minecraft:free</code>预设时有效。
: {{arg desc|be=CommandSelector<Actor>}}

{{argument|be=1|lookAtPosition: x y z|CommandPositionFloat}}
: 指定相机视角朝向的坐标。只在使用<code>minecraft:free</code>预设时有效。
: {{arg desc|be=CommandPositionFloat}}

{{argument|be=1|position: x y z|CommandPosition}}
: 指定相机视角的位置。只在使用<code>minecraft:free</code>预设时有效。
: {{arg desc|be=CommandPosition}}

{{argument|be=1|xRot: value|RelativeFloat}}
: 指定相机视角的垂直旋转角度。在使用<code>minecraft:follow_orbit</code>预设的情况下，还将修改玩家的朝向。
: {{arg desc|be=RelativeFloat}}且必须在-90和90之间（含）。

{{argument|be=1|yRot: value|RelativeFloat}}
: 指定相机视角的水平旋转角度。在使用<code>minecraft:follow_orbit</code>预设的情况下，还将修改玩家的朝向。
: {{arg desc|be=RelativeFloat}}

{{argument|be=1|xViewOffset: float|Float}}和{{argument|be=1|yViewOffset: float|Float}}
: 指定相机视角的偏移量。只在使用<code>minecraft:follow_orbit</code>预设时有效。
: {{arg desc|be=Float}}且必须在-64和64之间（含）。

{{argument|be=1|xEntityOffset: float|Float}}、{{argument|be=1|yEntityOffset: float|Float}}和{{argument|be=1|zEntityOffset: float|Float}}
: 指定相机视角相对于实体的偏移量。只在使用<code>minecraft:follow_orbit</code>预设时有效。
: {{arg desc|be=Float}}且必须在-64和64之间（含）。

{{argument|be=1|entity: target|CommandSelector<Actor>}}
: 指定要将相机视角聚焦的实体。只在使用<code>minecraft:free</code>预设时有效。
: {{arg desc|be=CommandSelector<Actor>}}

{{argument|be=1|xTargetCenterOffset: float|Float}}、{{argument|be=1|yTargetCenterOffset: float|Float}}和{{argument|be=1|zTargetCenterOffset: float|Float}}
: 指定相机视角相对于聚焦/目标实体中心的偏移量。只在使用<code>minecraft:free</code>预设时有效。
: {{arg desc|be=Float}}

== 示例 ==
{{info needed section}}
[[File:Over Shoulder Camera.jpg|thumb|{{cmd|camera|link=none}}实现的“越肩视角”]]

* 为自己设置持续5秒、运镜模式为<code>in_out_circ</code>、在当前位置上方5格绕X轴旋转90度的<code>minecraft:free</code>（自由视角）相机视角：
:: <code>/camera @s set minecraft:free ease 5 in_out_circ pos ~ ~5 ~ rot 90 0</code>
* 清除所有玩家的相机视角效果：
:: <code>/camera @a clear</code>
* 为随机玩家设置2秒淡入、持续1秒、淡出3秒和颜色纯白的相机视角效果：
:: <code>/camera @r fade time 2 1 3 color 255 255 255</code>
* 配合{{cmd|execute}}命令，为最近的玩家赋予“越肩视角”（需在[[循环型命令方块]]中执行）：
:: <code>/execute as @p at @s run camera @s set minecraft:free ease 0.25 in_out_quad pos ^-2 ^2 ^-4 facing ^ ^ ^5</code>
