'''昼夜更替（Daylight Cycle）'''是[[主世界]]中2个主要[[亮度]]设置的交替过程，周期20分钟。

== 行为 ==
{{see also|太阳|月亮}}

在昼夜更替中，[[太阳]]和[[月亮]]围绕着玩家旋转，分别在正午和午夜出现在玩家的正上方。太阳和月亮相对于星星和彼此总是保持在相同的位置。因此，日食不可能出现，而月亮显示的样式取决于经过的夜晚数量。

在单人游戏中，当游戏暂停或{{only|for=打开[[命令方块]]、[[拼图方块]]、[[测试方块]]的GUI窗口|je}}时，昼夜更替会暂停；除此之外，只要未关闭{{gamerule|advance_time|doDaylightCycle}}，昼夜更替永远不会暂停。

在多人游戏中，只要服务器正在运行且未关闭{{gamerule|advance_time|doDaylightCycle}}，昼夜更替就始终会正常进行。

当玩家处于[[下界]]或[[末地]]时，昼夜更替会一直进行，但这些维度本身不会发生改变，直到[[主世界]]被再次加载。在另一个维度创建的[[村庄]]若被加载，其中的[[村民]]仍会遵循正常的村庄时间表。

== 时间换算 ==
[[File:Day Night Clock 24h.png|240px|thumb|right|Minecraft时间与现实时间的大约换算图]]

=== 白天 ===
[[File:Survival.png|thumb|right|300px|一天的开始]]

白天是一天周期中最长的一节，持续10分钟。

开始：0刻（早上06:00:00.0）

中午：6000刻（下午12:00:00.0）

结束：12000刻（下午06:00:00.0）

玩家在一个[[单人游戏]]中的新世界首次出生时，时间总会处于白天的开始（0:00）。大多数[[多人游戏]]的[[服务器]]时间也是从这个时间开始，但昼夜更替会持续进行，不会受玩家加入影响。

白天时，[[太阳]]会逐渐升到蓝天的中央。天空的具体颜色取决于当前所在的[[生物群系]]。例如，[[沙漠]]的天空比[[草原]]蓝色更淡。

在将近正午的时候，所有直接暴露于天空下的方块均被内部天空光照为最大值15的阳光照射。阳光提供了[[树苗]]、[[草方块|草]]和[[农作物]]生长所需的充足阳光。直接暴露在阳光下的大部分[[亡灵生物]]（不处于阴凉处、水和[[细雪]]，且不戴[[头盔]]）开始自燃。另外，阳光会使尚未追逐玩家的[[蜘蛛]]进入中立状态，使[[末影人]]靠近玩家时随机传送并保持对玩家的中立。

在白天持续期间，[[阳光探测器]]的信号输出强度保持最大。

=== 日落 ===
[[File:A sunset.png|300px|thumb|在地图的高处看到的日落]]

日落是介于白天和夜晚之间的时间段，持续1.5分钟。

* 开始：12000刻（下午06:00:00.0）
* 中点：12900刻（下午06:54:00.0）
* 结束：13800刻（下午07:48:00.0）

日落时，[[太阳]]从西边降落，[[月亮]]从东边升起。下落的太阳附近的天空会有红晕。日落时的太阳看上去还会渐渐变大。

所有直接暴露在天空之下的、未被其他光源照亮的方块，每10秒钟亮度降低1级。

在日落和日出之间的时间段，玩家可以睡在[[床]]或{{in update|drop 3 2026|for={{pa|Straw Bed|}}}}上。在[[单人游戏]]中，睡觉会直接将昼夜更替快进到日出，且将[[天气]]转为晴朗。多人游戏中也可以实现，只需要所有的在线玩家都睡在床上，或睡在床上玩家的比例达到{{gamerule|players_sleeping_percentage|playersSleepingPercentage}}所设定的值即可。然而，游戏中许多机制中时间并不会随之流逝：比如，农作物不会生长，[[熔炉]]中的物品[[烧炼]]进度也不会改变。

=== 夜晚 ===
[[File:TundraNight.png|300px|thumb|[[冻原]]的夜晚；可以看到多种生物]]

夜晚持续7分钟。

* 开始：13800刻（下午07:48:00.0）
* 午夜：18000刻（早上12:00:00.0）
* 结束：22200刻（早上04:12:00.0）

晴朗的夜晚时，玩家可以在12542刻（下午06:32:31.2）到23459刻（早上05:27:32.4）时睡觉。在雨天，玩家可以在12010刻（下午06:00:36.0）到23991刻（早上05:59:27.6）时睡觉。

亡灵生物不再在12210（下午06:12:36.0）至23791刻（早上05:47:27.6）燃烧。

夜晚时，[[月亮]]会逐渐升到天空的中央，黑蓝色的天空布满了微小而白亮的[[星星]]。星星会随着月亮移动，日落即将结束的时候会先于月亮出现。

夜晚期间，整个世界被黑暗掩盖，内部天空光照最低降至4，从而使[[敌对生物]]会在地表生成。允许敌对生物生成的精确时间为9625刻。虽然夜晚的亮度低，但农作物仍会生长，除非玩家睡在[[床]]或{{in update|drop 3 2026|for={{pa|Straw Bed|}}}}上度过夜晚。

=== 日出/黎明 ===
[[File:Sunrise.png|300px|thumb|太阳从地平线上升起]]

日出是介于夜晚和白天之间的时间段，持续1.5分钟。

* 开始：22200刻（早上04:12:00.0）
* 中点：23100刻（早上05:06:00.0）
* 结束：24000（0）刻（早上06:00:00.0）

日出时，月亮往西方地平线方向降落，太阳从东方地平线上升起。升起的太阳附近的天空会有红晕。升起的太阳看上去会渐渐变大，但最后会随着高度增加而慢慢缩小至8×8像素。

所有直接暴露在天空之下的方块每隔10秒亮度增加1。最终，阳光的威力再一次展现，大部分怪物的威胁被驱除。

日出的曙光开始于22009刻（04:00:32）。精确的停止刷怪时间为{{only|je|for=22812刻（04:48:43）}}或{{only|be|for=22813刻（04:48:47）}}，雨天则推迟至23031刻（05:01:08）。<ref group="注" name="redstone-before-spawn">测量值来源于敌对生物生成周期状态变化前最后一次执行的[[命令]]的时间戳。在[[雷暴]]的持续时间内，敌对生物可在一天的任何时刻生成。</ref>

== 命令 ==
{{Main|命令/time}}
可以使用{{cmd|time}}命令修改时间。要启用或禁用昼夜更替机制，可使用命令{{cmd|gamerule}}调整游戏规则{{gamerule|advance_time|doDaylightCycle}}。

=== 设置时间 ===
可用{{cmd|time set}}命令将时间设置为特定值。

:语法：<code>-{}-'''/time''' set <''时间值'' | day | noon | night | midnight></code>

示例：

:{{cmd|time set 0}} - 将时间设为日出。
:{{cmd|time set day}} - 将时间设为白日（{{only|JE|for=1000刻}}/{{only|BE|for=下一日的1000刻}}）。
:{{cmd|time set 6000}} - 将时间设为中午。
:{{cmd|time set 12000}} - 将时间设为日落。
:{{cmd|time set night}} - 将时间设为夜晚（{{only|JE|for=13000刻}}/{{only|BE|for=下一日的13000刻}}）。
:{{cmd|time set midnight}} - 将时间设为午夜（{{only|JE|for=18000刻}}/{{only|BE|for=下一日的18000刻}}）。
:{{cmd|time set 18000}} - 将时间设为午夜。

=== 月相 ===
游戏中每过一天，时间计数便会增加24000刻。虽然每天的交替是一样的，但[[月亮]]会经历8种月相。虽然没有命令直接更改月相，但{{cmd|time add 24000}}命令可以快进至下一个月相。进一步而言，使用以下命令可以直接指定不同的月相：

:{{cmd|time set 13000}}或{{cmd|time set night}} - 满月
:{{cmd|time set 38000}} - 亏凸月
:{{cmd|time set 62000}} - 下弦月
:{{cmd|time set 86000}} - 残月
:{{cmd|time set 110000}} - 新月
:{{cmd|time set 134000}} - 娥眉月
:{{cmd|time set 158000}} - 上弦月
: {{cmd|time set 182000}} - 盈凸月

== 你知道吗 ==
* [[主世界]]的昼夜更替在玩家处于[[下界]]或[[末地]]时也会继续，不过产生的变化只会在重新加载主世界后才会发生。下界和末地中[[村民]]的行为也会受时间影响。
* 背景[[音乐]]会在昼夜更替中特定的时间响起。{{verify}}
[[File:Time reset after overflowing BE.gif|thumb|right|{{in|be}}时间溢出后会被重置]]
* {{cmd|time set}}命令能设置的最大时间值为2,147,483,647（2<sup>31</sup> - 1），这也是{{el|be}}中时间的极限；{{in|je}}使用NBT编辑器可达的最大时间值为9,223,372,036,854,775,807（2<sup>63</sup> - 1）。
** 时间超过最大值后，因数据溢出，昼夜更替无法正常继续，而会使时间倒退回{{only|for=-2,147,483,648|be}}或{{only|for=-9,223,372,036,854,775,808|je}}。
*** {{in|be}}-2,147,483,648（-2<sup>31</sup>）也是命令能够设置的最小时间值。小于该值时，游戏时间会变回最大值。
** 在游戏中正常达到这两个时刻需要很长时间：
*** 上述提到的2,147,483,647值在游戏中相当于：天数 = 89,478；当天刻 = 11,467；相当于现实时间的 [年/月/日（时:分:秒:毫秒）] = 1581/12/25（11:28:58:800）（考虑闰年导致的8天6小时修正），不考虑闰年则为 1582/1/1（17:28:58:800）。要达到此值，现实流逝时间约为1,242天18小时。
*** 上述提到的9,223,372,036,854,775,807相当于游戏中的384,307,168,202,282天，大约10,522亿年。要达到此值，现实流逝时间约为146亿年。
* {{in|be}}当游戏时间为-2,147,483,648至-24,000，且游戏规则<code>[[游戏规则/showDaysPlayed|showDaysPlayed]]</code>为<code>true</code>时，游玩的天数会显示为“{{tr|数不胜数！|多到數不清了！}}”。
