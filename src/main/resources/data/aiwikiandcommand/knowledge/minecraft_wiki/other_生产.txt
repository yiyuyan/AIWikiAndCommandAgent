'''生产（Farming）'''指有目的、系统性地获取[[可再生资源]]的活动。生产的目标产物通常为[[食物]]、[[方块]]、[[经验]]等。一些具体的形式介绍如下：

== 关于生物 ==
;{{EntityLink|id=cow|繁殖|动物农场}}
:用[[小麦]]、[[种子]]、[[胡萝卜]]来繁殖动物，以收集[[鸡蛋]]、[[奶桶]]、[[羊毛]]等物品。
;{{EntityLink|id=creeper|Tutorial:刷怪塔|刷怪塔}}
:建造刷怪的空间，以获得它们的掉落物。
;{{EntityLink|id=villager|Tutorial:村民养殖|村民繁殖机}}
:通过建造屋子和床，或是治疗僵尸村民来生成更多村民。

== 获得经验 ==
;{{BlockLink|id=monster-spawner|Tutorial:刷怪笼陷阱|刷怪笼陷阱}}
:通过留在刷怪笼附近来激活它进行刷怪。

== 耕种食物 ==
;{{ItemLink|wheat|小麦植株、胡萝卜、马铃薯和甜菜根农场|link=Tutorial:农作物种植}}
:种植[[小麦植株]]、[[胡萝卜]]、[[马铃薯]]、[[甜菜种子|甜菜根]]这四种主食作物。
;{{BlockLink|id=melon|Tutorial:西瓜和南瓜种植|西瓜农场}}
:种植[[西瓜]]来获得[[西瓜片]]。

== 获得方块 ==
;{{BlockLink|id=cobblestone|Tutorial:刷石机|刷石机}}
:获得[[圆石]]用于基本的建造。
;{{BlockLink|id=obsidian|Tutorial:黑曜石农场|黑曜石农场}}
:建造[[下界传送门]]等。
;{{BlockLink|id=ice|Tutorial:刷冰|刷冰机}}
:制作一个能稳定地自然生成[[冰]]的场地。
;{{BlockLink|id=wood|Tutorial:树木种植|树场}}
:种植[[树木]]以得到[[原木]]、[[树苗]]和[[苹果]]。
;{{BlockLink|id=cactus-side|Tutorial:仙人掌种植|仙人掌农场}}
:种植[[仙人掌]]以获得[[绿色染料]]或制作[[Tutorial:陷阱|陷阱]]。
;{{BlockLink|id=pumpkin|Tutorial:西瓜和南瓜种植|南瓜农场}}
:种植[[南瓜]]以获得[[雕刻南瓜]]及[[南瓜灯]]。
;{{BlockLink|id=vines|Tutorial:藤蔓种植|藤蔓农场}}
:种植[[藤蔓]]以代替梯子、合成[[苔石]]或[[苔石砖]]。

== 获得物品 ==
;{{ItemLink|id=Nether Wart|Tutorial:下界疣种植|下界疣农场}}
:种植[[下界疣]]以[[酿造]]。
;{{BlockLink|id=mushrooms|Tutorial:蘑菇种植|蘑菇农场}}
:种植[[蘑菇]]以制作[[蘑菇煲]]或生成[[巨型蘑菇]]。
;{{BlockLink|id=cocoa|Tutorial:可可豆种植|可可豆农场}}
:种植[[可可豆]]以制作[[曲奇]]或合成[[染料]]。
;{{ItemLink|id=sugar-cane|Tutorial:甘蔗种植|甘蔗农场}}
:种植[[甘蔗]]以获得[[糖]]，制作[[蛋糕]]的原料。
;{{ItemLink|id=egg|Tutorial:刷蛋|鸡蛋农场}}
:刷[[鸡蛋]]来制作[[蛋糕]]或生成[[鸡]]。
;{{ItemLink|id=snowball|Tutorial:刷雪机|刷雪机}}
:通过困住一个[[雪傀儡]]来获得在它脚下产生的[[雪]]。
;{{ItemLink|id=iron-ingot|Tutorial:铁傀儡陷阱|刷铁机}}
:将在[[村庄]]中自然生成的[[铁傀儡]]成体系地杀死来获得[[铁锭]]。
;{{ItemLink|id=chorus-fruit|Tutorial:种植紫颂果|紫颂果农场}}
:种植[[紫颂果]]以食用，或用来烧炼成[[爆裂紫颂果]]以合成[[紫珀块]]等。
;{{ItemLink|id=gold-nugget|Tutorial:僵尸猪灵陷阱|金粒农场}}
:通过在[[下界]]和[[主世界]]的[[下界传送门]]杀[[僵尸猪灵]]获取[[金粒]]。
;{{ItemLink|id=fishing-rod|Tutorial:刷鱼|钓鱼}}
:你可以通过[[钓鱼竿]]钓鱼以获取[[鱼]]、[[经验]]和一些其他的物品。
