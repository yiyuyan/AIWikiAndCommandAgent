'''元素（Elements）'''和'''同位素（Isotopes）'''是在Minecraft[[化学]]中的一种方块。

== 生成 ==
元素不会生成在世界中。

== 获取 ==
元素和同位素可以在[[元素构造器]]中制造。这是通过移动滑块或在输入框中输入数字来完成的，大显示器将显示选定的粒子数量，无论是否有效。如果原子结构是稳定的同位素，它可以从右侧的槽中取出。稳定同位素列表可以在下面找到。

一些元素可以在[[材料分解器]]中通过分解方块获得，方块会按百分比分解为其组成元素。这是获得未知元素的唯一方法；一些Minecraft方块中可以找到未知元素，例如[[灵魂沙]]和[[下界岩]]。

== 破坏 ==
元素被挖掘时会立刻被破坏。

{{Breaking table|未知元素|only=be}}

元素被破坏后会掉落自身。

=== 未知元素 ===
未知元素可以通过使用材料分解器来分解现实中不存在的东西来得到，包括[[红石矿石]]、[[下界岩]]、[[末地石]]、[[荧石]]、[[灵魂沙]]。

== 用途 ==
元素可以以装饰性方块放置，或者在[[合成]]、[[酿造]]或者[[实验台]]上用作原料。它们也可以用[[化合物创建器]]化合为化合物；可用组合参见[[化合物]]页面。

== 你知道吗 ==
* 元素构造器提供的许多“稳定”同位素在现实生活中具有放射性。例如，锝在现实生活中没有稳定的同位素，但是它在Minecraft中有3个稳定的同位素。
* 金属类元素的纹理可能采用了[[铁块]]的纹理。
