启用或禁用此设备上的[[游戏提示]]。

== 语法 ==
: <code>gametips <status: Status></code>

== 参数 ==
{{argument|be=1|status: Status|enum}}
: 必须为以下其中之一：
:* <code>disable</code>（可简写为<code>d</code>）代表禁用
:* <code>enable</code>（可简写为<code>e</code>）代表启用

== 示例 ==
* 禁用此设备上的[[游戏提示]]：<code>/gametips disable</code>或<code>/gametips d</code>
