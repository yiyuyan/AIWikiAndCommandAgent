'''磨制安山岩楼梯（Polished Andesite Stairs）'''是[[磨制安山岩]]制作的[[楼梯]]。

== 生成 ==
磨制安山岩楼梯不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|foot=1
|A1= Polished Andesite |A2= Polished Andesite |A3= Polished Andesite
|B2= Polished Andesite |B3= Polished Andesite
|C3= Polished Andesite
|Output= Polished Andesite Stairs,4
|type= Building block
}}

=== 切石 ===
{{Stonecutting
|foot=1
|Andesite; Polished Andesite
|Polished Andesite Stairs
}}

== 破坏 ==
挖掘磨制安山岩楼梯的合适工具是镐。磨制安山岩楼梯需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

磨制安山岩楼梯被破坏后会掉落自身。
