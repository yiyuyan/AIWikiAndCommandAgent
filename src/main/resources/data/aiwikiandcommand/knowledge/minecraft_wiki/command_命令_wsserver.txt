用于连接WebSocket服务器，WebSocket服务器使用命令信息与客户端交互，主要用于{{el|edu}}中。

== 语法 ==
: <code>wsserver <serverUri: text></code>
: <code>connect <serverUri: text></code>
: <code>dedicatedwsserver <server-address> <port></code>
:: 连接到指定的WebSocket服务器。

== 参数 ==
{{argument|be=1|serverUri: text|CommandRawText}}和{{argument|be=1|serverUri: message|CommandRawText}}
: 指向WebSocket服务器的URI。如果URI不等同于当前连接的服务器，则会先断开当前连接。域名解析在客户端完成。
