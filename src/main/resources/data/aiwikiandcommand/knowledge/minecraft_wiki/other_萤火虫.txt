'''萤火虫（Firefly）'''是一种最初设计为会被[[青蛙]]吃掉来产生[[蛙明灯]]的友好生物。

== 生成 ==
在最初，萤火虫被设计为在[[沼泽]]生物群系里成群生成。由于游戏里未加入其正常生成的能力，也不能通过命令生成，因此它只能在特定版本里使用[[附加包]]来手动生成，这是因为在编译零售版（常规版本）时去除了萤火虫的相关代码。

在部分开发者版本中，萤火虫拥有正常的生成能力：可以在沼泽里自然生成，也可以通过[[刷怪蛋]]和{{cmd|summon}}命令生成。在常规版本中可以利用加载附加包来实现。

== 掉落物 ==
萤火虫死亡时不掉落任何[[物品]]或[[经验]]。

如果萤火虫被[[青蛙]]捕食，则会使得青蛙掉落对应变种的[[蛙明灯]]。在开发者版本中可以通过额外代码来实现此功能。

== 行为 ==
萤火虫不是立体的实体且不会旋转其身体，因此玩家只能在Z轴方向上观察到它们。换句话说，如果玩家在X轴方向上正对着萤火虫，那么萤火虫就会“隐身”，类似于从特定的角度上观察[[红石线]]。

萤火虫会在空中漫无目的地飞行，即便被其他实体伤害或者被方块阻挡。在向下飞行时，萤火虫可能会因为着陆而产生方块粒子。

由于未实现动态纹理，萤火虫看起来是黑色的，而不是像原本计划那样闪烁着黄绿色的光。尽管如此，在开发者版本中可以通过额外代码来实现其发光的能力。

萤火虫的碰撞箱不会和玩家的有任何交互。

萤火虫没有独特音效，而是使用了玩家的受伤和死亡音效。

玩家无法对萤火虫使用[[拴绳]]。

== 你知道吗 ==
[[File:Firefly Spawn Egg BE1.png|thumb|right|64px|萤火虫的刷怪蛋]]
* 萤火虫的[[刷怪蛋]]是蓝色底加皮-{}-肤色斑点的纹理，是为数不多的在纹理上与实体外观无关联的刷怪蛋。
* 在[[Minecraft Dungeons]]里也出现了萤火虫。与原版不同的是，Minecraft Dungeons里的萤火虫是一个会发光的“小立方体”，会大量地在[[MCD:苦力怕森林|苦力怕森林]]、[[MCD:潮湿沼泽|潮湿沼泽]]里生成，同时也会出现在启动屏幕里的营火的周围和[[MCD:营地|营地]]中。
