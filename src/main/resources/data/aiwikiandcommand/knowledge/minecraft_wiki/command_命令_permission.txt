枚举或重新加载权限列表，或设置玩家的权限等级。

== 语法 ==
:<code>permission list</code>
::枚举当前使用的权限列表，仅[[BDS]]可用。
:<code>permission reload</code>
::在服务器上重新从<samp>permissions.json</samp>文件加载操作员列表，仅BDS可用。
:<code>permission set <player: target> [permission: PermissionLevel]</code>
::在客户端上设置玩家的权限等级，仅非BDS可用。但通常无法执行，因为其权限等级要求过高。<ref>{{bug|MCPE-161188||{{cmd|permission|link=none}}不能按照语法提示执行。}}</ref>

== 参数 ==
{{argument|be=1|player: target|CommandSelector<Player>}}
: {{arg desc|be=player}}
{{argument|be=1|permission: PermissionLevel|enum}}
: 指定权限等级所对应的身份。必须为以下其中之一：
:* <code>member</code> — 成员
:* <code>operator</code> — 操作员
:* <code>visitor</code> — 访客
