将一条私聊消息发送给一个或多个玩家。

== 语法 ==
* '''Java版'''
: <code>-{}-msg <targets> <message></code>
: <code>-{}-tell <targets> <message></code>
: <code>-{}-w <targets> <message></code>

* '''基岩版'''
: <code>tell <target: target> <message: message></code>
: <code>msg <target: target> <message: message></code>
: <code>w <target: target> <message: message></code>

== 参数 ==
{{argument|targets|entity|target: target|CommandSelector<Player>}}
: 指定私聊消息的接收玩家。{{IN|java}}使用目标选择器要求[[权限等级]]不低于2。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{argument|message|message|message: message|CommandMessage}}
: 指定要发送的消息。
: {{arg desc|je=message|be=CommandMessage}}
: {{in|JE}}目标选择器只有在[[权限等级]]不低于2时才会被替换为选中的实体的名称。

== 示例 ==
* 私信告诉Alice“搞快点！”：{{cmd|msg Alice 搞快点！|link=none}}
* 私信告诉自己附近5米内所有的玩家：{{cmd|1=msg @s @e[distance=..5,type=player]|link=none}}{{only|java}}{{cmd|1=msg @s @e[r=5,type=player]|link=none}}{{only|bedrock}}
* 私信告诉Alice处于创造模式中的玩家：{{cmd|1=msg Alice @a[gamemode=creative]|link=none}}{{only|java}}{{cmd|1=msg Alice @a[m=1]|link=none}}{{only|bedrock}}
