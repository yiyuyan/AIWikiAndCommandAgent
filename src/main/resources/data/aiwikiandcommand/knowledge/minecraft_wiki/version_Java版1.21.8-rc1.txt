'''1.21.8-rc1'''是[[Java版1.21.8]]的唯一一个发布候选版本，发布于2025年7月15日<ref>{{article|minecraft-1-21-8-release-candidate-1|Minecraft 1.21.8 Release Candidate 1|Jul 15, 2025}}</ref>，修复了一些漏洞。

== 修复 ==
{{fixes|fixedin=1.21.8 Release Candidate 1|showdesc=1|new=1
|;old
|295947|在某些英特尔集成显卡上，游戏画面会在一段时间后冻结。
|296107|在某些英特尔集成显卡上，实体和方块实体会在一段时间后出现图像损坏。
|296585|在某些英特尔设备上，召唤一个或多个文本展示实体后会出现闪烁和其他图像损坏。
|296908|在某些英特尔集成显卡上，文本和纹理图集会在一段时间后出现图像损坏。
|297784|在Gen11微架构的英特尔显卡上，实体阴影会在一段时间后出现异常。
|298903|在某些英特尔集成显卡上，物品栏中的物品会先变纯色而后消失，且文本会变色。
|298908|在某些英特尔集成显卡上，物品栏中的物品似乎被背面的光照亮。
|299144|在某些AMD显卡上，游戏在加载带有无效着色器的资源包时崩溃。
}}</onlyinclude>
