'''18w48b'''是[[Java版1.14]]的第10个快照，发布于2018年11月30日<ref>{{snap|18w48b|id=b|November 30, 2018}}</ref>，修复了一些漏洞。

== 修复 ==
{{fixes|fixedin=18w48b|prefix=Minecraft|showdesc=1
|;old
|118971|在旁观模式中进入方块时天空会变暗。
|;dev
|139725|世界生成时水方块被破坏（伴有破坏石头的音效和水粒子）。
|;previous
|140234|<code>server-port</code>在<samp>server.properties</samp>中被忽视。
|140235|使用{{cmd|locate|link=none}}命令或生成区块时导致Datafixer崩溃。
