此命令用于管理[[服务器]]中白名单。

== 用法 ==
{{In|java}}服务器的管理员'''永远'''能够登录开启白名单验证的服务器，无论他们的名字是不是在白名单上。

{{In|Bedrock}}若开启白名单验证，则玩家必须在白名单中才能进入服务器，而与其管理员权限无关。

白名单储存在{{only|je|for={{filename|[[whitelist.json]]}}}}或{{Only|bedrock|for={{filename|allowlist.json}}}}文件。

== 语法 ==
: {{el|je|short=1}}：<code>whitelist add <targets></code>
: {{el|be|short=1}}：<code>allowlist add <name: string></code>
:: 将玩家档案添加到白名单。指定的玩家不需要在线上。
: {{el|je|short=1}}：<code>whitelist list</code>
: {{el|be|short=1}}：<code>allowlist list</code>
:: 列出白名单中的玩家档案。
: {{el|je|short=1}}：<code>whitelist off</code>
:: 在此服务器上禁用白名单验证。
: {{el|je|short=1}}：<code>whitelist on</code>
:: 在此服务器上启用白名单验证。
: {{el|je|short=1}}：<code>whitelist reload</code>
: {{el|be|short=1}}：<code>allowlist reload</code>
:: 从硬盘中重新读取<samp>whitelist.json</samp>或{{Only|bedrock|for=<samp>allowlist.json</samp>}}中的白名单列表（当其在Minecraft外被修改时使用）。
: {{el|je|short=1}}：<code>whitelist remove <targets></code>
: {{el|be|short=1}}：<code>allowlist remove <name: string></code>
:: 将玩家档案从白名单中移除。指定的玩家不需要在线上。

== 参数 ==
{{el|je|short=1}}: {{argument|targets|game_profile}}
:指定要从白名单中添加或删除的玩家档案。
:{{arg desc|je=game_profile}}

{{el|be|short=1}}: {{argument|be=1|name: string|basic_string}}
:指定要从白名单中添加或删除的玩家名。
:{{arg desc|be=string}}
