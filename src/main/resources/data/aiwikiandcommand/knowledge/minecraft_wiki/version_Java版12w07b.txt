'''12w07b'''是[[Java版1.2.1]]的第7个快照，发布于2012年2月15日<ref>{{cite|url=http://mojang.com/2012/02/15/minecraft-snapshot-12w07a/|archive-url=1|archive=1|archive-time=20120217145323|title=Minecraft Snapshot 12w07b (Updated!)|author=Jens Bergensten|website=Mojang.com|date=Feb 15, 2012}}</ref>，修复了一些漏洞和崩溃。

== 修复 ==
; 修复了3个漏洞
: 修复了{{control|攻击}}着火的方块时会破坏方块的漏洞。
: 修复了生物在Y=255以上高度生成时发生的崩溃。
: 修复了多人游戏中绵羊的动画。</onlyinclude>
