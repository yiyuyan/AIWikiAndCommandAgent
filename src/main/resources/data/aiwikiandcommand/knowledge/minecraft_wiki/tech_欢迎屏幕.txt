{{Conjecture}}
'''欢迎屏幕（Welcome Screen）'''是在首次运行Minecraft时进入的界面。

== 说明 ==
欢迎屏幕是否会在游戏启动后显示由[[options.txt]]中对应的值控制：
* {{in|java|nc=1}}为{{code|onboardAccessibility}}，默认为{{samp|true}}。该值为{{samp|false}}时则不会在启动游戏后显示该屏幕。
* {{in|be|nc=1}}为{{code|has_dismissed_new_player_flow}}，默认为{{samp|0}}。该值为{{samp|1}}时则不会在启动游戏后显示该屏幕。
** 当{{filepath|minecraftWorlds}}中已存在世界时，该值会在游戏启动时自动更改为{{samp|1}}。

== Java版 ==
{{filetr|onboardAccessibility.png|thumb|辅助功能引导屏幕}}

首次进入游戏时，游戏会进入辅助功能引导屏幕。

此屏幕提供一些快捷辅助功能选项，如下：

; {{tp|options.narrator}}
: 切换复述功能的复述范围：{{tp|options.narrator.all}}、{{tp|options.narrator.chat}}、{{tp|options.narrator.system}}或{{tp|options.narrator.off}}。

; {{tp|accessibility.onboarding.accessibility.button}}
: 点击后会进入[[选项#accessibility|辅助功能设置]]界面。

; {{tp|options.language}}
: 点击后会进入[[语言]]选择界面。

; {{tp|gui.continue}}
: 点击后会进入[[主菜单]]。

点击{{tp|gui.continue}}后，游戏会将{{code|onboardAccessibility}}设置为{{samp|false}}以防止在之后显示此屏幕。

== 基岩版 ==
{{filetr|new player flow.png|thumb|欢迎屏幕}}

首次进入游戏时，游戏会进入欢迎屏幕，在简单介绍游戏玩法的同时引导玩家创建一个世界。

; {{tr|开始|入門說明}}
: 点击此按钮后，游戏会按顺序依次显示以下-{}-界面，供玩家按喜好选择。
# “游戏模式”界面。用于选择游戏模式。
# “生存难度”界面。用于选择游戏难度。
#* 若选择了创造模式，则不会显示此界面，且游戏难度固定为普通。
# “选择角色”界面。可以从9种[[皮肤#默认皮肤|默认皮肤]]中选择一个。
# “{{tr|控制模式|控制方式}}”界面。用于选择[[控制#触控|触控模式]]。
#* 此界面仅在使用触屏操控时显示。
# “{{tr|准备游玩|準備好游玩}}”界面。简单介绍即将创建的世界。点击“游玩 Minecraft”即可创建该世界并进入。

; 更多选项
: 点击后会进入[[主菜单]]。

进入世界或主菜单后，游戏会将{{code|has_dismissed_new_player_flow}}设置为{{samp|1}}以防止在之后显示此界面。

== 你知道吗 ==
* {{in|be}}登录提示会优先于此屏幕出现。
* 部分第三方{{el|java}}启动器可能会在启动游戏前将{{code|onboardAccessibility}}修改为{{samp|false}}，因此游戏将不会显示该屏幕。
