'''Minecraft启动器（Minecraft Launcher）'''是一个用于登录、下载并启动独立的[[Java版|Minecraft：Java版]]的主要客户端，以及启动{{el|be}}、{{el|Dungeons}}及{{el|Legends}}游戏的前端软件。它支持{{w|Microsoft Windows|Windows}}、{{w|macOS}}和{{w|Linux}}操作系统。

启动器负责下载主要的[[wzh:Java|Java]]软件包，包括含有游戏代码和诸如纹理等资源的{{filename|[[client.jar]]}}以及[[wikipedia:LWJGL|LWJGL]]。启动器会在第一次运行时强制让用户登录到一个或多个付费账户上。

可以使用启动器来运行{{el|je}}的所有正式版本（包括公开的快照）、绝大多数[[Java版Beta|Beta]]版本，以及部分的[[Java版Classic|Classic]]、[[Java版Infdev|Infdev]]、[[Java版Alpha|Alpha]]和[[Java版pre-Classic|pre-Classic]]版本。要查看启动器所有未包括的Java版版本，详见“[[启动器中丢失的版本]]”。除此之外，在Windows 10/11平台上，启动器还可以启动{{el|be|mcd|mclg}}。

== 启动 ==
[[File:Launcher login screen.png|缩略图|右|在用户未登录时启动器显示的登录屏幕]]
每次启动器运行时，它都会检查储存着Minecraft文件的[[.minecraft]]文件夹。其检查一个名为“<samp>[[launcher_profiles.json]]</samp>”的文件作为启动器的登录凭证。如果文件未找到、被损坏或没有用户登录的记录，那么用户必须使用有效的付费账户来进行登录，否则将只能游玩[[演示版]]或[https://www.minecraft.net/choose-your-game 购买游戏]。

当登录后，启动器会首先尝试验证登录。如果存在有效的“<samp>launcher_profiles.json</samp>”文件，且在最后一次关闭时进行了登录，但是没有网络连接，启动器将会启动“离线游戏”模式。如果成功连接到网络，启动器将会把最新版本的“versions”文件夹与服务器的最新发布的版本进行比较。当配置选项里的“最新版本”被选择时，如果选择的版本不存在，或版本需要进行更新，启动器将会下载所有最新的Minecraft组件以及Java二进制文件。它也会将<samp>assets</samp>文件夹里的所有文件都进行同步。

最后，一旦成功安装或更新之后，启动器将会启动“minecraft.jar”（通过“javaw.exe”，Java虚拟机可执行文件）。在缺失“.jar”的文件的情况下仍然可以启动。在这种情况下，启动器会自动下载缺失文件，但是如果没有网络连接，则会停止下载。

== 特性 ==
=== 启动器 ===
* 管理多个配置（储存在{{filename|launcher_profiles.json}}）。每个配置都可以控制：
** 游戏版本。包括使用已过时的预览版本和之前的预发布版。你也可以手动添加较旧/自定义的版本。<ref>{{tweet|dinner|344164561701724160}}</ref>
** 在游戏内使用的Microsoft账户
** Java命令行参数（例如堆大小）
** 游戏目录（硬盘上储存游戏文件的地方）
** 配置文件的图片，或自制的图片
* 启动器不会在硬盘上储存你的密码。启动器会使用一个“刷新令牌”进行验证。
* 启动器支持多个实例同时运行（游戏也支持）
* 启动器会自动更新
* 启动器有更新库的能力，例如{{w|LWJGL}}。
* 离线模式（第一次启动需要有网络连接来下载所需资源） 
* 可以通过[[崩溃#Hopper|Hopper]]向Mojang报告崩溃。
* 通过引用数据库的崩溃信息来提供如何修复漏洞。
* 启动器设置
* 切换账户或登出
* 更改皮肤
* 下载各版本的服务器
* 帮助按钮
* 点击启动器版本可显示启动器版本信息

=== 向后兼容性 ===
[[File:HowtoOldVersion2019.png|300px|缩略图|启用了Alpha和Beta版本的配置]]
启动器拥有游玩旧版本[[Java版Alpha|Alpha]]和[[Java版Beta|Beta]]的能力。当前，可以游玩快照、Alpha、Beta以及所有正式版本。四个[[Java版pre-Classic|pre-Classic]]版本、四个[[Java版Classic|Classic]]版本、还有一个[[Java版Infdev|Infdev]]版本都被归为“old_alpha”。<ref>{{tweet|dinner|364762596387205120}}</ref>然而，目前启动器依然没有可用的[[Java版Indev|Indev]]版本。

尽管如此，这些版本早已过时且可能会不稳定。任何由不稳定产生的漏洞、故障、遗失的特性和崩溃都不会解决。[[Mojang Studios]]还推荐玩家在其他目录下游玩以便它们不会损坏游戏本体。<ref>https://help.mojang.com/customer/portal/articles/1475923-changing-game-versions</ref>

要启用旧版本，在“设置”页面的“{{tr|通用|一般}}”选项卡中，勾选“{{tr|在启动器中显示《Minecraft：Java版》的历史版本|在啟動器中顯示 Minecraft Java 版的歷史版本|在啟動器中顯示 Minecraft：Java 版的歷史版本}}”，之后在“MINECRAFT: JAVA EDITION”页面的“配置”选项卡中新建一个配置并任选一个早期版本，最后点击“{{tr|新建|建立}}”按钮保存即可。

=== 皮肤 ===
{{main|皮肤}}
[[File:SkinLibrary.png|缩略图|启动器中的皮肤库]]
[[File:LauncherChangeSkin.png|缩略图|皮肤设置]]
你可以在Minecraft启动器中更改或添加你的自定义皮肤。要更改或添加你的皮肤，请打开“皮肤”选项卡，单击“{{tr|添加新皮肤|新增外觀}}”或某个已有皮肤，然后再单击“浏览”按钮浏览你的文件系统找到你的皮肤文件。皮肤文件的分辨率必须为64×64，否则启动器将不会接受它。此外，皮肤文件的文件格式必须为<code>.png</code> 。在你找到皮肤文件之后，点击“保存”按钮来确认你在游戏中的皮肤。

* 你也可以选择其他8个默认皮肤之一。
* 你可以在两种玩家模型中切换：{{tr|宽型|寬版|闊}}或{{tr|纤细|苗條}}。

=== 配置 ===
[[File:2019LauncherProfileSettings.png|缩略图|启动器中的配置设置]]
当你第一次打开Minecraft启动器的时候，它会创建一个最新版本Minecraft的配置。

但是，你可以在启动器里创建自己的配置。打开“配置”选项卡，然后点击“新配置”去创建一个。在此之后，你可以输入你想要的名称。如果你不输入名称，它将被命名为“<{{tr|未命名配置|未命名的安裝檔|未命名安裝檔案}}>”。然后你可以在启动器里自定义一张配置的图标，但是它必须是128×128分辨率且扩展名为<code>.png</code>的图片。选择你想要的版本，然后点击“保存”来保存你的配置。若想更改某个配置，则只需点击它或点击“…”按钮中的“编辑”选项。这同样适用于删除一个配置：点击你想要删除的配置旁的“…”按钮中的“删除”选项。
* 你可以通过点击“服务器”来下载服务端版本。
* 如果想要调整游戏窗口大小，修改“分辨率”来更改游戏窗口初始大小。
* 你可以通过“{{tr|显示更多选项|更多選項}}”来查看更多的配置选项。
* 如果你想改变<code>.minecraft</code>文件夹的路径，修改“{{tr|游戏目录|遊戲資料夾}}”选项。然后选择<code>.minecraft</code>文件夹的路径。你也可以通过点击“浏览”按钮来打开<code>.minecraft</code> 文件夹。
* 如果你勾选“快照”，会自动创建一个叫做“最新快照”的配置。
* 你可以手动设置[http://logging.apache.org/log4j/2.x/manual/configuration.html 日志{{tr|配置|組態}}]（详见[[:en:Minecraft_Wiki:Projects/wiki.vg_merge/Debugging|英文Wiki上的调试文章]]）。

== 命令行用法 ==
从2.1.1432开始，启动器有9个可用的命令行选项：
* <code>--clean</code> - 此选项从工作目录中删除<code>game</code>和<code>runtime</code>文件夹，包括其里面的文件。
* <code>--launcherui</code>
* <code>--workDir</code> - 此选项后接（相对或绝对）路径，将更改<code>.minecraft</code>文件夹的位置（和/或名称）。
* <code>--nativeLauncherVersion</code>
* <code>--tmpDir</code> - 此选项后接（相对或绝对）路径，将更改<code>tmp</code>文件夹的位置（和/或名称）。
* <code>--lockDir</code>
* <code>--winTen</code> - 此选项添加了对Windows 10的支持。由于启动器现在完全支持Windows 10，所以这个选项是不必要的，似乎没有任何效果。
* <code>--proxyHost</code>
* <code>--proxyPort</code>

可以使用<code>--workDir</code>选项创建游戏的便携式安装。例如，可以使用<code>--workDir .</code>（或<code>--workDir=.</code>）使启动程序使用当前目录（无论调用什么当前文件夹）。

== 你知道吗 ==
{{FakeImage|{{animate|Launcher Creeper face.png;Launcher shrug emoji.png|120px}}|测试阶段的彩蛋}}
* 在2016-2019启动器左上角可以找到一个隐隐可见的按钮，它会随机显示为[[苦力怕]]脸或耸肩的颜文字¯\_(ツ)_/¯。它在点击时会闪烁白色，不过没有实际用处。这在启动器的[[启动器2.1.497x|2019重新设计]]中被移除了。
** 在启动器的测试阶段，苦力怕的脸以及耸肩被用于语言选择菜单，当添加一个地球而不是简单地向下移动时，这作为一个彩蛋保存。
* 将鼠标悬停在2016-2019启动器中的“开始”按钮上足够长的时间将导致随机生物出现在窗口的右侧。
* 2022年7月2日，为了纪念于2022年6月30日因4期骨癌逝世的Minecraft YouTuber [[Technoblade]]，启动器背景图上的猪被戴上了皇冠。
