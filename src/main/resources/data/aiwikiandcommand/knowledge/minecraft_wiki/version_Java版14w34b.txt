'''14w34b'''是[[Java版1.8]]的第50个快照，发布于2014年8月18日<ref>{{cite|url=http://mojang.com/2014/08/minecraft-snapshot-14w34a/|archive-url=1|archive=1|title=Minecraft snapshot 14w34d|author=Dinnerbone|website=Mojang.com|date=Aug 18, 2014}}</ref>，修复了一些漏洞和[[14w34a]]的崩溃问题。

== 修复 ==
{{fixes|fixedin=14w34b|prefix=Minecraft|showdesc=1
|;dev
|59851|兔子一直看着玩家。
|65591|旁观模式中，玩家可以更改盔甲架上的物品。
|67873|兔子对创造模式的玩家有反应。
|67915|不向后兼容1.7存档中成书的文本内容。
|67936|被驯服的兔子在玩家处于旁观模式时仍然会传送。
|;previous
|67974|玩家高度接近254时，游戏崩溃。
|67976|无法放置盔甲架。
|67981|熔炉中的物品栏没有被正确更新，导致熔炉基本不能使用。
|67983|<code>Hopper: java.lang.NullPointerException: Ticking block entity</code>。
