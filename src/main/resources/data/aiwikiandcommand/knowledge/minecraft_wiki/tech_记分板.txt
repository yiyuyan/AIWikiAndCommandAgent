'''记分板（Scoreboard）'''系统是一套通过[[命令]]操纵的复杂游戏机制。主要为地图作者与[[服务器]]运营者准备，记分板可用多种形式追踪、设置并列出玩家及实体的分数。

== 记分项 ==

'''记分项（Objective）'''主要由三部分组成：名称、显示名称、准则。记分项可追踪或监听游戏内的某些物体或事件，并将该物体或事件的部分属性转化为可存储于实体内的分数。在游戏内部，记分板分数为一个32位整型数字，故不能为小数，取值范围为-2,147,483,648至2,147,483,647（闭区间）。

记分项'''名称（Name）'''：记分项的唯一标识名，用于在命令、目标选择器参数以及某些文件格式内部引用记分项。记分项名称区分大小写，{{in|java}}名称可以包含所有的大小写字母、数字、下划线、点、减号和加号。{{in|bedrock}}可以是任何字符。

'''显示名称（Display name）'''：用于在不同场合显示记分项。允许不同记分项拥有相同的显示名称。{{in|je}}为一个[[文本组件]]；{{in|be}}只能是一个文本。

'''准则（Criterion，复数为Criteria）'''：决定记分项应追踪游戏内的哪些物体或事件，该记分项的分数将根据指定的准则进行更新。下方的表格列举了所有的准则。

'''分数（Score）'''：除只读型（参见{{slink||准则}}）的记分项外，所有记分项的分数都可以被命令修改。可以指定增加或减少的值，也可以直接设置为某一特定值。

'''分数持有者（Score holder）'''：已被一个记分项记录的，拥有确定分值的玩家的名称或实体[[UUID]]。其中，玩家名不一定是一个实际存在的玩家。非玩家实体的分数只能通过命令修改，而不能通过游戏系统修改。和玩家不同，非玩家实体死亡后，其分数会被删除（对应一个记分项从内存中释放）。整个记分板系统中所有的分数持有者统称为'''被追踪的实体（Tracked entity/entities）'''。

命令可以通过[[目标选择器]]的{{cd|scores}}参数来检查实体的记分项分数，语法为{{cd|-{}-scores{{=}}{<名称>{{=}}<最小值>..<最大值>}<nowiki/>}}。其中，{{cd|-{}-<名称>}}即为记分项的唯一标识名。

比如，在[[命令方块]]中输入{{cmd|1=execute if entity @a[scores={deaths=1..5}]}}会让比较器或条件制约的命令方块在有玩家于<code>deaths</code>记分板上拥有1至5分时提供输出。

===== 复合准则 =====
复合准则由多个部分构成，各部分间使用点号{{cd|.}}来分隔。例如， <code>minecraft.killed_by:minecraft.zombie</code>是一种复合准则，当玩家被僵尸杀死时才会增加分数。

基于复合准则的所有分数都可以通过命令修改。

任何[[统计信息#命名空间ID|统计信息的命名空间ID]]都可用作复合准则。<ref>{{tweet|Dinnerbone|364670393354694656}}</ref>玩家自身统计数据的存储与记分板分数的存储互相独立。当这些统计数据更新时，跟踪的记分项也会同步更新。

除此之外，还有以下复合准则：

== 显示位置 ==
[[File:Scoreboard Display.png|缩略图|360px|以“列表”形式显示的某一玩家在这一记分项下获得了2点分数，同时在“侧边栏”模式中则为某一显示名称为“Quest Points”的记分项，其中该玩家没有获得分数]]
每个“显示位置（Display Slot）”可以依次显示一个记分项，并且多个显示位置可以被用于相同或不同的记分项。
* {{cmd|scoreboard objectives setdisplay}}命令可将记分项以及记分项中的分数以某些“形式”显示出来。
* {{only|for={{cmd|scoreboard objectives modify <objective> displayname}}命令可以修改记分项的显示名称。|je}}
* {{only|for={{cmd|scoreboard objectives modify <objective> rendertype}}命令可以修改记分项的渲染类型。|je}}
