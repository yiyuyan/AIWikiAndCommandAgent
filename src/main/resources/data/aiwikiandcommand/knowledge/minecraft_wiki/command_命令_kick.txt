将玩家踢出服务器。

== 语法 ==
* '''Java版'''
:<code>kick <targets> [<reason>]</code>

* '''基岩版'''
:<code>kick <name: target> <reason: message></code>

== 参数 ==
{{argument|targets|entity|name: target|CommandSelector<Player>}}
: 指定要踢出的玩家。
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}
: {{in|be}}也可以是玩家的XUID（Xbox UID）。

{{argument|reason|message|reason: message|CommandMessage}}
: 指定将显示给被踢出玩家的消息。{{in|je}}若未指定则使用默认消息“{{tp|multiplayer.disconnect.kicked}}”。{{in|be}}若未指定则使用默认消息“您已被踢出游戏”。
: {{arg desc|je=message|be=CommandMessage}}

== 示例 ==
* 踢出名为player的玩家：<code>/kick player</code>
* 踢出名为player的玩家，原因为“违反服务器规则”：<code>/kick player 违反服务器规则</code>
* {{in|be}}踢出XUID为“123456”的玩家：<code>/kick "123456"</code>
