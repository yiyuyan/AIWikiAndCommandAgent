{{documentation header}}
这个模板用于在[[辅助程序与编辑器]]的子页面中显示一致的表格格式。表格各行应由[[辅助程序与编辑器/entry]]模板生成。由于此模板并非被使用页面的子页面，所以<code>-{}-:程序和编辑器</code>的前缀是必要的。

== 用法 ==
该模板只有1个参数：{{p|1}}，包含了使用{{tl|:辅助程序与编辑器/entry}}的表格内容。

== 示例 ==
<pre style="width: 520px">
{{:辅助程序与编辑器/header|
{{:辅助程序与编辑器/entry
| name = Example 1
| author = Author
| image = Example.png
| platform = {{OS|win|linux|mac}}
| programming language = C++
| version = Latest Version
| date = Version date (no use yet)
| source available = Yes/No, license types
| minecraft version = {{v|1.1}}
| forum = http://www.minecraftforum.net/viewtopic.php?f=25&t=26659
| website = http://google.com
| notes = Description goes here.
}}
}}
</pre>
生成：

{{:辅助程序与编辑器/header|
{{:辅助程序与编辑器/entry
| name = Example 1
| author = Author
| image = Example.png
| platform = {{OS|win|linux|mac}}
| programming language = C++
| version = Latest Version
| date = Version date (no use yet)
| source available = Yes/No, license types
| minecraft version = {{v|1.1}}
| forum = http://www.minecraftforum.net/viewtopic.php?f=25&t=26659
| website = http://google.com
| notes = Description goes here.
}}
}}
