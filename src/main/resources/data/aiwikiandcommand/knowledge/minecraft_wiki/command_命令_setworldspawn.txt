设置[[世界出生点]]。

== 用法 ==
{{in|BE}}此命令只能用于[[主世界]]，不能用于其他[[维度]]。

出生点扩散半径由{{gamerule|respawn_radius|spawnRadius}}控制。

== 语法 ==
* '''Java版'''
: <code>setworldspawn [<pos>] [<rotation>]</code>

* '''基岩版'''
: <code>setworldspawn [spawnPoint: x y z]</code>

== 参数 ==
{{argument|pos|block_pos|spawnPoint: x y z|CommandPositionFloat}}
: 指定[[世界出生点]]坐标。若没有指定，默认为命令执行位置所在的方块位置。
: {{IN|java}}<''x''>或<''z''>应在[-30000000, 30000000)区间内，<''y''>应在[-20000000, 20000000)区间内。
: {{in|be}}大于30,000,000和小于-30,000,000的<''x''>和<''z''>值会分别被设置为30,000,000和-30,000,000，大于319和小于-64的<''y''>值会被分别设置为319和-64。
: {{IN|java}}{{arg desc|je=block_pos}}
: {{IN|bedrock}}{{arg desc|be=CommandPositionFloat}}

{{el|je|short=1}}：{{argument|rotation|rotation}}
: 指定出生时的旋转角，默认为{{cd|0 0}}。
: {{arg desc|je=rotation}}
