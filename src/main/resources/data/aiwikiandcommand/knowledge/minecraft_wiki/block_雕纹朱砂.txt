'''雕纹朱砂（Chiseled Cinnabar）'''是[[朱砂]]制作的装饰性方块，每个面都有类似[[蜘蛛]]的图案。

== 生成 ==
雕纹朱砂不会生成在世界中。

== 获取 ==
=== 合成 ===
{{Crafting
|B2=Cinnabar Slab
|B3=Cinnabar Slab
|Output=Chiseled Cinnabar
|type=Building block
}}

=== 切石 ===
{{stonecutting
|Cinnabar
|Chiseled Cinnabar
}}

== 破坏 ==
挖掘雕纹朱砂的合适工具是镐。雕纹朱砂需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落。

{{Breaking table}}

雕纹朱砂被破坏后会掉落自身。

== 用途 ==
雕纹朱砂目前仅用于装饰。
