'''创造模式物品栏（Creative Inventory）'''是[[创造模式]]的玩家无限获取[[物品]]的基本方式。

== 机制 ==
处于创造模式的玩家按下{{ctrl|物品栏}}键或{{only|be|for=快捷栏最右侧的[[File:Inventory Button.png|20px|class=pixel-image]]}}时，会打开创造模式物品栏。创造模式物品栏中包含了在生存模式能够得到的几乎所有物品，以及一些无法在生存模式中获得的物品，如[[刷怪蛋]]和[[基岩]]。玩家可以从这里获得几乎任何物品，并且可以无限使用。

=== Java版 ===
{{Filetr|Creative Inventory JE.png|缩略图|创造模式物品栏搜索页}}

创造模式物品栏的基本分组方式是'''创造标签页（Creative tab）'''。物品的创造标签页是物品的基本属性之一，且物品可以有任意数量的创造标签页。大多数物品都有一个创造标签页，部分物品有多个，极少数物品如[[知识之书]]没有创造标签页。

对创造模式物品栏中的物品单击鼠标左键可以抓取一个物品，并且抓取该物品的堆叠个数会随着单击该物品次数的增加而增加。对准堆叠物品单击左键和右键会分别抓取单个物品和一组物品，这时鼠标单击其他物品将会对鼠标单击的物品和开头抓取的物品进行位置交换。右键单击一组物品也将只抓取一个物品，但第二次右击时将会把那个物品放下，而不是拾起更多。按住{{Keys|Shift}}单击物品可抓取一组物品。在将鼠标悬停在某个物品上方时按下数字键，则会立即将鼠标悬停的整堆物品放入与该数字相对应的准备栏中。

将物品放入创造模式物品栏会摧毁这一堆叠的物品，包括直接点击物品将其拖入或按住{{key|Shift}}点击物品堆叠。

==== 搜索物品 ====
创造模式物品栏的右上角有一个搜索页，在搜索页以外的创造标签页按下{{key|T}}可以切换到搜索页。在右上角输入栏中直接输入物品在当前语言中的名称或其[[物品提示框]]中可能出现的文字即可搜索到此物品。输入栏为空时，所有物品都会在此显示。除此以外，输入<code>-{}-<''命名空间''>:<''物品ID''></code>能以英文ID搜索指定命名空间下的物品，命名空间可省略，但“:”不可省略；输入<code>-{}-#<''物品标签的命名空间ID''></code>会呈现这个[[Java版标签/物品|物品标签]]内的所有物品，命名空间也可省略。

搜索物品提示框时，物品栏会忽略由{{cd|d=pretty|base_attack_damage|base_attack_speed}}[[属性修饰符]]带来的特殊属性文本，而直接匹配常规ID下的原文。如搜索“5”时会显示下界合金镐（6 攻击伤害），因为非特殊属性修饰符会将其显示为“+5 攻击伤害”；搜索“+”或“-”时，所有的剑、镐、斧、锹、锄、重锤、三叉戟都会显示，即使它们的提示框中不包含“+”、“-”字符。

==== 已保存的快捷栏 ====
创造模式物品栏中有'''已保存的快捷栏'''。在创造模式中按下{{key|C}}+{{key|1-9}}会将当前的快捷栏保存至“{{tp|itemGroup.hotbar}}”选项卡中，并且可通过按下{{key|X}}+{{key|1-9}}加载。

已存储的快捷栏存储在客户端的{{filename|[[hotbar.nbt]]}}文件中，因此可以用于在不同世界之间复制物品。

==== 物品销毁 ====
在创造模式物品栏的“生存模式物品栏”一栏右下角有一个打叉的红色格子。将物品放入其中会摧毁这个堆叠的物品。按住{{key|Shift}}时点击该格子会清除物品栏中的所有物品。

=== 基岩版 ===
创造模式物品栏的基本分组方式是'''创造分类（Creative category）'''。物品的创造分类是物品的基本属性之一，物品只能有一个创造分类。大多数物品都有一个创造分类，少数物品如[[命令方块]]和[[结构方块]]没有创造分类。

创造模式物品栏共有5个标签页：4个创造分类标签页（“[[File:BE icon recipe construction.png|20px|class=pixel-image]]建筑”、“[[File:BE icon recipe equipment.png|20px|class=pixel-image]]{{tr|装备|用品}}”、“[[File:BE icon recipe item.png|20px|class=pixel-image]]物品”和“[[File:BE icon recipe nature.png|20px|class=pixel-image]]自然”）和1个“[[File:BE icon recipe all.png|20px|class=pixel-image]]全部”标签页。创造分类标签页会显示所有对应分类的物品，“全部”标签页则会显示所有物品，同时在顶部提供一个搜索栏。

玩家处于[[创造模式]]时，创造模式物品栏会代替[[配方书#基岩版|配方书]]出现。

; {{tr|经典UI|傳統UI}}
[[File:Creative Inventory BE (Classic).png|缩略图|{{tr|经典UI|傳統UI}}下的“全部”标签页]]
: 4个创造分类标签页可在左上方切换，从左到右排序，“全部”标签页显示在顶部靠近中间的位置。
: 在右上角可切换[[File:BE Fullscreen icon.png|30px|class=pixel-image]]全屏显示创造分类界面、[[File:BE Recipe Book and Inventory icon.png|35px|class=pixel-image]]显示创造分类界面和生存模式物品栏或[[File:BE Inventory icon.png|20px|class=pixel-image]]仅显示生存模式物品栏。生存模式物品栏中有一个2&times;2的[[合成方格]]。

; {{tr|携带版UI|Pocket UI}}
[[File:Creative Inventory BE (Pocket).png|缩略图|{{tr|携带版UI|Pocket UI}}下的“全部”标签页]]
: 全部5个标签页可在左侧切换，从上到下排序，“全部”标签页显示在最顶部。点击左下角的[[File:BE Inventory Tab icon.png|20px|class=pixel-image]]会显示玩家的[[物品栏]]。
: 点击右侧的[[File:BE Crafting Tab icon.png|20px|class=pixel-image]]或[[File:BE Armor Tab icon.png|20px|class=pixel-image]]可切换在屏幕右侧显示[[合成方格]]或[[物品栏#携带版UI|盔甲菜单]]，或点击[[File:BE Fullscreen Tab icon.png|20px|class=pixel-image]]隐藏这两个界面以全屏显示屏幕左侧的内容。

对创造标签页内的物品按下左键、{{tooltip|minetip=1|{{tr|拿起|撿起}}|默认为手柄右侧的上键。}}键或点击时会拿起一组对应物品，按下右键或{{tooltip|minetip=1|{{tr|获取一个|拿起一項}}|默认为手柄右侧的下键。}}键时则只会拿起一个物品。
* 使用键盘和鼠标时，对物品按下{{key|shift}}+左键/右键时，会将一组该物品移至快捷栏中最靠左的空格子或物品相同但数量不满一组的格子内（不满一组的格子优先），若快捷栏已满，则物品会进入物品栏。
* 使用手柄时，按下{{tooltip|minetip=1|{{tr|拿起|撿起}}|默认为手柄右侧的上键。}}和{{tooltip|minetip=1|{{tr|获取一个|拿起一項}}|默认为手柄右侧的下键。}}键时，会将该物品移至快捷栏中最靠左的空格子或物品相同但数量不满一组的格子内（不满一组的格子优先），同时手柄光标将留在原地。若没有可用的空格子或移动物品后有剩余物品时，则手柄光标会自动移至快捷栏最左侧的格子上，以方便玩家进行其他操作。

除“全部”外的标签页里会有一些相似的物品被集合起来，成为物品组。物品组可以通过按下带“+”符号的物品打开，通过按下“-”折叠。

将物品移入创造模式物品栏，或在全屏显示创造模式物品栏时对快捷栏中的物品按下{{key|Shift}}+左键/右键、{{tooltip|minetip=1|{{tr|摧毁|移除}}|默认为手柄右侧的上键。}}键或双击会摧毁这一物品。
