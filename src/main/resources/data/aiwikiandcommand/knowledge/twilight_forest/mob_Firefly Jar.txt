The Firefly Jar is a glass jar with a firefly inside which produces light when placed. It can be crafted by combining a Firefly and a Glass Bottle in a crafting bench. Great for decoration. Firefly Jars can be seen decorating Firefly Forests, dangling from trees.

By crouching and right-clicking this Jar, you can set the Firefly free, providing you both a Firefly and a Glass Bottle.
