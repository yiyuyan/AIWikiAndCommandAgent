A gloomy addition to the cloud family, the Rainy Cloud acts as an infinite downpour, drenching the blocks below it. This helps with watering crops, hurting Endermen, increasing fishing rate, all without the need of active rain! While it is not able to be found anywhere naturally, it can be crafted with the naturally found Fluffy Clouds up in the skies of the Highlands.
