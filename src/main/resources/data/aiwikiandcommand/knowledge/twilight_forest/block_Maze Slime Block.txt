Maze Slime Block is a block crafted from Maze Slimeballs. It functions similarly to Slime Block, allowing the player to bounce up if they land on the block from a great height.

As a Redstone component, Maze Slime Blocks can be used with a piston, only sticking to other Mazestone blocks.
