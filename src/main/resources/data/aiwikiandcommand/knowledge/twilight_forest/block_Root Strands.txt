Root Strands are prolific foliage that grow in caverns and dark places in the Twilight Forest. Though they appear mostly decorative, Root Strands that are sturdy enough to be climbable like Ladders and Vines. If Bone Meal is used on Root Strands, it can grow if below the block is free. Bone Meal can be applied anywhere on the Root Strands and will always grow from the bottom-most block. Root Strands can be harvested with Shears, or it can be broken with any tool and will drop 1-3 Stick instead. Root Strands can only be placed below certain blocks such as Dirt or Roots.

Placing a Root Strand into a Composter will have a 30% chance to raise the compost level by 1.
