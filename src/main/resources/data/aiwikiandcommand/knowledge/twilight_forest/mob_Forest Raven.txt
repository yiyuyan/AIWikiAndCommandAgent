The Forest Raven is a flying passive mob. It looks a lot like the Tiny Birds, but has a lot more health. Forest Ravens rarely appear around the Twilight Forest, but they seem to be more abundant around Obsidian Monoliths. The only way to get a Raven Feather, used to create a Magic Map Focus, is by slaying one of these animals.
