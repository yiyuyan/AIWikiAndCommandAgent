Wispy Cloud is a blocks found supporting the Cloud Cottage in the sky. This type of cloud is translucent and allows for light to pass through, similar to Glass. Much like Glass, it will require Silk Touch to obtain this fraile cloud. These clouds are so thin that any weather that hits it will fall right through. This also means that lava will burn right through any Wispy Cloud in it's way, so be careful!
