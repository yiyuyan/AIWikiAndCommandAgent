Minewood Core is a core that grows in a Miner's Tree. This core looks like a Minewood Log, except for a gray jewel shape in the middle. When right-clicked, the core will change to display a green jewel, as well as emitting a random warping sound.

When in the active state, certain blocks may begin to react. Like an Ore Magnet, a Minewood Core will begin to pull up ores from around it, excluding any Coal ores. This action will only happen if the blocks surrounding the ore can be replaced, allowing for the ores to magnetize to the core. This affects any block within a 16-block radius from the core.

Minewood Core cannot be harvested and will only drop a Minewood Log when broken. As such, caution must be taken to prevent the Minewood Core from breaking.
