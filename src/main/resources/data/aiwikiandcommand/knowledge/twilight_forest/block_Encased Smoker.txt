Encased Smoker is a decorative device with a similar function to Smokers. Where a Smoker constantly emits smoke, an Encased Smoker will only emit smoke with an active Redstone signal. Aside from this, Encased Smoker still remains a mostly decorative block. This block can only be harvested with an Axe.
