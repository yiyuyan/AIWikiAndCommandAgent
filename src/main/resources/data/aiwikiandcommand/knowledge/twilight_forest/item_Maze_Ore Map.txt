If a Maze Map can see through walls, what if it could see right through the stones around you to reveal all the treasures within? Well, if you perform a little upgrade, it can. It's expensive, but will almost certainly pay for itself quickly. A Ore Map is an item that can see through walls and detect ores within the layers above or below the Map's layer, displaying each ore in their respective colors. The Ore Map, when crafted, will be blank, so the user must use it to display the map. A little trick one can do with these maps is to create it on a layer where rare ores generate and then navigate on land to generate a view of what is beneath them.

All Ores found by this map will display their respective color on the Map, however Ores added by other mods will only display as pink.

## Obtaining
There is no real way to obtain the Ore Map without a bit of grind, requiring three different resource blocks to make it, as well as a Maze Map.
