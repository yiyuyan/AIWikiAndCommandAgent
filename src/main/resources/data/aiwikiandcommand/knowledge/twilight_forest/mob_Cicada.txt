The Cicada is a critter block commonly found on Twilight Oak Trees. When Cicadas emit sound, they create a green-colored musical note sprites identical to those created by a Note Block. It can be worn in the helmet slot, though it offers no additional protection. Cicadas can also be used to craft a Cicada Jar.

When broken, the Cicada will drop itself. However, when shot with an Arrow or crushed with an Anvil, it will drop Dye.
