Greater Potion Flask is an item that can store multiple doses of a single Potion. It can be found as rare loot in the Lich Tower.

The Greater Potion Flask can be filled by right-clicking the item with a Potion. Once filled, the Greater Potion Flask can only be filled with more doses of the same Potion. Unlike the Brittle Potion Flask, a Greater Potion Flask will not break when a dose is consumed. It has no durability and can be used many times. When it has been emptied, the Greater Potion Flask can be filled with any Potion again.
